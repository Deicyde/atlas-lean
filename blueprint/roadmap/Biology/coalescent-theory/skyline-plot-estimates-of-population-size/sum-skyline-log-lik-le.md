# The skyline estimates jointly maximize the likelihood

**The skyline estimates jointly maximize the likelihood**: for positive `c i`, `w i`,
`θ i` over a finite set of intervals, `∑ ℓ_i(θ_i) ≤ ∑ ℓ_i(c_i w_i)`.
