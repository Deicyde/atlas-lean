# Hill–Robertson / Ohta–Kimura, first row

**Hill–Robertson / Ohta–Kimura, first row.** On the simplex,
`L D² = -(3 + ρ + 8ν) D² + D (1 - 2p)(1 - 2q) + p (1 - p) q (1 - q)` (for all real `ρ`, `ν`).
