# Achaz's unbiasedness

**Achaz's unbiasedness** (Achaz 2009): if `E ξ_i = θ / i` for `1 ≤ i ≤ n - 1` (the
constant-size spectrum, `SiteFrequencySpectrum.integral_sfs`), every weighted estimator with
`∑_i ω_i = 1` has mean `θ`.
