# Kingman's formula

**Kingman's formula**: the probability `(n - k)! k! (k - 1)! ∏_{B ∈ π} |B|! / (n! (n - 1)!)`
of a partition `π` with `k` blocks of a sample of size `n` (meaningful for `1 ≤ k ≤ n`; for
the empty sample it gives `1` to the empty partition).
