# Slatkin's `F_ST` for the finite island model (Slatkin 1991)

**Slatkin's `F_ST` for the finite island model (Slatkin 1991).** For `d ≥ 2` demes and
`M = 4Nm > 0`, `F_ST = 1 / (1 + M d² / (d - 1)²)`.
