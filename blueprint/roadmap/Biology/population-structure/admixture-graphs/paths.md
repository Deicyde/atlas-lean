# Root-ward paths from a node of an admixture graph

**Root-ward paths from a node of an admixture graph.** The root-ward paths from `X`: the lists `[X = v₀, v₁, …, v_k = root]` with each `vᵢ₊₁` a
parent of `vᵢ`.
