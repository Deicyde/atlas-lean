# The FRAPPE update maximizes `Q(· | θ)`

**The FRAPPE update maximizes `Q(· | θ)`**: no parameter `θ'` in the strictly
positive parameter set has a larger `Q(θ' | θ)` than the closed-form update `emStep g hg θ`.
