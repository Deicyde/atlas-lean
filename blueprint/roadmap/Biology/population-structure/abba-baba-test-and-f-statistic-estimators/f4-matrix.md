# qpWave matrix of f4-statistics

**qpWave matrix of f4-statistics.** The qpWave matrix of left populations `L 0, …, L n` and right populations
`R 0, …, R r`: entry `(i, j)` is `f4 (L (i + 1)) (L 0) (R (j + 1)) (R 0)`.
