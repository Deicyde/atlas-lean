# Number of nonsynonymous sites per codon

**Number of nonsynonymous sites per codon.** The number of **nonsynonymous sites** per codon, counted under `ω = 1`:
`N = 3 ρ_N(1) / (ρ_S(1) + ρ_N(1))`.
