# Neighbor-joining Q-criterion

**Neighbor-joining Q-criterion.** The Studier–Keppler form of the neighbor-joining criterion on the cluster set `S`:
`Q(a, b) = (|S| - 2) D a b - ∑_{c ∈ S} D a c - ∑_{c ∈ S} D b c`.
