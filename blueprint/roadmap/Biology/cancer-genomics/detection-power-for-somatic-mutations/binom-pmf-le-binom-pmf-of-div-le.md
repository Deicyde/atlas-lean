# The binomial likelihood is unimodal in `p`, decreasing part

**The binomial likelihood is unimodal in `p`, decreasing part**: for `a ≤ n` and
`a / n ≤ p ≤ p' ≤ 1`, `Binom(a | n, p') ≤ Binom(a | n, p)`.
