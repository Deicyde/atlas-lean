# The binomial likelihood is unimodal in `p`, increasing part

**The binomial likelihood is unimodal in `p`, increasing part**: for `a ≤ n` and
`0 ≤ p ≤ p' ≤ a / n`, `Binom(a | n, p) ≤ Binom(a | n, p')`.
