# Rescaled purity lies in (0, 1)

**Rescaled purity lies in [0, 1].** The rescaled purity is again a purity: `0 ≤ α / (m - (m - 1) α) ≤ 1` for `m > 0` and
`0 ≤ α ≤ 1`.
