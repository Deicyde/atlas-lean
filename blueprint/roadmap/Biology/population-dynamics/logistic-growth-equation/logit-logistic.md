# Log-odds grow linearly

**Log-odds grow linearly** for a frequency (`K = 1`): for `0 < x₀ < 1` and all `r`, `t`,
`log (x(t) / (1 - x(t))) = log (x₀ / (1 - x₀)) + r t`.
