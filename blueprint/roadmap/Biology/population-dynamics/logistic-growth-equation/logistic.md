# Explicit solution of the logistic equation

**Explicit solution of the logistic equation.** Explicit solution of the logistic equation `x' = r x (1 - x / K)` with `x 0 = x₀`:
`K x₀ e^{r t} / (K + x₀ (e^{r t} - 1))`.
