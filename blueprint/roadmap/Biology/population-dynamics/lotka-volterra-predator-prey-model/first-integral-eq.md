# Positive solutions lie on level curves

**Positive solutions lie on level curves.** If `(x, y)` solves the Lotka–Volterra system
on `[0, ∞)` and both populations stay positive there, then `V(x t, y t) = V(x 0, y 0)` for
all `t ≥ 0`.
