# Steady-state exponential morphogen profile

**Steady-state exponential morphogen profile.** The steady-state gradient `c(x) = (j / √(D k)) e^{-x/λ}`, `λ = √(D / k)`, for source flux
`j` at `x = 0`. Meaningful for `D, k > 0`.
