# No traveling wave with `c² < 4 r D`

**No traveling wave with `c² < 4 r D`**: if `D, r > 0` and `c² < 4 r D`, a wave profile
tending to `0` at `+∞` is not eventually positive. (This excludes `|c| < 2 √(r D)`, not
`c < 2 √(r D)` for negative `c`.)
