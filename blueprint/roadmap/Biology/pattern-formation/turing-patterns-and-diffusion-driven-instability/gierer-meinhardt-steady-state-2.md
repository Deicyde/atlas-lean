# Gierer–Meinhardt steady state is an equilibrium

**Gierer–Meinhardt steady state is an equilibrium.** `((a + 1) / b, ((a + 1) / b)²)` is a steady state of the Gierer–Meinhardt kinetics when
`a + 1 ≠ 0` and `b ≠ 0`.
