# Finite domain

**Finite domain.** On `[0, L]` with Neumann boundary conditions, if `tr J < 0` and
`d_u, d_v > 0`, mode `n` is unstable iff `k_n² = (n π / L)²` lies in the unstable band
`(q₋, q₊)` (which requires a positive discriminant).
