# Turing's criterion

**Turing's criterion.** If the steady state is stable without diffusion
(`tr J < 0`, `0 < det J`) and `d_u, d_v > 0`, some Fourier mode is unstable iff
`d_v f_u + d_u g_v > 2 √(d_u d_v det J)`.
