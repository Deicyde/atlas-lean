# Steady state of the Gierer–Meinhardt kinetics

**Steady state of the Gierer–Meinhardt kinetics.** The homogeneous steady state `(u₀, v₀) = ((a + 1) / b, ((a + 1) / b)²)` of the
Gierer–Meinhardt kinetics (meaningful for `b ≠ 0`, `a + 1 ≠ 0`).
