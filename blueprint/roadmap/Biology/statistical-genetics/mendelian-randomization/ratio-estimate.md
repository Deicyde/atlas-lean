# Ratio estimate of a single SNP

**Ratio estimate of a single SNP.** The ratio estimate `β̂_{Yj} / β̂_{Xj}` of SNP `j` (Lean's `x / 0 = 0` gives `0` when
`β̂_{Xj} = 0`; such SNPs carry weight `0` in `ivwWeight`).
