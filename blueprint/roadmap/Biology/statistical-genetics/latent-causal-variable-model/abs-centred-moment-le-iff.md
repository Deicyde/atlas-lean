# The centred moments order `q₁²` and `q₂²`

**The centred moments order `q₁²` and `q₂²`**: if `κ_π ≠ 0` and `ρ_g = q₁ q₂ ≠ 0`, then
`|E(α₁ α₂³) - 3 ρ_g| ≤ |E(α₁³ α₂) - 3 ρ_g|` iff `q₂² ≤ q₁²`.
