# Sherman–Morrison applied to the candidate marker

**Sherman–Morrison applied to the candidate marker**: for positive definite `V₀` and
`c ≥ 0`, `(V₀ + c x xᵀ)⁻¹ x = (1 + c xᵀ V₀⁻¹ x)⁻¹ • V₀⁻¹ x`.
