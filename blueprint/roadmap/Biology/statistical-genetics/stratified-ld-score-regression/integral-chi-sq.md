# Expected statistic with per-marker variances

**Expected statistic with per-marker variances**, for an arbitrary genotype matrix:
`𝔼[χ² j] = N ∑_k r_jk² σ²_k + σ²_e (∑_i X_ij²) / N`. (For `N = 0` both sides are `0`.)
