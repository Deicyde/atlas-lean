# Excess error of a linear imputation

**Excess error of a linear imputation**: if `Σ_oo w = Σ_ot`, then for any weights `w'`,
`𝔼 (z_t - w'ᵀ z_o)² = 𝔼 (z_t - wᵀ z_o)² + (w' - w)ᵀ Σ_oo (w' - w)`.
