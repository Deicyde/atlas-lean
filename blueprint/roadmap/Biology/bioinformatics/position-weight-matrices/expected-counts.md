# Expected letter counts in motif columns

**Expected letter counts in motif columns.** The expected count of letter `b` in motif column `i` under the posteriors at `θ`:
`∑ₘ ∑_z P(z | xₘ, θ) [start z = some j ∧ xₘ (j + i) = b]`.
