# Omnitig

**Omnitig.** Omnitig (Tomescu–Medvedev, Definition 5): for all `1 ≤ i ≤ j ≤ t` (`t + 1 = w.length`),
no path from `v_j = src e_j` to `v_i = src e_i` has first edge `≠ e_j` and last edge
`≠ e_{i-1}`.
