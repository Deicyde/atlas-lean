# One-locus phantom heritability, unconditional

**One-locus phantom heritability, unconditional**: with monozygotic twins
(`k₂ = 1`), dizygotic twins (`k = (1/4, 1/2, 1/4)`) and a common environment `C`,
`2 (Cov_MZ - Cov_DZ) = V_A + (3/2) V_D`.
