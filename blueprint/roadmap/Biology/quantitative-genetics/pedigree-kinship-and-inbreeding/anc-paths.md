# Ancestral paths from an individual

**Ancestral paths from an individual.** The ancestral paths from `i`: the lists `[i = v₀, v₁, …, v_k]` with each `v_{t+1}` a parent
of `v_t` (`k ≥ 0`; the path `[i]` has no edge).
