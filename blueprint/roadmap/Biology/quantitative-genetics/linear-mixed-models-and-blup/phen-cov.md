# Phenotypic covariance of a linear mixed model

**Phenotypic covariance of a linear mixed model.** The phenotypic covariance `V = Z G Zᵀ + R` of the linear mixed model
`y = X b + Z u + e` with `Cov u = G`, `Cov e = R`.
