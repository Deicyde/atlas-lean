# Threshold theorem (Kermack–McKendrick 1927)

**Threshold theorem (Kermack–McKendrick 1927).** If initially `I(0) > 0`, with `γ > 0` and
`N > 0`, the number of infectives initially increases, `I'(0) > 0`, iff
`R₀ S(0) / N > 1` with `R₀ = β / γ`.
