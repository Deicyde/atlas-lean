# Convex order

**Convex order**: `g₁ ≤cx g₂` if `∫ φ dg₁ ≤ ∫ φ dg₂` for every convex `φ : ℝ → ℝ` that is
integrable under both laws (Shaked–Shanthikumar 2007, §3.A).
