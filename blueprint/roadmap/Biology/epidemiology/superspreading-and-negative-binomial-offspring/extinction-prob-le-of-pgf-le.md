# Comparison principle for Galton–Watson extinction

**Comparison principle for Galton–Watson extinction**: if the offspring generating
functions satisfy `f₂ ≤ f₁` on `[0, 1]`, then the extinction probabilities satisfy
`q₂ ≤ q₁`.
