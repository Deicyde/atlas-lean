# Monotonicity in the dispersion

**Monotonicity in the dispersion**: for `R ≥ 0`, `s ∈ [0, 1]` and `0 < k₁ ≤ k₂`,
`G_{k₂}(s) ≤ G_{k₁}(s)`; equivalently `k ↦ k log (1 + x / k)` is nondecreasing for `x ≥ 0`.
