# Solution of the Michaelis–Menten mass-action system

**Solution of the Michaelis–Menten mass-action system.** A solution of the Michaelis–Menten mass-action system on `[0, ∞)`:
`s' = -k₁ e s + kb c`, `c' = k₁ e s - (kb + k₂) c`, `e' = -c'`, `p' = k₂ c`.
