# The Goldbeter–Koshland function is a steady state

**The Goldbeter–Koshland function is a steady state** (Goldbeter–Koshland 1981, Eq. 7):
for `v, K₁, K₂ > 0`, `rateRatio K₁ K₂ (goldbeterKoshland v K₁ K₂) = v`.
