# Hill response coefficient

**Hill response coefficient** (Goldbeter–Koshland 1981, Eq. 11). For a Hill response with
`n > 0` and `K > 0`, if `S₉, S₁ > 0` give 90% and 10% response, then
`S₉ / S₁ = 81 ^ (1 / n)`.
