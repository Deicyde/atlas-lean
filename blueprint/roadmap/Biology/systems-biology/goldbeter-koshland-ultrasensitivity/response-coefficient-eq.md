# The response coefficient

**The response coefficient** (Goldbeter–Koshland 1981, Eq. 10): for `K₁, K₂ > -0.1`,
`R_v = 81 (K₁ + 0.1)(K₂ + 0.1) / ((K₁ + 0.9)(K₂ + 0.9))`.
