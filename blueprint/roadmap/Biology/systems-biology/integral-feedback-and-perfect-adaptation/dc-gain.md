# Steady-state (DC) gain of a linear system

**Steady-state (DC) gain of a linear system.** The steady-state (DC) gain `d - c ⬝ A⁻¹ b`; for nonsingular `A` the output at the
equilibrium for input `u` is `dcGain * u`.
