# Interaction graph of a Boolean network

**Interaction graph of a Boolean network.** In the interaction graph of `f : {0,1}ⁿ → {0,1}ⁿ` there is an edge `j → i` when the
`i`-th coordinate of `f` depends on the `j`-th variable.
