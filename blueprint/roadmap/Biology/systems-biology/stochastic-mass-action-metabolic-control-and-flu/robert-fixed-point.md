# Robert's theorem

**Robert's theorem** (Robert 1980): if the interaction graph of `f : {0,1}ⁿ → {0,1}ⁿ`
is acyclic, `f` has a unique fixed point `p`, and every synchronous trajectory reaches it
within `n` steps.
