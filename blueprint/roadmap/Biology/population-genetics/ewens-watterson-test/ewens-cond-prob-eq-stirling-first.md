# The Ewens–Watterson conditional law

**The Ewens–Watterson conditional law** (Ewens 1972; Watterson 1978): for `θ > 0`,
`P(π | K = K(π)) = w(π) / |s(n, K(π))| = n! / (|s(n, k)| ∏ j, j ^ (a j) (a j)!)`.
