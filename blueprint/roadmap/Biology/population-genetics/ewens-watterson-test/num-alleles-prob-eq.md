# Law of the number of alleles

**Law of the number of alleles** (Ewens 1972):
`P_θ(K = k) = |s(n, k)| θ ^ k / θ^{(n)}`. As an identity between the defining sums it holds
for every real `θ`; it is a probability for `θ > 0`.
