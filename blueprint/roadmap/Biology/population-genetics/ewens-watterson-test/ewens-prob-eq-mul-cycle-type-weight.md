# Factorization of the Ewens sampling formula

**Factorization of the Ewens sampling formula** (Ewens 1972):
`P_θ(π) = θ ^ K(π) / θ^{(n)} * w(π)`, with `K(π) = π.parts.card` the number of alleles.
