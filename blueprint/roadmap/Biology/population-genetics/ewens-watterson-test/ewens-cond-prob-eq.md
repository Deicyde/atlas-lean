# `K` is sufficient for `θ`

**`K` is sufficient for `θ`** (Ewens 1972): for `θ > 0`, the conditional law of the
allelic partition given the number of alleles is `w(π) / ∑_{K(π') = K(π)} w(π')`, which does
not depend on `θ`.
