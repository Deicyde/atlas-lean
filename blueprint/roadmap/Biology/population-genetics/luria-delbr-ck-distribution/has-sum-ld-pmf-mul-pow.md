# Lea–Coulson generating function

**Lea–Coulson generating function**: for `m ≥ 0` and `0 < z < 1`,
`∑ₙ pₙ zⁿ = exp (m (h(z) - 1)) = exp (m (1 / z - 1) log (1 - z))`.
