# Power form of the Lea–Coulson generating function

**Power form of the Lea–Coulson generating function.** The Lea–Coulson generating function in power form:
`exp (m (1 / z - 1) log (1 - z)) = (1 - z)^{m (1 - z) / z}` for `z < 1`, `z ≠ 0`.
