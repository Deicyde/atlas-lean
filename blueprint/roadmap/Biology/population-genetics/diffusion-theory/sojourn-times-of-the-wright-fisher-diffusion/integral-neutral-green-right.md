# Sojourn integral vanishes for a fixed allele

**Sojourn integral vanishes for a fixed allele.** Boundary value at `1`: a fixed allele spends no time in `(0, 1)`, so
`∫ x in 0..1, G(1, x) g(x) = 0`.
