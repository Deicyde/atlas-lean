# Maruyama effect, above the current frequency

**Maruyama effect, above the current frequency.** For `σ ≠ 0` and `0 < x < z < 1`,
`Ψ₂(z)` is strictly below its neutral value `2 x (1 - z) / ((1 - x) z)`.
