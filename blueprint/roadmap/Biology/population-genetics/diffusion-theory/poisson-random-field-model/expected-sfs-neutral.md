# Neutral site-frequency spectrum (Fu 1995)

**Neutral site-frequency spectrum (Fu 1995).** With `σ = 0`, for the segregating classes
`1 ≤ i < n` the expected number of sites with `i` derived copies in a sample of `n` is
`θ / i`.
