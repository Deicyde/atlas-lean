# Kimura–Crow limit

**Kimura–Crow limit**: with `M = 2N` gene copies and mutation probability `u = θ/(4N)`
(so that `θ = 4Nu`), the equilibrium homozygosity tends to `1/(1 + θ)` as `N → ∞`.
