# Syndrome

**Syndrome.** Let $F$ be a field, $\iota$ a finite set and $\rho$ a set. For a matrix
$H \in F^{\rho \times \iota}$ (a parity-check matrix) and a word $y \in F^\iota$, the syndrome of
$y$ is the vector $Hy \in F^\rho$.
