# Dual of the code with a given parity-check matrix

**Dual of the code with a given parity-check matrix.** Let $H$ be a matrix over a field $F$ with
finitely many rows and finitely many columns. Then the dual of the code with parity-check matrix
$H$ (the words $x$ with $Hx = 0$) is the code generated by $H$ (the span of its rows).
