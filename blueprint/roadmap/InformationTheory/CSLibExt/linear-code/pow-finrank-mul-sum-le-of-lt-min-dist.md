# Pow finrank mul sum le of lt min Dist

The **Hamming bound** for linear codes correcting `t` errors,
`q ^ dim C · Σ_{i ≤ t} (n choose i) (q - 1)^i ≤ q ^ n`, from MathlibExt's sphere-packing bound.
