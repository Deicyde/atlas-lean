# Dimension of the dual code

**Dimension of the dual code.** Let $F$ be a field and $\iota$ a finite set. For every linear
code $C \subseteq F^\iota$, $\dim C + \dim C^\perp = |\iota|$, where $C^\perp$ is the dual code.
