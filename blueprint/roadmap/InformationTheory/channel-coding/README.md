# Channel coding

Reliable transmission over noisy channels. For a discrete memoryless channel $W$, Shannon's noisy-channel coding theorem identifies the largest rate of reliable communication with the capacity $C = \max_{P_X} I(X; Y)$: rates below $C$ are achievable with vanishing error probability, Fano's inequality gives the weak converse, and the strong converse shows that above $C$ the error probability tends to one.
