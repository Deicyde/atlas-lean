# Definition 2.6.1

Let $\mathcal{C}$ be a multitensor category with enough projective objects. A module category $\mathcal{M}$ over $\mathcal{C}$ is called exact if for any projective object $P \in \mathcal{C}$ and any object $M \in \mathcal{M}$ the object $P \otimes M$ is projective in $\mathcal{M}$.
