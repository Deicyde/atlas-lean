# Proposition 1.11.3

Let $X$ be an invertible object in a rigid monoidal category $\mathcal{C}$. Then (i) ${}^{*}X \cong X^{*}$ and $X^{*}$ is invertible; (ii) if $Y$ is another invertible object then $X \otimes Y$ is invertible.
