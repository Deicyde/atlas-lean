# Definition 1.11.1

An object $X$ in a rigid monoidal category $\mathcal{C}$ is invertible if $\mathrm{ev}_{X}: X^{*} \otimes X \rightarrow \mathbf{1}$ and $\operatorname{coev}_{X}: \mathbf{1} \rightarrow X \otimes X^{*}$ are isomorphisms.
