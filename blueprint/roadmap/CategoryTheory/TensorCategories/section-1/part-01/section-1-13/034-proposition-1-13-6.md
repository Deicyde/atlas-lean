# Proposition 1.13.6

Let $P$ be a projective object in a multiring category $\mathcal{C}$. If $X \in \mathcal{C}$ has a right dual, then the object $P \otimes X$ is projective. Similarly, if $X \in \mathcal{C}$ has a left dual, then the object $X \otimes P$ is projective.
