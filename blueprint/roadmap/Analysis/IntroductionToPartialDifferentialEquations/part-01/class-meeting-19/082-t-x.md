# Proposition 2.0.1 (Calculation of the Fundamental Solution $K(t,x)$ for Schrödinger's equation)

Let $\phi(x)$ be a smooth compactly supported function, and let $\psi(t,x)$ be the function whose spatial Fourier transform is defined as $\hat{\psi}(t,\xi) = \hat{K}(t,\xi)\hat{\phi}(\xi)$ where $\hat{K}(t,\xi) = e^{-2\pi^{2}it|\xi|^{2}}$. Then if $t>0$, we have that $\psi(t,x) = (K(t,\cdot)*\phi)(x) \coloneqq \int_{\mathbb{R}^{n}} K(t,y)\phi(x-y)d^{n}y = \int_{\mathbb{R}^{n}} K(t,x-y)\phi(y)d^{n}y$ where $K(t,x) = \frac{1}{(2\pi it)^{n/2}} e^{i\frac{|x|^{2}}{2t}}$. Above, $i^{1/2} = e^{i\pi/4} = \frac{1}{\sqrt{2}}(1+i)$.
