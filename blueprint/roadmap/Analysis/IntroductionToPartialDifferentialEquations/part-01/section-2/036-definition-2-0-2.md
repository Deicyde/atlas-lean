# Definition 2.0.2 [2]

Let $\Omega \subset \mathbb{R}^{n}$ be a domain. A Green function in $\Omega$ is defined to be a function of $(x, y) \in \Omega \times \Omega$ verifying the following conditions for each fixed $x \in \Omega$: $\Delta_{y} G(x, y) = \delta(x)$, $y \in \Omega$, and $G(x, \sigma) = 0$, $\sigma \in \partial \Omega$.
