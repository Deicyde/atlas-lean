# Proposition 1.0.1 (Connection between transport equations and ODEs)

If $u$ solves the transport equation (1.0.1), then $u$ is constant along the integral curves of $X$. More precisely, if $\gamma(s)$ is any solution to (1.0.2), then $\frac{d}{ds} u(\gamma^{0}(s), \cdots, \gamma^{n}(s))=0$.
