# Zero-mean $H^2$ functions

**Zero-mean $H^2$ functions.** A continuous function
$u : (\mathbb{R}/2\pi\mathbb{Z})^2 \to \mathbb{R}$ is a zero-mean $H^2$ function when it is in
$H^2$ and its mean is $0$.
