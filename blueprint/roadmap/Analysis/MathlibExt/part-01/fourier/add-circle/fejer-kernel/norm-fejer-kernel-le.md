# Norm fejer Kernel le

Pointwise bound `‖K_N(x)‖ ≤ N + 1`, obtained from the triangle inequality applied
to the iterated Dirichlet sum together with `∑_{k=0}^{N}(2k+1) = (N+1)²`.
