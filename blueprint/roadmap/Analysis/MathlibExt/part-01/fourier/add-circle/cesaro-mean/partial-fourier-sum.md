# Partial Fourier Sum

The `N`-th partial Fourier sum of a function `f : AddCircle T → ℂ`, defined as
`S_N f(x) = ∑_{n = -N}^{N} ĉ_n(f) · fourier n x`, where `ĉ_n(f) = fourierCoeff f n`.
