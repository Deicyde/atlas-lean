# Boolean cube

**Boolean cube.** For $n \in \mathbb{N}$, the Boolean cube of dimension $n$ is the set of
functions $x : \{0, \dots, n-1\} \to \{\mathrm{true}, \mathrm{false}\}$. It represents
$\{-1, 1\}^n$, with true standing for $1$ and false for $-1$.
