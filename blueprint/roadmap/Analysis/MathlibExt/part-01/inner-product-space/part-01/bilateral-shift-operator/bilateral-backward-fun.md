# Bilateral backward shift of a sequence

**Bilateral backward shift of a sequence.** For a function $x : \mathbb{Z} \to K$ with values
in any set $K$, the bilateral backward shift of $x$ is the function $Bx : \mathbb{Z} \to K$
given by $(Bx)(n) = x(n + 1)$.
