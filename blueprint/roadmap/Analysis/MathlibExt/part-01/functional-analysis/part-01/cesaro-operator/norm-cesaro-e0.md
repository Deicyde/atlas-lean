# The first basis vector is a unit vector

**The first basis vector is a unit vector.** Let $\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$.
The first standard basis vector $e_0 = (1, 0, 0, \dots)$ of $\ell^2(\mathbb{N}, \mathbb{K})$
has norm $\|e_0\| = 1$.
