# Continuous functions on the unit interval

**Continuous functions on the unit interval.** $C([0, 1], \mathbb{R})$ denotes the space of
bounded continuous functions $[0, 1] \to \mathbb{R}$, with the supremum norm
$\|f\| = \sup_{x \in [0, 1]} |f(x)|$.
