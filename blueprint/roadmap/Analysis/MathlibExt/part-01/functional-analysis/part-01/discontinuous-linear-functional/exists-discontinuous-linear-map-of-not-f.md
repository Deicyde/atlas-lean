# A discontinuous linear functional on an infinite-dimensional normed space

**A discontinuous linear functional on an infinite-dimensional normed space.**
If `E` is not finite-dimensional over `𝕜 = ℝ, ℂ`, then there exists a linear
functional `f : E →ₗ[𝕜] 𝕜` that is not continuous.
