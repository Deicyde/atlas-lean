# Multiplication by a constant function

**Multiplication by a constant function.** Let $X$ be a compact topological space, let
$\mathbb{K}$ be $\mathbb{R}$ or $\mathbb{C}$, and let $\mu \in \mathbb{K}$. The multiplication
operator on $C(X, \mathbb{K})$ by the constant function with value $\mu$ equals $\mu$ times the
identity operator.
