# Korovkin's theorem

**Korovkin's theorem.** If `Lₙ` are positive linear operators on
`C([0, 1], ℝ)` converging to the identity on the test functions `1`, `x`,
`x²`, then `Lₙ f → f` in norm for every continuous `f`.
