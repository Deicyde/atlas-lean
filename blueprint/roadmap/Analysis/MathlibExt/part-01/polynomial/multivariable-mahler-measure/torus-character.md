# Torus character

**Torus character.** For an angle vector $\theta \in \mathbb{R}^n$, the torus character at
$\theta$ sends an exponent vector $e \in \mathbb{Z}^n$ to
$\exp\bigl(i \sum_{j} e_j \theta_j\bigr) \in \mathbb{C}$.
