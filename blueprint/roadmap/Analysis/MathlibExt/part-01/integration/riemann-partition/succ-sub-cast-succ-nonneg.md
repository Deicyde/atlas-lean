# Subintervals of a partition have nonnegative length

**Subintervals of a partition have nonnegative length.** If
$a = x_0 < x_1 < \cdots < x_n = b$ is a partition of $[a, b]$, then $x_{i+1} - x_i \ge 0$ for
every $i$ with $0 \le i < n$.
