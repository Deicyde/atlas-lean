# Partition

A partition of the closed interval `[a, b]`: a strictly increasing finite
sequence `a = x₀ < x₁ < ⋯ < xₙ = b` of points. The field `n` is the number
of subintervals, and `points` enumerates the `n + 1` endpoints.
