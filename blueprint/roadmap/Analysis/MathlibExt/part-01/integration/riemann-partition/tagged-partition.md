# Tagged partition

**Tagged partition.** A tagged partition of $[a, b]$ is a partition
$a = x_0 < x_1 < \cdots < x_n = b$ of $[a, b]$ together with a choice of a tag
$\xi_k \in [x_{k-1}, x_k]$ in each subinterval, for $k = 1, \dots, n$.
