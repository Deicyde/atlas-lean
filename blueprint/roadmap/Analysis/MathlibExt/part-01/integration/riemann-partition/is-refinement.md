# Refinement of a partition

**Refinement of a partition.** For partitions $P$ and $Q$ of $[a, b]$, $Q$ is a refinement of
$P$ when every point of $P$ is a point of $Q$, that is, when the point set of $P$ is contained in
the point set of $Q$.
