# Silver exponent

**Silver exponent.** The silver exponent is $\log_2 \rho = \log \rho / \log 2$, where
$\rho = 1 + \sqrt{2}$ is the silver ratio.

It is the catalogue's proposed optimal value of the gradient descent exponent.
