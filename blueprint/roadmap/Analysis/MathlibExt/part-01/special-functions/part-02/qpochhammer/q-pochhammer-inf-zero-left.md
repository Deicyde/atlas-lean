# The q-Pochhammer symbol with a = 0

**The q-Pochhammer symbol with a = 0.** For every complex number $q$ with $|q| < 1$,
$(0;q)_\infty = 1$, since every factor $1 - 0 \cdot q^n$ equals $1$.
