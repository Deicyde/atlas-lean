# Bound on the Weierstrass function

**Bound on the Weierstrass function.** The Weierstrass function
$W(x) = \sum_{k \ge 0} \cos(160^k x) / 4^k$ satisfies $|W(x)| \le 4/3$ for every real number $x$.
