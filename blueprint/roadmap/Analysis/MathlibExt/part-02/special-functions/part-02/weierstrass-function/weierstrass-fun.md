# The Weierstrass function

**The Weierstrass function.** The Weierstrass function is the function
$W : \mathbb{R} \to \mathbb{R}$ given by $W(x) = \sum_{k \ge 0} \cos(160^k x) / 4^k$, the sum
running over all natural numbers $k$.
