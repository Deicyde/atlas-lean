# The logistic function of the log odds

**The logistic function of the log odds.** For real numbers $a > 0$ and $b > 0$, the logistic
function $\sigma(z) = 1 / (1 + e^{-z})$ satisfies $\sigma(\log a - \log b) = a / (a + b)$.
