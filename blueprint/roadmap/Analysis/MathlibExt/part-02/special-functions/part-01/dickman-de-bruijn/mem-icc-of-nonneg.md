# Pointwise range bound for the Dickman–de Bruijn function

**Pointwise range bound for the Dickman–de Bruijn function.** If
$\rho : \mathbb{R} \to \mathbb{R}$ is a Dickman–de Bruijn function and $u \ge 0$ is real, then
$\rho(u) \in [0, 1]$.
