# Coordinate recurrence for periodic points of $\mu B$

**Coordinate recurrence for periodic points of $\mu B$.** If `x` is periodic for `μ • B`, its coordinates satisfy
`x k = μ ^ (n * m) * x (k + n * m)` for all `m`.
