# Weyl's inequality (lower bound), matrix form

**Weyl's inequality (lower bound), matrix form.** For Hermitian matrices
`A, B`, `λ_a(A) + λ_b(B) ≤ λ_{a+b-(n-1)}(A + B)` whenever `n - 1 ≤ a + b`.
