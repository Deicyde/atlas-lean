# Weyl's inequality (upper bound), matrix form

**Weyl's inequality (upper bound), matrix form.** For Hermitian matrices
`A, B`, `λ_{a+b}(A + B) ≤ λ_a(A) + λ_b(B)` whenever `a + b < n`.
