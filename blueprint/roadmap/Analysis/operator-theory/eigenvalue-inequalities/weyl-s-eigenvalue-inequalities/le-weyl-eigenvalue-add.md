# Weyl's inequality (lower bound)

**Weyl's inequality (lower bound).** For self-adjoint operators `T, S`,
`λ_a(T) + λ_b(S) ≤ λ_{a+b-(n-1)}(T + S)` whenever `n - 1 ≤ a + b`.
