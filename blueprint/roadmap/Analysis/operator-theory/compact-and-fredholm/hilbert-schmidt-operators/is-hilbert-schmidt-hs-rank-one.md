# Rank-one matrix of $\ell^2$ vectors is Hilbert–Schmidt

**Rank-one matrix of $\ell^2$ vectors is Hilbert–Schmidt.** A rank-one matrix with `ℓ²` vectors is Hilbert–Schmidt.
