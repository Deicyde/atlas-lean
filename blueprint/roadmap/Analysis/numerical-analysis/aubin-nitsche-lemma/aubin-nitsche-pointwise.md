# Aubin–Nitsche lemma, pointwise form

**Aubin–Nitsche lemma, pointwise form.** If `e` satisfies Galerkin
orthogonality against `Vh` and `z` solves the adjoint problem, then
for every competitor `zh ∈ Vh`,
`‖J e‖² ≤ ‖B‖ * ‖e‖ * ‖z - zh‖`.
