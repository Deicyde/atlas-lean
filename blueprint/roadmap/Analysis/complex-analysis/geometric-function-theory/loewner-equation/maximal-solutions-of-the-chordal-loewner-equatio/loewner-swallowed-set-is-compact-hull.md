# Loewner hulls are compact hulls

**Loewner hulls are compact hulls.** For continuous `W` and `t ≥ 0`, the Loewner hull `K_t` is a compact `ℍ`-hull (Lawler 2005,
Chapter 4; the capacity normalization is not proved).
