# Reproducing kernel of the Dirichlet space

**Reproducing kernel of the Dirichlet space.** The **Dirichlet kernel** at `z`: the `ℓ²(ℕ, ℂ)` sequence with
coefficients `(conj z)ⁿ / √(n + 1)`.
