# Bergman kernel evaluated at its own point

**Bergman kernel evaluated at its own point.** Evaluation of the kernel at its own point: `f_z(k_z) = (1 - ‖z‖²)⁻¹ ^ 2`,
so the pointwise bound is sharp.
