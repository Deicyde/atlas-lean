# Closed unit cube

**Closed unit cube.** For $d \in \mathbb{N}$, the closed unit cube $I^d = [0,1]^d$ is the
set of points $x \in \mathbb{R}^d$ with $0 \le x_i \le 1$ for every coordinate $i$.
