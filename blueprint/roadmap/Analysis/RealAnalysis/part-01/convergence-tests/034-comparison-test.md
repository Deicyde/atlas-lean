# Theorem (Comparison Test) [1]

Suppose for all $n\in \mathbb{N}$ $0\leq x_n \leq y_n$. Then, (1) if $\sum y_n$ converges, then $\sum x_n$ converges; (2) if $\sum x_n$ diverges, then $\sum y_n$ diverges.
