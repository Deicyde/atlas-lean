# Theorem (De Morgan's Laws) (Basic Set Theory) (2)

If $A,B,C$ are sets then (1) $(B\cup C)^c = B^c \cap C^c$, (2) $(B\cap C)^c = B^c \cup C^c$, (3) $A\setminus (B\cup C) = (A\setminus B) \cap (A\setminus C)$, and (4) $A\setminus(B\cap C) = (A\setminus B) \cup (A\setminus C)$.
