# Theorem (Mean Value Theorem) (Mean Value Theorem section) (1)

Let $f:[a,b] \to \mathbb{R}$ be continuous, and let $f$ be differentiable on $(a,b)$. Then, $\exists c\in (a,b)$ such that $f(b)-f(a) = f'(c)(b-a).$
