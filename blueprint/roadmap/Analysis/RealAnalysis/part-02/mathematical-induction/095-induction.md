# Theorem (Induction) (Mathematical Induction section)

Let $P(n)$ be a statement depending on $n\in \mathbb{N}$. Assume that (1) (Base case) $P(1)$ is true and (2) (Inductive step) if $P(m)$ is true then $P(m+1)$ is true. Then, $P(n)$ is true for all $n\in \mathbb{N}.$
