# Sum fib rpow le card mul rpow

Upper bounds of Theorem 3(ii) for Fibonacci numbers, with `α = (r + s) / 2`: if
`0 < α < 2` then
`∑_{k=1}^n F_k ^ α ≤ n (F_n F_{n+1} / n) ^ (α / 2) ≤ F_n F_{n+1}`.
