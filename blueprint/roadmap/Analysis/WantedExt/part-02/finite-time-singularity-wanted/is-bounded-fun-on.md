# Functions bounded on a set

**Functions bounded on a set.** A function $f : \beta \to \alpha$ into a space $\alpha$ with a
bornology is bounded on a set $s \subseteq \beta$ if the image $f(s)$ is a bounded subset of
$\alpha$.
