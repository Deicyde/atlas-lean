# Functions whose zeros lie in a given set

**Functions whose zeros lie in a given set.** A function $f : \mathbb{C} \to \mathbb{C}$ has
all its zeros in a set $l \subseteq \mathbb{C}$ if every $z \in \mathbb{C}$ with $f(z) = 0$ lies
in $l$.
