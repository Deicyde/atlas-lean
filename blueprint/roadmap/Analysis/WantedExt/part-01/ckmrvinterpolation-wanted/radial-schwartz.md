# Radial Schwartz functions

**Radial Schwartz functions.** For a natural number $n$, this is the set of complex-valued
Schwartz functions $f$ on $\mathbb{R}^n$ that are radial: $f(x) = f(y)$ whenever $|x| = |y|$.
