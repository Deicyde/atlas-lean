# Embedding of the first coordinate axis

**Embedding of the first coordinate axis.** For a positive integer $n$, this is the map
$\mathbb{R} \to \mathbb{R}^n$ sending $r$ to $(r, 0, \dots, 0)$, whose image is the first
coordinate axis.
