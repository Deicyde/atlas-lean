# Radial functions on $\mathbb{R}^n$

**Radial functions on $\mathbb{R}^n$.** A function $f \colon \mathbb{R}^n \to \mathbb{R}$ is
radial if $f(x) = f(y)$ for all $x, y \in \mathbb{R}^n$ with $\|x\| = \|y\|$, where $\|\cdot\|$ is
the Euclidean norm.
