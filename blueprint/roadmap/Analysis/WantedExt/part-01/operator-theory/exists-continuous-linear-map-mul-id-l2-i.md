# Mul By Identity Bounded On L2 Unit Interval Wanted

Consider the operator $T:L^{2}([0,1])\to L^{2}([0,1])$ defined by

\[
T(f)(t)=tf(t).
\]
Prove that $T$ is a bounded linear operator.
