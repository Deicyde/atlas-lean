# Disk To Upper Half Plane Cayley Wanted

Prove that the function

\[
\phi(z)=i\,\frac{1-z}{1+z}
\]
maps the set $D=\{z\in\mathbb{C}:|z|<1\}$ one-to-one onto the set
$U=\{z\in\mathbb{C}:\mathrm{Im}\,z>0\}$.
