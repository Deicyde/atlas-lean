# Rising sun set

**Rising sun set.** For real numbers $a, b$ and a function
$f : \mathbb{R} \to \mathbb{R}$, the rising sun set of $f$ on $(a, b)$ is the set of points
$x \in (a, b)$ for which there is some $t$ with $x < t \le b$ and $f(x) < f(t)$.
