# Sub two mul one add tsum prod eq pi mul cot

Theorem 1: for each integer `k ≥ 2`,
`(k - 2)(1 + Σ_{n≥1} (1/(n+1)) ∏_{j=1}^n (kj - (k-2))/(kj + 1)) = π cot(π/k)`.
