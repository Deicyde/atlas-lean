# Proposition 7.3

A linear functional $u \colon \mathcal{S}(\mathbb{R}^{n}) \to \mathbb{C}$ is continuous if and only if there exist $C, k$ such that $|u(\varphi)| \leq C \sum_{|\alpha| \leq k,\, |\beta| \leq k} \sup_{\mathbb{R}^{n}} |x^{\alpha} D_{x}^{\beta} \varphi|$.
