# Lemma 3.1

If $G \subset \mathcal{N}$ generates $\mathcal{N}$, in the sense that $\mathcal{N} = \bigcap\{\mathcal{N}' \mid \mathcal{N}' \supset G,\, \mathcal{N}' \text{ a } \sigma\text{-algebra}\}$, then $f \colon X \to Y$ is measurable iff $f^{-1}(A) \in \mathcal{M}$ for all $A \in G$.
