# Proposition 6.3

The function $\|u\|_{\mathcal{C}^{1}} = \|u\|_{\infty} + \sum_{i=1}^{n} \left\|\frac{\partial u}{\partial x_{i}}\right\|_{\infty}$ is a norm on $\mathcal{C}_0^{1}(\mathbb{R}^{n})$ with respect to which it is a Banach space.
