# Proposition 9.7

If $m \leq 0$ is an integer then $u \in H^m(\mathbb{R}^n)$ if and only if it can be written in the form $u = \sum_{|\alpha| \leq -m} D^\alpha v_\alpha$, $v_\alpha \in L^2(\mathbb{R}^n)$.
