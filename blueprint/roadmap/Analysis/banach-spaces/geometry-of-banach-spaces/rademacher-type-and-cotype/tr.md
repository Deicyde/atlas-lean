# Rademacher type constant

**Rademacher type constant.** For a real Banach space $X$ and a real number $p$,
$T^R_p(X)$ is the infimum in $[0, \infty]$ of all $C \in [0, \infty]$ such that $X$ has
Rademacher type $p$ with constant $C$.
