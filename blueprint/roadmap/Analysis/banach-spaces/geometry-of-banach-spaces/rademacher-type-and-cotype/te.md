# Enflo type constant

**Enflo type constant.** For a real Banach space $X$ and a real number $p$, $T^E_p(X)$ is
the infimum in $[0, \infty]$ of all $C \in [0, \infty]$ such that $X$ has Enflo type $p$ with
constant $C$.
