# Theorem (Szemeredi-Trotter) [2]

If $E \subset \mathbb{R}^2$ is a set of $N$ points and $L_R(E)$ the set of $R$-rich lines, then $|L_R(E)| \lesssim \frac{N^2}{R^3} + \frac{N}{R}$.
