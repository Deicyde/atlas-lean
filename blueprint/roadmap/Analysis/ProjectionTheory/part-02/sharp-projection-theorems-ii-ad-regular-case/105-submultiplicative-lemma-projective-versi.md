# Lemma (Submultiplicative Lemma, projective version)

If $\delta = \delta_1 \delta_2$, $\delta_1, \delta_2 < 1$, then $R_{AD, \mathrm{proj}}(\delta) \lessapprox R_{AD, \mathrm{proj}}(\delta_1) R_{AD, \mathrm{proj}}(\delta_2)$.
