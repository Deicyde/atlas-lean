# Control theory

Mathematical control theory of finite-dimensional systems: controllability of linear systems (controllability Gramian, Kalman rank condition, Hautus test), pole placement and stabilisation by state feedback, Lie-bracket conditions for nonlinear controllability, Brockett's obstruction to continuous feedback stabilisation and the return method. Optimal control and dynamic programming are under Convex analysis and calculus of variations and Computer science.
