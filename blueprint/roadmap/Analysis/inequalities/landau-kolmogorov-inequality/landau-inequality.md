# Landau–Kolmogorov inequality

**Landau–Kolmogorov inequality** on `ℝ` (case `n = 2`, `k = 1`): if `f` is twice
continuously differentiable with `|f| ≤ M₀` and `|f''| ≤ M₂` everywhere, then
`(f' x)² ≤ 2 * M₀ * M₂` for every `x`.
