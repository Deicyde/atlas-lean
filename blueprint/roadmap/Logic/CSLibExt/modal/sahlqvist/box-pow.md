# Iterated box

**Iterated box.** For a natural number $k$ and a modal formula $\varphi$, the iterated box
$\Box^k \varphi$ is defined by $\Box^0 \varphi = \varphi$ and
$\Box^{k+1} \varphi = \Box\,\Box^k \varphi$.
