# Completeness of GL for finite strict partial orders

A formula $\varphi$ is a theorem of GL if and only if $\varphi$ is valid in every Kripke model on a
finite set of worlds whose accessibility relation is transitive and irreflexive (Segerberg 1971;
independently de Jongh and Kripke). Completeness even holds for finite transitive irreflexive
trees; the Lean statement uses the larger class of finite strict partial orders, so it is the
weaker completeness claim.
