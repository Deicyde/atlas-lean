# Fuelled decoding of linear μ-calculus codes

Fuelled decoding of a code number, in the
[Cantor-pairing code of linear μ-calculus formulas](linear-mu-code.md), back to a formula. The fuel
bounds the recursion depth; plain decoding of a code `c` (see
[Decoding linear μ-calculus codes](linear-mu-decode.md)) supplies fuel `c + 1`, which exceeds the
depth of any formula with code `c` (see [Formula depth is bounded by its code](linear-depth-le-code.md)).
