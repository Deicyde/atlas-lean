# Corollary 21.11

The following hold: (a) $\ell(0)=1$. (b) If $A \sim B$ then $\ell(A)=\ell(B)$ and $\operatorname{deg}(A)=\operatorname{deg}(B)$. (c) For any $A \leq B$ we have $\ell(B)-\ell(A) \leq \operatorname{deg} B - \operatorname{deg} A$. (d) For all $D \geq 0$ we have $\ell(D) \leq \operatorname{deg} D+1$. (e) If $\operatorname{deg} D<0$ then $\ell(D)=0$.
