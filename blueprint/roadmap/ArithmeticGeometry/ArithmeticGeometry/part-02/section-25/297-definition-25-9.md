# Definition 25.9

The (absolute) height of a projective point $P = (x_0 : \cdots : x_n) \in \mathbb{P}^n(\overline{\mathbb{Q}})$ is $H(P) \coloneqq \prod_{p \in \mathcal{P}_k} \max_i |x_i|_p$ where $k = \mathbb{Q}(x_0, \ldots, x_n)$. For any $\lambda \in \overline{\mathbb{Q}}^{\times}$, $H(P)$ is well defined (it does not depend on a particular choice of $x_0, \ldots, x_n$). For $k = \mathbb{Q}$ we can write $P = (x_0 : \cdots : x_n)$ with the $x_i \in \mathbb{Z}$ having no common factor. Then $\max |x_i|_p = 1$ for $p < \infty$ and $H(P) = \max_i |x_i|_{\infty}$.
