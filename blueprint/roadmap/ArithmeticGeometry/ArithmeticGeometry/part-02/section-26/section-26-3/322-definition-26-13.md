# Definition 26.13

The elliptic curve $E/k$ given by Theorem 26.12 is the Jacobian of the genus one curve $C/k$; it is determined only up to $k$-isomorphism, so we call any elliptic curve that is $k$-isomorphic to $E$ "the" Jacobian of $C$.
