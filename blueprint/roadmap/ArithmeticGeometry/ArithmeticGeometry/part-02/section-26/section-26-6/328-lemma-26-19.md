# Lemma 26.19

If $\theta: C \rightarrow C'$ is an equivalence of $E$-torsors then $\theta(P)-\theta(Q)=P-Q$ for all $P, Q \in C$. Conversely, if $\theta: C \rightarrow C'$ is a $k$-isomorphism for which the above holds, then $\theta$ is an equivalence of $E$-torsors.
