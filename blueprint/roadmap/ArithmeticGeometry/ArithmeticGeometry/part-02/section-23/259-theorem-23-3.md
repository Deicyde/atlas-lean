# Theorem 23.3

Let $C/k$ be a curve with a rational point. Then $C$ has genus one if and only if it is isomorphic to a plane curve of the form $y^{2} + a_{1}xy + a_{3}y = x^{3} + a_{2}x^{2} + a_{4}x + a_{6}$ with $a_{1}, a_{2}, a_{3}, a_{4}, a_{6} \in k$.
