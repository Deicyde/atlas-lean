# Corollary 19.23

Let $f \in k(C)^{\times}$ for some curve $C/k$. Then $f$ has the same number of zeros and poles (counted with multiplicity), that is, $\deg \operatorname{div}_0 f = \deg \operatorname{div}_{\infty} f$. If $f \in k^{\times}$ then this number is 0, and otherwise it is equal to $[k(C):k(f)]$. In any case, we always have $\deg \operatorname{div} f = 0$.
