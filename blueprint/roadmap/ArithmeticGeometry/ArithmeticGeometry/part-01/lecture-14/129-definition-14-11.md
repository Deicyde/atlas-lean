# Definition 14.11

If $\varphi = (\varphi_1, \ldots, \varphi_n)$ is a morphism of varieties $X \rightarrow Y$ that are defined over $k$, we say that $\varphi$ is defined over $k$ if $\varphi_1, \ldots, \varphi_n \in k[Y]$. Equivalently, $\varphi$ is defined over $k$ if $\varphi^{\sigma} = (\varphi_1^{\sigma}, \ldots, \varphi_n^{\sigma}) = \varphi$ for all $\sigma \in G_k$. If $\varphi$ is an isomorphism defined over $k$ and it has an inverse isomorphism defined over $k$, then we say that $X$ and $Y$ are isomorphic over $k$.
