# Lemma 25

If $\mathcal{F}$ is coherent, then: 1.\ Fiber is always finite dimensional; 2.\ Fiber of $\mathcal{F}$ at $x$ is zero iff there exists $U \ni x$ such that $\mathcal{F}|_U = 0$; 3.\ The function $d \colon x \mapsto \dim(\text{fiber}(x))$ is (upper) semicontinuous. 4.\ The function $d$ is locally constant if and only if $\mathcal{F}$ is locally free.
