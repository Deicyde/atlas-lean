# Gal Linear Equiv

The invertible `ZMod p`-linear action of a Galois automorphism on `E[p]`,
packaged via `LinearEquiv.ofBijective` to avoid normalizing
`toZModLinearMap` projections inside a manual `LinearEquiv` construction.
