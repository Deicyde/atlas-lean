# Divisors on a curve

**Divisors on a curve.** For a set $C$ (the points of a curve), a divisor on $C$ is a finitely
supported function $D \colon C \to \mathbb{Z}$. Its support is the finite set of points
$P \in C$ with $D(P) \neq 0$.
