# Exponential decay from a one-step recursion

**Exponential decay from a one-step recursion.** If `φ_p(S) < 1` and `crossProb((k + 1)L) ≤ φ_p(S) · crossProb(kL)` for all `k`, then
`crossProb d p n ≤ C e^{-cn}` for some `c, C > 0`.
