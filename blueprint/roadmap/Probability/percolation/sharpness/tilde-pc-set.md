# Densities with a finite set of small Duminil-Copin–Tassion quantity

**Densities with a finite set of small Duminil-Copin–Tassion quantity.** The set of densities `p ∈ [0, 1]` for which some finite `S ∋ 0` has `φ_p(S) < 1`.
