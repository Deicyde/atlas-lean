# Half-spaces

**Half-spaces.** A set $A \subseteq \mathbb{R}^n$ is a half-space if there are a nonzero
vector $v \in \mathbb{R}^n$ and a real number $a$ such that
$A = \{x \in \mathbb{R}^n : \langle v, x \rangle \le a\}$.
