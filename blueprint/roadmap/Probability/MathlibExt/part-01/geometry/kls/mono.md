# Smooth Poincaré bounds are upward closed

**Smooth Poincaré bounds are upward closed.** Let $\mu$ be a measure on $\mathbb{R}^n$ and let
$C \le D$ in $[0, \infty]$. If $C$ is a smooth Poincaré bound for $\mu$, then so is $D$.
