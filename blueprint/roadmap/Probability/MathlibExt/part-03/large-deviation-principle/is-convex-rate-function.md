# Is Convex Rate Function

A **convex rate function** on a real vector space is a rate
function `I` that is convex: `I(ax + by) ≤ a · I(x) + b · I(y)` for
all `x, y ∈ X` and all weights `a, b ≥ 0` with `a + b = 1`.
