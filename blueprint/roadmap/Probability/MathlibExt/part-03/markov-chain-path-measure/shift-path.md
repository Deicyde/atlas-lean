# Time shift on path space

**Time shift on path space.** Let $S$ be a set and $n \in \mathbb{N}$. The time-$n$ shift on
the path space $S^{\mathbb{N}}$ sends a path $\omega$ to the path $k \mapsto \omega_{n+k}$.
