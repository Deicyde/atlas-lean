# Has Cutoff

Distance profiles `d n t` exhibit cutoff: some `tₙ → ∞` has `d n ⌈(1+η)tₙ⌉ → 0` and
`d n ⌊(1-η)tₙ⌋ → 1` for every `η ∈ (0,1)`.
