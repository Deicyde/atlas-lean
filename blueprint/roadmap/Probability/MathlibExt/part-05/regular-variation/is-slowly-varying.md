# Slowly varying function

**Slowly varying function.** A function $L : \mathbb{R} \to \mathbb{R}$ is slowly varying (at
infinity) if $L(x) > 0$ for all sufficiently large $x$ and, for every real $c > 0$,
$L(cx) / L(x) \to 1$ as $x \to \infty$.
