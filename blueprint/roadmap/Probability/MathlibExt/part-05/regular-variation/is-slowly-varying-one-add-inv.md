# The function $1 + (1 + x)^{-1}$ is slowly varying

**The function $1 + (1 + x)^{-1}$ is slowly varying.** The function
$x \mapsto 1 + (1 + x)^{-1}$ on $\mathbb{R}$ is slowly varying; it tends to the positive limit $1$
at infinity.
