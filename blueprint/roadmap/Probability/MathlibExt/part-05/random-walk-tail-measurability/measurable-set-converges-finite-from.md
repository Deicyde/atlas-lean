# Measurable Set converges Finite from

The event `{Sₘ converges to a finite limit}` is measurable with respect
to `σ(Xₙ, Xₙ₊₁, …)` for every `n`. The proof rewrites convergence as a
Cauchy condition expressed via tail partial sums.
