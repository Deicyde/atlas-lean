# Convergence of a random walk is measurable from every index

**Convergence of a random walk is measurable from every index.** Let $X_0, X_1, \dots$ be
real-valued functions on a set $\Omega$, let $S_m = \sum_{i < m} X_i$ be their partial sums, and
for $n \in \mathbb{N}$ let $\sigma(X_n, X_{n+1}, \dots)$ be the smallest σ-algebra on $\Omega$ for
which every $X_i$ with $i \ge n$ is Borel measurable. For every $n$, the set of $\omega \in \Omega$
for which $S_m(\omega)$ converges to a real limit as $m \to \infty$ is measurable with respect to
$\sigma(X_n, X_{n+1}, \dots)$.

The proof rewrites convergence as a Cauchy condition on the tail partial sums
$\sum_{n \le i < m} X_i$.
