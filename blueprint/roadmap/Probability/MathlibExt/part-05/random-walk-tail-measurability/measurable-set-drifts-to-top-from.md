# Measurable Set drifts To Top from

The event `{Sₘ → +∞}` (the partial sums of a sequence drift to `+∞`)
lies in the σ-algebra `σ(Xₙ, Xₙ₊₁, …)` for every `n`, by expressing it as
a countable Boolean combination of events measurable with respect to
`σ(Xₙ, Xₙ₊₁, …)`.
