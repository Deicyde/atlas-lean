# Convergence of a random walk is a tail event

**Convergence of a random walk is a tail event.** Let $X_0, X_1, \dots$ be real-valued
functions on a set $\Omega$ and let $S_m = \sum_{i < m} X_i$ be their partial sums. The set of
$\omega \in \Omega$ for which $S_m(\omega)$ converges to a real limit as $m \to \infty$ belongs to
the tail σ-algebra $\bigcap_{n} \sigma(X_n, X_{n+1}, \dots)$ of the sequence, where
$\sigma(X_n, X_{n+1}, \dots)$ is the smallest σ-algebra on $\Omega$ for which every $X_i$ with
$i \ge n$ is Borel measurable.
