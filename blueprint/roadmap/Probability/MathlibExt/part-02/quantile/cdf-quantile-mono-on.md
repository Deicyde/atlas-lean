# Monotonicity of the quantile function

**Monotonicity of the quantile function.** For every measure $\mu$ on $\mathbb{R}$, the quantile
function $Q_\mu$ is monotone on $(0, 1)$: if $0 < u \le v < 1$, then $Q_\mu(u) \le Q_\mu(v)$.
