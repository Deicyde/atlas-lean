# Is Exchangeable Event Wrt

An event `E ⊆ Ω` is **exchangeable with respect to the sequence**
`X : ℕ → Ω → S` if there is some exchangeable event `A ⊆ (ℕ → S)` such that
`E` is the pullback of `A` under `ω ↦ (n ↦ X n ω)`. Equivalently, `E` belongs
to the σ-field of exchangeable events generated by `X`.
