# Measurable Set inter eq top i Sup stopped Filtration

If `t` is measurable with respect to `⨆ n, ℱ n`, then `t ∩ {τ = ⊤}`
is measurable with respect to `⨆ n, ℱ_{τ ∧ n}`. The proof is induction
on the σ-algebra generated by the π-system of sets measurable at some
finite time; the basic case uses the sets
`(t ∩ {τ > m}) ∪ {τ ≤ m}`, which lie in `ℱ_{τ ∧ m}` and shrink to
`t ∩ {τ = ⊤}` after intersecting with `{τ = ⊤}`.
