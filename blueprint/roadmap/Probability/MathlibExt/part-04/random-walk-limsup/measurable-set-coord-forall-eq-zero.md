# The zero-sequence event is measurable

**The zero-sequence event is measurable.** In the sequence space $\mathbb{R}^{\mathbb{N}}$ with
its product σ-algebra, the set of sequences $\omega$ with $\omega_i = 0$ for every $i$ is
measurable.
