# Almost sure Hölder bound on the dyadic rationals

Let `X : ℝ → Ω → ℝ` be a process on a probability space with
`E |X s - X t|^β ≤ K |s - t|^{1 + α}` for all `s, t` (`α, β > 0`, `K ≥ 0`, the moments
`|X s - X t|^β` integrable). For every `0 < γ < α / β`, almost surely there is `C > 0` with
`|X q - X r| ≤ C |q - r|^γ` for all dyadic rationals `q, r ∈ [0, 1]`: a single full-measure set
carries the Hölder bound for the original process. The integrability of the moments is needed for
this Bochner-integral formulation (see the module docstring).
