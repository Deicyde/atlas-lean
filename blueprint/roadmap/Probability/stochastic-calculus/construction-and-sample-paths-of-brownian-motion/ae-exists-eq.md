# Linear Brownian motion hits every level

If `B` is a real Brownian motion, then almost
surely, for every `a ∈ ℝ`, there is a time `t` with `B t = a`: the hitting time
`T_a = inf {t ≥ 0 : B t = a}` is finite for every `a` (Le Gall, ENS notes *Intégration,
Probabilités et Processus Aléatoires*, Corollaire 14.4.3, second assertion).

## Informally uses

- [Brownian motion is unbounded above and below at infinity](ae-unbounded-at-top.md): the path
  takes values above and below every level, and the intermediate value theorem on a continuous
  path gives a time where it equals the level.
