# Stochastic domination from above passes to weak limits

**Stochastic domination from above passes to weak limits.** If `μₙ ≼ ρ` for all `n` and `μₙ → ν` weakly, then `ν(A) ≤ ρ(A)` for every increasing clopen
event `A`.
