# Stochastic domination from below passes to weak limits

**Stochastic domination from below passes to weak limits.** If `ρ ≼ μₙ` for all `n` and `μₙ → ν` weakly, then `ρ(A) ≤ ν(A)` for every increasing clopen
event `A`.
