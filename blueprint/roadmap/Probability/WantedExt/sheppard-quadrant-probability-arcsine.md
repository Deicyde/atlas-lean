# Sheppard Arcsine Wanted

Sheppard's formula (Gaussian arcsine law): for a standard bivariate normal vector with
correlation `ρ ∈ (-1, 1)`, the first-quadrant probability is `1/4 + arcsin ρ / (2π)`.
