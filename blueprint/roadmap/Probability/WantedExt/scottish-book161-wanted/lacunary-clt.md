# Lacunary CLT

The central limit theorem conclusion for a frequency sequence `r`: for
any `a < b`, the Lebesgue measure in `[0, 1]` of the set of `x` with
`a < (sin(2π r₁ x) + ... + sin(2π rₙ x)) / √n < b` tends to
`(1 / √π) * ∫_a^b exp(-y²) dy`.
