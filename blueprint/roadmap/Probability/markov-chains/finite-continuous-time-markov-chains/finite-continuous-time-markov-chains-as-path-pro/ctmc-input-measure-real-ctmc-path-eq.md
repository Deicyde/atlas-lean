# Kolmogorov

**Kolmogorov** (Norris 1997, §2.8, Theorem 2.8.2 for a finite state space): the chain
built from the jump chain and the holding times has transition function `exp (t • Q)`:
`P_i(X t = j) = exp (t Q) i j` for every `t ≥ 0`.
