# Sticky kernel

**Sticky kernel.** The **sticky kernel** with persistence `c`: `c • 1 + (1 - c) • 𝟙 πᵀ`. Started from `i`,
it stays at `i` with probability `c` and otherwise redraws the state from `π`.
