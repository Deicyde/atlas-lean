# Theorem (Martingale convergence) [2]

The following are equivalent for a martingale: (1) It is uniformly integrable. (2) It converges a.s. and in $L^1$. (3) It converges in $L^1$. (4) There is an integrable random variable $X$ so that $X_n = E(X \mid \mathcal{F}_n)$.
