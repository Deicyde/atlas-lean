# Theorem (Square integrable martingale maximal inequality)

If $X_n$ is a martingale with $E[X_n^2] < \infty$ for all $n$, and $A_n = \sum_{m=1}^n E[(X_m - X_{m-1})^2 \mid \mathcal{F}_{m-1}]$, then $E[\sup_m |X_m|^2] \leq 4 E[A_\infty]$.
