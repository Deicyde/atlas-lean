# CQR prediction band

For a threshold `Q ∈ ℝ ∪ {+∞}`, the band at `x` is
`[q_lo x - Q, q_hi x + Q]`, written as the set of `y` with `q_lo x - y ≤ Q` and `y - q_hi x ≤ Q`;
it is all of `ℝ` when `Q = ⊤`.

## Sources

- Y. Romano, E. Patterson and E. J. Candès, *Conformalized quantile regression*, NeurIPS 2019, arXiv:1905.03222, Algorithm 1 (output).
