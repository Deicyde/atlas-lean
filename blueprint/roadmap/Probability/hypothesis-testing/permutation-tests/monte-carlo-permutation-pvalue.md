# Monte Carlo permutation p-value

**Monte Carlo permutation p-value.** The Monte Carlo permutation p-value `(1 + #{b | T(g_b • ω) ≥ T(ω)}) / (B + 1)` of the
statistic `T` at the data `ω` with the `B` drawn group elements `g`.
