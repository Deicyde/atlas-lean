# Local fdr times mixture density equals the null part

**Local fdr times mixture density equals the null part.** The basic identity `fdr(z) f(z) = π₀ f₀(z)`, for every `z` (where `f(z) = 0` both sides
vanish because `π₀ f₀ ≤ f`).
