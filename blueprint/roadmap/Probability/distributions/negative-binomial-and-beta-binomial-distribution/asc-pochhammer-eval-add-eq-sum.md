# Chu–Vandermonde identity for rising factorials

**Chu–Vandermonde identity for rising factorials**:
`(α + β)^{(n)} = ∑_{k ≤ n} C(n, k) α^{(k)} β^{(n - k)}`, for all real `α, β`.
