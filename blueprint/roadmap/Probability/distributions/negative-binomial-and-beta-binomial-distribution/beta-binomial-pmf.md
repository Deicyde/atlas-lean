# Beta-binomial mass function

**Beta-binomial mass function.** Beta-binomial mass `C(n, k) α^{(k)} β^{(n - k)} / (α + β)^{(n)}` (zero for `k > n`, since
`C(n, k) = 0`). A probability mass function for `α, β > 0`.
