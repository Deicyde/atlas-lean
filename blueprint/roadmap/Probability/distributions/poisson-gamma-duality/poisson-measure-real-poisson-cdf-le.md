# Super-uniformity of the distribution-function transform

**Super-uniformity of the distribution-function transform**: for `K ~ Poisson(r)` and
every `α ≥ 0`, `P(F_r(K) ≤ α) ≤ α`. (For `α < 0` the event is empty.)
