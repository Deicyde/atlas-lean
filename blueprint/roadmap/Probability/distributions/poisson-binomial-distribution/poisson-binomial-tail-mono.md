# The burden-test p-value is monotone in every background rate

**The burden-test p-value is monotone in every background rate**: if `p i ≤ q i` for all
`i`, with all probabilities in `[0, 1]`, then `P_p(S ≥ k) ≤ P_q(S ≥ k)`.
