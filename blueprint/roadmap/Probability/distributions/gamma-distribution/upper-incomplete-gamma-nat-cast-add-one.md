# Upper incomplete gamma function at natural shapes

**Upper incomplete gamma function at natural shapes.** The closed form at natural shapes (DLMF 8.4.8): for `x ≥ 0`,
`Γ(n + 1, x) = n! e^{-x} ∑_{k = 0}^{n} x ^ k / (k!)`.
