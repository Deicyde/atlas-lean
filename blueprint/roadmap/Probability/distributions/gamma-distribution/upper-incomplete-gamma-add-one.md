# Recurrence for the upper incomplete gamma function

**Recurrence for the upper incomplete gamma function.** The recurrence `Γ(a + 1, x) = x ^ a e^{-x} + a Γ(a, x)` for `a > 0` and `x ≥ 0`
(DLMF 8.8.2), from integration by parts.
