# Pointwise bound behind the p-biased inequality

**Pointwise bound behind the p-biased inequality.** The pointwise bound `(q/2) m^(q-2) V ≤ (1-p) + p z^q - m^q` for all `z ≥ 0`, with
`m = pih_m p z`, `V = pih_V p q z`.
