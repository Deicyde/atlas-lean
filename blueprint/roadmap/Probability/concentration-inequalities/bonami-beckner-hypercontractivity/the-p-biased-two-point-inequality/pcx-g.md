# Convex auxiliary function for the p-biased inequality

**Convex auxiliary function for the p-biased inequality.** `(1-p)(1 - p t)^q + p(1 + (1-p) t)^q - 1 - 2q(q-1) p²(1-p)² t²`, convex and nonnegative on
`[-1/(1-p), 1/p]` for `1 ≤ q ≤ 2`.
