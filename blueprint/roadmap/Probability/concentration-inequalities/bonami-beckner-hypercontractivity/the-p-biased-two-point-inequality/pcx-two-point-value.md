# p-biased two-point inequality

**p-biased two-point inequality.** The **`p`-biased two-point inequality**: for `0 < p < 1`, `1 ≤ q ≤ 2` and real `u, v`,
`((1-p) u + p v)² + 4(q-1) p²(1-p)²(u - v)² ≤ ((1-p)|u|^q + p|v|^q)^(2/q)`.
