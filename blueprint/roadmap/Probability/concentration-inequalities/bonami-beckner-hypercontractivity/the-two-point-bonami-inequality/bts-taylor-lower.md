# Taylor lower bound for $(1+t)^q + (1-t)^q$

**Taylor lower bound for $(1+t)^q + (1-t)^q$.** For `1 ≤ q ≤ 2` and `|t| ≤ 1`, `2 + q(q-1) t² ≤ (1 + t)^q + (1 - t)^q`.
