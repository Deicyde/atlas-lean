# Stick-breaking measure

**Stick-breaking measure.** The discrete measure `∑ₖ πₖ δ_{θₖ}` with the stick-breaking weights `πₖ = stickWeight b k`
(negative weights, which do not occur for proportions in `[0, 1]`, are read as `0`).
