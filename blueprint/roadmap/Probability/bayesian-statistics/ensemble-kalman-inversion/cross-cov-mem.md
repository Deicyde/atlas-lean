# The cross-covariance stays in the ensemble's subspace

If every particle $u^{(k)}$ lies in a linear subspace $S$, then $C^{up}(u)\, d \in S$ for every $d$:
$C^{up}(u)\, d$ is a linear combination of the deviations $u^{(k)} - \overline u$, which lie in $S$.
