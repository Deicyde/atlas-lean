# The closed-form expected number of ones tends to `N α`

As the number of features `K → ∞`, the closed-form expected number of ones `N α / (1 + α/K)` of the finite feature model tends to `N α` (Griffiths and Ghahramani 2011, Section 4.6, the limit of Equation 11). The paper reads this as consistent with the expected number of entries of the Indian buffet process, `N α`, which follows from each object having a `Poisson(α)` number of features; that property is not formalized here.
