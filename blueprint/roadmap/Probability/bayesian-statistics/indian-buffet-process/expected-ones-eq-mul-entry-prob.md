# The closed-form expected number of ones is `N K` model entry probabilities

For `α > 0` and `K ≥ 1`, the closed-form expected number of ones of the finite feature model equals `N K · P(zᵢₖ = 1)`, where `P(zᵢₖ = 1)` is computed from the beta–Bernoulli model. Griffiths and Ghahramani's Equation 11 is the sum of these `N K` equal entry probabilities by linearity of expectation; the random matrix and its expectation are not formalized here, so this identifies each summand of the closed form with a model probability.
