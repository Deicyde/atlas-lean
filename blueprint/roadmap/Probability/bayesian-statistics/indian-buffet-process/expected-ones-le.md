# The closed-form expected number of ones is at most `N α`

For `α ≥ 0` and every number of features `K`, the closed-form expected number of ones of the finite feature model is at most `N α`. This is the bound, independent of `K`, that Griffiths and Ghahramani (2011, Section 4.1, with Equation 11) note for the finite model; here it is an inequality about the recorded closed form.
