# An event depends on the coordinates its indicator depends on

If the indicator function `1_A` of `A` depends only on the coordinates in `S`, that is, it takes
the same value at any two configurations that agree on `S`, then so does the event `A`: whether a
configuration lies in `A` depends only on its values on `S` (see
[Event depending only on a set of coordinates](../../reimer-inequality/down-compression-and-disjoint-pairs/depends-on.md)).
