# Increasing event

**Increasing event.** An event `A ⊆ ConfigSpace E` is *increasing* if it is an upper set for the coordinatewise
order: `ω ∈ A` and `ω ≤ ω'` imply `ω' ∈ A`. This is `IsUpperSet A`.
