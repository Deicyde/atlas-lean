# Box-value bound fails for non-symmetric weights

**Box-value bound fails for non-symmetric weights.** For a non-symmetric weight, `wdpairs w 𝒜 ℬ ≤ wboxValue w (boxDoubled 𝒜 ℬ)` can fail.
