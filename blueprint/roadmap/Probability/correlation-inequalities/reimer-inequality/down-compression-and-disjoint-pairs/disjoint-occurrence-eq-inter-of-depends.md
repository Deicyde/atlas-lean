# Disjoint occurrence equals intersection for disjoint dependence sets

**Disjoint occurrence equals intersection for disjoint dependence sets.** If `A` depends only on `S`, `B` only on `T`, and `S, T` are disjoint, then
`A □ B = A ∩ B`.
