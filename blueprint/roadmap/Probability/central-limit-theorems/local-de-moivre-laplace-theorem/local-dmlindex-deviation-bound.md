# Deviation bound for the De Moivre–Laplace index

**Deviation bound for the De Moivre–Laplace index.** Eventually, the deviation `|2k - n|` for `k = localDMLIndex x n` is at most `|x| √n + 2`,
since `k = ⌊n/2 + x √n / 2⌋`.
