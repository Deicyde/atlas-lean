# Operator norm of random matrices

The largest eigenvalue of an $n \times n$ random matrix with independent, mean-zero, unit-variance
entries has size $2\sqrt{n}$. It is $O(\sqrt{n})$ with overwhelming probability (an
$\varepsilon$-net argument), it concentrates with $O(1)$ fluctuations (Talagrand's inequality),
and for Wigner matrices with finite fourth moment $\|M_n\| / \sqrt{n} \to 2$ almost surely (Bai and
Yin for the upper bound, the semicircle law for the lower bound). These are the topics of §2.3 of
Tao's *Topics in Random Matrix Theory*; all four results are stated, not yet proved.
