# Increment of the win probability of threshold rules

**Increment of the win probability of threshold rules** (Ferguson, *Optimal Stopping and
Applications*, Chapter 2, the computation before equation (4)): for `1 ≤ r < n`,
`P_{r+1} - P_r = (T_r - 1)/n`, so `P_{r+1} ≤ P_r` if and only if
`∑_{k=r+1}^{n} 1/(k - 1) ≤ 1`.

## Sources

- T. S. Ferguson, *Optimal Stopping and Applications*, online text (UCLA Department of Mathematics), Chapter 2, §2.1, the equivalence $P_{r+1} \le P_r \iff \sum_{k=r+1}^{n} 1/(k-1) \le 1$ before equation (4).
