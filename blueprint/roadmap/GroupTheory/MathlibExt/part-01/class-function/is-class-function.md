# Class functions on a group

**Class functions on a group.** Let $G$ be a group and $k$ a set. A function
$f : G \to k$ is a class function when it is constant on conjugacy classes, that is,
$f(h g h^{-1}) = f(g)$ for all $g, h \in G$.
