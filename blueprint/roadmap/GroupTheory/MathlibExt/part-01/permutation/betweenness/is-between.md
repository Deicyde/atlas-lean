# Strict betweenness

**Strict betweenness.** Let $\alpha$ be a type with a relation $<$ and let $a, b, c \in \alpha$.
Then $b$ lies strictly between $a$ and $c$ when either $a < b$ and $b < c$, or $c < b$ and
$b < a$.
