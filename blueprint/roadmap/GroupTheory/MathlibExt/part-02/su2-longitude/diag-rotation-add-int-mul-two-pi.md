# Diagonal rotations are $2\pi$-periodic

**Diagonal rotations are $2\pi$-periodic.** For every real number $\theta$ and every integer
$n$, the diagonal rotation through $\theta + 2\pi n$ equals the diagonal rotation through
$\theta$.
