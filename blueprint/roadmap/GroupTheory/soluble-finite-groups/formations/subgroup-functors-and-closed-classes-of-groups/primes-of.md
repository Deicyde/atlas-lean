# Prime divisors of a class of finite groups

**Prime divisors of a class of finite groups.** For a class $\mathfrak{X}$ of finite groups,
$\pi(\mathfrak{X})$ is the set of primes $p$ that divide the order of some group in
$\mathfrak{X}$.
