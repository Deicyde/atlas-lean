# Three Hall Subgroups Intersect In Core

Kourovka 18.31 (E. P. Vdovin, D. O. Revin): for every set of primes `π`, every finite
`D_π`-group `G` has three Hall `π`-subgroups whose intersection is `O_π(G)`.
