# Abelian Subgroup Generators Le Twice Normal refuted

Resolved false: Muliarchyk (Theorem 1.1) constructs a finite `2`-group of order `2^(110N+1)`, `N =
2124210350`, whose abelian normal subgroups can be generated by `32N + 1` elements while an
elementary abelian subgroup needs `65N > 2(32N + 1)` generators; the 21st issue of the Kourovka
Notebook marks 20.75 solved ("No, it is not"). Source: E. I. Khukhro and V. D. Mazurov (eds.),
Unsolved Problems in Group Theory: The Kourovka Notebook, 21st issue, arXiv:1401.0300v49 (2026),
Problem 20.75 (L. Pyber); resolution: K. Muliarchyk, An explicit counterexample to Kourovka Notebook
Problem 20.75, preprint (2026), Kourovka Notebook site, Theorem 1.1: for N = 2124210350 an
explicitly specified finite 2-group of order 2^(110N+1) in which every abelian normal subgroup can
be generated by at most 32N + 1 elements and some elementary abelian subgroup needs 65N generators;
Kourovka Notebook (21st issue), Problem 20.75: No, it is not,
https://kourovkanotebookorg.wordpress.com/wp-content/uploads/2026/09/kourovka_20.75_solution.pdf.
