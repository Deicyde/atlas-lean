# Alternating Group Recognizable By Spectrum

Kourovka 16.107 (W. J. Shi): for all large `n`, every finite group with the same set of element
orders as `Aₙ` is isomorphic to `Aₙ`, i.e. `h(π_e(Aₙ)) = 1`.
