# Restricted Wreath

The restricted (standard) wreath product `A ≀ B`: the elements of Mathlib's regular wreath
product `A ≀ᵣ B = (B → A) ⋊ B` whose function part has finite support. Written as the subgroup
generated by these elements, which already form a subgroup; for finite `B` it is all of
`A ≀ᵣ B`.
