# Exponent Four Detected On Bounded Subsets

Kourovka 13.10 (V. V. Bludov): there is `f : ℕ → ℕ` such that every soluble group `G` of
derived length (at most) `k` generated by a set `A`, in which the identity `x⁴ = 1` holds on every
subgroup generated by at most `f(k)` elements of `A`, has exponent dividing 4.
