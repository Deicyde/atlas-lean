# Finite State Automorphisms Irreducible Generators

Kourovka 16.86 (V. I. Sushchanskiĭ): for every `d ≥ 2` the group of finite-state automorphisms
of the `d`-regular rooted tree has an irreducible system of generators: a generating set none of
whose proper subsets generates the group.
