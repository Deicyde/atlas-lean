# Polynomial Folner Exhaustion Implies Polynomial Growth

Kourovka 14.27 (A. G. Vaillant): if `Γ` is generated by a finite set `S` and has finite subsets
`F₁ ⊊ F₂ ⊊ ⋯` (here `F 0 ⊊ F 1 ⊊ ⋯`) with union `Γ`, `|∂Fₖ| / |Fₖ| → 0` and `|Fₖ| ≤ c kᵈ` for
some `c ≥ 0`, `d ≥ 1`, then `Γ` has polynomial growth.
