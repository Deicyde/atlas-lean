# Totient Le Aut Order refuted

Resolved false: the Kourovka Archive answers 15.43(a) negatively (Bray and Wilson): some finite
groups have `|Aut G| < φ(|G|)`, and the ratio `|Aut G| / φ(|G|)` can be made arbitrarily small.
