# Golden integers

**Golden integers.** Let $\tau = (1 + \sqrt{5})/2$ be the golden ratio. A real number $x$ is a
golden integer when $x = a + b\tau$ for some integers $a$ and $b$. Since $\tau^2 = \tau + 1$, these
are exactly the elements of $\mathbb{Z}[\tau]$.
