# Letter Function

The function attached to a letter: `a ↦ f(x) = 2x`, `a⁻¹ ↦ x/2`, `b ↦ g(x) = 2^x` and
`b⁻¹ ↦ log₂ x` (the inverse of `g` for large `x`, which is all that matters for germs at `+∞`).
