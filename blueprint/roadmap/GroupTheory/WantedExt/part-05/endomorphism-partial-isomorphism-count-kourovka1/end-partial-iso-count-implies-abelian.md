# End Partial Iso Count Implies Abelian

Kourovka 19.20 (P. J. Cameron): a finite group `G` with `|End(G)| = |PIso(G)|` is abelian,
where `PIso(G)` is the set of partial isomorphisms of `G` (isomorphisms `H ≃ K` between subgroups
`H`, `K` of `G`).
