# Oc Seven Group Is Alternating

Kourovka 19.80 (W. J. Shi): every `OC₇`-group, that is, every group whose set of element orders
is exactly `{1, 2, …, 7}` (such a group is periodic), is isomorphic to the alternating group
`A₇`.
