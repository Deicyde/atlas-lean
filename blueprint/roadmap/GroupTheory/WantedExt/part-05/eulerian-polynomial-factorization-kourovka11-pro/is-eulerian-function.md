# Is Eulerian Function

`φ` is the Eulerian function of the finite group `G` (G. E. Wall): `∑_{K ≤ H} φ(K) = f(H)` for
every subgroup `H`. This determines `φ` uniquely, by induction on `H`; `φ ⊤` is the Eulerian
polynomial `φ(G)`.
