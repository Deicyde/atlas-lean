# Is PSolvable

`G` is `p`-solvable: it has a subnormal series `1 = N₀ ≤ N₁ ≤ ⋯ ≤ Nₙ = G` each of whose factors
`Nᵢ₊₁ / Nᵢ` is a `p`-group or has order prime to `p`.
