# Spectrum Group Count Bounded Or Infinite

Kourovka 13.63 (W. J. Shi): there is `k` such that for every `Γ ⊆ ℕ` the number `h(Γ)` of
isomorphism classes of finite groups `G` with `π_e(G) = Γ` is either at most `k` or infinite.
