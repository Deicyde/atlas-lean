# Is EAutomorphism

`φ` is an `e`-automorphism: for any two `φ`-invariant subgroups `A ⊄ B` (`φ(A) = A` and
`φ(B) = B`), some `a ∈ A \ B` has `[a, φ] ∈ B`.
