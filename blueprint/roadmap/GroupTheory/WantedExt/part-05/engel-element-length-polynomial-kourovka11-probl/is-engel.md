# Bounded Engel element

**Bounded Engel element.** An element $g$ of a group $G$ is an Engel element if there is an
$l \ge 1$ such that $[h, g; l] = 1$ for every $h \in G$, where $[h, g; 0] = h$,
$[h, g; i + 1] = [[h, g; i], g]$ and $[x, y] = x^{-1} y^{-1} x y$.
