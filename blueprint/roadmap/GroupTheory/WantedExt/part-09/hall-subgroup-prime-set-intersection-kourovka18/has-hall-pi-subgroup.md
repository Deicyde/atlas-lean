# The class $E_\pi$ of groups with a Hall π-subgroup

**The class $E_\pi$ of groups with a Hall π-subgroup.** Let $\pi$ be a set of natural numbers.
A group $G$ belongs to the class $E_\pi$ when $G$ has a Hall $\pi$-subgroup.
