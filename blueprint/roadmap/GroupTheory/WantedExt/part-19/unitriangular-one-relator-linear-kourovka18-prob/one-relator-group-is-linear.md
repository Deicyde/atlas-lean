# One Relator Group Is Linear

Kourovka 18.86 (V. A. Roman'kov): the group `⟨a, b | [[a, b], b] = 1⟩` is linear, that is, it
has a faithful representation in `GLₙ(K)` for some field `K` and some `n`.
