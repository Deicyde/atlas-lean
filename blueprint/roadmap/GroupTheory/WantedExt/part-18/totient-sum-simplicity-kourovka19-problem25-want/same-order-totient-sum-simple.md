# Same Order Totient Sum Simple

Kourovka 19.25 (B. Curtin, G. R. Pourgholi): if finite groups `G` and `H` have the same order
and the same totient sum `∑_{g ∈ G} φ(|g|) = ∑_{h ∈ H} φ(|h|)`, and `G` is simple, then `H` is
simple.
