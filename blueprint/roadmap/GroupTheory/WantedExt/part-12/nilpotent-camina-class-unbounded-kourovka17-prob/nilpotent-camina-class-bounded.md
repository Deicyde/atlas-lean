# Nilpotent Camina Class Bounded

Kourovka 17.47 (S. H. Ghate, A. S. Muktibodh): there is a bound `c` on the nilpotency class of
the nilpotent groups `G` in which every coset `x[G, G]` with `x ∉ [G, G]` equals the conjugacy
class `x^G`.
