# Quaternion Real Part Range Contains Interval

Kourovka 16.69(b) (J. Mycielski): for every nontrivial word `w(x, y)` the range of
`Re w(x, y)` over nonzero quaternions `x, y` contains the interval `[-5/27, 1]`.
