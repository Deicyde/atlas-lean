# Spectrum Recognizes PSL27

Kourovka 16.57 (V. D. Mazurov): every group, finite or not, whose set of element orders is
`{1, 2, 3, 4, 7} = ω(L₂(7))` is isomorphic to `L₂(7) = PSL(2, 7)`.
