# Sylow Character Degree Exponent Bounded

Kourovka 15.62 (A. Moretó): there is a function `f` such that `e_p(P) ≤ f(e_p(G))` for every
prime `p`, finite group `G` and Sylow `p`-subgroup `P` of `G`.
