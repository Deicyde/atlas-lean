# Centre Derived Rank Le Complement Rank

Kourovka 21.150 (V. I. Zenkov): let the finite group `G` be an extension of a normal
elementary abelian subgroup `A` by an elementary abelian complement `B ≅ G / A`, and let `a ∈ A`
satisfy `C_B(a) = 1`. Then, for `H = ⟨a, B⟩`, the rank of `Z(H) ∩ H'` is at most the rank of `B`:
whenever `B` is generated by `k` elements, so is `Z(H) ∩ H'`.
