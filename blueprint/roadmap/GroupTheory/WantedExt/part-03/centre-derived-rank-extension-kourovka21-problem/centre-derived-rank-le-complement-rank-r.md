# Centre Derived Rank Le Complement Rank refuted

Resolved false: for `A = F₃[x, y]/(x, y)³`, `B = ⟨1 + x, 1 + y⟩` acting by multiplication, `G = A ⋊
B` and `a = 1`, one has `C_B(a) = 1`, while `Z(H) ∩ H' = ⟨x², xy, y²⟩` has rank `3 > 2 = rank B`
(Monticone; van Doorn, Judin, Monticone and Morrison, Theorem 9.1). The 21st issue of the Kourovka
Notebook marks 21.150 solved ("No, not always"). Source: E. I. Khukhro and V. D. Mazurov (eds.),
Unsolved Problems in Group Theory: The Kourovka Notebook, 21st issue, arXiv:1401.0300v49 (2026),
Problem 21.150 (V. I. Zenkov); resolution: P. Monticone, letter of 21 March 2026 and solution note,
Kourovka Notebook site; W. van Doorn, E. Judin, P. Monticone and D. Morrison, On some problems from
the Kourovka Notebook, preprint, arXiv:2607.17477 (2026), Kourovka Notebook (21st issue), Problem
21.150: No, not always: A = F₃[x, y]/I³ (I = (x, y)), B = ⟨1 + x, 1 + y⟩ acting by multiplication, G
= A ⋊ B, a = 1; then C_B(a) = 1 and Z(H) ∩ H' = ⟨x², xy, y²⟩ has rank 3 while B has rank 2; van
Doorn-Judin-Monticone-Morrison, Theorem 9.1, https://arxiv.org/abs/2607.17477.
