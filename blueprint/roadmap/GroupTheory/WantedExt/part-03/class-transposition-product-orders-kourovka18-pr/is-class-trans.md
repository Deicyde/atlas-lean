# Is Class Trans

`σ` is the class transposition `τ_{r₁(m₁), r₂(m₂)}` (Kourovka 17.57): for `0 ≤ rᵢ < mᵢ` and
disjoint residue classes `r₁(m₁)`, `r₂(m₂)`, it interchanges `r₁ + k m₁` and `r₂ + k m₂` for every
integer `k` and fixes everything else.
