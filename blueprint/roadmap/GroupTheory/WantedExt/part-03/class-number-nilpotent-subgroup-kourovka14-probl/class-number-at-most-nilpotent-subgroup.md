# Class Number At Most Nilpotent Subgroup Order

Kourovka 14.54 (M. W. Liebeck, L. Pyber): every finite group `G` has a nilpotent subgroup `N`
with `k(G) ≤ |N|`, where `k(G)` is the number of conjugacy classes of `G`.
