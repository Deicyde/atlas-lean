# Is PSubnormal

`H` is `ℙ`-subnormal in `G`: `H = G`, or there is a chain `H = H₀ < H₁ < ⋯ < Hₙ = G` in which
every index `|Hᵢ : Hᵢ₋₁|` is a prime.
