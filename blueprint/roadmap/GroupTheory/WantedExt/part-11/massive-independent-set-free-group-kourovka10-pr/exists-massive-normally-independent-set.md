# Exists Massive Normally Independent Set

Kourovka 10.13 (R. I. Grigorchuk): some set `E` of reduced words in `a, b, a⁻¹, b⁻¹` (elements
of the free group `F₂`) is normally independent and massive, `limsup |Eₙ|^{1/n} = 3`, where `Eₙ`
is the set of words of length `n` in `E`. Since `|Eₙ| ≤ 4 · 3^{n-1}`, massiveness is stated as:
for every `0 < c < 3`, `|Eₙ| ≥ cⁿ` for infinitely many `n`.
