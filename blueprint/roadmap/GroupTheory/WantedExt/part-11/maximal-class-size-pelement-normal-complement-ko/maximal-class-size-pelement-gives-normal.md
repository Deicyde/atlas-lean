# Maximal Class Size PElement Gives Normal Complement

Kourovka 20.27 (I. B. Gorshkov): if a `p`-element `g` of a finite group `G` has
`|g^G|_p = max_{x ∈ G} |x^G|_p`, then `G` has a normal `p`-complement.
