# Exists FGInfinite Profinite CNGroup Not Prosoluble

Kourovka 20.90 (P. Shumyatsky): there is an infinite, topologically finitely generated
profinite group in which the centralizer of every non-trivial element is pronilpotent (a
CN-group) and which is not prosoluble (some continuous finite quotient is not soluble).
