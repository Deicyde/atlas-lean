# Perfect Centreless Order Le Max Class Sq

Kourovka 20.30 (P. M. Neumann and M. R. Vaughan-Lee): every perfect (`G' = G`) and
centreless finite group `G` satisfies `|G| ≤ n²`, where `n` is the largest size of a conjugacy
class of `G`. Since `n = |x^G|` for some `x`, this is `|G| ≤ |x^G|²` for some `x ∈ G`.
