# Polycyclic group

**Polycyclic group.** A group $G$ is polycyclic if for some $n \ge 0$ there are subgroups
$1 = H_0 \le H_1 \le \cdots \le H_n = G$ such that for each $i < n$, $H_i$ is normal in
$H_{i+1}$ and the quotient $H_{i+1} / H_i$ is cyclic.
