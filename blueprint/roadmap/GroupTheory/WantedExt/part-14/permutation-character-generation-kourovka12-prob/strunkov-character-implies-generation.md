# Strunkov Character Implies Generation

Kourovka 12.79 (S. P. Strunkov): if `a, b` are elements of a finite group `G` such that
`1^G - 1_{⟨a⟩}^G - 1_{⟨b⟩}^G - 1_{⟨ab⟩}^G + 2` is a character of `G`, then `G = ⟨a, b⟩`.
