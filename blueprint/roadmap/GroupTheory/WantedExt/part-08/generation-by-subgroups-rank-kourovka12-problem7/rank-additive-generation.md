# Rank Additive Generation

Kourovka 12.71 (L. Ribes): for all finite groups `A` and `B` there is a finite group `G`
generated by subgroups isomorphic to `A` and `B` with `d(G) = d(A) + d(B)`, where `d` is the
minimal number of generators (`Group.rank`).
