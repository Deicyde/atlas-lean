# Is Supersoluble

`G` is supersoluble: for some elements `g₀, …, g_{n-1}` every subgroup `Gᵢ = ⟨g_j : j < i⟩`
(`i ≤ n`) is normal in `G` and `G_n = G`, so `1 = G₀ ≤ ⋯ ≤ G_n = G` is a normal series with cyclic
factors `G_{i+1} / G_i = ⟨G_i, g_i⟩ / G_i`.
