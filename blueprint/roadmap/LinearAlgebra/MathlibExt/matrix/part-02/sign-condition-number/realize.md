# Real sign matrix of a Boolean matrix

**Real sign matrix of a Boolean matrix.** The realization of a Boolean $n \times n$ matrix $A$
is the real $n \times n$ matrix whose $(i, j)$ entry is $-1$ if $A_{ij}$ is true and $1$ if
$A_{ij}$ is false.
