# Generalized Hyper Fibonacci toeplitz has Positive Minors

For `r ≥ 1` and `Δ = a² + pab - b²`: if `Δ > 0`, the Toeplitz matrix `T_{r+2,2n}^{(r)}` is
totally positive for all large `n`; if `Δ < 0`, so is `T_{r+2,2n+1}^{(r)}`.
