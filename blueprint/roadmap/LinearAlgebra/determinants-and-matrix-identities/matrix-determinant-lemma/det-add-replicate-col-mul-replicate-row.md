# Matrix determinant lemma in column-times-row form

The matrix determinant lemma with the rank-one update written as a column matrix times a row
matrix, and with no invertibility hypothesis: for a square matrix `A` over a commutative ring and
vectors `u`, `v`, let `U` be the matrix with the single column `u` and `V` the matrix with the
single row `v`. Then `det (A + U V) = det A + vᵀ adj(A) u`, where `adj(A)` is the adjugate of
`A`.
