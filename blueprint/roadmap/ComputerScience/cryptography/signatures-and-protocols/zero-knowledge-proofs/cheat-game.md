# The experiment of a cheating prover

For a statement $x$, a cheating prover with coins in a finite nonempty set and a finite nonempty set
of challenges: the experiment draws the prover's coins $r$ and a challenge $e$ uniformly and
independently; from its coins $r$ the prover sends a commitment $a(r)$; on the challenge $e$ it
answers $z(r, e)$; the experiment outputs whether the verifier accepts.
