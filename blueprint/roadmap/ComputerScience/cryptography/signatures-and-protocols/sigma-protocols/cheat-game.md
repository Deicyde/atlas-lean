# Cheating-prover experiment

For a statement $x$, a cheating prover with coins in a finite nonempty set sends the commitment $a(r)$
computed from its coins $r$, and answers a challenge $e$ with $z(r, e)$. The experiment draws the coins
and a challenge uniformly and outputs $1$ when the verifier accepts $(a(r), e, z(r, e))$.
