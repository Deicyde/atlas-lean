# Theorem 2 [2]

Suppose $A$ is a square matrix admitting a decomposition $A = L + S$ where $L$ is invertible and the largest singular value of $L^{-1}S$ has absolute value $\rho < 1$. Then the iteration given by (1), (2) for solving $Ax = b$ converges to the correct answer as $\rho^k$.
