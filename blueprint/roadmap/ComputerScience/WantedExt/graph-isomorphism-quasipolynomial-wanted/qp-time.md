# Quasipolynomial time bound

**Quasipolynomial time bound.** For an exponent $c \in \mathbb{N}$ and an input length
$n \in \mathbb{N}$, the quasipolynomial time bound is
$q_c(n) = 2^{(\lfloor \log_2(n+2) \rfloor + 2)^c}$.
