# Sign of a Boolean label

**Sign of a Boolean label.** For a commutative ring $K$, the sign of a Boolean label $y$ is
the element $\operatorname{sign}(y) \in K$ equal to $1$ if $y$ is true and to $-1$ if $y$ is
false.
