# Stability of single linkage in the sup norm

If two dissimilarities on the same set
satisfy `|d₁ x y - d₂ x y| ≤ η` for all `x, y`, then their single-linkage ultrametrics satisfy
`|u₁ x y - u₂ x y| ≤ η` for all `x, y` (Carlsson and Mémoli, JMLR 11 (2010), Lemma 15, stated
there for two metrics on a finite set; the chain argument needs neither hypothesis).
