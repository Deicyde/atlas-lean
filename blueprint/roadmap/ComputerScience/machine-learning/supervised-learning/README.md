# Supervised learning and regression

Prediction from labelled data: least squares, ridge, lasso and kernel or Gaussian-process regression (including GBLUP), the bias-variance decomposition, Bayes classifiers and optimal predictors, log loss, decision-tree information gain, backpropagation, and sufficient input subsets. Ridge regression is the finite-dimensional case of [Tikhonov regularization](../../../Analysis/convex-analysis-and-variations/tikhonov-regularization/README.md); point estimation theory (risk, sufficiency, James–Stein shrinkage) is under [statistical estimation](../../../Probability/statistical-estimation/README.md), and Gauss–Markov and generalized least squares under [linear models and multivariate analysis](../../../Probability/linear-models-multivariate/README.md).
