# Counterfactual probability given evidence

**Counterfactual probability given evidence** (Pearl, *Statistics Surveys* 2009, §3.4, the
computation of `P(Y_{x₁} = y₁ | Y = y₀, X = x₀)` following eq. (28)): the probability that the
event `Y` holds for the counterfactual values `X_{W ← w}(u)`, under the law of the disturbances
conditioned on the event that the factual values `X(u)` satisfy `E`.
