# PAC learning

Valiant's model of learning from random examples, on CSLib's PAC library (error, learners, version spaces, consistency, PAC learnability, VC dimension): Valiant's Bernoulli-trial bound, the Occam bound for consistent learners over a finite class, learning k-CNF by elimination, and the fundamental theorem relating PAC learnability to the VC dimension. Uniform deviation bounds for the agnostic case are under [generalization bounds and concentration](../generalization-bounds-and-concentration/README.md); boosting weak learners is under [online learning and boosting](../online-learning-and-boosting/README.md).
