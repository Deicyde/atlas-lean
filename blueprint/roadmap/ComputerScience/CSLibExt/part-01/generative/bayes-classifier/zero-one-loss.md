# The 0-1 loss

**The 0-1 loss.** For elements $c$ and $y$ of a type $C$ of classes, the 0-1 loss of
predicting $y$ when the true class is $c$ is the extended nonnegative real number that equals
$0$ if $y = c$ and $1$ if $y \ne c$.
