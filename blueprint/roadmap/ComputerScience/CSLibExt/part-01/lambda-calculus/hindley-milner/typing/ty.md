# Monotypes

**Monotypes.** A monotype over a set $B$ of base types is a term over the constants $B$: a
type variable $\alpha \in \mathbb{N}$, a base type $b \in B$, or an arrow $\tau_1 \to \tau_2$ of
two monotypes (a binary node).
