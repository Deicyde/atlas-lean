# Terms of the simply typed lambda calculus with references

**Terms of the simply typed lambda calculus with references.** Fix a type $B$ of base types.
The terms are generated by: variables, given as de Bruijn indices $x \in \mathbb{N}$;
abstractions $\lambda{:}T.\,t$, where $T$ is a type over $B$ and $t$ is a term in which index $0$
refers to the abstraction's parameter; applications $t_1\,t_2$; the unit value $\mathsf{unit}$;
store locations $l \in \mathbb{N}$; allocations $\mathsf{ref}\,t$; dereferences $!t$; and
assignments $t_1 := t_2$.

Store locations arise during evaluation, not in source programs.
