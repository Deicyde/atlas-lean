# Probabilistic PCA covariance

**Probabilistic PCA covariance.** For a real $d \times q$ matrix $W$ and a real number
$\sigma^2$, the probabilistic PCA covariance is the $d \times d$ matrix $W W^\top + \sigma^2 I$.
