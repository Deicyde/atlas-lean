# Gate variables in a range

**Gate variables in a range.** For natural numbers $k$ and $k'$, a variable $x \in \mathbb{N}$
is a gate in range $[k, k')$ if $x = 2j + 1$ for some $j \in \mathbb{N}$ with $k \le j < k'$.
