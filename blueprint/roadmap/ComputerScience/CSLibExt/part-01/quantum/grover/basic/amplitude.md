# Real amplitude vectors

**Real amplitude vectors.** For a type $\alpha$ (the search space), a real amplitude vector
indexed by $\alpha$ is a function $\psi : \alpha \to \mathbb{R}$, assigning a real amplitude to
each point of $\alpha$.
