# Grover angle

**Grover angle.** For a finite search space $\alpha$ and a marked set $M \subseteq \alpha$, the
Grover angle of $M$ is $\theta = \arcsin \sqrt{|M| / |\alpha|}$, where the quotient
$|M| / |\alpha|$ is taken to be $0$ when $\alpha$ is empty.
