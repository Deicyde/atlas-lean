# Infinite run

**Infinite run.** In a labelled transition system, a sequence of states $s_0, s_1, s_2, \dots$
is an infinite run when for every $i$ there is a label $a$ such that there is a transition from
$s_i$ to $s_{i+1}$ labelled $a$.
