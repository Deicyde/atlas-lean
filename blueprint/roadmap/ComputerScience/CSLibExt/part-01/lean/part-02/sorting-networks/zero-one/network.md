# Comparator network

**Comparator network.** A comparator network on $n$ wires is a finite list of pairs $(i, j)$
of wires $i, j \in \{0, \dots, n - 1\}$, each pair standing for the comparator $(i, j)$; the
comparators are applied in list order.
