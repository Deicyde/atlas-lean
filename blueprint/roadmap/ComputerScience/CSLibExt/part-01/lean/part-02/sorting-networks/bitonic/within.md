# Comparators within an interval

**Comparators within an interval.** A list $ps$ of comparators, each a pair $(i, j)$ of
natural numbers, lies within $[l, h)$ if every comparator $(i, j)$ in $ps$ satisfies
$l \le i < h$ and $l \le j < h$.
