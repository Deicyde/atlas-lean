# Interval indicators

**Interval indicators.** A sequence $s : \mathbb{N} \to \{0, 1\}$ is an interval indicator
of length $L$ if there are natural numbers $a \le e \le L$ such that for every $i < L$,
$s(i) = 1$ exactly when $a \le i < e$.
