# Total value of a knapsack selection

**Total value of a knapsack selection.** For knapsack items $x_0, \dots, x_{n-1}$ with values
$v_i$ and a set $S \subseteq \{0, \dots, n - 1\}$ of item indices, the total value of $S$ is
$\sum_{i \in S} v_i$.
