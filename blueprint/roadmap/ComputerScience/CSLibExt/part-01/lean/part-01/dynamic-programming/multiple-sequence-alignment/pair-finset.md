# Pairs of rows

**Pairs of rows.** For $k \in \mathbb{N}$, the finite set of all pairs $(i, j)$ with
$i, j \in \{0, \dots, k-1\}$ and $i < j$, so that each unordered pair of distinct rows appears
exactly once.
