# Child index in a $d$-ary heap array

**Child index in a $d$-ary heap array.** For natural numbers $d$, $i$ and $k$, the child of
index $i$ with zero-based offset $k$ in a contiguous level-order $d$-ary tree is the index
$d i + k + 1$.
