# Next split axis of a kd-tree

**Next split axis of a kd-tree.** For a dimension $d \ge 1$ and an axis
$a \in \{0, \dots, d - 1\}$, the next split axis is $(a + 1) \bmod d$, so the axes are
visited cyclically.
