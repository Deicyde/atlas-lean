# Membership in an axis-aligned box

**Membership in an axis-aligned box.** For $lo, hi, p \in \mathbb{Z}^d$, the point $p$ lies
in the closed axis-aligned box $[lo, hi]$ when $lo_i \le p_i \le hi_i$ for every coordinate
$i \in \{0, \dots, d-1\}$.
