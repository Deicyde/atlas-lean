# Number of keys of a node

**Number of keys of a node.** Write $|t|$ for the number of nodes of a binary tree $t$. For
binary trees $l$ and $r$ and a key $k$, the node with key $k$, left subtree $l$ and right subtree
$r$ has $|l| + |r| + 1$ nodes.
