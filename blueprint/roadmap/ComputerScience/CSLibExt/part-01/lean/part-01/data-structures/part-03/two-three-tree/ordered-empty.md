# The empty 2-3 tree is ordered

**The empty 2-3 tree is ordered.** For every type $\alpha$ with a relation $<$, the empty
2-3 tree of unspecified height over $\alpha$ (the leaf, of height $0$) satisfies the ordering
invariant.
