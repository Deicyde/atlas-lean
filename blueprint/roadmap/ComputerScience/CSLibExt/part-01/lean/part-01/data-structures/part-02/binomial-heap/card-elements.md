# Size of a valid binomial tree

**Size of a valid binomial tree.** For a type $\alpha$ with a relation $\le$, every valid
binomial tree of rank $r$ over $\alpha$ represents a multiset of exactly $2^r$ elements, counted
with multiplicity.
