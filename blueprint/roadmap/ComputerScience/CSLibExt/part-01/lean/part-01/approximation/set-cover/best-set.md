# Greedy choice of a set

**Greedy choice of a set.** Given a list $F$ of finite sets and a finite set $U$, the best set
of $F$ for $U$ is the first set $S$ in the list $F$ that maximizes $|S \cap U|$, or $\emptyset$
when $F$ is empty.
