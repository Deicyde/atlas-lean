# Card nonwitnesses le of carmichael

CLRS Theorem 31.38, case 2: for a Carmichael number (Mathlib's `Nat.IsCarmichael`) the
non-witnesses lie in the proper subgroup `{x : x^(2^j u) = ±1}`.
