# Soundness of a β-contraction in the graph model

If $(\lambda.M)\,N$ contracts to $M[N]$ (CSLib's β-step, with $\lambda.M$ and $N$ locally closed), both sides have the same denotation in $P(\omega)$ under all valuations (D. Scott, *Data types as lattices*, SIAM J. Comput. 5(3) (1976), 522–587, Theorem 2.2, the rule β).
