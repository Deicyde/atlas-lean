# Chosen value in a state

**Chosen value in a state** (Section 2.2): every acceptor of some quorum accepted a proposal
with value `v`, all with the same number.

## Sources

- L. Lamport, *Paxos Made Simple*, ACM SIGACT News 32(4), December 2001, 51–58; author's version dated 01 Nov 2001: Section 2.2.
