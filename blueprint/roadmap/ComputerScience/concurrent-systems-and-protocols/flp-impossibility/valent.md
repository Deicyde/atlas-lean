# Valence of a state

`Valent a s b` holds when some state reachable from `s` by the algorithm `a` has decided $b$. In the terms of Fischer, Lynch and Paterson (1985, §3), $b$ belongs to the set $V$ of decision values of the configurations reachable from $s$; $s$ is bivalent when $|V| = 2$ and $b$-valent when $V = \{b\}$.
