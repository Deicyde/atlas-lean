# Program counter of a bakery process

`doorway U m`: choosing, with the entries `U` still
to read and running maximum `m`; `write m`: about to write the ticket `1 + m`; `exit`: about to
reset `choosing`; `l2 j` and `l3 j`: at statements L2 and L3 of the loop, for index `j`.

## Sources

- L. Lamport, *A New Solution of Dijkstra's Concurrent Programming Problem*, Communications of the ACM 17(8), August 1974, 453–455: p. 454.
