# Application in `P(ω)` is jointly Scott-continuous

The map $(u, x) \mapsto \operatorname{app}(u, x)$ on $P(\omega) \times P(\omega)$ is Scott-continuous. Continuity in each variable separately implies joint continuity (D. Scott, *Continuous Lattices*, Oxford PRG-7 (1971), Proposition 2.6; D. Scott, *Data types as lattices*, SIAM J. Comput. 5(3) (1976), 522–587, §1).
