# The interval cutoff of zero width vanishes

**The interval cutoff of zero width vanishes.** For all real numbers $a$, $b$ and $x$, the
interval cutoff $\chi_{a,b,0}$ with endpoints $a$, $b$ and width $0$ satisfies
$\chi_{a,b,0}(x) = 0$.
