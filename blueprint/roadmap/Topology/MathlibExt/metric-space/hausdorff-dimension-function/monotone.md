# Monotonicity of a Hausdorff dimension function

**Monotonicity of a Hausdorff dimension function.** Every Hausdorff dimension function
$\psi : [0,\infty) \to [0,\infty)$ is non-decreasing: if $r \le s$ then $\psi(r) \le \psi(s)$.
