# Is Geodesic On With Speed

`γ` is a geodesic of speed `c` on the set of times `s`: every `t ∈ s` has a neighborhood on
which `γ` realizes distances with factor `c`, i.e. `edist (γ t₁) (γ t₂) = c * edist t₁ t₂` whenever
`t₁, t₂ ∈ s` are `ε`-close to `t`.
