# Geodesics defined for all times

**Geodesics defined for all times.** Let $X$ be a pseudo-extended metric space. A curve
$\gamma : \mathbb{R} \to X$ is a geodesic if it is a geodesic on the set of all times
$\mathbb{R}$.
