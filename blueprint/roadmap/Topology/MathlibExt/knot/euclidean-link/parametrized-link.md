# Parametrized link

**Parametrized link.** An oriented labeled parametrized smooth link with $n$ components
in Euclidean 3-space is a family $(\gamma_i)_{i < n}$ of parametrized knots whose traces
$\gamma_i(\mathbb{R})$ are pairwise disjoint.
