# The letter T

**The letter T.** The letter-T curve is the subset

$$T = \{(0, y) : 0 \le y \le 1\} \cup \{(x, 1) : -1 \le x \le 1\}$$

of $\mathbb{R}^2$: a vertical stem with a horizontal bar on top, meeting at the branch point
$(0, 1)$.
