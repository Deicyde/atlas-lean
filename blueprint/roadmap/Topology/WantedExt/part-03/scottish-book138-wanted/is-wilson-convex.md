# Is Wilson Convex

A set is convex in the sense of Wilson when, for every `x, y` in it and
every `t ∈ [0, 1]`, there is exactly one `z` in it with
`dist x z = t * dist x y` and `dist z y = (1 - t) * dist x y`.
