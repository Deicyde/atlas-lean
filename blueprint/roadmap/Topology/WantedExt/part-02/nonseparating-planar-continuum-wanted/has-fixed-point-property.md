# Fixed point property

**Fixed point property.** A subset $K$ of the Euclidean plane $\mathbb{R}^2$ has the fixed
point property when every continuous map $f \colon K \to K$ has a fixed point, that is, a point
$x \in K$ with $f(x) = x$.
