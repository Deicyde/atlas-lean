# Dense macias Topology arithmetic Progression

For positive integers `a, b` with `gcd(a, b) = 1`, the arithmetic progression
`aℕ₀ + b = {b, a + b, 2a + b, …}` is dense in the comaximal space `CM(ℕ)`.
