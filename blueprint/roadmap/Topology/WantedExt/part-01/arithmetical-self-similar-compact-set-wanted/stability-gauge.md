# Stability Gauge

The stability gauge `‖n‖_K := ℓ μ + d - u` (when `n / ρ^ℓ ∈ T_u`) of a
quasi-arithmetical compact set of module `μ` and ratio `ρ`, with the displacement `d`
chosen so that `‖1‖_K = 0`, i.e. `d = -(ℓ₁ μ - u₁)` for the witness `1 / ρ^{ℓ₁} ∈ T_{u₁}`.
