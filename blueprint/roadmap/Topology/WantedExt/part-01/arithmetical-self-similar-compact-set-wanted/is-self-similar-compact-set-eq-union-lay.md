# Is Self Similar Compact Set eq union layers

Proposition 2: a self-similar compact set of module `μ` and ratio `ρ` is
`K = {0} ∪ ⋃_{n ≥ 0} (T_0 ∪ ⋯ ∪ T_{μ-1}) / ρ^n`.
