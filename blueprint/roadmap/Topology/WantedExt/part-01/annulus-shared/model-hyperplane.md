# Model hyperplane

**Model hyperplane.** For $n \ge 1$, the model hyperplane in $\mathbb{R}^n$ is the set of
points $x = (x_0, \dots, x_{n-1})$ whose first coordinate $x_0$ is $0$. It is the local model for
a locally flat embedded sphere.
