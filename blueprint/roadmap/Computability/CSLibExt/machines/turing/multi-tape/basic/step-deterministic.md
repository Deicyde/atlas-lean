# Step determinism

**Step determinism.** Let $M$ be a deterministic multi-tape Turing machine, with the one-step
relation it inherits as a nondeterministic machine. If a configuration $c$ steps to both $c_1$
and $c_2$, then $c_1 = c_2$.
