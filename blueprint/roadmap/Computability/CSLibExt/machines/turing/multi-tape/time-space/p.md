# Polynomial time on multi-tape machines

**Polynomial time on multi-tape machines.** $\mathrm{P}$ is the set of languages of Boolean
strings that lie in $\mathrm{DTIME}(n \mapsto n^d)$ for some $d \in \mathbb{N}$.
