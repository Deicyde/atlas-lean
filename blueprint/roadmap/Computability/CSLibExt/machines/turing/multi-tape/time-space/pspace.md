# Polynomial space on multi-tape machines

**Polynomial space on multi-tape machines.** $\mathrm{PSPACE}$ is the set of languages of
Boolean strings that lie in $\mathrm{DSPACE}(n \mapsto n^d)$ for some $d \in \mathbb{N}$.
