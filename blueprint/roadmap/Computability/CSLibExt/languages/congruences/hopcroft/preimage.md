# Preimage of a set under a letter

**Preimage of a set under a letter.** For a DFA $M$ with transition function $\delta$, a set
$C$ of states and a letter $a$, the preimage of $C$ under $a$ is the set of states $q$ with
$\delta(q, a) \in C$.
