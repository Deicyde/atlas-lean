# K

Stacks: input `X`, output `O`, the edge bits `E` (reversed between passes), junk `J`, the
counters `S`, `T`, `N` (for `s`, `t`, `n`; `N` counts the passes left) and `U`, `V` (for an
arc), the marks `M` (vertex `0` on top) and the parked marks `P`.
