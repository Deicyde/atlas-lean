# Stack-cap constraint 2

**Stack-cap constraint 2.** For natural numbers $m$, $T$ and $d$ with $T \ge 1$, the stack cap
$H = m + (T + 1) d + 1$ for input bound $m$, run length $T$ and per-step growth $d$ satisfies
$2d \le H$.
