# Drain step count

**Drain step count.** For a list $k_1, \dots, k_m$ of stacks and contents $S$ assigning a
list $S_k$ to each stack $k$, the drain step count is $1 + \sum_{i=1}^{m} (|S_{k_i}| + 1)$.
