# Empty scratch counters

**Empty scratch counters.** An assignment $F$ of natural numbers to the generator's counters
has empty scratch counters when $F(Q) = F(\mathrm{tmp}) = F(\mathrm{md}) = F(c_1) = F(c_2) = 0$.
