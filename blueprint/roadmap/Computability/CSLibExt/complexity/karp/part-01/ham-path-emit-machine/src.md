# Counters read by copy sites

**Counters read by copy sites.** The type with the five elements $p, n, r, j, d$, naming the
counters of the HAMPATH emitter that a copy site can read: the diamond top $p$, the row end $n$,
the row vertex $r$, the clause index $j$ and the detour vertex $d$.
