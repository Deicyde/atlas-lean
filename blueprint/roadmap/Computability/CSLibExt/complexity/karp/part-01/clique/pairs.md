# Vertex pairs in encoding order

**Vertex pairs in encoding order.** For a natural number $n$, the list of all pairs $(i, j)$ of
natural numbers with $i < j < n$, ordered by $i$ ascending and, for each $i$, by $j$ descending
from $n - 1$ to $i + 1$.
