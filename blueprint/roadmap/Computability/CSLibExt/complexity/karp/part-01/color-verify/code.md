# Two-bit code of a color

**Two-bit code of a color.** The code of a color $c \in \{0, 1, 2\}$ is the pair of bits whose
first bit is $1$ iff $c = 2$ and whose second bit is $1$ iff $c = 1$: $0 \mapsto 00$,
$1 \mapsto 01$ and $2 \mapsto 10$.
