# Lab

Labels. `c0 fl`/`c1 fl b` read the two bits of a token (`fl`: current clause satisfied),
`adv fl o` moves one assignment bit `B → A` (`o = some s`: literal token `1s`), `restore fl`
moves the used assignment bits back `A → B`.
