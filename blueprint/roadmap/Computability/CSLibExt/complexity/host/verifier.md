# Verifier host

**Verifier host.** A component that starts with `x` on `cX` and `w` on `cW` and stops at
`yes` or `no` according to `f x w` within `p (|x| + |w|)` steps gives a polynomial-time `TM2`
machine for `f` on the `x # w` input.
