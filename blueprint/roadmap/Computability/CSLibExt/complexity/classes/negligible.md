# Negligible functions

**Negligible functions.** A function $e : \mathbb{N} \to \mathbb{Q}$ is negligible if for
every natural number $c$ there is a natural number $N$ such that $e(n) \le 1 / n^c$ for all
natural numbers $n \ge N$.
