# Kingman limit of a subadditive cocycle

**Kingman limit of a subadditive cocycle.** The limit `lim X n / n` in Kingman's theorem, defined as `limsup X n / n` cast to `ℝ` (so it is
`0` where the `limsup` is infinite).
