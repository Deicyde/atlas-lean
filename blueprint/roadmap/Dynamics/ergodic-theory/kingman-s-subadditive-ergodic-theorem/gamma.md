# Time constant of a subadditive cocycle

**Time constant of a subadditive cocycle.** The time constant `lim_n (∫ X n dμ) / n = inf_n (∫ X n dμ) / n` (Fekete's lemma); it is
meaningful when `expSeq n / n` is bounded below.
