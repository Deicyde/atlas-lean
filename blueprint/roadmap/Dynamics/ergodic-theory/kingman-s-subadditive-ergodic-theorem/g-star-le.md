# Upper limit of a cocycle bounded by Birkhoff limits of blocks

**Upper limit of a cocycle bounded by Birkhoff limits of blocks.** For each `k ≥ 1`, `limsup X n / n ≤ birkhoffLimit (T^[k]) (X k) / k` almost everywhere.
