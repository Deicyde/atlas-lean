# Invariant set as a set equal to its preimage

A set `E` is invariant under `T` in the sense of [Invariant set of a map](is-invariant-set.md)
(`x ∈ E ↔ T x ∈ E` for every `x`) exactly when `T⁻¹(E) = E`. This is the notion of invariance
used in the definition of pre-ergodicity (every measurable set `E` with `T⁻¹(E) = E` has measure
zero or full measure) and of the σ-algebra of invariant measurable sets.
