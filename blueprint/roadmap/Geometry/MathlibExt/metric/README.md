# Distances in finite configurations

## Mathematical overview

A finite configuration determines distances between its points. This section distinguishes the set of distances, the number of distinct distances, and the multiplicity of an individual distance. It also counts unit-distance pairs and compares that count with the total number of unordered pairs.

Start with [distance multiplicity](distance-multiplicity.md) and [distance sets](distance-set.md), then compare [distinct distances](distinct-distances.md) with [unit-distance counts](unit-dist-num.md).
