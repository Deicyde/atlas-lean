# Membership in an integer unit cube

**Membership in an integer unit cube.** For $v \in \mathbb{Z}^n$ and $x \in \mathbb{R}^n$, $x$
lies in the integer unit cube at $v$ if and only if $v_i \le x_i < v_i + 1$ for every
coordinate $i$.
