# The coordinate cube as an absolute-value box

**The coordinate cube as an absolute-value box.** For every $n$, the coordinate cube in
$\mathbb{R}^n$ equals the set of points $x \in \mathbb{R}^n$ with $|x_i| \le 1$ for every
coordinate $i$.
