# A Borsuk cover bounds the Borsuk number

**A Borsuk cover bounds the Borsuk number.** If a set $s$ in the Euclidean space
$\mathbb{R}^n$ has a $k$-piece Borsuk cover for a natural number $k$, then the Borsuk number of
$s$ is at most $k$.
