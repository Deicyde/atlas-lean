# Euclidean distance set

**Euclidean distance set.** For a set $E \subseteq \mathbb{R}^d$, the distance set of $E$ is
$\Delta(E) = \{\lvert x - y \rvert : x, y \in E\}$, the set of Euclidean distances between pairs
of points of $E$.
