# Sphere-packing density in four dimensions

## Mathematical overview

Sphere packing studies how disjoint balls occupy space. This section develops density notions for four-dimensional packings, including finite-radius and upper densities, unit-ball volume, and periodic packings. Individual articles specify the density notion and hypotheses used in each bound.
