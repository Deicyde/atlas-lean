# Exists cube Count le const mul pow

Real `O(t ^ d)` consequence (source lines 283–311): with
`M = 2 * ⌈K * √d⌉₊ + 3`, the constant `C = 2 ^ d * M ^ n` depends on `f`
(through `K`), `n`, and `d`, but not on `t`. Uses `⌈t⌉₊ ≤ 2 * t` for `t ≥ 1`.
