# Integer Cube Set

The set of integer unit-cube indices meeting the dilate `t • f (unitCube d)`.
A vector `v : Fin n → ℤ` is included when some cube point `y` has `t * f y` in
the half-open cube `[vᵢ, vᵢ + 1)` in every coordinate.
