# The moving sofa problem

## Mathematical overview

The moving sofa problem asks how large a planar shape can be while still passing through an L-shaped corridor by rigid motion. This section develops the corridor, motion, passage, and area definitions. The unit-square example provides a basic feasible shape; the optimal-area definition formulates the separate optimization question.
