# Wolff's planar distance set theorem

**Wolff's planar distance set theorem.** Every compact set $E \subseteq \mathbb{R}^2$ with
Hausdorff dimension greater than $4/3$ has a distance set $\{|x - y| : x, y \in E\}$ of positive
Lebesgue measure.
