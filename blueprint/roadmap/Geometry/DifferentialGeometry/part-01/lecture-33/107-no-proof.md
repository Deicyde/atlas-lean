# Theorem 33.3 (no proof)

Let $M, \tilde{M} \subset \mathbb{R}^{n+1}$ be compact connected hypersurfaces with orientations, and $\phi \colon M \rightarrow \tilde{M}$ a smooth map. Suppose that $p \in \tilde{M}$ is a point with the following properties: (i) there are only finitely many $y_{1}, \ldots, y_{k} \in M$ such that $\phi(y_{i}) = p$; (ii) at each $y_{i}$, we have $\operatorname{det}(D\phi_{y_{i}}) \neq 0$. Then $\operatorname{deg}(\phi) = \sum_{i=1}^{k} \operatorname{sign}(\operatorname{det}(D\phi_{y_{i}}))$.
