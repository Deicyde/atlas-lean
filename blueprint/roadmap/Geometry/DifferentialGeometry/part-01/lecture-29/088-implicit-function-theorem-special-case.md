# Corollary 29.1 (Implicit function theorem, special case)

Let $\tilde{V} \subset \mathbb{R}^{n+1}$ be an open subset, $\psi \colon \tilde{V} \rightarrow \mathbb{R}$ a smooth function, and $y \in \tilde{V}$ a point such that $\psi(y) = 0$, $D\psi(y) \neq 0$. Then there are: an open subset $V \subset \tilde{V}$, still containing $y$; an open subset $U \subset \mathbb{R}^{n+1}$ containing 0; and a diffeomorphism $\phi \colon U \rightarrow V$ such that $\phi(0) = y$, and $\psi(\phi(x)) = x_{n+1}$ for all $x$.
