# Definition 26.1

A function $f \colon M \rightarrow \mathbb{R}$ is smooth if for every point $y \in M$ there is an open subset $V \subset \mathbb{R}^{n+1}$ containing $y$, and a smooth function $\tilde{f} \colon V \rightarrow \mathbb{R}$, such that $f|_{M \cap V} = \tilde{f}|_{M \cap V}$. We call $\tilde{f}$ a local extension of $f$.
