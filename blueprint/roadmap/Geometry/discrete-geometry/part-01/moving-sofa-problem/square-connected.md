# The unit square is connected

**The unit square is connected.** The unit square
$\{z \in \mathbb{C} : 0 \le \operatorname{Re} z \le 1,\ 0 \le \operatorname{Im} z \le 1\}$ is a
nonempty connected subset of $\mathbb{C}$.
