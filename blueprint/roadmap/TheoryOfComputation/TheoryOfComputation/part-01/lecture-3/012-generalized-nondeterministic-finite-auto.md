# Definition (Generalized Nondeterministic Finite Automaton)

A Generalized Nondeterministic Finite Automaton (GNFA) is similar to an NFA, but allows regular expressions as transition labels. For convenience we assume: one accept state, separate from the start state; one arrow from each state to each state, except (a) only exiting the start state and (b) only entering the accept state.
