# Definition (IP)

$\mathsf{IP} = \{A \mid \text{for some } V \text{ and } P \text{ (honest prover):}$ $w \in A \Rightarrow \Pr[(V \leftrightarrow P) \text{ accepts } w] \geq 2/3$; $w \notin A \Rightarrow \text{for any prover } \tilde{P},\; \Pr[(V \leftrightarrow \tilde{P}) \text{ accepts } w] \leq 1/3\}$.
