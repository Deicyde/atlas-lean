# Reachability for a TM2 machine

**Reachability for a TM2 machine.** For a TM2 machine $M$ and configurations $c$ and $d$, $d$
is reachable from $c$ when there is some $n \in \mathbb{N}$ such that $M$ runs from $c$ to $d$
in exactly $n$ steps.
