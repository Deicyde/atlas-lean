# Le Gall's 2012 bound on the dual exponent

**Le Gall's 2012 bound on the dual exponent.** For every field $F$, the dual matrix
multiplication exponent $\alpha(F)$ of the arithmetic-circuit model satisfies
$\alpha(F) > 0.30298$.
