# Duan–Wu–Zhou bound on the square exponent

**Duan–Wu–Zhou bound on the square exponent.** For every field $F$, the square matrix
multiplication exponent $\omega(F)$ of the arithmetic-circuit model satisfies
$\omega(F) \le 2.371866$.
