# Signed integer from a magnitude–sign pair

**Signed integer from a magnitude–sign pair.** The integer decoded from a pair $(k, s)$ of a
natural number $k$ and a boolean $s$ is $k$ if $s$ is true and $-k$ if $s$ is false.
