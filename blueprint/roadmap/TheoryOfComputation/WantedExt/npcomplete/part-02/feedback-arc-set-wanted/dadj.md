# Directed adjacency in an arc list

**Directed adjacency in an arc list.** For a list $E$ of ordered pairs of natural numbers and
natural numbers $u$ and $v$, the directed adjacency test returns true when the pair $(u, v)$
occurs in $E$, that is, when $E$ contains an arc from $u$ to $v$, and false otherwise.
