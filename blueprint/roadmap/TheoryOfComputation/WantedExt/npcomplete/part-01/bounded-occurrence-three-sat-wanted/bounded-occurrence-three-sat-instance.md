# Bounded-occurrence 3-SAT instances

**Bounded-occurrence 3-SAT instances.** A bounded-occurrence 3-SAT instance is a pair
$(n, \varphi)$ of a natural number $n$, the number of variables, and a CNF formula $\varphi$.
