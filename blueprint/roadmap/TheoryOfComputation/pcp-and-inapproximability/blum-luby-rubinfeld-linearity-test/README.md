# Blum–Luby–Rubinfeld linearity test

The BLR test reads a function on the cube at three correlated points and accepts when the values are consistent with linearity. Its Fourier analysis, the prototype of local testing and of the long-code tests behind PCP-based hardness results, shows that a function accepted with probability `1 - ε` is `ε`-close to a character.
