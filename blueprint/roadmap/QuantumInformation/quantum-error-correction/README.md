# Quantum error correction

Quantum error correction protects quantum information against noise by encoding it into a subspace of a larger system: quantum codes, the Knill–Laflamme conditions for correctability, and stabilizer and CSS codes.

The topics follow the order of Preskill's lecture notes (Chapter 7): the Knill–Laflamme criterion for correctability, the bit-flip code as the first example, the distance of a code and the correction of $t$ errors by a code of distance $2t + 1$, and the CSS construction from classical linear codes.
