# Arith Prog Poly irreducible

Main theorem: for `m ≥ 2` and coprime positive integers `a`, `d` with `8a > m² d²`, the
polynomial `a x^m + (a + d) x^(m-1) + ⋯ + (a + (m-1)d) x + (a + md)` is irreducible over `ℤ`.
