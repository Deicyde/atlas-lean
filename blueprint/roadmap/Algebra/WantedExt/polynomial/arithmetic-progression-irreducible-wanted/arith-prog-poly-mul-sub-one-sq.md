# Arith Prog Poly mul sub one sq

Lemma 1, identity: with `a_n = a + (n - 1)d`,
`A_m(x)(x - 1)² = a_1 x^{m+2} - a_0 x^{m+1} - a_{m+2} x + a_{m+1}`; stated for all `m, a, d ≥ 0`
(the paper says positive).
