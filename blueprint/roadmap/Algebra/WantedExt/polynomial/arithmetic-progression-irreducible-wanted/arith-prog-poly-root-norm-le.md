# Arith Prog Poly root norm le

For `m ≥ 2`, positive integers `a ≥ d`, and `λ` the positive solution of equation (3),
every zero `z ∈ ℂ` of `A_m(x)` has `|z| ≤ λ`, with equality only at `z = -λ`.
