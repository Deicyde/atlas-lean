# Lemma 18

**Lemma 18.** If `b₀ + b₂ ≡ b₁ + b₃ ≡ 0 (mod 2)`, `β β̄ γ γ̄ ∈ 2^4 ℤ_odd` and
`b₀b₂ + b₁b₃ + c₀c₂ + c₁c₃ ≡ 2 (mod 4)`, then `β β̄ γ γ̄ = 2^4 p (2m + 1)` with `p ∈ P`.
