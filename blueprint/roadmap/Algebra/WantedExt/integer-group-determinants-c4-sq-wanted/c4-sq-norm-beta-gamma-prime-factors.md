# Lemma 13

**Lemma 13.** If `b₀ + b₂ ≢ b₁ + b₃ (mod 2)` and `β β̄ ≡ -3 (mod 8)`, then
`β β̄ γ γ̄ = (8j + 1)(8m - 3)(8n - 3)` with `8m - 3, 8n - 3 ∈ P`, where `j ≡ m + n` or
`j ≢ m + n (mod 2)` according as `b₀b₂ + b₁b₃ + c₀c₂ + c₁c₃ ≡ 0` or `2 (mod 4)`.
