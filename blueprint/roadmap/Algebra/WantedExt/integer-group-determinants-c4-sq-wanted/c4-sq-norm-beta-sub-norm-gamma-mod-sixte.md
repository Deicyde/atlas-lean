# Lemma 12

**Lemma 12.** If `b₀ + b₂ ≢ b₁ + b₃ (mod 2)`, then
`β β̄ - γ γ̄ ≡ 4(b₀b₂ + b₁b₃ + c₀c₂ + c₁c₃) (mod 16)`.
