# Injective iff sum pow eq

Elements `a₁, …, a_q` of the finite field `K` with `q` elements are distinct if and only
if `∑ aᵢ^t = 0` for `t = 0, 1, …, q - 2` and `∑ aᵢ^(q-1) = -1` (with `0 ^ 0 = 1`).
