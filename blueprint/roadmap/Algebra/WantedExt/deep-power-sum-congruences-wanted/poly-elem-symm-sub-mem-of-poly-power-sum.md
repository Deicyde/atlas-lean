# Poly Elem Symm sub mem of poly Power Sum sub mem

Let `A` be a torsion-free `ℤ_(p)`-algebra, `𝔞` a divided-power ideal and `P, Q` monic. If
`p_n(P) ≡ p_n(Q) mod n𝔞` for `1 ≤ n ≤ N`, then `e_n(P) ≡ e_n(Q) mod 𝔞` for `1 ≤ n ≤ N`.
