# P Equiv Class Sum

The contribution `g_λ = Σ_{μ ∼_p λ} (-1)^μ p_μ / z_μ` of one `p`-equivalence class to
`e_n` (Corollary 21), with `(-1)^μ = (-1)^(n - #parts)` and `z_μ = Π_a a^(r_a) r_a!`, as a
symmetric polynomial in finitely many variables over `ℚ`.
