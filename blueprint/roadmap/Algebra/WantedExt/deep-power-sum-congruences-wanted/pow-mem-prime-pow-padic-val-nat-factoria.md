# Pow mem prime pow padic Val Nat factorial iff

For an ideal `b` of any commutative ring, `a ^ n ∈ p ^ v_p(n!) b` for all `n ≥ 1` and `a ∈ b`
if and only if `a ^ p ∈ p b` for all `a ∈ b`.
