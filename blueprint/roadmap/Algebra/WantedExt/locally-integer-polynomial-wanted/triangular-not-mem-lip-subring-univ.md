# Triangular not mem lip Subring univ

The function `x ↦ x(x+1)/2` is not LIP on `ℤ`: no integer polynomial takes the values
`0, 0, 1` at `-1, 0, 1`, since `1 - (-1)` must divide `p(1) - p(-1)`.
