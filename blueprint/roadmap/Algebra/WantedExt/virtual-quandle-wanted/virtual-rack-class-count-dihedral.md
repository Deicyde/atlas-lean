# Virtual Rack Class Count dihedral

For `n > 0`, the number of isomorphism classes of virtual quandles whose underlying quandle
is the dihedral quandle `R_n` is `v(R_n) = φ(n) ∑_{d ∣ n} 1/φ(d)`.
