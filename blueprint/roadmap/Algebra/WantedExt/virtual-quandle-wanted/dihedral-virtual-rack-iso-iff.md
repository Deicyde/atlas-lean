# Dihedral virtual Rack Iso iff

For `n > 0`, the virtual dihedral quandles `(R_n, T_{a,u})` and `(R_n, T_{b,v})` are
isomorphic if and only if `u = v` and `b = y a + (1 - u) x` for some `x ∈ ℤ/nℤ` and
`y ∈ (ℤ/nℤ)ˣ`.
