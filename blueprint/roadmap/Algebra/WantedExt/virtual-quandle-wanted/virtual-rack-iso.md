# Virtual Rack Iso

Two virtual racks `(R₁, f₁)` and `(R₂, f₂)` are isomorphic: some bijective rack
homomorphism `ψ : R₁ ≃ R₂` intertwines the virtual structures, `ψ f₁ = f₂ ψ`.
