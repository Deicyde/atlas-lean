# Lemma 3

**Lemma 3.** Let `F ⊆ G` be fields and `S ⊆ Fⁿ`. If some nonzero `t ∈ Gⁿ` has `s · t = 0`
for all `s ∈ S`, then some nonzero `u ∈ Fⁿ` has `s · u = 0` for all `s ∈ S`.
