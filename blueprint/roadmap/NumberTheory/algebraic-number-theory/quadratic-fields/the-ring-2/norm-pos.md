# Nonzero elements of $\mathbb{Z}(\sqrt{-2})$ have positive norm

**Nonzero elements of $\mathbb{Z}[\sqrt{-2}]$ have positive norm.** For $x = a + b\sqrt{-2}$
in $\mathbb{Z}[\sqrt{-2}]$ with norm $N(x) = a^2 + 2b^2$, we have $N(x) > 0$ if and only if
$x \ne 0$.
