# The zeroth $r$-Fibonacci polynomial vanishes

**The zeroth $r$-Fibonacci polynomial vanishes.** For every natural number $r$ and all
$x, y$ in a commutative semiring $R$, the $r$-Fibonacci polynomial $U^{(r)}_0(x, y)$ is $0$.
