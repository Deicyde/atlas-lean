# Recurrence for the Pell–Lucas numbers

**Recurrence for the Pell–Lucas numbers.** Write $Q_n$ for the $n$-th Pell–Lucas (associated
Pell) number. For every natural number $n$, $Q_{n+2} = 2Q_{n+1} + Q_n$.
