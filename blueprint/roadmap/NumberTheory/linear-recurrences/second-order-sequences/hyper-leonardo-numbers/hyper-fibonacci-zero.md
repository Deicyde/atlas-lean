# Hyper-Fibonacci numbers of order zero

**Hyper-Fibonacci numbers of order zero.** For every natural number $n$, the hyper-Fibonacci
number $F^{(0)}_n$ equals the $n$-th Fibonacci number $F_n$ (with $F_0 = 0$ and $F_1 = 1$).
