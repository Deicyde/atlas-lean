# Recurrence of the shifted Padovan sequence

**Recurrence of the shifted Padovan sequence.** For every natural number $n$, the shifted
Padovan sequence $(a_n)_{n \ge 0}$ satisfies $a_{n+3} = a_{n+1} + a_n$.
