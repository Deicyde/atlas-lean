# Corollary 13.4

Let $E/\mathbb{F}_{p}$ be an elliptic curve over a field of prime order
 $p>3$. Then $E$ is supersingular if and only if $\operatorname{tr}
 \pi_{E}=0$, equivalently, if and only if $\# E(\mathbb{F}_{p})=p+1$.
