# Definition 14.7

For any nonzero complex function $f(z)$ that is meromorphic on an open
 neighborhood of a point $z_{0} \in \mathbb{C}$ we define
 $$\operatorname{ord}_{z_{0}}(f)\coloneqq \begin{cases}n & \text{ if } f
 \text{ has a zero of order } n \text{ at } z_{0} \\ -n & \text{ if } f
 \text{ has a pole of order } n \text{ at } z_{0} \\ 0 & \text{ otherwise
 }\end{cases}$$
