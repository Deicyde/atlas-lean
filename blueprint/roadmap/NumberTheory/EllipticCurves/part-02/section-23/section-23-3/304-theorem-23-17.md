# Theorem 23.17

Let $E / k$ be an elliptic curve with the distinguished point 0. The
 Abel-Jacobi map $E \mapsto \operatorname{Pic}^{0} E$ defined by $P \mapsto
 [P]-[0]$ is a group isomorphism.
