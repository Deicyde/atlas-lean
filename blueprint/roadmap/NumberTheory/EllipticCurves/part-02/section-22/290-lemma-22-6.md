# Lemma 22.6

Let $\mathcal{O}$ be an imaginary quadratic order of discriminant $D$ and let
 $\mathbb{F}_q$ be a finite field with $q \perp D$. The set
 $\operatorname{Ell}_{\mathcal{O}}(\mathbb{F}_q)$ is either empty or has
 cardinality $h(D)$. If $\operatorname{Ell}_{\mathcal{O}}(\mathbb{F}_q)$ is
 nonempty, so is $\operatorname{Ell}_{\mathcal{O}'}(\mathbb{F}_q)$ for every
 imaginary quadratic order $\mathcal{O}'$ containing $\mathcal{O}$.
