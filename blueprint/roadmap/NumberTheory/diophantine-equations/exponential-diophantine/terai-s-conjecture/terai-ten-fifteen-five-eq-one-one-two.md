# The Terai equation $(10m^2 + 1)^x + (15m^2 - 1)^y = (5m)^z$

**The Terai equation $(10m^2 + 1)^x + (15m^2 - 1)^y = (5m)^z$.** For every integer
$m > 1$, the only solution of $(10m^2 + 1)^x + (15m^2 - 1)^y = (5m)^z$ in positive integers
$x, y, z$ is $(x, y, z) = (1, 1, 2)$.
