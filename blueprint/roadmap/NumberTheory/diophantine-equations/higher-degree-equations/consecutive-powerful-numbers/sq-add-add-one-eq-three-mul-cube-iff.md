# Integer solutions of $u^2 \pm u + 1 = 3v^3$

**Integer solutions of $u^2 \pm u + 1 = 3v^3$.** For all integers $u$ and $v$,
$u^2 + u + 1 = 3v^3$ if and only if $(u, v) = (-2, 1)$ or $(u, v) = (1, 1)$, and
$u^2 - u + 1 = 3v^3$ if and only if $(u, v) = (2, 1)$ or $(u, v) = (-1, 1)$.
