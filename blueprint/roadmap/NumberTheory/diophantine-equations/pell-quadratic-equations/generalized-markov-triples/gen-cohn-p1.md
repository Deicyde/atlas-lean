# The matrix $P_{1;\ell}$

**The matrix $P_{1;\ell}$.** For a natural number $k$ and an integer $\ell$, $P_{1;\ell}$ is
the integer $2 \times 2$ matrix with first row $(\ell, 1)$ and second row
$(-\ell^2 + 2k\ell + 3\ell - 1, -\ell + 2k + 3)$.
