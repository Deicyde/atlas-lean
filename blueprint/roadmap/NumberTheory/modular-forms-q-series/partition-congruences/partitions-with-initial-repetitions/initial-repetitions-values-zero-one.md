# Small values of the partition functions $c_2$, $c_3$, $c_8$ and $c_8'$

**Small values of the partition functions $c_2$, $c_3$, $c_8$ and $c_8'$.** We have
$c_2(0) = 0$, $c_2(1) = 1$, $c_3(1) = 1$, $c_8(0) = c_8(1) = 1$, $c_8'(0) = 1$ and $c_8'(1) = 0$.
