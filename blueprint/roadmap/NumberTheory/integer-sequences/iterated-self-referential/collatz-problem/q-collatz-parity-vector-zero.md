# The parity vector of $0$

**The parity vector of $0$.** For all $A, B \in \mathbb{F}_2[[q]]$, the parity vector of $0$
under the $q$-analog $T_{A,B}$ of the $3x+1$ map is $0$, that is, $\mathrm{PV}_{A,B}(0) = 0$.
