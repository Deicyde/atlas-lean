# Admissible profiles for $M_k$

A function $F : \mathbb R^k \to \mathbb R$ is an admissible profile if it is measurable and bounded, vanishes outside [Maynard's simplex](maynard-simplex.md) $\mathcal R_k$, and satisfies $I_k(F) \ne 0$ and $J_k^{(m)}(F) \ne 0$ for every $m$.

Relation to the source. Maynard (2015), Proposition 4.2, takes the set $\mathcal S_k$ of Riemann-integrable $F : [0, 1]^k \to \mathbb R$ supported on $\mathcal R_k$ with $I_k(F) \ne 0$ and $J_k^{(m)}(F) \ne 0$. Every such function is bounded and measurable, so this class contains $\mathcal S_k$ (extended by $0$ outside the cube); it is larger, since it also contains bounded measurable functions that are not Riemann-integrable.

## Sources

- J. Maynard, "Small gaps between primes", *Ann. of Math.* 181 (2015), 383–413; theorem and display numbers are those of arXiv:1311.4600v3 (28 Oct 2019).
