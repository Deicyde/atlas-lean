# The averaging operator is entire

**The averaging operator is entire.** The function $E_1 : \mathbb{C} \to \mathbb{C}$ given by
$E_1(u) = \int_0^1 e^{tu}\,dt$ is complex differentiable at every point of $\mathbb{C}$.
