# Cyclic Count is Equivalent composite Cyclic Count

Campbell and Cohen, Lemma 1: `A(x) ~ cc(x) ~ x e^{-γ} / log log log x` as `x → ∞`, where
`A(x)` counts cyclic numbers `≤ x` and `cc(x)` counts composite cyclic numbers `≤ x`.
