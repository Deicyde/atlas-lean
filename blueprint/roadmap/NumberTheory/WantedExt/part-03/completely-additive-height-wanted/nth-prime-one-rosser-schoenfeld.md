# Nth Prime One rosser schoenfeld

Lemma 1 (Rosser-Schoenfeld): there is an absolute `k₀` with
`k (log k + log log k - 1) ≤ pₖ ≤ k (log k + log log k)` for all `k ≥ k₀`.
