# Sum rpow div log is Equivalent

Lemma 5 (a logarithmic-integral sum): for fixed `β > 0`,
`∑_{2 ≤ i ≤ m} i^{β-1} / log i ∼ m^β / (β log m)` as `m → ∞`.
