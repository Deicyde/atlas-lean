# Canonical Seq partition Profile growth

Corollary 3 (ordinary partition profile `π_k = 1`, so `α = C = 1`): the canonical sequential
model has `S_seq(x) ≍ x / (log x)²` and `F_seq(x) = ∑_{n ≤ x} H_seq(n) ≍ x² / (log x)²`.
