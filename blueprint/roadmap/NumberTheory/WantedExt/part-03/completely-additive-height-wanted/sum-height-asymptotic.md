# Sum height asymptotic

Proposition 7 (prime reduction), final form: for completely additive `H` there is `C` with
`|F(x) - x ∑_{p ≤ x} H(p)/(p - 1)| ≤ C log x ∑_{p ≤ x} H(p)` for all real `x ≥ 2`.
