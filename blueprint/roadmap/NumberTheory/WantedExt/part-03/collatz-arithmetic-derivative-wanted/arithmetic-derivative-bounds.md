# Arithmetic Derivative bounds

For `n ≥ 2` with least prime factor `p` and `Ω(n)` prime factors counted with multiplicity,
`Ω(n) n^{(Ω(n) - 1)/Ω(n)} ≤ D(n) ≤ n log_p(n) / p`, and each bound is an equality exactly when
`n` is a prime power.
