# Lemma 1

**Lemma 1.** For `α = a₁ ω + ⋯ + a_{p-1} ω^{p-1}` with rational `aᵢ`,
`‖α‖² = p² ‖α‖_E² - (p + 1) Tr_{K/ℚ}(α)²` where `‖α‖_E² = ∑ aᵢ²`; consequently
`‖α‖_E² ≤ ‖α‖²`.
