# Lemma 4

**Lemma 4.** The second moment is
`M_2(p, N) = (2/3)(p³ - 2p² + 1) N (N + 1)`.

Only the exact formula is stated; the paper's `= (2/3) p³ N² + O(p² N² + p³ N)` follows
from it.
