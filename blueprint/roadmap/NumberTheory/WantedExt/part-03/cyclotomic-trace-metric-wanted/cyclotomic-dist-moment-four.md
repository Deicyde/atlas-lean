# Lemma 6

**Lemma 6.** The fourth moment is
`M_4(p, N) = (2/45) N (N+1) (p-1) ((2N² + 2N)(5p⁵ - 8p⁴ + p³ + 8p² - 21p - 18) - 3(p² - p - 1)²)`.

Only the exact formula is stated; the paper's `= (4/9) p⁶ N⁴ + O(p⁵ N⁴ + p⁶ N³)` follows
from it.
