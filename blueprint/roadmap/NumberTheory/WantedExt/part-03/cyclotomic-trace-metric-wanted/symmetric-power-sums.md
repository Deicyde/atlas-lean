# Lemma 3

**Lemma 3.** The power sums `S_r(N) = ∑_{-N ≤ a ≤ N} a^r` satisfy `S_r(N) = 0`
for odd `r`, `S_2(N) = N(N+1)(2N+1)/3` and `S_4(N) = N(N+1)(2N+1)(3N²+3N-1)/15`.

The paper takes `N ≥ 1`; `N = 0` is included.
