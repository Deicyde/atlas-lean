# Lemma 7

**Lemma 7.** The variance-type sum
`R(p, N) = #B(p, N)⁻² ∑_{α, β} (d(α, β)² - (2/3) p³ N²)²` satisfies
`R(p, N) ≪ p⁵ N⁴ + p⁶ N³`, with an absolute implied constant.
