# Frobenius eq max apery sub

Brauer–Shockley: if `S` is the numerical semigroup generated by positive integers
`A_1, …, A_k` with `gcd = 1`, and `a = A_i ≥ 2`, then `F(S) = max_{1 ≤ x ≤ a-1} m_x - a`,
where `m_x` is the least element of `S` congruent to `x` modulo `a`. The case `a = 1`
(an empty maximum) is excluded.
