# Compound Sequence erase frobenius eq iff

For the compound sequence `C = {c_0, …, c_n}`, `0 ≤ j ≤ n` and `C⋆ = C ∖ {c_j}` with
`gcd(C⋆) = 1`: `F(⟨C⋆⟩) = F(⟨C⟩)` if and only if `a_j = 1`.
