# Paperfolding Cont Frac Word const six two

For the constant creases `xₖ = 6`, `A₂ = [1, 1, 5, 2, 5, 1, 1, 5, 1, 1]`, the start of the
paper's expansion of `6 ∑ 12^(-2^k)`.
