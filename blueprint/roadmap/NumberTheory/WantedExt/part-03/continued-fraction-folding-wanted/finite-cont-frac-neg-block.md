# Finite Cont Frac neg block

Normalizing a negated block: for positive integers `a₁, …, aₜ` with `t ≥ 2`,
`[…, x, -aₜ, -aₜ₋₁, …, -a₁] = […, x - 1, 1, aₜ - 1, aₜ₋₁, …, a₁]`.
