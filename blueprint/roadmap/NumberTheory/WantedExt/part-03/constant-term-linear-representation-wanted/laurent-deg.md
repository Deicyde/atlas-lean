# Laurent Deg

Kohen's degree of a Laurent polynomial: the largest absolute value of any exponent of any
single variable occurring in it (`0` for the zero polynomial), e.g.
`deg(5x^{-3}y^{-2} + 2xy^{-1}) = 3`.
