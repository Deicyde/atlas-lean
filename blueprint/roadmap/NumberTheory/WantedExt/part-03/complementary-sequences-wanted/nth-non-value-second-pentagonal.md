# Nth Non Value second Pentagonal

The `n`-th non-second-pentagonal number (second pentagonal numbers `(3j² + j)/2`, `j ≥ 1`):
with `s = ⌊√(2n/3)⌋`, it is `n + s + 1` if `2n ≥ s(3s + 5) + 4` and `n + s` otherwise.
