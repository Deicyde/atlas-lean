# Nth Non Value polygonal shift

Shifted form: for `k ≥ 3` and real `r` with `-1 ≤ r ≤ k - 4`, with
`s = ⌊√((2n + r) / (k - 2))⌋`, the `n`-th non-`k`-gonal number is `n + s + 1` if
`2n > (k - 2) s (s + 1)` and `n + s` otherwise.
