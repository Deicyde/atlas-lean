# Nth Non Value pyramidal two case

For `3 ≤ k ≤ 5` the `n`-th non-`k`-gonal-pyramidal number is, with `s = ⌊∛(6n / (k - 2))⌋`,
`n + s - 1` if `6n ≤ s(s - 1)(s(k - 2) + k + 1)` and `n + s` otherwise.
