# Nth Non Value polygonal eq round shift

For every `k ≥ 3` the `n`-th non-`k`-gonal number is
`n + ⌊√((2n - 2 + ⌊(k + 1)/4⌋) / (k - 2)) + 1/2⌋` (the choice `r = ⌊(k + 1)/4⌋ - 2`).
