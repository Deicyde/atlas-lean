# Nth Non Value

The `n`-th (`1`-indexed) positive integer that is not a value `f m` with `m ≥ 1`, i.e. the
paper's `f_P(n)` for the complementary sequence of `f = f_{¬P}`. At `n = 0` it agrees with
`n = 1` (junk value of the `1`-indexing).
