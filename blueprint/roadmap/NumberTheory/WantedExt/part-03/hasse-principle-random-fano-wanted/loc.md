# 𝕍Loc

The set `𝕍ˡᵒᶜ_{d,n}` of everywhere locally soluble degree-`d` hypersurfaces in `ℙⁿ`:
those `V` for which `V(𝔸_ℚ) ≠ ∅`, i.e., which have a solution in the adele ring.
