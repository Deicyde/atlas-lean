# Digit Sum partial Sum trollope Delange

The Trollope-Delange formula in base `q`, for real `x ≥ 1`:
`∑_{n ≤ x} s_q(n) = (q - 1)/(2 log q) · x log x + x F(log x / log q) - h(x)
  + (1 + ⌊x⌋ - x) s_q(⌊x⌋)`.
