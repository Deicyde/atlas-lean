# Digit Sum Arith pow partial Sum is Big O

For every integer `k ≥ 2`,
`∑_{n ≤ x} s_q^{(k)}(n) = a(k) x log^{2k-1} x + O(x log^{2k-2} x)` as `x → ∞`.
