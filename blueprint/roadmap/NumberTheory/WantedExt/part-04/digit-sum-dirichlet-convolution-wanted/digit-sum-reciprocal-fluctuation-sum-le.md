# Digit Sum reciprocal fluctuation sum le

For real `x > 0` and `y`,
`∑_{n ≤ y} s_q(n)/n · F(log(x/n)/log q) ≤ F_M ∑_{n ≤ y} s_q(n)/n`, where
`F_M = sup_t |F(t)|`.
