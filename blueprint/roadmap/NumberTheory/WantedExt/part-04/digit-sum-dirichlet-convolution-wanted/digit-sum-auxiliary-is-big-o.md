# Digit Sum auxiliary is Big O

The size bounds `h(x) = O(1)`, `F` bounded, `J(x) = O(log x)`, `G(x) = O(log x)`,
`H(x) = O(log² x)`, `K(x) = O(1)` and `L(x) = O(log x)` as `x → ∞`.
