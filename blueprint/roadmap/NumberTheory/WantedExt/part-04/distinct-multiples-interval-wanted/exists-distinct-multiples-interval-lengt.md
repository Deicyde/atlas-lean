# Exists distinct Multiples Interval Length sub gt

Theorem 1: for all large enough `n` there is a positive `m` with
`f(n, m) - f(n, n) > 0.36 n log n / log log n`; equivalently
`max_m f(n, m) - f(n, n) > 0.36 n log n / log log n`.
