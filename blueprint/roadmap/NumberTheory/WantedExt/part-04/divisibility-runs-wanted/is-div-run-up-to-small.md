# Is Div Run Up To small

The first three run-length thresholds: a run of length `≥ 1` holds iff
`x ≠ 0` and `x ∣ a`; of length `≥ 2` iff in addition `y ≠ 0` and `y ∣ b`;
of length `≥ 3` iff in addition `x + y ≠ 0` and `x + y ∣ c`.
