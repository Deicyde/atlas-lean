# Div Run Count one

Proposition 4: `A_B(1) = 4(2B+1)³ D(B) + 2B(2B+1)((2B+1)² - 1)` with
`D(B) = ∑_{m=1}^B ⌊B/m⌋`, and `A_B(1) = 32 B⁴ log B + O(B⁴)` (the `O` stated with an
explicit constant for `B ≥ 2`).
