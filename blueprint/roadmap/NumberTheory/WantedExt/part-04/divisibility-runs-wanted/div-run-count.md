# Div Run Count

`A_B(r)`: the number of configurations `(x, y, a, b, c) ∈ [-B, B]⁵` with `(x, y) ≠ (0, 0)`
and `(a, b, c) ≠ (0, 0, 0)` (the set `𝒞_B`) whose divisibility run length is at least `r`.
