# Exists short Interval Divisor Count le sqrt letendre

Letendre's square-root saving: uniformly in `0 < η < θ < 1` and `n ≥ 2`,
`D_n(n^θ, n^η) ≪ τ(n)^{1 - ξ(θ, η)/2} √(log τ(n) / (θ(1 - θ)))`, with an absolute implied
constant.
