# Exists short Interval Divisor Count le letendre

Letendre's main bound: uniformly in `0 < η < θ < 1` and `n ≥ 2`,
`D_n(n^θ, n^η) ≪ τ(n)^{1 - ξ(θ, η)} V(n) log τ(n) / (θ(1 - θ))`, with `V(n)` the largest
exponent in the factorization of `n`.
