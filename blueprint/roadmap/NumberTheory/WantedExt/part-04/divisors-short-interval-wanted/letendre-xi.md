# Letendre Xi

Letendre's saving exponent `ξ(θ, η)` of Theorem 1: `1` if `η ≤ θ²`; otherwise `θ²/η` if
`θ ≤ 1/2` and `2η ≤ θ`, `4(θ - η)` if `θ ≤ 1/2` and `2η > θ`,
`(1 - θ)²/((1 - θ)² + η - θ²)` if `θ > 1/2` and `2η ≤ 3θ - 1`, and `4(θ - η)` if `θ > 1/2`
and `2η > 3θ - 1`.
