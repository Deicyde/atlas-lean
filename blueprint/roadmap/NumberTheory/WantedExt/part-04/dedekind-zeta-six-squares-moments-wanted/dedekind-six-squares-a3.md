# Dedekind Six Squares A3

The exponent `a_{3,ℓ} = ∑_{i=1}^{⌈ℓ/2 - 1⌉} C(ℓ, 2i+1) · 4(2i+1)!/((i-1)!(i+3)!)`
(`⌈ℓ/2 - 1⌉ = ⌊(ℓ - 1)/2⌋`; each quotient is an integer).
