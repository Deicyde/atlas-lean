# Gobel Sequence root strict Anti

Lemma 7: for `k, l ≥ 2` and `n ≥ 1`, the real numbers
`C_{k,l}(n) = g_{k,l}(n)^{1/k^n}` satisfy `C_{k,l}(n) > C_{k,l}(n + 1) > 1`.
