# Norm incomplete quadratic sum lt sqrt add sqrt

Corollary 6.1: for a prime `p`, a quadratic `f(x) = a x² + b x + c` with `p ∤ a`, and
`1 ≤ B ≤ p`, `|S_p(f, B)| < √p + √((2/π) p log p + p/2)`.
