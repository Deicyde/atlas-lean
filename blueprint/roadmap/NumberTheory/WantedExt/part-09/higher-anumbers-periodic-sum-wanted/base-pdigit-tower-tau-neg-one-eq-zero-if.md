# Base PDigit tower Tau neg one eq zero iff

For `τ = (p + 1)/d` with `d ∣ p - 1`, `[p^{-1}](τ i) = [p^0](τ i)` if and only if `p ∣ i`.
The paper's positivity of `i` is dropped (the claim holds at `i = 0`) and `p` is any prime.
