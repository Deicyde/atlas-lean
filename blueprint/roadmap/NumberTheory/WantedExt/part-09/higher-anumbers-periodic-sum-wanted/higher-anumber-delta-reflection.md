# Higher ANumber Delta reflection

For `0 ≤ i < τ_D p` with `p ∤ i`: (i) if `τ_D ∤ i` then `δ(i) + δ(τ_D p - i) = 1`; (ii) if
`τ_D ∣ i` then `δ(i) = δ(τ_D p - i) = 0`. For `0 ≤ j < d` with `p ∤ j`: (iii) if `τ_D ∤ j` then
`δ(j) + δ(d - j) = 1`; (iv) if `τ_D ∣ j` then `δ(j) = 0`.
