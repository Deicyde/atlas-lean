# Height One Multiple Zeta

The height one multiple zeta function
`ζ(s, {1}^j) = ∑_{n₁ > ⋯ > n_{j+1} ≥ 1} n₁^{-s} (n₂ ⋯ n_{j+1})^{-1}`, convergent for
`Re s > 1`.
