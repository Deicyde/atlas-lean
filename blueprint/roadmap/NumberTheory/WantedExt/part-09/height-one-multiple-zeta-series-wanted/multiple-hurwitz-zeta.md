# Multiple Hurwitz Zeta

The multiple Hurwitz zeta function of order `r` at `a = 1`, by the Dirichlet series (2.2):
`ζ_r(s) = ∑_{m ≥ 0} binom(m + r - 1, m) (m + 1)^{-s}`, convergent for `Re r < Re s`.
