# Has Sum height One Multiple Zeta mul pow

For `Re s > 1`, `|r - 1| < |s - 1|` and `Re r < Re s` (where (2.2) converges),
`ζ_r(s) = ∑_{j ≥ 0} ζ(s, {1}^j) (r - 1)^j`.
