# Hyper Leonardo mul sub sq

Proposition 4: for `r ≥ 1` and `n ≥ 1`,
`Le^{(r)}_{n-1} Le^{(r)}_{n+1} - (Le^{(r)}_n)² = Le^{(r)}_n Le^{(r-1)}_{n+1} - Le^{(r-1)}_n Le^{(r)}_{n+1}`
(written with `r + 1` and `n + 1`; `n = 0` would use the undefined term `Le^{(r)}_{-1}`).
