# Hyper Leonardo generating Function

Theorem 1: `∑_{n ≥ 0} Le^{(r)}_n tⁿ = (1-t+t²)/((1-2t+t³)(1-t)^r)`, stated after
clearing denominators in `ℤ⟦t⟧`.
