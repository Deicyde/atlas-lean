# Leonardo generating Function

Corollary 2: `∑ Le_n tⁿ = 2/(1-t-t²) - 1/(1-t) = (1-t+t²)/(1-2t+t³)`, stated as
`(∑ Le_n tⁿ)(1-2t+t³) = 1-t+t²` and `(∑ Le_n tⁿ)(1-t-t²)(1-t) = 2(1-t) - (1-t-t²)` in `ℤ⟦t⟧`.
