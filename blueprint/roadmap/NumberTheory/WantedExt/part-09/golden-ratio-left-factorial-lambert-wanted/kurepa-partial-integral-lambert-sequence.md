# Kurepa Partial Integral lambert Sequence bounds

Theorem 10: `b n < !n < b n + 1` for `n ≥ 5`, where `b n = !n(a n)` is Kurepa's partial
integral at `a n` and `!n = ∑_{k<n} k!`.
