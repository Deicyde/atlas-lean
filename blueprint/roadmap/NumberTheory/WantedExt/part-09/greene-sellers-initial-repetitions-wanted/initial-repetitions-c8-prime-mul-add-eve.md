# Initial Repetitions C8 prime mul add even

For a prime `p ≥ 7` and `1 ≤ r ≤ p - 1` such that `15r + 1` is not a square modulo `p`,
`c₈(pn + r)` is even for all `n ≥ 0`. "Quadratic residue" is read as "square in `ZMod p`", so `0`
counts as a residue.
