# Initial Repetitions values zero one

Values at `0` and `1`: `c₂(0) = 0`, `c₂(1) = 1`, `c₃(1) = 1`, `c₈(0) = c₈(1) = 1`,
`c₈'(0) = 1` and `c₈'(1) = 0`.
