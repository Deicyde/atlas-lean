# Initial Repetitions C2

`c₂(n)`: the number of partitions of `n` with some `j ≥ 1` appearing exactly `j` times as
the only part less than `2j + 1`, even parts `≥ 2j + 2` distinct, odd parts `≥ 2j + 1`
unrestricted.
