# Andrews rogers Ramanujan second dissection

Andrews' identity (6.23): for `|q| < 1`,
`(q²;q²)_∞ ∑_{j ≥ 0} q^{j²+j}/(q;q)_j = ∑_{λ ∈ ℤ} (q^{60λ²+8λ} - q^{60λ²+32λ+4} + q^{60λ²+28λ+3}
- q^{60λ²+52λ+11})`. All exponents are nonnegative for integer `λ`.
