# Andrews rogers Ramanujan first dissection

Andrews' identity (6.22): for `|q| < 1`,
`(q²;q²)_∞ ∑_{j ≥ 0} q^{j²}/(q;q)_j = ∑_{λ ∈ ℤ} (q^{60λ²+4λ} - q^{60λ²+44λ+8} + q^{60λ²+16λ+1}
- q^{60λ²+64λ+17})`. All exponents are nonnegative for integer `λ`.
