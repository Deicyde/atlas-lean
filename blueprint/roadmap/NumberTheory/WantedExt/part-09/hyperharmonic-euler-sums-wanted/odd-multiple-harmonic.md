# Odd Multiple Harmonic

The depth-`k` odd harmonic number `O_n(k) = H_n(k; 1/2)
= ∑_{1 ≤ i_1 < ⋯ < i_k ≤ n} ∏_j 1 / (i_j - 1/2)`, with `O_n(0) = 1` and `O_n(k) = 0` for
`k > n`.
