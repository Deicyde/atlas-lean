# Gobel Residue eq none iff

Lemma 2 (Matsuhira–Matsusaka–Tsuchida, Lemma 10): for `k ≥ 2`, `r ≥ 1`, a prime `p` and a
positive integer `n` with `ν_p(n!) ≤ r`, `g_{k,p,r}(n) = F` if and only if `g_{k,n} ∉ ℤ_(p)`.
