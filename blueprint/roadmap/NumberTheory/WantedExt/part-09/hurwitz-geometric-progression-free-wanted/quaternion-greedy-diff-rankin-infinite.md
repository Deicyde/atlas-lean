# Quaternion Greedy diff rankin infinite

Both differences `G₃*(Q_Hur ∖ {0}) ∖ S(G₃*(ℕ₊))` and `S(G₃*(ℕ₊)) ∖ G₃*(Q_Hur ∖ {0})`
between the quaternion greedy set and the norm preimage of Rankin's greedy set are infinite.
