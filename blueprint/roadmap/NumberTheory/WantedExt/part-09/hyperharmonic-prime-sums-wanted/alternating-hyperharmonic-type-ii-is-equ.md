# Alternating Hyperharmonic type II is Equivalent

Lemma 13: for `r, p ≥ 1`, the type II numbers satisfy
`H_n^{(p,r,2)} ∼ n^{r-1} ζ̄(p) / (r-1)!` (with `ζ̄(1) = log 2`).
