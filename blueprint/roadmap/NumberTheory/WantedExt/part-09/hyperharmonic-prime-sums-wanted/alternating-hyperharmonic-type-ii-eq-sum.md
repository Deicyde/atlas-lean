# Alternating Hyperharmonic type II eq sum

Lemma 3: for `r, n, p ≥ 1`, the type II generalized alternating hyperharmonic numbers satisfy
`H_n^{(p,r,2)} = ∑_{m=0}^{r-1} ∑_{j=0}^{r-1-m} a(r, m, j) n^j H̄_n^{(p-m)}`, with `a = liCoeffA`.
