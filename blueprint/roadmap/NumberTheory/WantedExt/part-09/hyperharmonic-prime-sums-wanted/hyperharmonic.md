# Hyperharmonic

Hyperharmonic numbers (Conway–Guy): `h_n^{(0)} = 1/n` and
`h_n^{(r+1)} = ∑_{k=1}^{n} h_k^{(r)}`, so `h_n^{(1)} = H_n`. The value at `n = 0` is `0` for
every order.
