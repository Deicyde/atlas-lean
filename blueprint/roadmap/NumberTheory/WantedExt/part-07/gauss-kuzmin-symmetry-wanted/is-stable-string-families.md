# Is Stable String families

Stable families: (i) `(t, 2t)` and `(t, 1, 2t + 1)` are stable for `t ∈ ℕ`; (ii) if `a` is
stable then so is `(t, a⃖, 2t)`; (iii) for each `n ≥ 2` there are infinitely many stable strings of
length `n`.
