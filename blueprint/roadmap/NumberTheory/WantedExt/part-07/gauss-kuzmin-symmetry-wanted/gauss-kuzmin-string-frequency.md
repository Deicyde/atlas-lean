# Gauss Kuzmin string frequency

Generalized Gauss-Kuzmin theorem: for almost every real `x` and every string `a` of positive
integers, the frequency of the indices `i` with `a_{i+1}(x) = a₁, …, a_{i+n}(x) = aₙ` tends to
`P_GK(a)`.
