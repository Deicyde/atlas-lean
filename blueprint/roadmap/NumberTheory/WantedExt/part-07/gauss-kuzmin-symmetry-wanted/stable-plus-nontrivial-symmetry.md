# Stable plus nontrivial symmetry

If `a = (a₁, …, aₙ)` is a stable string of positive integers, then
`a⁺ = (2, 1, a₁, …, aₙ₋₁, aₙ + 1)` has the nontrivial symmetry
`σ(a⁺) = (2, aₙ + 1, aₙ₋₁, …, a₁, 1)`.
