# Ici one sub log two subset closure floor gaps

Theorem 5 (i) (D. R. Richman): the set `S` of values
`f_n(x) = ⌊nx⌋ - Σ_{k=1}^n ⌊kx⌋/k = ⌊nx⌋ - n A_n(x)` (`n ≥ 1`, `x ∈ ℝ`) is dense in
`[1 - log 2, ∞)`.
