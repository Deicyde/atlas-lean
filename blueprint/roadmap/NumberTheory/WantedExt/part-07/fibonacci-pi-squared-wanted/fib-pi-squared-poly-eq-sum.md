# Fib Pi Squared poly eq sum

Lemma 2.4: for `n ≥ 1`,
`p_n(x) = Σ_(j=0)^(n-1) (-1)^j C(n-1, j) Π_(k=2j+3)^(2n) (2x + k) Π_(t=1)^j (x + t)²`.
