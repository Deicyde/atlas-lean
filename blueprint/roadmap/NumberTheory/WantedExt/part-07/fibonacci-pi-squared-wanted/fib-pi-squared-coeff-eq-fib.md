# Fib Pi Squared coeff eq fib

Lemma 2.3: `a_n = ((25 - 4√5) / 250) F_n - (8√5 / 250) F_(n-1)`, stated for `n ≥ 1`; the case
`n = 0` with the paper's convention `F_(-1) = 1` is the initial value `a 0 = -8√5 / 250`.
