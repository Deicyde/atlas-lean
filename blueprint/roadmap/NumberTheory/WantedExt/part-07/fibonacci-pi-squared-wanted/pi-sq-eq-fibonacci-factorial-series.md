# Pi sq eq fibonacci factorial series

Theorem 2.1: for every `n ≥ 1`,
`π² = (b_(n-1) + (-1)ⁿ Σ_k (k!)² p_n(k) F_(2k+2) / (2k+2n)!) / a_(n-1)` (2.1) and
`π² = (b_n + (-1)^(n+1) Σ_k (k!)² p_n(k) F_(2k+1) / (2k+2n)!) / a_n` (2.2).
