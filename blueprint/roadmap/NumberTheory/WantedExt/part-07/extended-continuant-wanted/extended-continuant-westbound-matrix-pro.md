# Extended Continuant westbound matrix prod

Proposition 1: for `n ≥ 1`, the westbound matrix product
`∏_{i=n}^{1} [[0, 1], [1, -x_{-i}]]` (factor `i = n` leftmost) equals
`[[K_{-n-1}(x)_0, K_{-n-2}(x)_1], [K_{-n-2}(x)_0, K_{-n-3}(x)_1]]`.
