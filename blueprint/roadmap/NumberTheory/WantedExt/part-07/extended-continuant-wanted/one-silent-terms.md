# One Silent terms

Theorem 5 (1-silent BpCFs): if `k_i ≐ c_i` and `k_{-i-2} ≐ d_i` for all `i ≥ 0`, then
`x_n = y_n` for `n ≥ 0`, `x_{-n} = -z_n` for `n ≥ 1`, and `z_0 = 0` (the paper's `0 < ᾱ < 1`
for the EA-generated SCF of the irrational `ᾱ`).
