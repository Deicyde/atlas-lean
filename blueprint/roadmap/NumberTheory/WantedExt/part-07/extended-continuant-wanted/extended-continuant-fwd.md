# Extended Continuant Fwd

Forward branch of the extended continuant with start index `b`: the value at `n` is
`K_{n-2}(x)_b`, so `0 ↦ 0`, `1 ↦ 1`, and `n + 2 ↦ x_{b+n} K_{n-1} + K_{n-2}`.
