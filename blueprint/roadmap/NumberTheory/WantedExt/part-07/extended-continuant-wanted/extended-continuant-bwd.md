# Extended Continuant Bwd

Backward branch of the extended continuant with start index `b`: the value at `m` is
`K_{-1-m}(x)_b`, so `0 ↦ 1`, `1 ↦ 0`, and `m + 2 ↦ -x_{b-1-m} K_{-2-m} + K_{-1-m}`.
