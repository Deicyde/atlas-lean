# Proposition 1 (i)

**Proposition 1 (i)** (reversal). For an index `k` of weight `w` and a color map `c`,
`ζ^c_{𝒜,N}(k) = (-1)^w ζ^{c←}_{𝒜,N}(k←)`, where `k← = (k_r, …, k₁)` and
`c←(α) = (α - α_r, …, α - α₁)` when `c(α) = (α₁, …, α_r)`, `c←(α) = ∅` when `c(α) = ∅`.
