# Theorem 2

**Theorem 2** (Wieferich). If `p` is a non-Wieferich prime (`p² ∤ 2^{p-1} - 1`), then
the first case of Fermat's last theorem holds for the exponent `p`: there are no integers
`x, y, z` with `p ∤ x y z` and `x^p + y^p = z^p`.
