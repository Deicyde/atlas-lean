# Exists primitive Root pow card sub one div order Of

For a prime `p` and a nonzero residue `a`, some primitive root `g` modulo `p` satisfies
`ind_g(a) = (p - 1) / ord_p(a)`, i.e. `g ^ ((p - 1) / ord_p(a)) = a`.
