# H Full Omega HB weighted sum bounded

Lemma 4: for `h ≥ 2`, `A`, and `σ > 1/(h+1)` there is a constant `c` with
`∑_{0 ≤ a ≤ n} |B_z(a)| q^{-σa} ≤ c` for all `|z| ≤ A` and `n ≥ 2`, where `B_z(a)` are the
coefficients of `B_{h,N_h}(u, z)`.
