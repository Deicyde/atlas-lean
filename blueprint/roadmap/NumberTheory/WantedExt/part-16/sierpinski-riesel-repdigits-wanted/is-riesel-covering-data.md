# Is Riesel Covering Data

Covering data `{(r_j, m_j, p_j)}` producing `k` as a Riesel number by the covering system
method: as for `IsSierpinskiCoveringData`, with `p_j ∣ k·2^{r_j} - 1` (that is, `k ≡ 2^{-r_j}`).
