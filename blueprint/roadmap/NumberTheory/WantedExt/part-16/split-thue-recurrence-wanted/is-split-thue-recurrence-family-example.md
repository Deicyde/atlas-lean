# Is Split Thue Recurrence Family example

Characteristic example: `G 1 n = 3 ^ n`, `G 2 n = 5 ^ n + 1`, `G 3 n = 5 ^ n + 2 ^ n`
(dominant roots `3, 5, 5`; second dominant roots `1, 2`) satisfy the hypotheses with
`d = 3`.
