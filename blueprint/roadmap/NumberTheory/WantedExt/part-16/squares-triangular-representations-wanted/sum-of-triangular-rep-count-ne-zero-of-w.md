# Sum Of Triangular Rep Count ne zero of window

Representability criterion for triangular numbers: for `n ≥ 1` and an odd prime
`p` with `p - 1 ≥ n + 1`, if `t_{s-(p-1)}(n) + ⋯ + t_{s-1}(n) ≢ 0 (mod p)` then
`t_s(n) ≠ 0` (every `s ∈ ℤ`).
