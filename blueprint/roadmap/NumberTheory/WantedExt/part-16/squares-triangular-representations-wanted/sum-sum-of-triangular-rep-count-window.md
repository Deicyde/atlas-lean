# Sum sum Of Triangular Rep Count window

For `n ≥ 1`, an odd prime `p` with `p - 1 ≥ n + 1`, and every integer `s ≥ p`:
`∑_{i=0}^{p-1} t_{s-i}(n) ≡ 0 (mod p)`.
