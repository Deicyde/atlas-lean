# Lehmer Completions

The admissible completions `u_{s+1} ≤ ⋯ ≤ u_r` of `t_1 ≤ ⋯ ≤ t_s` used in Definition 9:
lists `u` with `s + |u| = r`, `t ⌢ u` nondecreasing and every `u_j ≥ 2`.
