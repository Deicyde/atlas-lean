# Super Leonardo P

The supergeneralized Leonardo `p`-numbers `𝓛_{p,k,x}(n)`: `x n` for `n ≤ p`, and
`𝓛(n-1) + 𝓛(n-p-1) + k` for `n > p`. Only the initial values `x 0, …, x p` are used.
