# Laurent sub convergent order

Let `α` be irrational with convergents `P_n / Q_n`. (i) If `|α| ≥ 1`, then
`|α - P_n/Q_n| < |α|` for all `n ≥ 0`. (ii) If `|α| < 1`, then `|α - P₀/Q₀| = |α|` and
`|α - P_n/Q_n| < |α|` for all `n ≥ 1` (`|y| = |x|^{-y.order}`).
