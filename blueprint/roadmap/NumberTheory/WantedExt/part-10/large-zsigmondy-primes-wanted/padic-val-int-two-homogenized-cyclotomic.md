# Padic Val Int two homogenized Cyclotomic

Let `a > b` be odd positive integers. Then for `n ≥ 1`, `v_2(Φ_n(a, b))` is `v_2(a - b)` if
`n = 1`, `v_2(a + b)` if `n = 2`, `1` if `n = 2^β` with `β ≥ 2`, and `0` otherwise.
