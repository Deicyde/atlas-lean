# Pow sub one mod Eq one sq iff order Of eq

For a prime `p ∤ a`: `p ∈ W(a)` if and only if `ord_{p²}(a) = ord_p(a)`, with `p ∈ W(a)`
written `a^{p-1} ≡ 1 (mod p²)` (the paper's equation (8)); the source's `a ≥ 2` is dropped (both
sides hold at `a = 1`).
