# Proposition 18

**Proposition 18**: for `n ≥ p + r` and `0 ≤ k ≤ ⌊(n - p - r)/(p+1)⌋`,
`∑_{i=0}^{r} C(r, i) R_{p,n+pi}(k + i) + (2^r - 1) p = R_{p,n+(p+1)r}(k + r)` (the printed
range `0 ≤ n ≤ ⌊(n-p-r)/(p+1)⌋` is read with `k` for the first `n`, as in
Proposition 7).
