# Proposition 2

**Proposition 2**: the homogeneous recurrence
`𝓛_{p,n} = 𝓛_{p,n-1} + 𝓛_{p,n-p} - 𝓛_{p,n-2p-1}` for `n ≥ 2p + 1`, with initial values
`𝓛_{p,i} = 1` for `i ≤ p` and `𝓛_{p,p+j} = (j + 1) + jp` for `1 ≤ j ≤ p`.
