# Multiple Polylog

The multiple polylogarithm
`Li_k(z) = ∑_{0 < m₁ < ⋯ < m_r} z^{m_r} / (m₁^{k₁} ⋯ m_r^{k_r}) ∈ ℝ[[z]]`.
