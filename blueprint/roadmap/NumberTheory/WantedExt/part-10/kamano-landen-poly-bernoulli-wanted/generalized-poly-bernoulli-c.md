# Generalized Poly Bernoulli C

Kamano's generalized poly-Bernoulli numbers of the first kind:
`d/dt Li_{k↑}(g; (β, γ); z(t)) = ∑_n C_n^{(k, g, (β, γ))} tⁿ / n!`.
