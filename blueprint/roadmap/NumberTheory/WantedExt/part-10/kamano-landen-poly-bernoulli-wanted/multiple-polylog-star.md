# Multiple Polylog Star

The non-strict multiple polylogarithm
`Li⋆_k(z) = ∑_{0 < m₁ ≤ ⋯ ≤ m_r} z^{m_r} / (m₁^{k₁} ⋯ m_r^{k_r})`; for an index
(all `k_i ≥ 1`) the `m_i = 0` terms vanish since `1/0 = 0`.
