# Landen Data

The data `g = (g₀, g₁, …, g_s)` of the paper: `g₀ = (1 -1; c₀ d₀)` and
`g_i = (a_i b_i; c_i d_i)` for `1 ≤ i ≤ s` (indexed here by `Fin s`).
