# Padovan Perrin Recurrence is Solution iff

For `s > 0`, a sequence solves the `([k]; p; s)`-Padovan–Perrin recurrence exactly when
`v (n + (s + p)) = k₁ v (n + p) + k₂ v n` for every `n`.
