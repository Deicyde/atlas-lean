# Padovan Perrin char Poly separable of p eq one

For positive integers `k₁, k₂, s` and `p = 1`, if
`(-k₂ (s + 1) / (k₁ s))^s ≠ k₁ / (s + 1)` then `P(z) = z^{s+1} - k₁ z - k₂` has only simple roots
(stated as separability over `ℂ`).
