# Padovan Perrin Fundamental mul sum

Product identity of the Fibonacci fundamental system: for `m, n ≥ 0` and
`1 ≤ i, j ≤ s + p`,
`v⁽ˢ⁺ᵖ⁻ʲ⁺¹⁾ (n + m + s + p - i) = ∑_{k=1}^{s+p} v⁽ˢ⁺ᵖ⁻ᵏ⁺¹⁾ (m + s + p - i) v⁽ˢ⁺ᵖ⁻ʲ⁺¹⁾ (n + s + p - k)`.
Stated over any commutative ring.
