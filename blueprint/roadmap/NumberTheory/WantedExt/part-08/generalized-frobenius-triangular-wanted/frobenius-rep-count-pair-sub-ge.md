# Frobenius Rep Count pair sub ge

For coprime positive `a < b`, `s, k ≥ 0` and an integer `m > g(a, b; s) + ka`, every
`j ≥ 0` has `d(m - ja; a, b) ≥ d(g(a, b; s) + (k - j)a; a, b)`.
