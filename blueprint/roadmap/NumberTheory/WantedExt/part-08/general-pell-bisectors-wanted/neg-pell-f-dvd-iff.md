# Neg Pell F dvd iff

For `d > 1` whose negative Pell equation is solvable in integers and `0 < n ≤ m`: `f_n ∣ f_m`
if and only if either `d = 2` and `n = 1`, or `m` is a multiple of `n` with odd quotient.
