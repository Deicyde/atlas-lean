# Overpartition mod eight iff d D convolution

`p̄(4m+3) ≡ 0 (mod 8)` for all `m` is equivalent to
`∑_{i ≥ 1} d_D(i) d_D(4m-i) ≡ 0 (mod 4)` for all `m`, where `p̄` counts overpartitions.
