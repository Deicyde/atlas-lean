# Partition mod five iff sigma convolution

Ramanujan's congruence `p(5m+4) ≡ 0 (mod 5)` for all `m` is equivalent to
`∑_{i ≥ 1} σ(i) σ(5m+1-i) ≡ 0 (mod 5)` for all `m`.
