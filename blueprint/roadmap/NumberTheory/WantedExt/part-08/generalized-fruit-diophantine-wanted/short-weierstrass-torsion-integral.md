# Short weierstrass torsion integral

Nagell-Lutz integrality: for an elliptic curve `E : y² = x³ + A x + B` over `ℚ` with
`A, B ∈ ℤ`, every torsion point `P = (x, y) ∈ E(ℚ)` of order `m ≥ 2` has `x, y ∈ ℤ`.
