# Tsum lucas Poly cube odd index

Corollary 4.9: for real `x > 0`,
`Σ_{n≥1} ((x³ + 3x)ℓ_{6n+3} + 3x ℓ_{2n+1})/(ℓ_{2n+1}² + x² + 4)³ = 1/(x² + 2)³` and
`Σ_{n≥1} (x(x⁴ + 4x² + 3)f_{6n+3} - 3x f_{2n+1})/(ℓ_{2n+1}² - x²(x² + 4))³
  = ((x² + 3)³ + 1)/(x³(x² + 4)(x² + 3)³)`.
