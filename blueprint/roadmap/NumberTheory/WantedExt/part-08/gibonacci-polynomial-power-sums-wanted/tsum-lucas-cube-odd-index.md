# Tsum lucas cube odd index

Corollary 4.10: `Σ_{n≥1} (4L_{6n+3} + 3L_{2n+1})/(L_{2n+1}² + 5)³ = 1/27` and
`Σ_{n≥1} (8F_{6n+3} - 3F_{2n+1})/(L_{2n+1}² - 5)³ = 13/64`.
