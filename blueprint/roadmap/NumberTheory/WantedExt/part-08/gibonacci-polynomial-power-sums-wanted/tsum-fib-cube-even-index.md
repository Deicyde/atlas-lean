# Tsum fib cube even index

Corollary 4.4: `Σ_{n≥1} (4F_{6n} + 3F_{2n})/(F_{2n}² + 1)³ = 5` and
`Σ_{n≥2} (8L_{6n} - 3L_{2n})/(F_{2n}² - 1)³ = 140/27`.
