# Tsum fib Poly cube even index

Corollary 4.3: for real `x > 0`,
`Σ_{n≥1} ((x³ + 3x)f_{6n} + 3x f_{2n})/(f_{2n}² + 1)³ = x² + 4` and
`Σ_{n≥2} (x(x⁴ + 4x² + 3)ℓ_{6n} - 3x ℓ_{2n})/(f_{2n}² - x²)³
  = (x² + 4)((x² + 2)³ + 1)/(x³(x² + 2)³)`.
