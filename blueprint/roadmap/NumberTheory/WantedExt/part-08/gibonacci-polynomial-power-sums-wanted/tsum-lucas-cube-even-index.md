# Tsum lucas cube even index

Corollary 4.6: `Σ_{n≥1} (4L_{6n} - 3L_{2n})/(L_{2n}² - 5)³ = 1` and
`Σ_{n≥2} (8F_{6n} + 3F_{2n})/(L_{2n}² + 5)³ = 74/9261`.
