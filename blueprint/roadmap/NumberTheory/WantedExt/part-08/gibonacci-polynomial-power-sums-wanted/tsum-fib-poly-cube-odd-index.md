# Tsum fib Poly cube odd index

Corollary 4.7: for real `x > 0`,
`Σ_{n≥1} ((x³ + 3x)f_{6n+3} - 3x f_{2n+1})/(f_{2n+1}² - 1)³ = (x² + 4)/x³` and
`Σ_{n≥1} (x(x⁴ + 4x² + 3)ℓ_{6n+3} + 3x ℓ_{2n+1})/(f_{2n+1}² + x²)³
  = (x² + 4)((x² + 1)³ + 1)/(x² + 1)³`.
