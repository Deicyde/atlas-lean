# Tsum lucas Poly cube even index

Corollary 4.5: for real `x > 0`,
`Σ_{n≥1} ((x³ + 3x)ℓ_{6n} - 3x ℓ_{2n})/(ℓ_{2n}² - Δ²)³ = 1/x³` and
`Σ_{n≥2} (x(x⁴ + 4x² + 3)f_{6n} + 3x f_{2n})/(ℓ_{2n}² + (x² + 4)x²)³
  = (1/(x² + 4))(1/(x² + 2)³ + 1/(x⁴ + 4x² + 2)³)`.
