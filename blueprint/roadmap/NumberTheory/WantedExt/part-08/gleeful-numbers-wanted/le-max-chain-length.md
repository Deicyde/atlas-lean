# Lemma 2

**Lemma 2.** If `k > 1` and `M = M(x, k) ≥ M₀ ≥ 6`, then
`M ≥ (k+1) x^{1/(k+1)} / (log x)^{k/(k+1)} · D(M₀, k)`.
