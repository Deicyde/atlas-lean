# Lemma 1

**Lemma 1.** If `k > 1` and `M = M(x, k) ≥ M₀ ≥ 6`, then
`M < 4^{1/(k+1)} (k+1) x^{1/(k+1)} / (log x)^{k/(k+1)} · C(M₀, k)`.
