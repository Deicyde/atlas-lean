# Lemma 3

**Lemma 3.** If `k > 1` and `M = M(x, k) ≥ M₀ ≥ 6`, then
`log M < log x / (k+1) · 1 / A(M₀)` and `log M ≥ log x / (k+1) · 1 / B(M₀, k)`.
