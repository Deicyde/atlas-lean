# Gen Cohn Tree is Gen Cohn Triple

Corollary 3.15: the vertex of `GCT(k, ℓ)` at each path is a `k`-generalized Cohn triple
associated with the vertex of `MT(k)` at the same path (the canonical graph isomorphism
`GCT(k, ℓ) → MT(k)`).
