# Parent

Lemma 3.11: if `(P, Q, R)` is a `k`-generalized Cohn triple associated with `(a, b, c)`,
then `(P, R, P⁻¹(R + S))` is one associated with `(a, c, b')` and `((P + S)R⁻¹, P, R)` one
associated with `(b', a, c)`, where `b' = (a² + kac + c²)/b`.
