# Vieta eq

The integer presentation of the Vieta jumpings displayed after Corollary 2.2: for a
`k`-generalized Markov triple, `(a² + kab + b²)/c = (3 + 3k)ab - c - k(a + b)` and
`(b² + kbc + c²)/a = (3 + 3k)bc - a - k(b + c)`, stated without division.
