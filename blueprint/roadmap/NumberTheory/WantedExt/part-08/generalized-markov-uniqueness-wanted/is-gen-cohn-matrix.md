# Is Gen Cohn Matrix

A `k`-generalized Cohn matrix: an integer `2 × 2` matrix `P` of determinant `1` whose
`(1, 2)`-entry `p₁₂` is a `k`-generalized Markov number and whose trace is
`(3 + 3k) p₁₂ - k`.
