# Characteristic number of $(1, 5, 2)$

**Characteristic number of $(1, 5, 2)$.** The number $2$ is a characteristic number of
$(m_r, m_t, m_s) = (1, 5, 2)$: indeed $0 < 2 < 5/2$ and $1 \cdot 2 \equiv 2 \pmod 5$.
