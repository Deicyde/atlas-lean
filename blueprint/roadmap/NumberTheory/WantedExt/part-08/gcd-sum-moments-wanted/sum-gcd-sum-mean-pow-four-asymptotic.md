# Theorem 3

**Theorem 3** (`k = 4`). There is a real polynomial `P` such that for every `ε > 0`,
`∑_{n ≤ x} A(n)^4 = x P(log x) + O_ε(x^{157/199 + ε})` as `x → ∞`.
