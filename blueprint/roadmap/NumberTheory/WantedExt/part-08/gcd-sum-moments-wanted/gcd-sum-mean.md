# Gcd Sum Mean

The mean gcd-sum function `A(n) = P(n)/n`, where `P(n) = ∑_{j=1}^n gcd(j, n)` is Pillai's
gcd-sum function (`A(0) = 0` by the convention `x / 0 = 0`).
