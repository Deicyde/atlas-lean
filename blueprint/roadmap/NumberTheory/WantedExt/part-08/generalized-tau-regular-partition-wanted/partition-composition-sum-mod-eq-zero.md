# Partition composition sum mod Eq zero

For a prime `l ≥ 5` and `m ≥ 0` with `m ≢ 0` and `m ≢ (-1)^r C(l - 3, r) (mod l)` for all
`0 ≤ r ≤ (l - 3)/2`: every `n ≡ m (mod l)` has
`∑_{a_1 + ⋯ + a_{l-3} = n} p(a_1)⋯p(a_{l-3}) ≡ 0 (mod l)`.
