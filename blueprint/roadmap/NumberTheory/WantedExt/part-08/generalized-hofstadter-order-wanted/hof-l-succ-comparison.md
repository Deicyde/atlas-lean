# Hof L succ comparison

For `k, n ≥ 1` and `0 ≤ j ≤ k`: `L_k(n) ≥ L_{k+1}(n)`, i.e.
`C_k^{(=k)}(n) ≥ C_{k+1}^{(=k+1)}(n)`, and `L_k^j(n) < L_{k+1}^{j+1}(n)`.
