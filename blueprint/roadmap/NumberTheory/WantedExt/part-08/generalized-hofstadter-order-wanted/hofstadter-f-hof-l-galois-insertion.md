# Hofstadter F hof L galois Insertion

For `j ≥ 0` and `k ≥ 1`, `F_k^j` and `L_k^j` form a Galois connection
(`F_k^j(n) ≤ m ↔ n ≤ L_k^j(m)`), and it is a Galois insertion: `F_k^j ∘ L_k^j = id`.
