# Hofstadter F eq hof Count ne one

For `k > 1`, `F_k(n) = n - C_k^{(=1)}(n) = C_k^{(≠1)}(n)`; hence `∂F_k(n) = 0` exactly when
`x_k[n] = 1`, and `∂F_k(n) = 1` otherwise.
