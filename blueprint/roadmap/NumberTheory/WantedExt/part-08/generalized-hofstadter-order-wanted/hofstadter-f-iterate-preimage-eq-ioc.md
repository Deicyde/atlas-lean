# Hofstadter F iterate preimage eq Ioc

For `j ≥ 0` and `k ≥ 1`: (a) for `n ≥ 1`, `F_k^{-j}({n}) = (L_k^j(n-1), L_k^j(n)]`;
(b) equivalently, for `m ≥ 1`, `L_k^j(F_k^j(m) - 1) < m ≤ L_k^j(F_k^j(m))`.
