# Abs convergent num sub lt of le den

Theorem 10 (Hardy–Wright, Theorem 182): for an irrational `x` with
convergents `p_n / q_n`, if `n > 1`, `0 < q ≤ q_n` and `p / q ≠ p_n / q_n`,
then `|p_n - q_n x| < |p - q x|`.
