# Pell Shifted Norm le pell Shift Bound

With `x₁ = sup {x ≥ 0 : f_{i,j}(x) = K}` (Equation (3.6)), `f_{i,j}(x) ≤ K` for all
`x ∈ [0, x₁]`.
