# Pell inverse floor

For real `x ≥ 1` and `t = g(x)` (the `t ≥ 0` with `u(t) + v(t) = x`),
`⌊g(x)⌋ = ⌊(log ⌊x⌋ + C) / log(α + β √D)⌋` with `C = log(2 √D / (1 + √D))`.
