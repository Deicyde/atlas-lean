# Pell solutions eq signed powers

Every integer solution of `x² - D y² = 1` is `(i u_n, j v_n)` for some `n ≥ 0` and signs
`i, j ∈ {1, -1}`, where `u_n + v_n √D = (α + β √D)^n`; conversely every such pair is a solution.
