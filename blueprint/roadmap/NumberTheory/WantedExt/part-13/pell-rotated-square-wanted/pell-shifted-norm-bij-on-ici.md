# Pell Shifted Norm bij On Ici

With `x₁ = sup {x ≥ 0 : f_{i,j}(x) = K}` (Equation (3.6)), on `[x₁, ∞)` the function
`f_{i,j}` equals `u + v + i a + j b` (Equation (3.7)), is strictly increasing, and maps
`[x₁, ∞)` bijectively onto `[K, ∞)`.
