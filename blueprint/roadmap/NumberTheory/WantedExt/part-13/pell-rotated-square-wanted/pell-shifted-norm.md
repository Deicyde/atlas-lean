# Pell Shifted Norm

The function `f_{i,j}(x) = |i u(x) + a| + |j v(x) + b|`, the `L¹` norm of the real solution
`R_{i,j}(x)` of the shifted Pell equation `(x - a)² - D (y - b)² = 1`.
