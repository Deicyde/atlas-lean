# Digit Sum Congruence Count

`N_b(k, q, r, x, y)`: the number of integer solutions of `x_1 + ⋯ + x_k ≡ r (mod q)` with
`x ≤ x_1 < y` and `0 ≤ x_i < b` for `2 ≤ i ≤ k` (meant for `k ≥ 1`); `x, y` are taken natural.
