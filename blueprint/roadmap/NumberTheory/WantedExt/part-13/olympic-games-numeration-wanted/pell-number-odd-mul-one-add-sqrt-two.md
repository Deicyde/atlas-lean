# Pell Number odd mul one add sqrt two

For `k ≥ 0` and `α = 1 + √2`: `P_{2k+1} α = P_{2k+2} + (√2 - 1)^{2k+1}` and
`H_{2k} α = H_{2k+1} + √2 (√2 - 1)^{2k}`.
