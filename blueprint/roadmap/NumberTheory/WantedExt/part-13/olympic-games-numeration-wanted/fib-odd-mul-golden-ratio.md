# Fib odd mul golden Ratio

For `k ≥ 0`, `F_{2k+1} φ = F_{2k+2} + ((√5 - 1) / 2)^{2k+1}` and
`F_{2k+1} (1 + φ) = F_{2k+3} + ((√5 - 1) / 2)^{2k+1}`.
