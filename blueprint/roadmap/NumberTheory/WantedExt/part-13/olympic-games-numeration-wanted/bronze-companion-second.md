# Bronze Companion Second

The companion bronze numbers of the second type, `D_n = B_{n+1} - B_n = 2B_n + B_{n-1}`
(`D_0 = 1`, `D_1 = 2`, `D_{n+1} = 3D_n + D_{n-1}`).
