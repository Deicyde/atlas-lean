# Haugland's 2016 upper bound for the minimum-overlap constant

**Haugland's 2016 upper bound for the minimum-overlap constant.** The continuous Erdős
minimum-overlap constant $C_{1b}$ satisfies $C_{1b} \le 0.380926$.
