# Lemma 4

**Lemma 4.** On `y² = x³ + ax - b` with `a, b ∈ ℤ`, `a ≠ 0`, `b > 0` (and
`4a³ + 27b² ≠ 0`), every `P ∈ E(ℚ) \ {O}` satisfies `H(P) < √(1 + |a|) · H(x(P))^{3/2}`.
