# Corollary 1

**Corollary 1.** On `y² = x³ + ax + b` with `a, b ∈ ℤ`, `ab ≠ 0` (and `4a³ + 27b² ≠ 0`),
if `1 + |a| < ‖p‖^{1/2} / 1.782` then every `P ∈ E(ℚ) \ {O}` with `x(P) y(P) ≠ 0` satisfies
`H(P) > ‖p‖^{1/6} / 1.634`, where `‖p‖ = √(2 + a² + b²)`.
