# Theorem 2

**Theorem 2.** On `y² = x³ + ax + b` (`a, b ∈ ℤ`, `4a³ + 27b² ≠ 0`):
(a) if `a = ±1` and `b ∉ {0, ±1}`, no point `P ∈ E(ℚ) \ {O}` has `H(P) < (|b|/5)^{1/3}`;
(b) if `a ∉ {0, ±1}` and `b = -1`, no point `P ∈ E(ℚ) \ {O}` has `H(P) < (|a|/5)^{1/3}`;
(c) if `a ∉ {0, ±1}` and `b = 1`, the only points `P ∈ E(ℚ) \ {O}` with
`H(P) < (|a|/5)^{1/3}` are `(0, ±1)`.
