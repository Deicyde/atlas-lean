# Right Trunc Squarefree Count

`L_{b,k}`: the number of right-truncatable square-free numbers with exactly `k` digits in
base `b`, i.e. the `x` with `b^{k-1} ≤ x < b^k` such that `⌊x / b^ℓ⌋` is square-free for every
`ℓ ∈ {0, …, k-1}`.
