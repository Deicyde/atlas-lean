# Infinite shortest weakly Prime Additive dvd iff

Fang and Chen: for a positive integer `m` there are infinitely many shortest weakly
prime-additive numbers `n` (length `κ_n = 3`) with `m ∣ n` if and only if `8 ∤ m`.
