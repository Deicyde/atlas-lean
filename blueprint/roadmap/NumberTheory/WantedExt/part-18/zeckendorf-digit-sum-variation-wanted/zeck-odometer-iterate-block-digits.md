# Zeck Odometer iterate block digits

If `x_{ℓ+1} = ⋯ = x_{ℓ+4} = 0` (`ℓ ≥ 2`), `r_{ℓ+2} = 1` and `r < F_{ℓ+3}`, then either
`(x + r)_{ℓ+k} = r_{ℓ+k}` for `k = 1, 2, 3, 4`, or `(x + r)_{ℓ+1} = 0` and `(x + r)_{ℓ+3} = 1`.
