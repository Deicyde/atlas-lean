# Zeck Adic Variation one of mem cylinder even

On `C_{00(10)^d}`: `Δ^{(1)} = 1 - d`, and for `k ≥ 2`, `Δ_k^{(1)} = (2 - k)/2` if `k` is even
and `k ≤ 2d`, `(1 - k)/2` if `k` is odd and `k ≤ 2d + 1`, and `1 - d` if `k ≥ 2d + 2` (halves
written as `2 Δ_k^{(1)} = ⋯`).
