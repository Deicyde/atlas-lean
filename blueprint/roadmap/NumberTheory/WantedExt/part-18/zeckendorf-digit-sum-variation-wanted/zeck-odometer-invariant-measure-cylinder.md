# Zeck Odometer invariant measure cylinder

The `T`-invariant probability measure `ℙ` gives the cylinder `C_{r_ℓ ⋯ r_2}` (`ℓ ≥ 2`,
`(r_ℓ, …, r_2)` admissible, here the digits of some `y ∈ 𝕏`) the mass `1/φ^{ℓ-1}` if `r_ℓ = 0`
and `1/φ^ℓ` if `r_ℓ = 1`.
