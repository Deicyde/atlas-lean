# Zeck Odometer iterate high digits

If `r < F_{ℓ+1}` (`ℓ ≥ 2`) and `x_{ℓ+2} = x_{ℓ+3} = 0`, then `(x + r)_k = x_k` for all
`k ≥ ℓ + 3`.
