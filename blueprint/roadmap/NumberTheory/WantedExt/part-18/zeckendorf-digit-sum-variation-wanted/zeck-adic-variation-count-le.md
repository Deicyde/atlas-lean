# Zeck Adic Variation count le

For `r ≥ 1`, `N ≥ 1`, `k ≥ 2` and `d, d' ∈ ℤ`:
`(1/N)|{n < N : (Δ^{(r)}(n), Δ_k^{(r)}(n)) = (d, d')}| ≤ rφ³ ℙ(Δ^{(r)} = d, Δ_k^{(r)} = d')`,
and in particular `(1/N)|{n < N : Δ^{(r)}(n) = d}| ≤ rφ³ ℙ(Δ^{(r)} = d)`.
