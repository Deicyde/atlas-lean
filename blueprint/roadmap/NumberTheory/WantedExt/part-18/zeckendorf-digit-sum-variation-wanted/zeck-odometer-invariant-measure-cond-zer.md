# Zeck Odometer invariant measure cond zeros

For `2 ≤ k_0 < k_1 < ⋯ < k_ℓ` and a union `A` of cylinders of order `k_0 - 1` (a set
determined by `x_2, …, x_{k_0}`) with `x_{k_0} = 0` on `A` and `ℙ(A) > 0`:
`1/φ^ℓ ≤ ℙ_A(x_{k_i} = 0 for 1 ≤ i ≤ ℓ) ≤ (2/φ²)^ℓ`.
