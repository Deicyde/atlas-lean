# Zeck Adic Variation

The variation `Δ^{(r)}(x) = lim_{k → ∞} Δ_k^{(r)}(x)` on `𝕏`, where the integer sequence
`Δ_k^{(r)}(x)` is eventually constant; it is `0` (a junk value) elsewhere, a set the paper shows
to be finite.
