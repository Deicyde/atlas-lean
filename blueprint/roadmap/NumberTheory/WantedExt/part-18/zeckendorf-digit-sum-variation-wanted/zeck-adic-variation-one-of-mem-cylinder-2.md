# Zeck Adic Variation one of mem cylinder odd

On `C_{001(01)^d}`: `Δ^{(1)} = -d`, and for `k ≥ 2`, `Δ_k^{(1)} = -k/2` if `k` is even and
`k ≤ 2d + 2`, `(1 - k)/2` if `k` is odd and `k ≤ 2d + 1`, `(3 - k)/2` if `k = 2d + 3`, and `-d` if
`k ≥ 2d + 4` (halves written as `2 Δ_k^{(1)} = ⋯`).
