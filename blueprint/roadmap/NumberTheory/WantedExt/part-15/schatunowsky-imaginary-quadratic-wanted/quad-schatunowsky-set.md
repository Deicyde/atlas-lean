# Quad Schatunowsky Set

The paper's set `Q_{m,ℓ}` (Equation (4)), as a set of elements of `𝓞 K` (it is closed under
multiplication by units): `α` with `N(α) > 1` such that every `β` with `1 < N(β) < N(α)` and
`gcd(α, β) = 1` has `Ω(β) ≤ ℓ`.
