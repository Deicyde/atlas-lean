# Shifted Floor Residue Count one asymptotic series

Corollary 35: for `m ≥ 2` and `α, ν ∈ [0, 1)`, uniformly over `n` with
`nα ≥ ν`, `𝓝_{n,α,ν,1,m} = -αn/(1-α) +
n ∑_{i ≥ 0} (1/(1+im-α) - 1/(2+im-α)) + O(√n)`.
