# Card eisenstein ellipse eq

Corollary 43: the elliptical region `x² + xy + y² ≤ n` contains
`6 𝓝_{n,0,0,1,3} + 1` lattice points. Stated for every `n : ℕ` (both sides
are `1` at `n = 0`).
