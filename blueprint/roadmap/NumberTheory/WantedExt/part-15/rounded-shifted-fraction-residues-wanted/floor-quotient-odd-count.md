# Floor Quotient Odd Count

The floor sequence parity count `𝓕_n`: the number of `k` with `1 ≤ k ≤ n`
for which `⌊n/k⌋` is odd (OEIS A059851). Natural-number division `n / k` is
`⌊n/k⌋`.
