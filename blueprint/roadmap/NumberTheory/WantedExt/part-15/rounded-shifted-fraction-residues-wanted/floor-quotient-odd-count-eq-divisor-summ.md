# Floor Quotient Odd Count eq divisor summatory sub

Corollary 3: `𝓕_n = D(n) - 2 D(n/2)`, where `D(x) = ∑_{m ≤ x} τ(m)` is
the divisor summatory function; for integer `m`, `m ≤ n/2` means
`m ≤ ⌊n/2⌋ = n / 2`.
