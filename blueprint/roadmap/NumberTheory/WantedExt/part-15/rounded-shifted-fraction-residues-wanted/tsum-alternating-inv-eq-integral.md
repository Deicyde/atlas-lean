# Tsum alternating inv eq integral

Proposition 36: for integers `2 ≤ r ≤ m` and `α ∈ [0, 1)`,
`∑_{i ≥ 0} (1/(r+im-α) - 1/(r+1+im-α)) = ∫_0^1 (1-x) x^{r-1-α} / (1-x^m) dx`.
