# Lemma 1

**Lemma 1.** For `F` in the Selberg class, `k ≥ 1` and `a ∈ ℂ` there is `E₁ ≥ 1` such that
`F^(k)` has no a-point in `Re s ≥ E₁`. Stated under `a ≠ 0` or `a(n) ≠ 0` for some `n ≥ 2`
(for `F = 1`, `a = 0` every point is a `0`-point).
