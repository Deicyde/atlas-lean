# Lemma 3

**Lemma 3.** For `k ≥ 1` and `a ∈ ℂ` there are `E₂ ≤ 0` and `τ_k` such that `F^(k)` has no
a-point in `Re s ≤ E₂`, `|Im s| ≥ τ_k`. Stated under `a ≠ 0` or `a(n) ≠ 0` for some `n ≥ 2`.
