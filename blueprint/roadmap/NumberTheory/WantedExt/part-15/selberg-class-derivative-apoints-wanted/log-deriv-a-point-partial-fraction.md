# Lemma 5

**Lemma 5.** For `σ₁ < Re s < σ₂` and large `t = Im s` (with `s` not an a-point),
`F^(k+1)(s) / (F^(k)(s) - a) = ∑_{|γ - t| ≤ 1} 1 / (s - ρ) + O(log t)`, the sum over the
a-points `ρ = β + iγ` of `F^(k)` with multiplicity.
