# Second Order Gen Value family integer

If `r, s` are coprime (`s ≠ 0`) and `A(r/s)` is an integer, then
`A(A^{(r,s)}_n / A^{(r,s)}_{n+1})` is an integer whenever `A^{(r,s)}_{n+1} ≠ 0` (all `n ∈ ℤ`).
