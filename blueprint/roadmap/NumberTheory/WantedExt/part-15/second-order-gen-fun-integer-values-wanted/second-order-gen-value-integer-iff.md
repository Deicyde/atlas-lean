# Second Order Gen Value integer iff

For coprime `r, s` (`s ≠ 0`), `A(r/s)` is an integer iff `b ≡ -a r s⁻¹ (mod |s² - prs - r²|)`,
stated for every inverse `t` of `s` modulo `s² - prs - r²`.
