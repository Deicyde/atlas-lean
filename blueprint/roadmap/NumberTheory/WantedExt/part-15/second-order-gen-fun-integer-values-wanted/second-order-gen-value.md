# Second Order Gen Value

The generating function `A(x) = (a(1 - px) + bx) / (1 - px - x²)` of `A_0 = a`, `A_1 = b`,
`A_{n+1} = p A_n + A_{n-1}`, as a rational function evaluated at `x ∈ ℚ`.
