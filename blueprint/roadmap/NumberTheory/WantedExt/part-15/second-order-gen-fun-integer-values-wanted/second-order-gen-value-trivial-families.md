# Second Order Gen Value trivial families integer

(i) `A(A^{(0,1)}_n / A^{(0,1)}_{n+1})` is an integer for all `n ≠ -1`; (ii)
`A(A^{(-b,a)}_n / A^{(-b,a)}_{n+1})` is an integer whenever `A^{(-b,a)}_{n+1} ≠ 0`.
