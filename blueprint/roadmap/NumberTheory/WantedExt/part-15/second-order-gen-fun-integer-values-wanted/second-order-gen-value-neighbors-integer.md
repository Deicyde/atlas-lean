# Second Order Gen Value neighbors integer

If `r, s ≠ 0`, `r + ps ≠ 0`, `gcd(r, s) = 1` and `A(r/s)` is an integer, then `A(s/(r + ps))`
and `A((s - pr)/r)` are integers.
