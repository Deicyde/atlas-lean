# Repetend digit diff of columns eq

If `n_r = 2`, with rows `b ≠ b'` and `D_i = r_{b',i} - r_{b,i}`, `S_i` the column sum: if
columns `i` and `j` match then `D_i = ±D_j` and `S_i = S_j`.
