# Ne add one of sq add mul mem

If `b_2 = b^2 + u n` with `u ∈ ℤ` and `2 ≤ b_2 ≤ n - 2`, then `b ≠ u + 1`. Stated for every
natural `b` (the paper's `b` is a small base).
