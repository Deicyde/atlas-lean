# Padic Val Nat sq sub add one of order Of eq

Class C setting (`n = p^i` with `p ≡ 1 (mod 6)` prime, `Q = p^j`, `j ≥ 1`, `i ≥ 2j`, `B` of
order `L = 6Q` mod `n`):
`B^2 - B + 1 = M` with `p`-adic valuation exactly `i - j` (so `M = l p^(i-j)`, `p ∤ l`).
