# Pow mod eq sub one of order Of eq

Class C setting (`p ≡ 1 (mod 6)`): if `0 ≤ z < 6Q` with `z ≡ 2 (mod 6)` and
`z ≡ B⁻¹ (mod Q)`, or `z ≡ 1 - B (mod Q)`, then `B^z ≡ B - 1 (mod n)`.
