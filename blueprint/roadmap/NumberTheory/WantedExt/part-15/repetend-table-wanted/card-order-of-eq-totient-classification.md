# Card order Of eq totient classification

If `E(L, n) = φ(L)` and `L ≥ 2` is even, then `n = 4, L = 2`, or `n = t q` with `t ∈ {1, 2}`,
`q` an odd prime power and `L ∣ φ(q)`.
