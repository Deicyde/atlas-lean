# Q Collatz Parity Vector mod Eq iff

For odd `A, B`, `n ∈ ℕ` and `a, b ∈ 𝔽₂[[q]]`:
`PV(a) ≡ PV(b) (mod 2^{n+1})` if and only if `a ≡ b (mod q^{n+1})`.
