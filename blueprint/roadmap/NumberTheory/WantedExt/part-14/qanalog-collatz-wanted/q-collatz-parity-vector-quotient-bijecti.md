# Q Collatz Parity Vector quotient bijection

For odd `A, B` and `n ≥ 1`, the map `[a] ↦ [PV(a)]` is a well-defined bijection from
`𝔽₂[[q]]/(qⁿ)` to `ℤ₂/2ⁿ ≅ ℤ/2ⁿ`.
