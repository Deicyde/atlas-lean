# Q Collatz one one add X sq polynomial

For `T = T_{1,1+q²}`: the `T`-orbit of every polynomial reaches the `2`-cycle `{1, q}` or
one of the fixed points `0`, `1 + q`; and `T(x)` is a polynomial if and only if `x` is.
