# Q Collatz add X pow mul

For odd `A, B`, `n ∈ ℕ` and `U, V ∈ 𝔽₂[[q]]` with `V` odd,
`T_{A,B}(U + q^{n+1} V) = T_{A,B}(U) + qⁿ W` for some odd `W`.
