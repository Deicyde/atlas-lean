# Convergent Den symm split

Proposition 3 (i): for a symmetric sequence `a₁, …, a_{l-1}` and `1 ≤ i ≤ l - 2`,
`q_{l-1} = q_i q_{l-1-i} + q_{i-1} q_{l-2-i}`. The case `i = 0` (with `q_{-1} = 0`) is
omitted.
