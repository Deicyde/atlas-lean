# Is Quadratic Packing Polynomial sheared example twelve sevenths

The sheared polynomial `P̂(x, y) = 6x(x - 3/2) + x + 3/2 y + 2` is a QPP on the sheared
lattice sector `Î(12/7) = M(I(12/7))`, `M(x, y) = (x - y/2, y)`.
