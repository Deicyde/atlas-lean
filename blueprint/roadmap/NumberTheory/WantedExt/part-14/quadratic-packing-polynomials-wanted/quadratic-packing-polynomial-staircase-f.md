# Quadratic Packing Polynomial staircase First Height

Lemma 15: if `P` is a QPP on `I(n/m)` with step difference `k > 0`, then the first step of
the staircase `J_k` has height `ȳ_k = n/l - 1`, `l = gcd(m - 1, n)`.
