# Sz Dual Index

The SZ dual index `k†`: the index read off `τ̃(p^{k₁} y ⋯ p^{kᵣ} y)`, where `τ̃` is the
anti-automorphism of words with `τ̃(p) = y`, `τ̃(y) = p` (reverse the word, swap the letters). For
`k = (k₁, {0}^{d₁-1}, …, kᵣ, {0}^{dᵣ-1})` it is `(dᵣ, {0}^{kᵣ-1}, …, d₁, {0}^{k₁-1})`.
