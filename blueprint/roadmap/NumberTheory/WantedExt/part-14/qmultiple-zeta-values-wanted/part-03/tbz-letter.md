# Tbz Letter

A letter of the Takeyama–Bradley–Zhao model as general-qMZV data: `none` is the symbol
`1̄` (summand `q^m / (1 - q^m)`, data `(1, X)`) and `some k` is `k ∈ ℕ`, `k ≥ 1` (summand
`q^{(k-1)m} / (1 - q^m)^k`, data `(k, X^{k-1})`); `some 0` is junk (data `(0, 1)`).
