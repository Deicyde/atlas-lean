# Ooz QMZV eq sz Star QMZV sz Dual Index

OOZ-qMZVs as SZ-star qMZVs, `ζ_q^OSZ = ζ_q^{SZ,⋆} ∘ τ̃` on `𝔎¹`: for an SZ-admissible index `k`
(empty or `k₁ ≥ 1`), `ζ_q^OOZ(k) = ζ_q^{SZ,⋆}(k†)`.
