# The map $V_{TBZ}$ on the index $(1)$

**The map $V_{TBZ}$ on the index $(1)$.** The map $V_{TBZ}$ sends the SZ index $(1)$ to the
one-letter TBZ word $\bar 1$ with coefficient $1$.
