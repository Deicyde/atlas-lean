# Bi Bracket Diamond

Bachmann's product on letters `z_{k,d}` (pairs `(k, d)`):
`z_{k₁,d₁} ⊠ z_{k₂,d₂} = C(d₁ + d₂, d₁) (∑_{j ≤ k₁} λ_{k₁,k₂}^j z_{j,d₁+d₂}
+ ∑_{j ≤ k₂} λ_{k₂,k₁}^j z_{j,d₁+d₂} + z_{k₁+k₂,d₁+d₂})`.
