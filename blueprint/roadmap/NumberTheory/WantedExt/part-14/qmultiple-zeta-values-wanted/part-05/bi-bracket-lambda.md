# Bi Bracket Lambda

Bachmann's coefficients
`λ_{a,b}^j = (-1)^{b-1} C(a + b - j - 1, a - j) B_{a+b-j} / (a + b - j)!`, with Mathlib's
Bernoulli numbers `bernoulli` (`B₁ = -1/2`).
