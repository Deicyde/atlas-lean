# Bz QMZV bz Block Index dual

BZ duality `ζ_q^BZ ∘ τ = ζ_q^BZ` on `𝔥⁰`, in index form: for `aⱼ, bⱼ ≥ 1`,
`ζ_q^BZ(a₁ + 1, {1}^{b₁-1}, …, aᵣ + 1, {1}^{bᵣ-1}) =
ζ_q^BZ(bᵣ + 1, {1}^{aᵣ-1}, …, b₁ + 1, {1}^{a₁-1})`.
