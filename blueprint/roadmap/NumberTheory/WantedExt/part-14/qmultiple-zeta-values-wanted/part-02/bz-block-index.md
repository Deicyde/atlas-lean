# Bz Block Index

The admissible index `(a₁ + 1, {1}^{b₁-1}, …, aᵣ + 1, {1}^{bᵣ-1})` built from
`[(a₁, b₁), …, (aᵣ, bᵣ)]`; for `aⱼ, bⱼ ≥ 1` it corresponds to the word
`x^{a₁} y^{b₁} ⋯ x^{aᵣ} y^{bᵣ}` of `𝔥⁰`, and the duality `τ` maps it to the index
of `[(bᵣ, aᵣ), …, (b₁, a₁)]`.
