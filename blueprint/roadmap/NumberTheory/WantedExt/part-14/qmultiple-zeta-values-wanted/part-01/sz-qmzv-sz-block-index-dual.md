# Sz QMZV sz Block Index dual

SZ duality in index form: for `kⱼ, dⱼ ≥ 1`,
`ζ_q^SZ(k₁, {0}^{d₁-1}, …, kᵣ, {0}^{dᵣ-1}) = ζ_q^SZ(dᵣ, {0}^{kᵣ-1}, …, d₁, {0}^{k₁-1})`.
The paper's equivalent word form `ζ_q^SZ ∘ τ̃ = ζ_q^SZ` on `𝔎¹` is not stated
separately.
