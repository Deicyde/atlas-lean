# Pythagorean cathetus product

Product of Pythagorean triples through a cathetus: let `(a, a₁, a₂)` and `(b, b₁, b₂)` be the
triples generated by (1), `x² / (2d) ∓ d / 2`, from `d₁ ∈ C(a)` and `d₂ ∈ C(b)`, and let
`(ab, y, z)` be the triple generated from `d₃ = d₁ d₂`. Then `y = a₁ b₂ + a₂ b₁`,
`z = y + d₁ d₂` (2), `y = a₁ b₁ + a₂ b₂ - d₁ d₂`, `z = a₁ b₁ + a₂ b₂` (3), and `d₁ d₂ ∈ C(ab)`.

Corrected reading: the source takes any triple `(ab, y, z)` with `z - y = d₃ ∈ C(ab)` and
concludes `d₃ = d₁ d₂`, which is false as printed: for `(3, 4, 5)` twice (`d₁ = d₂ = 1`) and
`(9, 12, 15)` (`d₃ = 3 ∈ C(9)`), `d₃ ≠ d₁ d₂` and `a₁ b₂ + a₂ b₁ = 40 ≠ 12`. Following the
closing clause "with `d₃ = d₁ · d₂`", the triple for `ab` is the one generated by `d₃ = d₁ d₂`.
