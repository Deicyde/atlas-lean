# Unit Circle Rat Mul

Amato's product on rational points of the unit circle (14)(I): for `(a/c, b/c)` and
`(d/f, e/f)`, `(ad / (cf + eb), (bf + ec) / (cf + eb))`; in coordinates
`(x, y) ⊙ (x', y') = (x x' / (1 + y y'), (y + y') / (1 + y y'))`.
