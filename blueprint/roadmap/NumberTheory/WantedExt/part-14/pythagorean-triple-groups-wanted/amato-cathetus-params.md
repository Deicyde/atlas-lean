# Amato Cathetus Params

Amato's parameter set `C(x)` for Pythagorean triples with cathetus `x`, as printed: for odd
`x`, `D(x) = {d ∈ ℕ : d ≤ x, d ∣ x²}`; for even `x = 2ⁿ k` (`k` odd), `D(x) ∩ P(x)` with
`P(x) = {2^s l : l ∣ x², s ∈ {1, …, n - 1}}`.
