# Lemma 3

**Lemma 3.** `π_{ℓ,c,d}`, the number of primes `n ≤ g_ℓ(c, d)` with more than
`ℓ` representations `n = c x + d y`, equals the number of primes `n` with
`ℓ c d < n ≤ g_ℓ(c, d)` of the form `n = ℓ c d + c x₀ + d y₀` with `0 ≤ x₀ ≤ d` and
`0 ≤ y₀ ≤ c`.
