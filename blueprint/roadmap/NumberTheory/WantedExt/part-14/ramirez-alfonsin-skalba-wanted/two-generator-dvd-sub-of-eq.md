# Lemma 1

**Lemma 1.** If `c x + d y = c x' + d y'` with `x, y, x', y' ∈ ℕ` and `c, d`
coprime, then `c ∣ y - y'` and `d ∣ x - x'`.

The paper's standing assumption `1 < c < d` is not needed and is dropped.
