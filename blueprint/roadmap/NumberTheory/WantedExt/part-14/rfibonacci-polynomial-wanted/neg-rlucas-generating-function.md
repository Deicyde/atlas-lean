# Neg RLucas generating Function

Theorem 8, `V` part, as an identity of formal power series: for `r ≥ 2`,
`(1 - y^{-1} z^r + x y^{-1} z^{r+1}) ∑_{n ≥ 0} V^{(-r)}_n z^n = r + 1 - y^{-1} z^r`.
