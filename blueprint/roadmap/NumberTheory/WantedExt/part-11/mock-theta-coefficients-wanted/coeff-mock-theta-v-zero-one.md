# First coefficients of the mock theta function $v$

**First coefficients of the mock theta function $v$.** Write
$v(q) = \sum_{n \ge 0} P_v(n) q^n$ for the eighth-order mock theta function $v$. Then
$P_v(0) = 0$ and $P_v(1) = 1$.
