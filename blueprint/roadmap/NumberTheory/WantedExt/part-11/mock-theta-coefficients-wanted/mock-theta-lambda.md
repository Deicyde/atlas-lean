# Mock Theta Lambda

The sixth-order mock theta function
`λ(q) = ∑_{n ≥ 0} (-1)^n q^n (q; q^2)_n / (-q; q)_n` as an integer power series; the `n`th
summand has order `n`, so the coefficient of `q^m` only involves the summands `n ≤ m`.
