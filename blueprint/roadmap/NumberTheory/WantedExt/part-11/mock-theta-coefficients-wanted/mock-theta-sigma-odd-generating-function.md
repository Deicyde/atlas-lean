# Mock Theta Sigma odd generating Function

Theorem 5: `∑_{n ≥ 0} P_σ(2n+1) q^n = f_2^2 f_6^2/(f_1^2 f_3)`, stated with the
denominator cleared, where `∑ P_σ(n) q^n = σ(q)`.
