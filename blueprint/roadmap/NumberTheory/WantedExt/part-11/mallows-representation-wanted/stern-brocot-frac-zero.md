# The Stern–Brocot path starts at $1/2$

**The Stern–Brocot path starts at $1/2$.** For every real number $\alpha$, the first
fraction $f_1(\alpha)$ on the Stern–Brocot path of $\alpha$ is $1/2$, as the pair with numerator
$1$ and denominator $2$.
