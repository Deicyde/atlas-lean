# Mallows Rep ae not relatively Dense

For almost every irrational `α ∈ (0, 1)` some finite word over `{L, M, R}` does not occur
relatively densely in `M(α)`: there is no `ℓ > 0` such that every length-`ℓ` window contains an
occurrence of it.
