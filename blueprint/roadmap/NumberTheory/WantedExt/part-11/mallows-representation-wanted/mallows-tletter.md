# Mallows TLetter

The letter `T_i`: when the next odd position is adjacent (`adj`), `L` for `O_L` and `R` for
`O_R`; otherwise `L` if both odd letters are `O_R`, `R` if both are `O_L`, and `M` if they
differ.
