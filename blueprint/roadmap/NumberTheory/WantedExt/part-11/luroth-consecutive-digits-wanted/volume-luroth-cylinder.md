# Volume luroth Cylinder

The Lüroth cylinder `I_n(c) = {x ∈ (0, 1] : d_j(x) = c_j, 1 ≤ j ≤ n}` has Lebesgue
measure `∏ 1 / (c_j (c_j - 1))`. Stated for every `c`; when some `c_j < 2` both sides
vanish.
