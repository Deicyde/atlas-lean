# Modified Degenerate Bernoulli miki

Corollary 2, Miki-type identity: for `n ≥ 4` and `𝔅_{k,λ} = 𝔅_{k,λ}(0)`,
`∑_{k=1}^{n-1} 𝔅_{k,λ} 𝔅_{n-k,λ} / k - ∑_{k=1}^{n-1} C(n, k) 𝔅_{k,λ} 𝔅_{n-k,λ} / k =
λ / log (1+λ) · H_n 𝔅_{n,λ} + n/2 · 𝔅_{n-1,λ}`, for `λ ≠ 0, -1`.
