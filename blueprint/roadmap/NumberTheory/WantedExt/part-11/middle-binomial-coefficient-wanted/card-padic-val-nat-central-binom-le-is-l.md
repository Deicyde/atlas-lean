# Card padic Val Nat central Binom le is Little O

Lemma 4: with `D = D_p = 1 + ⌊log x / log p⌋` and `K = ⌊exp(0.8 √(log x))⌋`, the number of
`m ≤ x` with `v_p(C(2m, m)) ≤ D / log D` for some prime `p ≤ 2K` is `o(x)` as `x → ∞`
(counted over `1 ≤ m ≤ x`).
