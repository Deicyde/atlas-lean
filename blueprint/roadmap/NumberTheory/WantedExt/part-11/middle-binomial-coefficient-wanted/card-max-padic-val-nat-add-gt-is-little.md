# Card max padic Val Nat add gt is Little O

Lemma 5: with `D = D_p` and `K` as in Lemma 4, the number of `m ≤ x` such that
`max {v_p(m + i) : 1 ≤ i ≤ K} > D / log D` for some prime `p < 2K` is `o(x)` as `x → ∞`
(counted over `1 ≤ m ≤ x`).
