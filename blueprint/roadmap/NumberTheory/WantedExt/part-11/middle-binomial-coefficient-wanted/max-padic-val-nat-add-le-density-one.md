# Max padic Val Nat add le density one

Lemma 2: the set of `m` such that `max {v_p(m + i) : 1 ≤ i ≤ k} ≤ 3 log k / log p` for all
`k` with `(1/2) log m < k < log m` and all primes `p ≤ 2k` has natural density `1`.
