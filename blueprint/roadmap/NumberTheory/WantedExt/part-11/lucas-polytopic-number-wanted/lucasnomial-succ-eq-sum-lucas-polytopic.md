# Theorem 2

**Theorem 2.** For `n ≥ 1`,
`[n + d, d + 1] = ∑_{k=1}^n φ^{(d+1)(n-k)} φ'^{k-1} [k + d - 1, d]`, and the same with `φ`
and `φ'` exchanged.
