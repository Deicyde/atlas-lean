# Dim H well Approximable Set rpow

The Jarník–Besicovitch theorem: for `τ ≥ 1`, the set `W(τ)` of `x ∈ [0, 1)` with
`|x - p/q| < q^{-(1+τ)}` for infinitely many `q` has Hausdorff dimension `2/(1+τ)`.
Here `W(τ) = W(ψ)` with `ψ(q) = q^{-τ}`.
