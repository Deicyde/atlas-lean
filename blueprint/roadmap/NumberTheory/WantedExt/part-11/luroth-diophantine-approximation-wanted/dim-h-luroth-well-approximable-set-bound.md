# Dim H luroth Well Approximable Set bounds

For `ψ : ℕ → (0, 1]`, `1/(1 + τ̄_ψ) ≤ dim L(ψ) ≤ 1/(1 + τ_ψ)` (in `ℝ≥0∞`, with
`1/∞ = 0`).
