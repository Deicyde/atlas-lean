# Exists luroth Convergent eq of mem luroth Triple Set

If `x ∈ (0, 1]` and `(P/Q, Q, d) ∈ S` satisfy `0 < x - P/Q ≤ 1/((d - 1) Q)`, then
`P/Q` is a Lüroth convergent of `x`.
