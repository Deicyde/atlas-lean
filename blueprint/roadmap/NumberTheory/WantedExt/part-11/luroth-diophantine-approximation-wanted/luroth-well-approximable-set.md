# Luroth Well Approximable Set

The set `L(ψ)` of Lüroth `ψ`-well approximable numbers: the `x ∈ (0, 1]` with
`|x - P_n(x)/Q_n(x)| < ψ(Q_n(x))/Q_n(x)` for infinitely many `n`.
