# Dim H luroth Well Approximable Set rpow of one le

Cao–Wu–Zhang: for `τ ≥ 1`, `dim L(τ) = 1/(1+τ)`, where `L(τ) = L(ψ)` with
`ψ(q) = q^{-τ}`.
