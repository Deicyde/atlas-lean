# Dc Level DNodes sub pred

Lemma 17: for `n = 2^k + r` with `r` odd, `0 < r < 2^k`, and `0 < i < k`,
`λᵢ(n) - λᵢ(n-1)` is `1` if `nᵢ = 0` and `-1` if `nᵢ = 1`.
