# Hamming Weight eq takagi diff

Theorem 28: for `n = 2^k + r` with `0 ≤ r < 2^k`,
`s₁(n) = 2^(k-1) (τ(r/2^k) - τ((r+1)/2^k)) + (k+2)/2`.
