# Dc Level DNodes

The number `λᵢ(n)` of `D`-nodes on level `i` of the divide-and-conquer tree on `n`
leaves: `n mod 2^i` if the binary digit `nᵢ` is `0`, and `2^i - (n mod 2^i)` if it is `1`.
