# Takagi dyadic eq midpoint add

Theorem 24: for `1 ≤ r ≤ 2^k - 1` and `ρ₁` the position of the lowest nonzero bit of
`r`, `τ(r/2^k) = (τ((r-1)/2^k) + τ((r+1)/2^k))/2 + (1 - ρ₁)/2^k`.
