# Sum hamming Weight range eq trollope

Corollary 30 (Trollope): for `n = 2^k + r` with `0 ≤ r < 2^k` and `x = r/2^k`,
`S₁(n) = n log₂ n / 2 + 2^(k-1) (2x - τ(x) - (1+x) log₂(1+x))`.
