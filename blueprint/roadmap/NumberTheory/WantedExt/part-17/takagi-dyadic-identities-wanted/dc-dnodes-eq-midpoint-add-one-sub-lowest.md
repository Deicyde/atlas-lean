# Dc DNodes eq midpoint add one sub lowest Bit

Corollary 10: for `n = 2^k + r` with `0 < r < 2^k` and `ρ₁` the position of the lowest
nonzero bit of `r`, `δ(n) = (δ(n-1) + δ(n+1))/2 + 1 - ρ₁`.
