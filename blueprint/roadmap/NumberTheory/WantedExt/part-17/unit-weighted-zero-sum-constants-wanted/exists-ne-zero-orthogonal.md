# Exists ne zero orthogonal

Lemma 4.2: if `a + 1 ≤ m` and `v_1, …, v_a ∈ ℤ_2^m`, some nonzero `w ∈ ℤ_2^m` satisfies
`w · v_i = 0` for all `i`.
