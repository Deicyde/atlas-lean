# Exists consecutive orthogonal

Lemma 3.2: if `2^a ≤ m` and `v_1, …, v_a ∈ ℤ_2^m`, some nonzero `w ∈ ℤ_2^m` whose ones
occupy consecutive positions `s, …, t` satisfies `w · v_i = 0` for all `i`.
