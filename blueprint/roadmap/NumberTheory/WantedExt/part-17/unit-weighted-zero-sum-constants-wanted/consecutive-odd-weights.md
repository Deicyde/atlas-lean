# Consecutive odd weights

Theorem 7.2: for even `n` with `v_2(n) = r`, `m = n / 2^r`, `B` the odd elements of `ℤ_n`
and `{m} ⊆ A ⊆ B`, `C_A(n) = 2^r`.
