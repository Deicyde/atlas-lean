# Exists weight orthogonal

Lemma 5.3: if `m` is even with `2^a ≤ m` and `v_1, …, v_a ∈ ℤ_2^{m+a}`, some `w ∈ ℤ_2^{m+a}`
with exactly `m` coordinates equal to one satisfies `w · v_i = 0` for all `i`.
