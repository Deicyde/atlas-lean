# Unit Weighted Zero Sum of even non Divisible

Lemma 3.5 (Griffiths): for `n = p^r` with `p` prime, if for each `i ∈ [1, r]` the set
`X_i = {j : x_j ≢ 0 (mod p^i)}` has even size, then `(x_1, …, x_k)` is a `U(n)`-weighted
zero-sum sequence.
