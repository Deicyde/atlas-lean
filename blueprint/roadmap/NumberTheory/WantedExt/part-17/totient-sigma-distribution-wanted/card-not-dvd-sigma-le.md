# Card not dvd sigma le

For every prime `p` and every `x ≥ e^p`, the number `S_p(x)` of positive integers
`n ≤ x` with `p ∤ σ(n)` is `O(x (log log x / log x)^(1/(p-1)))`, with an absolute implied
constant.
