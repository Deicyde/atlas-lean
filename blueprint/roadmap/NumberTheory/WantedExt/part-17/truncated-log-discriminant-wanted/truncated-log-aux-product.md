# Truncated Log Aux Product

`X(m) = ∏_{k=1}^{m-1} (1/m + ω^k + ω^{2k}/2 + ⋯ + ω^{(m-1)k}/(m-1))` for a
primitive `m`-th root of unity `ω`, as the resultant of `1 + x + ⋯ + x^{m-1}`
with `1/m + x + x²/2 + ⋯ + x^{m-1}/(m-1)`.
