# Discr truncated Log prime power

If `p ≡ 1 (mod 4)` is prime, `e ≥ 1`, and `n = p^e`: for odd `e`, `disc(F_n)` is not
a rational square; for even `e`, it is not a rational square if and only if `𝒫_n` is
not.
