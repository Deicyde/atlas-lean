# Valuation Common Lift Count

For a tuple `P` of points, the number of `(k, l) ∈ 𝔽_p²` at which every translate
`(r_i + kp, s_i + lp)` has `ν_p(f) > 1`; divided by `p²` it is `E[Y_{l₁} ⋯ Y_{l_k}]`.
