# Gauss Class Number small

Characteristic values of the class numbers: `h(-3) = h(-4) = h(-12) = 1` and
`H(-12) = 2` (the forms `x ^ 2 + 3y ^ 2` and the imprimitive `2x ^ 2 + 2xy + 2y ^ 2`).
