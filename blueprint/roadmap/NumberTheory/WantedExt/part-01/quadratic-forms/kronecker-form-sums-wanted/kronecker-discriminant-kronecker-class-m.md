# Kronecker Discriminant kronecker Class Multiplier small

Characteristic values of `d(n)` and `ℓ(n)`: `d = -4, -3, -8` for `(α, g) = (0, 1),
(0, 3), (1, 1)`; `ℓ = 1` for `h = 1`, and `ℓ = 5` for `d = -4`, `h = 3`.
