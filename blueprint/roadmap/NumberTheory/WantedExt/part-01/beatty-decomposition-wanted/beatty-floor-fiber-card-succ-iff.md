# Beatty floor fiber card succ iff

If `1 / (k + 1) < α < 1 / k` and `β = α / (1 - α)`, then a non-negative integer `t`
is attained by `⌊nα⌋` (`n ≥ 1`) exactly `k + 1` times if and only if it is attained by
`⌊nβ⌋` exactly `k` times.
