# Beatty floor inv sub eq floor sub two

Identity (8): for complementary Beatty sequences `a n = ⌊nα⌋`, `b n = ⌊nβ⌋` with
`1 < α < 2` and every positive integer `n`,
`⌊α⁻¹ b n⌋ - ⌊α⁻¹ (a n + 1)⌋ = ⌊(β - 2) n⌋`.
