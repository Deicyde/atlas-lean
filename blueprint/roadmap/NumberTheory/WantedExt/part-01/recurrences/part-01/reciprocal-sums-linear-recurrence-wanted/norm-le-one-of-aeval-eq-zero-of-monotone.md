# Norm le one of aeval eq zero of monotone coeff

Eneström–Kakeya theorem, monotone form: if a nonzero real polynomial
`a₀ + a₁ x + ⋯ + aₙ xⁿ` of degree `n` satisfies `0 ≤ a₀ ≤ a₁ ≤ ⋯ ≤ aₙ`, then every complex
root `z` satisfies `‖z‖ ≤ 1`.
