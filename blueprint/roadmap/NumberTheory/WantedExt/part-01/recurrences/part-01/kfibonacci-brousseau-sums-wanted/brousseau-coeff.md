# Brousseau Coeff

The coefficient polynomial `C_k^(p)(n) = ∑_{r=0}^p (-1)^r A_k^(r) binom(p, r) n^(p-r)`
of Definition 5 (with `0^0 = 1`, which gives the paper's separate value
`C_k^(p)(0) = (-1)^p A_k^(p)`).
