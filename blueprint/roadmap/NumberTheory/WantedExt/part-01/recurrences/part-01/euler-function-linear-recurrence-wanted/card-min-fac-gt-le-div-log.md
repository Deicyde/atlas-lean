# Card min Fac gt le div log

Brun sieve bound: uniformly for `x ≥ y ≥ 2`, the number `Φ(x, y)` of positive `n ≤ x` whose
least prime factor `p(n)` exceeds `y` (with `p(1) = 1`, as `Nat.minFac 1 = 1`) is `≪ x / log y`.
