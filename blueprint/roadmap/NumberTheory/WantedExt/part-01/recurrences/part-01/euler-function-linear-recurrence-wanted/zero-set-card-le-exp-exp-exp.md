# Zero set card le exp exp exp

Schmidt's zero bound: a nondegenerate complex linearly recurrent sequence `(U_n)_{n ≥ 1}` of
(minimal) order `k ≥ 2` has finitely many zeros, at most `exp(exp(exp(3k log k)))`.
