# Circuit Array X row one

Corollary 4.5, corrected: `C^X₁,ₛ = (3·9^{s-2}X - 1)/(3·9^{s-2}X - 3)` for `s ≥ 2`. The printed
denominator `3·9^{s-2}X` is the row-`0` formula; Table 2 has `(3X - 1)/(3X - 3)` at `s = 2`
(`13/12` at `X = 9`, not `26/27`).
