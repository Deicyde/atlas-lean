# Circuit Array X row two

Corollary 4.6: for `s ≥ 2`, `C^X₂,ₛ = (c₂,₀(s) - c₂,₁(s) X + c₂,₂(s) X²)/(9^{s-2}X - 1)²` with
`c₂,₀(s) = 27·9^{s-3} - 1`, `c₂,₁(s) = 24(2s - 3)·9^{s-3}`, `c₂,₂(s) = 81·81^{s-3} - 3·9^{s-3}`
(reading the printed `c₂,₂(X²)` as `c₂,₂(s)X²`, as in Remark 4.7).
