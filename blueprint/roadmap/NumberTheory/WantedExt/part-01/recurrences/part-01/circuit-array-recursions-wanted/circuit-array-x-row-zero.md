# Circuit Array X row zero

Corollary 4.4: the closed form (2.6) of row `0`, `C^X₀,ₛ = (3·9^{s-2}X - 1)/(3·9^{s-2}X)` for
`s ≥ 1` (Table 2, row `0`), and numerically `C₀,ₛ = (9^s/3 - 1)/(9^s/3)`.
