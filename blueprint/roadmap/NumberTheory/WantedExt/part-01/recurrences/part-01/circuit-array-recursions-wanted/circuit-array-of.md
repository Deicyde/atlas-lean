# Circuit Array Of

The circuit array of a grid family: `C_{i,j} = T^j_{2j-1, j - ⌊(i+1)/2⌋, L}` for even `i` and
the right edge for odd `i`, meaningful for `0 ≤ i ≤ 2(j - 1)`, `j ≥ 1`.
