# Gibonacci mul gibonacci add eq seed combination

For gibonacci sequences `G`, `H` and integers `k`, `s`:
`H_(k+1) G_(s+1) + H_k G_s = G_0 H_(k+s) + G_1 H_(k+s+1)`.
