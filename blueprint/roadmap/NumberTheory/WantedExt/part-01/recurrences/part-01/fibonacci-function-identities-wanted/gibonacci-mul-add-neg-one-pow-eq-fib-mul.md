# Gibonacci mul add neg one pow eq fib mul

For gibonacci sequences `G`, `H` and integers `r`, `s`, `k`:
`H_s G_(k+r) + (-1)^(r-1) H_(s-r) G_k = F_r (G_0 H_(k+s-1) + G_1 H_(k+s))`.
