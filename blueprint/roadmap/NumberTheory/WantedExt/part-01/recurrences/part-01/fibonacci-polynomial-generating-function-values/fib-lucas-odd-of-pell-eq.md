# Fib Lucas odd of pell eq

Proposition 2.3: if `b ∣ a` and `P, Q ∈ ℕ` satisfy `P² - (a² + 4b) Q² = -4b`, then
`b^n P = L_{2n+1}` and `b^n Q = F_{2n+1}` for some `n ∈ ℕ`, where `F_i = F_i(1)` and
`L_i = L_i(1)`.
