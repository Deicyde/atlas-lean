# Lcm mem lucas Average Set

Theorem 2.5: if `m, n ∈ S'(U)` and `m ∣ r`, then `B_U(r) ≡ 0 (mod m)`,
`lcm(m, n) ∈ S'(U)`, `A_W(m)`, `A_W(n)`, `A_W(lcm(m, n))` are integers for all `W(a, b)`, and
`B_W(r) ≡ 0 (mod m)` for all `W(a, b)`.
