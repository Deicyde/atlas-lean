# Is Least lucas Average Set of six dvd

Theorem 2.21: for nondegenerate `U(a, b)` and `n` with `6 ∣ n`, `a ≡ 1` and
`b ≡ -1 (mod rad(n))`: `C'(n) = C(n) = n` and `A_W(n)` is an integer for all `W(a, b)`.
