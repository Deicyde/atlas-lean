# 9 is a Frobenius pseudoprime for P = 4, Q = -1

**9 is a Frobenius pseudoprime for P = 4, Q = -1.** For the Lucas sequences with parameters
$P = 4$ and $Q = -1$, so that $D = P^2 - 4Q = 20$, the number $9$ is a Frobenius pseudoprime.
