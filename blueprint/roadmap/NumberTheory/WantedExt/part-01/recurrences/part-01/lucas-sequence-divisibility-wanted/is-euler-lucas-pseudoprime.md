# Is Euler Lucas Pseudoprime

Euler–Lucas pseudoprime: odd composite `N`, `gcd(N, QD) = 1`, and
`U_{(N-(D/N))/2} ≡ 0` if `(Q/N) = 1`, `V_{(N-(D/N))/2} ≡ 0` if `(Q/N) = -1` (mod `N`).
