# Three QR is DCarmichael divisibility

If `3qr` (`3 < q < r` primes) is `D`-Carmichael of signature `(α, β, γ)` (`D ≡ 0, 1 (mod 4)`),
then `q - β ∣ 3r - αγ` and `r - γ ∣ 3q - αβ`; moreover `r = 3q + 2γ` if `γ = -αβ`, and
`2r = 3q + γ` if `γ = αβ`.
