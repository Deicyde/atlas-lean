# Lucas Digit Sum five seven 6601

The paper's example: `6601 = 5·7 + 7² + 5·7³ + 2·7⁴` and `(5 | 7) = -1`, so
`s₇(6601) = -5 + 1 - 5 + 2 = -7`.
