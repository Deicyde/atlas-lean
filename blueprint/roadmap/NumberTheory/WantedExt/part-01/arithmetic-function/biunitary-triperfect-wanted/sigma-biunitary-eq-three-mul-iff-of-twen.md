# Sigma Biunitary eq three mul iff of twenty Seven dvd

There is exactly one biunitary triperfect number divisible by `3³`, namely `2160`:
for positive `N` with `27 ∣ N`, `σ**(N) = 3N` iff `N = 2160`.
