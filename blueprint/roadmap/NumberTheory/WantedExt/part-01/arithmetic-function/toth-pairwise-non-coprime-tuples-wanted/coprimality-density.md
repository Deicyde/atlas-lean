# Coprimality Density

The asymptotic density `A_G = ∏_p ∑_{F ⊆ E} (-1)^{|F|} / p^{v(F)}` of the
coprimality graph with edge set `E`, where `v(F)` is the number of distinct
vertices appearing in `F` (Arias de Reyna–Heyman form of the constant).
