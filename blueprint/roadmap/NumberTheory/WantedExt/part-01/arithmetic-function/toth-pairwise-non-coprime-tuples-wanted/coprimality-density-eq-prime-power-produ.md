# Coprimality Density eq prime power product

Theorem 9, second representation:
`A_G = ∏_p (1 - 1/p)^k ∑_{ν} δ_G(p^{ν₁}, …, p^{ν_k}) / p^{ν₁ + ⋯ + ν_k}`.
