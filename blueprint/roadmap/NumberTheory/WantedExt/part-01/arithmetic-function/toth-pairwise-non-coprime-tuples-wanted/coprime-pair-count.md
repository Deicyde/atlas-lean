# Coprime Pair Count

The number of pairs `i < j` with `gcd(n_i, n_j) = 1`; the paper's
`β_r(n) = 1` exactly when this count is `r`, `β'_r(n) = 1` exactly when it is at
least `r`, and `β = β_0`.
