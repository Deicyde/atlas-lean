# Coprimality graph count asymp

Theorem 1: for a coprimality graph with edge set `E` and maximum degree
`d_G`, `∑_{n₁, …, n_k ≤ x} δ_G(n) = A_G x^k + O(x^{k-1} (log x)^{d_G})`.
