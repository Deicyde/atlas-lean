# Exactly coprime pairs inclusion exclusion

Lemma 5: inclusion–exclusion for `β_r`:
`β_r(n) = ∑_{j=r}^{k(k-1)/2} (-1)^{j-r} binom(j, r) ∑_{|E| = j} δ_G(n)`;
the case `r = 0` is the paper's identity for `β`.
