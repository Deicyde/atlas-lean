# Coprimality Density eq independent set product

Theorem 1, display (A_G): Hu's form of the constant,
`A_G = ∏_p ∑_{m=0}^{k} i_m(G) p^{-m} (1 - 1/p)^{k-m}`, where `i_m(G)` is the
number of independent vertex sets of size `m`.
