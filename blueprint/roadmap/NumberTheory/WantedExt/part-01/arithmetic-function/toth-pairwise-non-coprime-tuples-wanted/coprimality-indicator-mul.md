# Coprimality Indicator mul

Lemma 4: `δ_G` is multiplicative as a function of `k` variables:
`δ_G(m₁n₁, …, m_kn_k) = δ_G(m) δ_G(n)` whenever
`gcd(m₁ ⋯ m_k, n₁ ⋯ n_k) = 1`.
