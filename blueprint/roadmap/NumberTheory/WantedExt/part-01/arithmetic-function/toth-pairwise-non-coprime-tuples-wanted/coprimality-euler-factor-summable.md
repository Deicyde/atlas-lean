# Coprimality euler factor summable

Theorem 7, convergence clause: the Euler product `D'_G(s)` is absolutely
convergent, i.e. `∑_p |D'_{G,p}(s) - 1| < ∞`, whenever
`Re (s_{i₁} + ⋯ + s_{i_j}) > 1` for every set of `j ≥ 2` non-isolated vertices.
