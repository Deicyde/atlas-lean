# Eulerian Form exponent eq one or mul pow five lt

If an odd perfect number has Euler form `n = q^e m²`, then `e = 1` or
`q < (2/((3²)(5²)(11²)(13²)))^{1/5} m^{2/5}`, stated in the equivalent integer form
`3² 5² 11² 13² q⁵ < 2 m²`.
