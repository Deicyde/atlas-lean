# Inv zeta le rpow of riemann Hypothesis

Lemma 8, equation (25) (quoted classical result): the Riemann hypothesis
implies `1/ζ(σ + it) = O(|t|^ε)` for each fixed `1/2 < σ ≤ 1`, `|t| ≥ t₀`; the
constants depend on `σ` and `ε`.
