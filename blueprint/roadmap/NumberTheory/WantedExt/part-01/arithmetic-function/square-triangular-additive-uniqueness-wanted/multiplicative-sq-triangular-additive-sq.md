# Multiplicative sq triangular additive sq

Let `f` be multiplicative with `f (u² + t_v) = f (u²) + f (t_v)` for all positive
`u, v`. If `N ≥ 3` and `f n = n` for `1 ≤ n ≤ N - 1`, then `f (m²) = m²` for every `m` with
`1 ≤ m ≤ N - 2`.
