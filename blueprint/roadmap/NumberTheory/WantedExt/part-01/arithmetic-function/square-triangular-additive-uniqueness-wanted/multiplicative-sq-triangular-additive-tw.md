# Multiplicative sq triangular additive two pow odd

Let `f` be multiplicative with `f (u² + t_v) = f (u²) + f (t_v)` for all positive
`u, v`. If `N ≥ 4` and `f n = n` for `1 ≤ n ≤ N - 1`, then `f (2^(2k-1)) = 2^(2k-1)` for
every positive `k` with `2k ≤ N - 2`.
