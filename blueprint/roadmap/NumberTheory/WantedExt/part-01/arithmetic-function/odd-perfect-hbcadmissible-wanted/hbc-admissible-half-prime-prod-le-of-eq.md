# Hbc Admissible half prime prod le of eq five

Let `p_1 < ⋯ < p_k` be primes with `∏_{i=1}^k (1 - 1/p_i) ≤ 1/2 < ∏_{i=1}^{k-1} (1 - 1/p_i)`
(51) and `p_1 = 5`. Then `∏_{i=1}^k p_i ≤ F_k(√(8/3^{31/32}))` (52), where
`F_k(x) = x^{2^k} - x^{2^{k-1}}`.
