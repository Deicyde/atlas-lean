# Hbc Admissible seven tenths prod le

For `k ≥ 3` and every HBC-admissible `k`-tuple `y_1 < ⋯ < y_k` for `7/10`
(`∏_{i=1}^k (1 - 1/y_i) ≤ 7/10 < ∏_{i=1}^{k-1} (1 - 1/y_i)`),
`∏_{i=1}^k y_i ≤ (2/7)((√15)^{2^k} - (√15)^{2^{k-1}})` (31). The sharpness remark is not stated.
