# Parallelogram multiplicative k sq add one

Lemma 3.
Setting: `f` is multiplicative with `f (m² + n²) + f (m² - n²) = 2 f (m²) + 2 f (n²)`
for `m > n ≥ 1`
(the setting of Theorems 1 and 2), and `f (q^s) = q^{2s}` for all primes `q < p`, `s ≥ 1`.
If `p = 4k - 1`, then `f (k² + 1) = (k² + 1)²` and
`f (4k² + 1) = (4k² + 1)²`.
