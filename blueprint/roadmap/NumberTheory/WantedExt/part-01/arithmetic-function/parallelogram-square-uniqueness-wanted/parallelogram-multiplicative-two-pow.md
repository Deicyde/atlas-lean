# Parallelogram multiplicative two pow

Theorem 3: for `f` multiplicative with `f (m² + n²) + f (m² - n²) = 2 f (m²) + 2 f (n²)`
(`m > n ≥ 1`), if `f 4 = 0` then `f (2^r) = 0` for `r ≥ 2`; otherwise `f (2^r) = 2^{2r}` for
`r ≥ 1`.
