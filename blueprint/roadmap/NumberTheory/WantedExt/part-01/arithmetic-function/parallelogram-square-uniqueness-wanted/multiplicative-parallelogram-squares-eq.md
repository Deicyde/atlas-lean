# Multiplicative parallelogram squares eq sq

A multiplicative function with
`f (m² + n²) + f (m² - n²) = 2 f (m²) + 2 f (n²)` for all positive integers `m > n` and
`f 4 ≠ 0` is `f n = n²`.
