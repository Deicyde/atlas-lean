# Loglog ratio sum le one

Proposition 3, inequality (25): for every integer `n ≥ 2`, with `L = log n`,
`4.151332 (log L - 2) / L + 3.151332 (log L - 1) / L + 3.151332 (log L - 2) / L² ≤ 1`.
