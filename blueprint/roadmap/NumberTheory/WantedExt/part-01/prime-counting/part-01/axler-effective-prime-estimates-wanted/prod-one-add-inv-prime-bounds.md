# Prod one add inv prime bounds

For every real `x ≥ 1757126630797`,
`6e^γ/π² · exp(-f(x) - 1.02/((x - 1) log x)) · log x < ∏_{p ≤ x} (1 + 1/p) <
6e^γ/π² · (1 + 1/x) · exp(f(x)) · log x`
with `f(x) = 0.024334/(3 log³ x) · (1 + 15/(4 log x))` the right-hand side of (17).
