# Calzado shifted primes sifted asymp

Lemma 6, equation (15): for `a` even and nonzero there are constants
`0 < C₁ < C₂` with `C₁ x / (log x)^2 < S(A, P, x^{1/5}) < C₂ x / (log x)^2`
for all sufficiently large `x`, where `A = {n + a : n ≤ x prime}`.
