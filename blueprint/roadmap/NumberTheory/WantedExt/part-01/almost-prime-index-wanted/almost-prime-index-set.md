# Almost Prime Index Set

`N_{k_1 k_2 ⋯ k_m}` with `k_1 = k` and `[k_2, …, k_m] = L`: for `L = []` the `k`-almost
primes, and otherwise the `k`-almost primes whose (`1`-based) index lies in `N_{k_2 ⋯ k_m}`.
