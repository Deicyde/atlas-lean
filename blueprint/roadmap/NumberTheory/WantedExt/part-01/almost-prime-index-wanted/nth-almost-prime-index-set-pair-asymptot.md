# Nth almost Prime Index Set pair asymptotic

For fixed `j, k ≥ 1`, the `n`th member `p_{j,k,n}` of `N_{jk}` satisfies
`p_{j,k,n} = n log² n · (j-1)! (k-1)! / (log log n)^{j+k-2} · (1 + O(1/log log n))`.
