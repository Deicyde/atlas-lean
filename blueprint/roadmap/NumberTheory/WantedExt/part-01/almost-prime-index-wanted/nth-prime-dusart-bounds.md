# Nth prime dusart bounds

Dusart's bounds for the `n`th prime `p_n`: `p_n ≥ n (log n + log log n - 1)` and
`p_n ≥ n (log n + log log n - 1 + (log log n - 2.25) / log n)` for `n ≥ 2`, and
`p_n ≤ n (log n + log log n - 0.9484)` for `n ≥ 39017`.
