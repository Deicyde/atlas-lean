# Almost Prime count le erdos sarkozy

Erdős–Sárközy uniform bound: `N_{k+1}(t) ≪ (k⁴ / 2^k) t log t` for all real `t ≥ 1` and
integers `k ≥ 1`, with an absolute implied constant.
