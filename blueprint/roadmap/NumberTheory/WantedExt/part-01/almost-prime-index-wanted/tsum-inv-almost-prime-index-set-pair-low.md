# Tsum inv almost Prime Index Set pair lower bound

For fixed `j ≥ 1`, `∑_{n ∈ N_{jk}} 1/n ≫ k^{j-1}` as `k → ∞`; in particular, for fixed
`j ≥ 2` this reciprocal sum tends to infinity with `k`.
