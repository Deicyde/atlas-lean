# Tendsto tsum inv almost Prime Index Set append zero

For fixed `m ≥ 2` and `k_1, …, k_m ≥ 1` (here `k_1 = k` and `[k_2, …, k_m] = ks ≠ []`), the
reciprocal sum of `N_{k_1 ⋯ k_m k}` tends to `0` as `k → ∞`.
