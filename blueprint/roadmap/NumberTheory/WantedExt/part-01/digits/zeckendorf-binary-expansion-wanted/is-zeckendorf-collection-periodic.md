# Is Zeckendorf Collection periodic

Periodic collections: for a list `L = (e_1, …, e_N)` with `N ≥ 2` and `e_1 ≠ 0`, the sums of
finitely many disjoint `L`-blocks form a Zeckendorf collection with `β̂^n = θ^n` for `n ≥ 2`.
