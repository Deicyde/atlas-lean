# Liminf zeckendorf Binary Count div rpow

Zeckendorf binary expansions: with `z(x)` the number of `n < x` whose binary expansion has no
two adjacent `1`s, `φ` the golden ratio and `γ = log₂ φ`, `liminf z(x) / x^γ = (3φ + 1) / 5`.
