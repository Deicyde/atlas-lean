# Zeckendorf Collection subset iff

Subcollections: if `Ẽ` and `E` are Zeckendorf collections and `β̂^n` are the immediate
predecessors in `E`, then `E ⊆ Ẽ` if and only if `β̂^n ∈ Ẽ` for all `n ≥ 2`.
