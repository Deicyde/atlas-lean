# Has Sum l Star Block Sum Count

Generating function: with `f(x) = 1 - ∑_{k=1}^{N-1} e_k x^k - (1 + e_N) x^N`,
`∑ C_k x^k = (1 - x^N) / f(x)` on an open interval around `0`.
