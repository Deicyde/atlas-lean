# Ncard proper LStar Block

Counting proper blocks: for `s ≤ k` with `k - s + 1 ≡ j (mod N)`, `1 ≤ j ≤ N`, there are
exactly `e_j` proper `L*`-blocks with support interval `[s, k]`.
