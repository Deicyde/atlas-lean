# Is Permutiple String

An `(n, b)`-permutiple string: a member of `L` which produces a permutiple, i.e. it is
`(d₀, d_{σ(0)})(d₁, d_{σ(1)}) ⋯ (d_k, d_{σ(k)})` for an `(n, b, σ)`-permutiple
`(d_k, …, d₀)_b = n (d_{σ(k)}, …, d_{σ(0)})_b`.
