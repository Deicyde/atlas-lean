# One c one two pow iff

There is a representation `2^n = (1, c, 1)_b` that is not of binomial form
(`c ≠ 2`) if and only if (i) `2^n - 1 = kb` with `b ≤ k ≤ 2b - 1`, and (ii) it is
not the case that `n` is even and `b = 2^{n/2} - 1`.
