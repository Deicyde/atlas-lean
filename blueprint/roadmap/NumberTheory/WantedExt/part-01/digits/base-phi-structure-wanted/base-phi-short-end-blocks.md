# Base Phi short end blocks

Short end blocks: `R_1 = V₀(1,2,1)`, `R_{10} = V(1,2,-1)`,
`R_{00·0} = V₀(1,2,0)`, `R_{00·1} = V(3,1,1)`, for `N ≥ 1`.
