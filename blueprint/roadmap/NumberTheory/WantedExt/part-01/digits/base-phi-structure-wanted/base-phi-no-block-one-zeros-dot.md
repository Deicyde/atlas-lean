# Base Phi no block one zeros dot

No base phi expansion contains `d_{2m} ⋯ d_0 · d_{-1} = 10^{2m} · 1`, and
none contains `d_{2m+1} ⋯ d_0 · d_{-1} = 10^{2m+1} · 0`, for `m ≥ 1`.
