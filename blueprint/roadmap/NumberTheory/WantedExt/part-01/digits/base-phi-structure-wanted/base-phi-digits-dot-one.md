# Base Phi digits dot one

The block `d_1 d_0 · d_{-1} = 10 · 1` never occurs, and
`d_1 d_0 · d_{-1} = 00 · 1` occurs in `β(N)`, `N ≥ 1`, if and only if
`N = 3 ⌊n φ⌋ + n + 1` for some `n ≥ 1`.
