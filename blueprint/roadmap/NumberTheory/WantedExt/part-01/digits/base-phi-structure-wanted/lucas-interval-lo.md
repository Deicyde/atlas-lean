# Lucas Interval Lo

The left end of the Lucas interval `Λ_m`, where `Λ_{2n} = [L_{2n}, L_{2n+1}]` and
`Λ_{2n+1} = [L_{2n+1} + 1, L_{2n+2} - 1]`: it is `L_m` for even `m` and `L_m + 1` for odd `m`.
