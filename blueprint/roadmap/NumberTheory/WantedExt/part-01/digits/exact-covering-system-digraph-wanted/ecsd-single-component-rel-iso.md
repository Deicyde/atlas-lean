# Ecsd single component rel Iso

A degree-2 ECSD `G(d₁n + a₁, d₂n + a₂)` (`d₁, d₂ ∈ {2, -2}`, `a₁ - a₂` odd) with a
single component is isomorphic to `G(2n, -2n + 1)` or to `G(-2n + 1, -2n + a)` with
`a = 0`, `a = 2` or `a ≡ 1 (mod 3)`.
