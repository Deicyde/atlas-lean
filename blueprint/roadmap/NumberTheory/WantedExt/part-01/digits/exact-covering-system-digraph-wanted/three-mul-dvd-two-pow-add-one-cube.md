# Three mul dvd two pow add one cube

If `n ∣ (2ⁿ + 1)/3` then `3n ∣ (2^(3n) + 1)/3`, stated in the equivalent integral
form `3n ∣ 2ⁿ + 1 → 9n ∣ 2^(3n) + 1` (for `n = 0` the hypothesis fails, so positivity
is not assumed).
