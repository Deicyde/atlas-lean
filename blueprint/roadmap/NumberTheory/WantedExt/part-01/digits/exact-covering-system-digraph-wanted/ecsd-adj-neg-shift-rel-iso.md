# Ecsd Adj neg shift rel Iso

The map `n ↦ -(n + k)` is an isomorphism `G_S ≅ G_{S'}` with
`S' = {(-aᵢ + (dᵢ - 1)k, dᵢ)}`. Stated for an arbitrary finite rule list; the paper's
exact-covering hypothesis on `S` is not needed.
