# Negabinary digits one a complete iff

Every integer is `∑_{j=0}^k bⱼ(-2)ʲ` with digits `bⱼ ∈ {1, a}` iff `a = 1 ± 3ᵐ` for
some `m ∈ ℕ₀`. The length `k` ranges over `ℕ`.
