# Ecsd type three three cyclic bounds

For `a ∈ ℤ` even with `a ≡ 2 (mod 3)`, every cyclic vertex `m` of the Type 3.3 ECSD
`G(-2n + 1, -2n + a)` satisfies `-(a - 1)/3 < m < 2a/3` if `a ≥ 2`, and
`-2(|a| + 1)/3 < m < |a|/3 + 1` if `a ≤ -2`.
