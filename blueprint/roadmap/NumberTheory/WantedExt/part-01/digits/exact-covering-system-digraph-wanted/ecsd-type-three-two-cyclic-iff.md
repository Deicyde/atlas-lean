# Ecsd type three two cyclic iff

For `a ∈ ℕ` even with `a ≡ 1 (mod 3)`, `m` is a cyclic vertex of the Type 3.2 ECSD
`G(-2n + 1, -2n + a)` iff `-(a - 1)/3 < m < 2a/3`.
