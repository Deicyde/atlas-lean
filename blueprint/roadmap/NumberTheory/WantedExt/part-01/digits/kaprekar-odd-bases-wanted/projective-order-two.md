# Projective Order Two

The projective order of `2` modulo `n`, `λ(n) = min {m > 0 : 2 ^ m ≡ ±1 (mod n)}`
(OEIS A003558); defined as `0` when no such `m` exists, which happens exactly for even `n`
(including `n = 0` and `n = 2`).
