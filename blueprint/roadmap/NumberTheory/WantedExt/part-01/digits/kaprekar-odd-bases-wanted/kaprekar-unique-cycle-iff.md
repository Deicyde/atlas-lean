# Kaprekar unique cycle iff

For odd `B ≥ 3`, `K_B` has a unique terminal cycle on `X_B` (some periodic point `c`
whose orbit contains every periodic point of `X_B`) if and only if `B ∈ {3, 5, 7}`.
