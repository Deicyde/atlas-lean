# Neg Base Sq Digit Sum samples

Sample values: `-1 = 1·(-10) + 9` and `10 = 1·100 + 9·(-10)` give `S_{2,-10}(-1) =
S_{2,-10}(10) = 82`, and `5 = 16 - 12 + 1` gives `S_{2,-4}(5) = 11`.
