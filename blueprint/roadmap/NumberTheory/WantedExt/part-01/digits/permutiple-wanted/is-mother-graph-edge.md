# Is Mother Graph Edge

`(x, y)` is an edge of the `(n, b)`-mother graph `M`: `x` and `y` are base-`b` digits
and `λ(x + (b - n) y) ≤ n - 1`, where `λ` is the least non-negative residue modulo `b`
(computed in `ℤ`).
