# Permutiple Graph Edges

The edge set `E_p = {(d_j, d_{σ(j)}) | 0 ≤ j ≤ k}` of the graph `G_p` of a numeral
`(d_k, …, d_0)_b` with digit permutation `σ` (the vertices of `G_p` are all base-`b`
digits, so `G_p` is determined by its edge set).
