# Permutiple Carry relation

Carry relation: for an `(n, b, σ)`-permutiple with carries `c_j`,
`b c_{j+1} - c_j = n d_{σ(j)} - d_j` for all `0 ≤ j ≤ k` (in `ℤ`).
