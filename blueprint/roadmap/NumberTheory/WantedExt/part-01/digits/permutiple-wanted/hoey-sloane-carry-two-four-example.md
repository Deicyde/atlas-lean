# Hoey Sloane Carry two four example

Characteristic example: on the `(2, 4)`-permutiple string `(0,0)(2,3)(1,2)(3,1)` the
Hoey-Sloane machine passes through the states `0, 0, 1, 1, 0` (Figure 4 of the paper).
