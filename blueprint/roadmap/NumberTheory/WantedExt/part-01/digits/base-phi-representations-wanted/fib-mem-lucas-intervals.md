# Fib mem lucas Intervals

`F_{2n+2}` lies in the even Lucas interval `Λ_{2n} = [L_{2n}, L_{2n+1}]` and
`F_{2n+3}` in the odd Lucas interval `Λ_{2n+1} = [L_{2n+1} + 1, L_{2n+2} - 1]`,
for all `n ≥ 1`.
