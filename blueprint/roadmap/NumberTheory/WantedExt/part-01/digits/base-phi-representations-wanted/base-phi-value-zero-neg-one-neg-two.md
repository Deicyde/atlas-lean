# The base phi expansion $1.11$ has value two

**The base phi expansion $1.11$ has value two.** The base phi value of the set
$\{0, -1, -2\}$ is $2$, that is, $1 + \varphi^{-1} + \varphi^{-2} = 2$, where $\varphi$ is the
golden ratio.
