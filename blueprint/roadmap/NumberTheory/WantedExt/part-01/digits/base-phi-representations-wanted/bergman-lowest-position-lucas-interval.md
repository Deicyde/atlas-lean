# Bergman lowest position lucas Interval

Part (b): if the lowest digit `1` of `β(N)` is at position `R`, then `-R = 2n`
for `N ∈ Λ_{2n}` and `-R = 2n + 2` for `N ∈ Λ_{2n+1}`.
