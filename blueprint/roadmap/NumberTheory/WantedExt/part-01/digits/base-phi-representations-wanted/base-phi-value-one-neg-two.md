# The base phi expansion $10.01$ has value two

**The base phi expansion $10.01$ has value two.** The base phi value of the set $\{1, -2\}$
is $2$, that is, $\varphi + \varphi^{-2} = 2$, where $\varphi$ is the golden ratio.
