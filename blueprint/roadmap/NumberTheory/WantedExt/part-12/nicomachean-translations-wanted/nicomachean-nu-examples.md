# Nicomachean Nu examples

`ν(1, 2, 3, 4) = 0`, `ν(1, 2) = 0`, `ν(3, 3, 3) = 0`, and the paper's
`ν(1, 2, 2, 3, 4, x, 6, 8) = (5 - x)(x - 4)(8 + x)` at `x = 5` (value `0`) and `x = 6`
(value `-28`).
