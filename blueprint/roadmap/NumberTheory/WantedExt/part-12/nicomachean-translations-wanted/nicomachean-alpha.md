# Nicomachean Alpha

The second factor `α(n, s, a) = 2n^2 + na - a^2 + n(n-1)(s - s^2)/2 - (n-1)as` of
`ν(S_m)` in the paper's (`nusm`), where `S_m` joins `n` copies of `n` with the arithmetic
progressions `S, S + n, …, S + mn`, `S = (a, a + s, …, a + (n-1)s)`.
