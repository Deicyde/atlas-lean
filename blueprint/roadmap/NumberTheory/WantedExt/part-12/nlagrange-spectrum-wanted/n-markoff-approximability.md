# N Markoff Approximability

The `n`-Markoff approximability
`μₙ(ξ, ξ') = sup_{(s,t) ∈ ℤ² ∖ 0} gcd(t, n) |ξ - ξ'| / (|s - tξ| |s - tξ'|)` in `EReal`.
