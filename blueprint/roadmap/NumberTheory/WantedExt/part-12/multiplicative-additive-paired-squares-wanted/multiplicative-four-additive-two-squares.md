# Multiplicative four additive two squares base

If `f` is multiplicative, `4`-additive on `E₂ = {a² + b² : a, b ≥ 1}` (Equation (2) with
`k = 4`) and `f(2) ≠ 0`, then `f(n) = n` for every `n ∈ {2, 3, 4, 5, 6, 7, 8, 10}`.
