# The odd-case polynomial $P_{m,o}$

**The odd-case polynomial $P_{m,o}$.** For a natural number $m$ and a real number $x$,

$$P_{m,o}(x) = \sum_{j=0}^{m} (4j + 1 + jx) \bigl((j + 1)(j - 2) + j^2 x\bigr).$$
