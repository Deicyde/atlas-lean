# Theorem 5

**Theorem 5.** The sum `T(n) = ∑_{k=0}^{n} [`binom(n + 2k, 2k)` binom(n, k) mod 2]` is the run length transform
of `1, 2, 2, 2, …`, the sequence of `2`s prepended with a `1`.
