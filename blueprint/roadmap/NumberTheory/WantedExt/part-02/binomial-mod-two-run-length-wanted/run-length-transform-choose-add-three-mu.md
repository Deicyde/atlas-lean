# Theorem 8

**Theorem 8.** The sum `T(n) = ∑_{k=0}^{n} [`binom(n + 3k, 6k)` binom(n, k) mod 2]` is the run length transform
of the doubled positive integers `1, 1, 2, 2, 3, 3, …`.
