# Theorem 14

**Theorem 14.** The sum `T(n) = ∑_{k=0}^{n} [`binom(6k, n + 3k)` binom(n, k) mod 2]` is the run length transform
of the sequence alternating between `1` and the positive integers, `1, 1, 1, 2, 1, 3, 1, 4, …`.
