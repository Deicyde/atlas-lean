# Central Binom add eq central Binom mul choose iff of le ten

Lemma 1: for positive `x`, `a`, `b` with `a + b ≤ 10`,
`C(2(a+b), a+b) = C(2a, a) C(x+2b, b)` if and only if `x = a = 1`.
