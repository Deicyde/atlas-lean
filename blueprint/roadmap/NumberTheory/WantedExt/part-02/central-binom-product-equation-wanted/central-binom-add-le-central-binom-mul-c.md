# Central Binom add le central Binom mul choose of le

Proposition 1: for positive `x`, `b`, nonnegative `a` and `x ≥ a`,
`C(2(a+b), a+b) ≤ C(2a, a) C(x+2b, b)`, with equality if and only if `x = a = 1`.
