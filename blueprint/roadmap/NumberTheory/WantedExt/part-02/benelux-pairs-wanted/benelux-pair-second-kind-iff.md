# Benelux pair second kind iff

For positive integers `m < n < 1.4 · 10¹²`, `(m, n)` is a Benelux pair of second kind
if and only if `(m, n) = (35, 4374)` or `(m, n) = (2^k + 1, 2^{2k} + 2^{k+1})` for some
integer `0 ≤ k ≤ 20`.
