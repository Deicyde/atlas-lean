# Benelux pair first kind iff

For positive integers `m < n < 1.4 · 10¹²`, `(m, n)` is a Benelux pair (of first kind)
if and only if `(m, n) = (75, 1215)` or `(m, n) = (2^k - 2, 2^{2k} - 2^{k+1})` for some
integer `2 ≤ k ≤ 20`.
