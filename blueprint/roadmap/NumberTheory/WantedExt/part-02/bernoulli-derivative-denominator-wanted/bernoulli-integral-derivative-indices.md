# Bernoulli Integral Derivative Indices

The set `\overline{𝒮}_k = {n ≥ 1 : B_n^{(k)}(x) ∈ ℤ[x]}` of indices whose `k`-th derivative
Bernoulli polynomial has only integral coefficients; `\overline{𝒮} = \overline{𝒮}_1`.
