# Bernoulli derivative integral iff

For `n ≥ 1`: `B_n'(x) ∈ ℤ[x]` iff `𝔻^⊥_n = 1`, iff `𝔇_{n-1} = rad(n)`; in these cases `n + 1`
is prime.
