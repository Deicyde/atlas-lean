# Bernoulli Diff Denominator parity radical lcm

For `n ≥ 1`: `𝔻_n` is odd iff `n = 2^e` (`e ≥ 0`); if `n + 1` is composite then
`rad(n + 1)` divides `𝔻_n` and `𝔻^⊥_n`; and for odd `n ≥ 3`,
`𝔻_n = lcm(𝔻_{n+1}, rad(n + 1))`.
