# Bernoulli Diff Denominator Coprime Part small

Values `𝔻^⊥_1 = 1`, `𝔻^⊥_2 = 1`, `𝔻^⊥_3 = 2`, `𝔻^⊥_5 = 6`, `𝔻^⊥_9 = 10`.
