# Infinite set Of prime dvd fibonomial

Corollary 4: for every prime `p` there are infinitely many `n` such that
every Fibonomial coefficient `[n, k]_F = F_n! / (F_k! F_{n-k}!)` with
`1 ≤ k < n` is an integer multiple of `p` (`F_n!` is
`fibonacciFactorial`).
