# Corollary 15

**Corollary 15**: `∑_{i=k}^n s(n,i) S(i,k)/i =
(-1)^{n-k} ((n-1)!/k!) ∑_{ℓ=0}^{n-k} ((-1)^ℓ/ℓ!) B_ℓ^*`
for `1 ≤ k ≤ n`.
