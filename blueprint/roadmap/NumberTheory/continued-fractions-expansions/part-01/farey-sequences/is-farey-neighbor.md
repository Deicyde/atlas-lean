# Farey neighbors

**Farey neighbors.** For a natural number $n$, rationals $x$ and $y$ are Farey neighbors of
order $n$ when both lie in the Farey set $F_n$, $x < y$, and no element $z$ of $F_n$ satisfies
$x < z < y$.
