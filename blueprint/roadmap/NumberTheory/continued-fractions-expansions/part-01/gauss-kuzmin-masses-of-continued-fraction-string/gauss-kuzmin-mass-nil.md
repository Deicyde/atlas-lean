# Gauss–Kuzmin mass of the empty string

**Gauss–Kuzmin mass of the empty string.** The Gauss–Kuzmin mass of the empty string is
$P_{GK}(()) = \frac{1}{\log 2} \int_{[0, 1)} \frac{dx}{1 + x}$.
