# Higher-order Bernoulli numbers of order one

**Higher-order Bernoulli numbers of order one.** For every natural number $n$, the
higher-order Bernoulli number $B_n^{(1)}$ equals the Bernoulli number $B_n$, with the
convention $B_1 = -1/2$.
