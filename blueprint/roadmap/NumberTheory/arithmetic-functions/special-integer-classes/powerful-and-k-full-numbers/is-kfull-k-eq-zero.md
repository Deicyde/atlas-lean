# The $0$-full numbers

**The $0$-full numbers.** A natural number $n$ is $0$-full if and only if $n \ne 0$, since
$p^0 = 1$ divides $n$ for every prime $p$.

The source considers only $k$-full numbers with $k \ge 2$.
