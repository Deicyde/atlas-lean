# The grid function stays below $1$ on $(10, 279)$

**The grid function stays below $1$ on $[10, 279)$.** For every natural number $j$ with
$10 \le j < 279$, the Breusch grid function $G_9$ for $k = 9$ satisfies $G_9(j) < 1$.
