# The grid function stays below $3$ on $(10, 963)$

**The grid function stays below $3$ on $[10, 963)$.** For every natural number $j$ with
$10 \le j < 963$, the Breusch grid function $G_9$ for $k = 9$ satisfies $G_9(j) < 3$.
