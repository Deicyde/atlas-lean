# The grid function stays below $2$ on $(10, 657)$

**The grid function stays below $2$ on $[10, 657)$.** For every natural number $j$ with
$10 \le j < 657$, the Breusch grid function $G_9$ for $k = 9$ satisfies $G_9(j) < 2$.
