# Grid bound $G_9 \le 3$ for $0 \le j < 2700$

**Grid bound $G_9 \le 3$ for $0 \le j < 2700$.** For every natural number $k < 2700$,
the grid function satisfies $G_9(0 + k) \le 3$; that is, $G_9(j) \le 3$ for all natural
numbers $j < 2700$.
