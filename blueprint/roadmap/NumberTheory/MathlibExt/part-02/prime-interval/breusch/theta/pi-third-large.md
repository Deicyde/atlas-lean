# Prime-counting bound $\pi(m) \le m/3$ from $156$ on

**Prime-counting bound $\pi(m) \le m/3$ from $156$ on.** Let $\pi(m)$ denote the number of
primes $p \le m$. For every natural number $m \ge 156$, $3\pi(m) \le m$.
