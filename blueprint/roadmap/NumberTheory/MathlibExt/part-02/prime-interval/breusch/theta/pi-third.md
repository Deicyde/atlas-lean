# Prime-counting bound $\pi(x) \le x/3$ for real $x \ge 36$

**Prime-counting bound $\pi(x) \le x/3$ for real $x \ge 36$.** Let $\pi(n)$ denote the
number of primes $p \le n$. For every real number $x \ge 36$, $\pi(\lfloor x \rfloor) \le x/3$.
