# Base polynomial of the $b$-nomial coefficients

**Base polynomial of the $b$-nomial coefficients.** For a natural number $b \ge 2$, this is
the integer polynomial $1 + X + \dots + X^{b-1} = \sum_{i=0}^{b-1} X^i \in \mathbb{Z}[X]$.
