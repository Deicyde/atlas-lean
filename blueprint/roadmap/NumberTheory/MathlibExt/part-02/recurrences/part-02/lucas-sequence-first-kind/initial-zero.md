# Lucas sequence of the first kind: value at zero

**Lucas sequence of the first kind: value at zero.** If $(u_n)_{n \ge 0}$ is the Lucas sequence
of the first kind with integer parameters $P$ and $Q$, then $u_0 = 0$.
