# The normalized Chebyshev error

**The normalized Chebyshev error.** For real $t$, let $H(t) = \theta(e^t) e^{-t} - 1$, where
$\theta(x) = \sum_{p \le x} \log p$ is the Chebyshev function, the sum running over primes
$p \le x$.
