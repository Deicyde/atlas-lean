# The four Gaussian units are distinct

**The four Gaussian units are distinct.** Let $u_0 = 1$, $u_1 = -1$, $u_2 = i$ and
$u_3 = -i$ in $\mathbb{Z}[i]$. For $j, k \in \{0, 1, 2, 3\}$, if $u_j = u_k$ then $j = k$.
