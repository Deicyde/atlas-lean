# Fibonacci Jordan quotient at one

**Fibonacci Jordan quotient at one.** The Jordan-type quotient $J_{r,F} = F_{2r+1}! / F_r!$
of Fibonacci factorials takes the value $J_{1,F} = F_3! / F_1! = 2$.
