# Sum divisors emod four eq card

For an integer-valued character `χ` that is `±1` on the divisors of a nonsquare `n` and has
`χ n = 1`, the divisor sum `∑_{d ∣ n} χ d` is congruent to the number of divisors modulo `4`.
