# Carmichael numbers via the residue ring

**Carmichael numbers via the residue ring.** A natural number $n$ is a Carmichael number if
and only if $n > 1$, $n$ is not prime, and $x^n = x$ for every element $x$ of
$\mathbb{Z}/n\mathbb{Z}$.
