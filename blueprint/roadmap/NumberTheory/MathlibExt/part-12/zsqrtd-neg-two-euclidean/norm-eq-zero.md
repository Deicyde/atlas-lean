# The norm on $\mathbb{Z}(\sqrt{-2})$ vanishes only at zero

**The norm on $\mathbb{Z}[\sqrt{-2}]$ vanishes only at zero.** For $x = a + b\sqrt{-2}$ in
$\mathbb{Z}[\sqrt{-2}]$ with norm $N(x) = a^2 + 2b^2$, we have $N(x) = 0$ if and only if
$x = 0$.
