# The $1$-full numbers

**The $1$-full numbers.** A natural number $n$ is $1$-full if and only if $n \ne 0$, since
$p^1 = p$ divides $n$ for every prime $p$ dividing $n$.

The source considers only $k$-full numbers with $k \ge 2$.
