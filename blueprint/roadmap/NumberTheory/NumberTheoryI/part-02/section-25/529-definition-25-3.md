# Definition 25.3

A direct system (or inductive system) in a category is a family of objects $\{X_i: i \in I\}$ indexed by a directed set $I$ and a family of morphisms $\{f_{ij}: X_i \rightarrow X_j: i \leq j\}$ such that each $f_{ii}$ is the identity and $f_{ik} = f_{jk} \circ f_{ij}$ for all $i \leq j \leq k$.
