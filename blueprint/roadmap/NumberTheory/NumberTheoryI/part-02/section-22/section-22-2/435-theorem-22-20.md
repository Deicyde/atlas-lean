# Theorem 22.20

Let $\mathcal{C}$ be a congruence subgroup of modulus $\mathfrak{m}$ for a number field $K$ and let $n\coloneqq \left[\mathcal{I}_{K}^{\mathfrak{m}}: \mathcal{C}\right]$. The set of primes $\{\mathfrak{p} \in \mathcal{C}\}$ has Dirichlet density $d(\mathcal{C})= \begin{cases}\frac{1}{n} & \text{if } L(1, \chi) \neq 0 \text{ for all } \chi \neq \mathbb{1} \text{ in } X(\mathcal{C}) \\ 0 & \text{otherwise}\end{cases}$
