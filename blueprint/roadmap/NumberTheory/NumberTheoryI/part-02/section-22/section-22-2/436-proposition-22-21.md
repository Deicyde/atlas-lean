# Proposition 22.21

Let $\mathcal{C}$ be a congruence subgroup of modulus $\mathfrak{m}$ for a number field $K$ and let $n\coloneqq \left[\mathcal{I}_{K}^{\mathfrak{m}}: \mathcal{C}\right]$. For every $I \in \mathcal{I}_{K}^{\mathfrak{m}}$ the set $\{\mathfrak{p} \in I\mathcal{C}\}$ has Dirichlet density $d(I\mathcal{C})= \begin{cases}\frac{1}{n} & \text{if } L(1, \chi) \neq 0 \text{ for all characters } \chi \neq \mathbb{1} \text{ in } X(\mathcal{C}) \\ 0 & \text{otherwise}\end{cases}$
