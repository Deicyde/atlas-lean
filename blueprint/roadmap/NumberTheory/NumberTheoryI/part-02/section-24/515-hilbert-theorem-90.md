# Corollary 24.3 (Hilbert Theorem 90)

Let $L / K$ be a finite cyclic extension with Galois group $\operatorname{Gal}(L / K) = \langle\sigma\rangle$. Then $N(\alpha) = 1$ if and only if $\alpha = \beta / \sigma(\beta)$ for some $\beta \in L^{\times}$.
