# Theorem 28.9 (Chebotarev density theorem)

Let $L / K$ be a finite Galois extension of number fields with Galois group $G\coloneqq \operatorname{Gal}(L / K)$. Let $C \subseteq G$ be stable under conjugation, and let $S$ be the set of primes $\mathfrak{p}$ of $K$ unramified in $L$ with $\operatorname{Frob}_{\mathfrak{p}} \subseteq C$. Then $d(S)=\# C / \# G$.
