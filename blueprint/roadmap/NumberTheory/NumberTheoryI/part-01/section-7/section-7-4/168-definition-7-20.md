# Definition 7.20

Assume $AKLBG$ with finite residue fields. For each unramified prime $\mathfrak{q}$ of $L$ we define the Artin symbol $\left(\frac{L/K}{\mathfrak{q}}\right) \coloneqq \sigma_{\mathfrak{q}}$.
