# Corollary 3.17 (Finite approximation)

Let $I$ be a nonzero fractional ideal in a Dedekind domain $A$ and let $\mathfrak{p}_1, \ldots, \mathfrak{p}_n$ be a finite set of nonzero prime ideals of $A$. Then $I$ contains an element $x$ for which $v_{\mathfrak{p}_i}(x) = v_{\mathfrak{p}_i}(I)$ for $1 \leq i \leq n$.
