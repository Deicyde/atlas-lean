# $\omega_1$-tree

**$\omega_1$-tree.** An *ω₁-tree* is a tree of height ω₁ all of whose levels are countable: every node has height <
ω₁, every level Lev_α(T) with α < ω₁ is nonempty, and every such level is countable.
