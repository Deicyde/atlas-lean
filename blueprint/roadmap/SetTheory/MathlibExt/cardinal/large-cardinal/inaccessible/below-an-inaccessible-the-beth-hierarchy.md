# Below an inaccessible `κ`, the beth hierarchy stays below...

Below an inaccessible `κ`, the beth hierarchy stays below `κ`: `κ` is a beth
fixed point (`IsInaccessible.beth_ord`) and `beth` is strictly monotone.
