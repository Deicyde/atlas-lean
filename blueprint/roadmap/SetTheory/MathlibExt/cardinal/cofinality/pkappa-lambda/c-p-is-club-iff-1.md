# C ⊆ P_κ(λ) is club iff 1

C ⊆ P_κ(λ) is club iff

1. C is ⊆-cofinal: ∀ x ∈ P_κ(λ)  ∃ y ∈ C  (x ⊆ y), and
1. C is closed under unions of nonempty ⊆-directed subfamilies of size < κ: for every nonempty
   ⊆-directed D ⊆ C with |D| < κ, ⋃ D ∈ C.
