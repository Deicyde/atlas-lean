# Martin Axiom

MA(κ) is the statement that for any ccc poset (P,≤), for any sequence (D_α : α<κ') of dense
subsets of the partial order for some κ'≤ κ, for any condition p∈ P, there is a filter G meeting all
D_α's and p∈ G.
