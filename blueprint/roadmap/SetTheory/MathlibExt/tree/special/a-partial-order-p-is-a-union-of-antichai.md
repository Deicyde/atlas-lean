# A partial order (P, ≤) is a *union of ω antichains* if P =...

A partial order (P, ≤) is a *union of ω antichains* if P = ⋃_{n<ω} Aₙ where each Aₙ ⊆ P is an
antichain (a set of pairwise ≤-incomparable elements).
