# Cofinal type

**Cofinal type.** A cofinal type is an equivalence class of preordered sets under Tukey
equivalence $\equiv_T$, where $D \equiv_T E$ means $D \le_T E$ and $E \le_T D$ (Tukey
reducibility in both directions).
