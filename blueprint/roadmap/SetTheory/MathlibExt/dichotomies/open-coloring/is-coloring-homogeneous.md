# Homogeneous set for a coloring

**Homogeneous set for a coloring.** Let $X$ be a set and $K \subseteq X \times X$. A set
$H \subseteq X$ is $K$-homogeneous if $(x, y) \in K$ for all distinct $x, y \in H$.
