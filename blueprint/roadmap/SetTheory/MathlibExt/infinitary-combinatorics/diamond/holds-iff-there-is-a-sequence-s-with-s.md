# ◇_κ holds iff there is a sequence ⟨ S_α : α < κ⟩ with S_α ⊆...

◇_κ holds iff there is a sequence ⟨ S_α : α < κ⟩ with S_α ⊆ α for all α < κ, such that for every
X ⊆ κ, {α < κ : X ∩ α = S_α} is stationary in κ.
