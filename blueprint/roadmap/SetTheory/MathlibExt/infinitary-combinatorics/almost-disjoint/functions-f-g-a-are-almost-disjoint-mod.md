# Functions f, g ∈ ∏_{α<ω₁} A_α are *almost disjoint mod the...

Functions f, g ∈ ∏_{α<ω₁} A_α are *almost disjoint mod the nonstationary ideal* if the set {  α
< ω₁ : f(α) = g(α)  } on which they agree is nonstationary in ω₁.
