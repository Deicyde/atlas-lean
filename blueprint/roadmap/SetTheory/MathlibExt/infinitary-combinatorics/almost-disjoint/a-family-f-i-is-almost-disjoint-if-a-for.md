# A family F ⊆ 𝒫(I) is *κ-almost disjoint* if |A| = κ for...

A family F ⊆ 𝒫(I) is *κ-almost disjoint* if |A| = κ for every A ∈ F and |A ∩ B| < κ for all
distinct A, B ∈ F.
