# Set of regular cardinals below a cardinal

The **regular cardinals below `κ`**, carried as initial ordinals: the set of initial ordinals `α`
(ordinals with no smaller ordinal of the same cardinality) that lie below the initial ordinal of
`κ` and whose cardinality is regular. It parallels the
[Set of inaccessible cardinals below a cardinal](set-of-inaccessible-cardinals-below-a-ca.md),
and it is exactly the set required to be stationary in `κ` in the definition of a
[Weakly Mahlo cardinal](../mahlo-cardinals/weakly-mahlo-cardinal.md).
