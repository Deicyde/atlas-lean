# Borel and analytic determinacy

Martin proved in ZFC that every Borel game is determined, the strongest determinacy statement ZFC proves; the proof needs the axiom of replacement. Determinacy of analytic games needs more: Martin derived it from a measurable cardinal. Projective determinacy follows from infinitely many Woodin cardinals (Martin and Steel, 1989), which this graph does not yet define.
