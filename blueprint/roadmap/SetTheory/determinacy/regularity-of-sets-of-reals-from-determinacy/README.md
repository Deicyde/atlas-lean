# Regularity of sets of reals from determinacy

If every set in a reasonable class of sets of reals is determined, every set in the class is regular: it is countable or contains a perfect set (Davis), it has the property of Baire (Banach–Mazur, Oxtoby), and it is measurable for every σ-finite Borel measure (Mycielski–Świerczkowski). Applied to the projective sets under projective determinacy, these results give the "right" theory of the projective sets that Woodin's 2001 Notices article presents as evidence for projective determinacy.
