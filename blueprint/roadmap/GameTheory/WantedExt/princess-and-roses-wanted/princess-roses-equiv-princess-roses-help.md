# Princess Roses equiv princess Roses Helper

For `a ≥ b ≥ c ≥ d`, the P&R position `(a, b, c, d)` has the Sprague–Grundy value of the
P&R Helper position `[d, b - c + d, a - c + d]` (stated as equivalence of the two games).
