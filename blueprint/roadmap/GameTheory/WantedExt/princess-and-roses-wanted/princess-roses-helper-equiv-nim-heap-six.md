# Princess Roses Helper equiv nim Heap six iff of mem U

On region `U`, a P&R Helper position has Sprague–Grundy value `6` if and only if it is
`[x, x + 2, x + 5]` with `x ≡ 1 (mod 8)`, and it never has value `7`.
