# Lemma 2

**Lemma 2.** If `x` is supported by a basic vector `z ≤ x` of type (A0), then every move
`x → x' = x - d(j)` (keep pile `j`) has `B(x') ≤ B(x) - 1` with `B(x')` odd, and
`B(x') = B(x) - 1` when `z j < b(z)`, or `z j = b(z)` and `z i < min(b(z), x i)` for some `i`.
