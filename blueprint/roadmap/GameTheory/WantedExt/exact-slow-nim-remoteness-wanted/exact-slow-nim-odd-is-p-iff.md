# Proposition 1

**Proposition 1.** For `0 < k`, an odd position `x` (all entries odd) of `NIM(k + 1, k)` is
a P-position iff it satisfies (B) of Theorem 1 for some `m`: `Σ x = k m + k - 1`, `max x < m`,
and `m` even.
