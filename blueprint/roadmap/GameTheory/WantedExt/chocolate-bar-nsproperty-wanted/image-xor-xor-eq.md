# Image xor xor eq

Identity (19): if `g`, `h` have the NS property, `x ≤ g z` and `y ≤ h z`, then
`{x ⊕ y ⊕ w : w < z} = {min (g w') x ⊕ min (h w') y ⊕ w' : w' < z}`.
