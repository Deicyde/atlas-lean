# Height Chocolate Bar Grundy add div eq zero iff

For `F (w, x) = ⌊(w + x) / k⌋` with `k = 4m + 3`, a bar position `y ≤ F (w, x)` of
`CB(F, 0, w, x, y, 0)` is a P-position (Grundy number `0`) iff `w ⊕ x ⊕ y = 0`.
