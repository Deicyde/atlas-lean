# Exists split of div two pow lt

If `⌊z / 2^i⌋ < ⌊z' / 2^i⌋`, there are `c`, `s ≥ i` and `t < 2^s` with
`z = c 2^(s+1) + t < c 2^(s+1) + 2^s ≤ z'`.
