# Exists of lt xor

Two-dimensional mex step: if `g` has the NS property, `x ≤ g z` and `c < x ⊕ z`, then
`c = u ⊕ z` for some `u < x`, or `c = min (g w) x ⊕ w` for some `w < z`.
