# Euclid Moves

The moves of Euclid from `(a, b)`: when `0 < a < b`, replace `b` by `b - j a` for
`1 ≤ j` with `b - j a` still positive (and symmetrically when `0 < b < a`); a position
with equal or zero entries has no moves.
