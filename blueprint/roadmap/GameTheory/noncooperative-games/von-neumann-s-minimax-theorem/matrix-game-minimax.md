# Von Neumann's minimax theorem

Let $A$ be a real $m \times n$ matrix with $m, n \ge 1$, and write $\Delta_k$ for the probability
vectors in $\mathbb{R}^k$. Then
$$\sup_{p \in \Delta_m} \inf_{q \in \Delta_n} p^{\top} A q = \inf_{q \in \Delta_n} \sup_{p \in \Delta_m} p^{\top} A q:$$
the row player's maximin value equals the column player's minimax value.
