# Saddle points of finite matrix games

Let $A$ be a real $m \times n$ matrix with $m, n \ge 1$, the payoff of a zero-sum game to the row
player, and write $\Delta_k$ for the probability vectors in $\mathbb{R}^k$, the mixed strategies.
There are $p \in \Delta_m$ and $q \in \Delta_n$ with
$$p'^{\top} A q \le p^{\top} A q \le p^{\top} A q'$$
for all $p' \in \Delta_m$ and $q' \in \Delta_n$: each of $p$ and $q$ is a best response to the other.
