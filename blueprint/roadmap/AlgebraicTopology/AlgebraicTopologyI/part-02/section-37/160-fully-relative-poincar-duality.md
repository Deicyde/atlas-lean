# Theorem 37.1 (Fully relative Poincaré duality)

Let $M$ be an $n$-manifold and $K \supseteq L$ a pair of compact subsets. Assume given an $R$-orientation along $K$, with corresponding fundamental class $[M]_{K}$. With $p + q = n$, the map $\cap[M]_{K} \colon \check{H}^{p}(K, L; R) \rightarrow H_{q}(M - L, M - K; R)$ is an isomorphism.
