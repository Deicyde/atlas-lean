# Replica-symmetric parameters are admissible

For every $q_1 \in [0, 1]$, $k = 1$, $m = (0, 1)$ and $q = (0, q_1, 1)$ are admissible Parisi
parameters (Talagrand, *The Parisi formula*, Ann. of Math. 163 (2006), (1.6)–(1.7)). The value
of the functional at these parameters is the replica-symmetric solution, the right one at high
temperature (the case $k = 1$ discussed after Theorem 1.1). The lemma shows that the set over
which the Parisi infimum runs is nonempty.
