# Trace base Change

Trace commutes with base change: the image of `T_{B/A} b` under
`A → A'` is the trace of `1 ⊗ b` in `A' ⊗[A] B`. This is the trace clause
of ATLAS `NumberTheoryI`, Lemma 4.49.
