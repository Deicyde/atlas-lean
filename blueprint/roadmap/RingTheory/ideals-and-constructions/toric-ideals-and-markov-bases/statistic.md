# Sufficient-statistic map of a toric model

For `T : X → ℕ^d`, the additive map sending a
table of counts `a : X →₀ ℕ` to `∑_x a(x) T(x) ∈ ℕ^d`: the sufficient statistic `t` of
Diaconis–Sturmfels (1998), equation (1.3), whose fibres are the sets `F_t` of data sets with the
same sufficient statistic.
