# Binomials of a toric model

The set of binomials `x^a - x^b` whose exponent vectors have
the same sufficient statistic, `∑ a(x) T(x) = ∑ b(x) T(x)`. Up to a monomial factor these are the
monomial differences `x^{f⁺} - x^{f⁻}` with `∑ f(x) T(x) = 0` of Diaconis–Sturmfels (1998),
equation (3.1), since `x^a - x^b = x^{a ⊓ b} (x^{a - a ⊓ b} - x^{b - a ⊓ b})`.
