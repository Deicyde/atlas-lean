# Corollary 3.5

If $X, Y$ are locally compact second countable Hausdorff spaces then the natural bilinear map $\boxtimes: \operatorname{Meas}_{c}^{0}(X) \times \operatorname{Meas}_{c}^{0}(Y) \rightarrow \operatorname{Meas}_{c}(X \times Y)$ uniquely extends to a bilinear map $\boxtimes: \operatorname{Meas}_{c}(X) \times \operatorname{Meas}_{c}(Y) \rightarrow \operatorname{Meas}_{c}(X \times Y)$ which is continuous in each variable.
