# Corollary 18.8 (The Duflo-Joseph theorem)

$\phi$ is an isomorphism, i.e., the action homomorphism $\phi: U_{\chi_{\lambda+\rho}} \rightarrow \operatorname{Hom}_{\text{fin}}(M_{\lambda}, M_{\lambda})$ is an isomorphism.
