# Corollary 16.5

(i) If $P \in \mathcal{O}$ is projective then so is $V \otimes P$. (ii) If $\lambda \in \mathfrak{h}^{*}$ is dominant then the object $V \otimes M_{\lambda-\rho} \in \mathcal{O}$ is projective.
