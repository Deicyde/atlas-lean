# Definition 8.3

A vector $v$ in $V[\lambda]$ is called a singular (or highest weight) vector of weight $\lambda$ if $e_{i} v=0$ for all $i$, i.e., if $\mathfrak{n}_{+} v=0$. A representation $V$ of $\mathfrak{g}$ is a highest weight representation with highest weight $\lambda$ if it is generated by such a nonzero vector.
