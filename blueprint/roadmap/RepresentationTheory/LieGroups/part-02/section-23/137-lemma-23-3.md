# Lemma 23.3

When $\lambda$ dominates $\chi$ then (i) Theorem 23.2 holds; (ii) For each $\mu \in S$ there exists an indecomposable projective functor $F_{\mu}$ sending $M_{\lambda - \rho}$ to $P_{\mu - \rho}$.
