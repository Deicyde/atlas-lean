# Lemma 23.7

If $F$ is an indecomposable projective functor with $F = F \circ \Pi_{\chi_{\lambda}}$ for some dominant $\lambda$ and $F(M_{\lambda - \rho}) = P_{\mu - \rho}$ for some $\mu$, then $S_*(F) = \xi \coloneqq W(\mu, \lambda)$ and $(\mu, \lambda)$ is a proper representation of $\xi$.
