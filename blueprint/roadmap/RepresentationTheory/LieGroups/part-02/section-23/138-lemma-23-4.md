# Lemma 23.4

Let $\lambda \in \mathfrak{h}^*$ be dominant and $\varphi, \psi \in \lambda + P$, $\psi \preceq \varphi$. Then $(\lambda - \varphi)^2 \leq (\lambda - \psi)^2$, and if $(\lambda - \varphi)^2 = (\lambda - \psi)^2$ then $\psi \in W_{\lambda} \varphi$.
