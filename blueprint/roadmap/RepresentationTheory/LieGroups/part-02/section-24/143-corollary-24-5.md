# Corollary 24.5

Let $\theta = \chi_{\lambda}$ where $\lambda$ is dominant. If $M_{\lambda - \rho}$ is irreducible then $U_{\theta}$ is a simple algebra. Conversely, if $U_{\theta}$ is simple then $M_{\mu - \rho}$ is irreducible for all $\mu$ with $\chi_{\mu} = \theta$.
