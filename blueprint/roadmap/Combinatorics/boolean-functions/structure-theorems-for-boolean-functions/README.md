# Structure theorems for Boolean functions

Theorems saying that a Boolean function `f : {-1, 1}ⁿ → {-1, 1}` with a simple Fourier spectrum or few influential coordinates is close to a simple function: Friedgut–Kalai–Naor (degree-1 concentration forces a dictator), Friedgut's junta theorem (small total influence forces a junta), the Level-1 Inequality and Majority Is Stablest.

- [Level-1 Inequality](level-one-inequality.md)
