# Walsh character on the Boolean cube

The Walsh character `χ_S(x) = ∏_{i ∈ S} (-1)^{x i}` on `{0, 1}^ι`.

This sign convention, used for the KKL inequality, differs from that of the
[Fourier character on the Boolean cube](../../../../Analysis/harmonic-analysis/discrete-fourier-analysis/fourier-analysis-on-the-boolean-cube/cube-chi.md)
by the factor `(-1)^{|S|}` when the coordinates are `{0, …, n - 1}`; see
[Walsh character agrees with the canonical cube character up to sign](khc-walsh-char-eq-cube-chi.md).
