# A canceling partition for $x_1 + 2x_2 - x_3 - 2x_4 = 0$

**A canceling partition for $x_1 + 2x_2 - x_3 - 2x_4 = 0$.** The equation
$x_1 + 2x_2 - x_3 - 2x_4 = 0$, with coefficient vector $(1, 2, -1, -2)$, has a canceling
partition.
