# Theorem 8.2.2 (Janson inequality III)

Assume Setup 8.1.1. For any $0 \leq t \leq \mu$, $$\mathbb{P}(X \leq \mu - t) \leq \exp\!\left(\frac{-t^2}{2(\mu + \Delta)}\right).$$
