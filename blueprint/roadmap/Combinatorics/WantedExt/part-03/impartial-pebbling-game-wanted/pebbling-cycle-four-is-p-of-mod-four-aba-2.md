# Pebbling cycle Four is P of mod Four ABACHat

Theorem 18: every `C_4` `(2:1)`-pebbling game in
`(X_{abab} ∪ X_{aabc} ∪ X_{aaab}) ∩ \hat Y_{abac}` is a P-game.
