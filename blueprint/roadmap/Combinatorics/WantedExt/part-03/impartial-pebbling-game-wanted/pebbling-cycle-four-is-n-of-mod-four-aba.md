# Pebbling cycle Four is N of mod Four ABABHat Compl

Theorem 20: every `C_4` `(2:1)`-pebbling game in
`(X_{abab} ∪ X_{aabc} ∪ X_{aaab}) ∩ (\hat Y_{abab})^c` is an N-game.
