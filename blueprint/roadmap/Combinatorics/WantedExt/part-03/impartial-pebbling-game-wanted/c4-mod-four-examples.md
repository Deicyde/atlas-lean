# C4 Mod Four examples

Small values of the mod-`4` patterns: `(2,0,0,1) ∈ Y_{aabc}`, `(0,1,0,0) ∈ \hat Y_{abac}`,
`(0,0,0,0) ∈ \hat Y_{abab}`, and `(1,1,0,0) ∈ (\hat Y_{abab})^c`.
