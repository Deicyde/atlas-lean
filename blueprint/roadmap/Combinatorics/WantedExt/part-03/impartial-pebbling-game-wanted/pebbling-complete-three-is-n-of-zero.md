# Pebbling complete Three is N of zero

Lemma 11: for `1 ≤ ℓ ≤ k - 1`, every game in `Γ{a₁, a₂, 0}` on `K_3` with
`a₁ + a₂ = 6k - 2ℓ + 1` and `a₂ ≤ k` is an N-game (the paper's ordering `a₁ ≥ a₂` follows from
these hypotheses).
