# C4 Pattern examples

Small values of the mod-`3` patterns: `(0,0,0,0) ∈ \hat X_{aabb}`, `(1,0,0,0) ∈ X_{aaab}`,
`(0,1,0,1) ∈ X_{abab}`, `(0,0,1,2) ∈ X_{aabc}`, `(0,1,0,2) ∈ X_{abac}`, and
`(0,0,0,0) ∉ X_{aaab}`.
