# Restricted Sumset Shift In Dense Set

Erdős Problem 656: if `A ⊆ ℕ` has positive upper density, then there are an infinite `B ⊆ A`
and an integer `t` with `b₁ + b₂ + t ∈ A` for all distinct `b₁, b₂ ∈ B`.
