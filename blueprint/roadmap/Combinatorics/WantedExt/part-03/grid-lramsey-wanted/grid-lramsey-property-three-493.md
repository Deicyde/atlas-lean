# Grid LRamsey Property three 493

`R_3(L) ≤ 493`, the paper's main bound: every 3-coloring of `[493] × [493]`
contains a monochromatic L. By `GridLRamseyProperty.mono` it implies the bounds of
Theorems 2–5.
