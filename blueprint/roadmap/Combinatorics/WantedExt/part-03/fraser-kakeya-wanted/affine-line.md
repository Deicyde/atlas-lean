# Affine line

**Affine line.** Let $F$ be a finite field and $d$ a natural number. For $y, x \in F^d$, the
affine line with base point $y$ and direction $x$ is the set $\{y + a x : a \in F\} \subseteq F^d$.
When $x = 0$ this set is the single point $\{y\}$.
