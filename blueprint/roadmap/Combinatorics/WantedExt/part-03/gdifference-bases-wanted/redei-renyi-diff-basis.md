# Redei Renyi diff Basis

The Rédei–Rényi set: with `k = ⌈√n⌉`, the set
`B_n = {1, …, k - 1} ∪ {k, 2k, …, k², (k + 1)k}` has `2k` elements and is a `1`-difference
basis for `[n]` (`n ≥ 1`).
