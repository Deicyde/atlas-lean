# Diff Basis Number

`η_g(n)`: the least size of a finite set `A ⊆ ℤ` that is a `g`-difference basis for
`[n] = {1, …, n}`, i.e. `r_{A-A}(x) ≥ g` for every `x ∈ [n]`.
