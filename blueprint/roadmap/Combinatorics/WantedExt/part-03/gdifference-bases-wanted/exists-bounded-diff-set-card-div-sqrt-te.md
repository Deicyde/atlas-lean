# Exists bounded Diff Set card div sqrt tendsto

Lower bound construction: for fixed `g ≥ 1` there are sets `A_n ⊆ [n]` with
`r_{A_n - A_n}(x) ≤ g` for all nonzero `x` and `|A_n| = (1 - o(1)) √(gn)`.
