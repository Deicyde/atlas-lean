# Descending wave

**Descending wave.** A $k$-term descending wave is a sequence $x_0, x_1, \dots, x_{k-1}$ of
natural numbers with $x_0 < x_1 < \dots < x_{k-1}$ and $x_{j-1} + x_{j+1} \le 2 x_j$ for every
$j$ with $0 < j < k - 1$.
