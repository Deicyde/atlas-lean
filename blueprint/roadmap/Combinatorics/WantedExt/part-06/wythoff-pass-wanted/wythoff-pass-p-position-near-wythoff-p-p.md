# Wythoff Pass p Position near wythoff p Position

Every position `(x, y, 1)` with `𝒢₁(x, y, 1) = 0` lies within Euclidean distance `√20` of
some `(v, w)` with `𝒢₁(v, w, 0) = 0`.
