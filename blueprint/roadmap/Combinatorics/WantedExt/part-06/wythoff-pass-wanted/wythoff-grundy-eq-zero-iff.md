# Wythoff Grundy eq zero iff

Wythoff's theorem: the positions of classical Wythoff's game with Grundy number `0`
(the P-positions) are exactly `(⌊nφ⌋, ⌊nφ⌋ + n)` and `(⌊nφ⌋ + n, ⌊nφ⌋)` for `n ≥ 0`, where
`φ = (1 + √5)/2`.
