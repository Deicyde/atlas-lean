# Wythoff Mex A

The mex sequence `a_n` of `K^ℓ`:
`a_n = mex({a_i, b_i | i < n} ∪ {0, 1, …, ℓ})` with `b_i = a_i + i + ℓ + 1`, so
`(a₀, b₀) = (ℓ + 1, 2ℓ + 2)`.
