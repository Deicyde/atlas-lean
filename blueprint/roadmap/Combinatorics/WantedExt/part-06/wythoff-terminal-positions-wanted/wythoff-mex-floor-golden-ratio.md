# Wythoff Mex floor golden Ratio

Corollary 19: for `ℓ ≥ 1` there is a bounded `λ_ℓ : ℕ → ℤ` with
`a_n = ⌊(n + ℓ)φ⌋ + λ_ℓ(n)` and `b_n = ⌊(n + ℓ)φ²⌋ + λ_ℓ(n) + 1` for all `n`.
