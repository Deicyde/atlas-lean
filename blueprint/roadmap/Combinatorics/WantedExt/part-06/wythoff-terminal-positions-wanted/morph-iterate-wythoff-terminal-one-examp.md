# Morph Iterate wythoff Terminal one example

The prefix `f₁⁴(0)` of `f₁^ω(0)` for `f₁ : 0 ↦ 01, 1 ↦ 2, 2 ↦ 34, 3 ↦ 31, 4 ↦ 2` starts
`0, 1, 2, 3, 4, 3` (the table after Proposition 22), via the existing `morphIterate`.
