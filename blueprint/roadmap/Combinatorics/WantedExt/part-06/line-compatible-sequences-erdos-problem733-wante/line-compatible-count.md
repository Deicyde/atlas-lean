# Line Compatible Count

`f(n)`: the number of line-compatible sequences for `n`, i.e. of distinct multisets
`lineSizes P` over `n`-point sets `P ⊆ ℝ²` (a finite set: each has at most `n²` entries, all at most
`n`).
