# Majority Is Least Stable For

The Majority Is Least Stable conjecture in `n` variables: every linear threshold function
`f : {-1, 1}ⁿ → {-1, 1}` satisfies `Stab_ρ[f] ≥ Stab_ρ[Maj_n]` for all `ρ ∈ [0, 1]`.
