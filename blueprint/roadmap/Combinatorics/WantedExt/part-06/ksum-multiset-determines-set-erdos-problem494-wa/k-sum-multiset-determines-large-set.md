# K Sum Multiset Determines Large Set

Erdős Problem 494 (Selfridge and Straus), with `|A|` large: for every `k ≥ 3` there is `n₀`
such that finite sets `A, B ⊆ ℂ` of the same size `≥ n₀` with `A_k = B_k` are equal.
