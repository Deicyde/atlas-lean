# Kneser Hypergraph Coloring

Erdős Problem 780: if `n ≥ k r + (t - 1)(k - 1)`, every coloring of the `r`-subsets of an
`n`-set with `t` colors has a color class containing `k` pairwise disjoint `r`-subsets.
