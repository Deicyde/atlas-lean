# Line Count Gap Above Projective Plane

Erdős Problem 903: if `p` is a prime power, `n = p² + p + 1` and `A₁, …, A_t` is a `2`-design on
`{1, …, n}` with more than `n` blocks, then it has at least `n + p` blocks.
