# Roth Number Log Power Decay

Erdős Problem 140: for every `C > 0`, `r₃(N) ≪ N / (log N)^C`, where `r₃(N) = rothNumberNat N`
is the largest size of a subset of `{0, …, N - 1}` with no non-trivial three-term arithmetic
progression.
