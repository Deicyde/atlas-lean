# Matching Above Threshold

Erdős Problem 747 (Shamir's problem), upper half of the threshold `ℓ(n) ∼ n log n`: with
`ℓ(n) = ⌈(1 + ε) n log n⌉` edges the random hypergraph has `n` disjoint edges with probability
tending to `1`.
