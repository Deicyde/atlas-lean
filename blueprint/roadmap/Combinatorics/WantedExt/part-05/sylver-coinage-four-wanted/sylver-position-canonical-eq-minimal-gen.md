# Sylver Position canonical eq minimal Generators

Proposition 4, part 1: for a finite position `M` in canonical form (no element is
superfluous: removing any `a ∈ M` changes `L(M)`), the minimal system of generators of the
numerical semigroup `S(M) = (ℕ ∪ {0}) \ L(M)` (the additive closure of `M`) is `M`, i.e. `M` is
the set of nonzero elements of `S(M)` that are not a sum of two nonzero elements of `S(M)`.
