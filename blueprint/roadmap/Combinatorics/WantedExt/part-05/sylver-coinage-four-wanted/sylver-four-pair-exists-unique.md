# Sylver four pair exists Unique

For odd `q > 3`, `{4, q}` is an N-position and there is a unique odd `x_q` such that
`{4, x_q}` is an N-position and `{4, q, x_q}` is a P-position (when `q < x_q`, `(q, x_q)` is a
4-pair).
