# Generalized Triangle Five Turan Number

AimPL Problem 2.1 (Hypergraph Turán problem), case `k = 5`: for all large `n`, `ex(n, B_{5,2})`
is the largest size of an `n`-vertex blow-up of the Steiner system `S(4, 5, 11)`.
