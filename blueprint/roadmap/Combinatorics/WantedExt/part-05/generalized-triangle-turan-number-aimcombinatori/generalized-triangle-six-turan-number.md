# Generalized Triangle Six Turan Number

AimPL Problem 2.1 (Hypergraph Turán problem), case `k = 6`: for all large `n`, `ex(n, B_{6,2})`
is the largest size of an `n`-vertex blow-up of the Steiner system `S(5, 6, 12)`.
