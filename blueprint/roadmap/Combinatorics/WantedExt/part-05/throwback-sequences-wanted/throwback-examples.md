# Throwback examples

Characteristic values: `τ(3, 4, 5, …) = (4, 5, 6, 3, 7, …)`, and the throwback sequence of
`(3, 4, 5, …)` begins `3, 4, 5, 6, 3, 7` (Table 1, OEIS A357081).
