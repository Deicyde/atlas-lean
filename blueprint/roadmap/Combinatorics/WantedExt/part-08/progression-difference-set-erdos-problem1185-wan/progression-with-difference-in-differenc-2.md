# Progression With Difference In Difference Set refuted

Resolved false: erdosproblems.com/1185 records that the answer is no already for `k = 3`:
Furstenberg gave an infinite set `B` such that `B - B` is not `2`-intersective, i.e. some set of
positive density contains no `3`-term progression with difference in `B - B`; truncating both sets
at `N` gives counterexamples with `|B ∩ [1, N]|` unbounded. Source: T. F. Bloom, Erdős Problems,
Problem #1185, https://www.erdosproblems.com/1185 (status SOLVED); resolution: H. Furstenberg,
Recurrence in Ergodic Theory and Combinatorial Number Theory, Princeton University Press (1981),
erdosproblems.com/1185: false already at k = 3, since Furstenberg gave an infinite set B such that B
- B is not 2-intersective.
