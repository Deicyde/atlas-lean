# Leftover Value

The Burr-Erdős-Spencer value `r(k, k - 1) - 1 + rem(n - r(k, k - 1) + 1, k)` of the least
possible number of uncovered vertices, where `r(k, k - 1)` is the classical two-colour Ramsey
number `graphRamsey k (k - 1)`.
