# Has Multicolored Sunflower

A collection `S` of triples contains a multicolored sunflower: three triples
`(x₁, y₁, z₁), (x₂, y₂, z₂), (x₃, y₃, z₃) ∈ S`, not all equal, with `x₁ + y₂ + z₃ = 0`.
