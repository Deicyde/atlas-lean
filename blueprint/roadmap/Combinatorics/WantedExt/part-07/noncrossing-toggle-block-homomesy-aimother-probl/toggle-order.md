# Toggle Order

The arcs `(i, i + d)` ordered by length `d = 1, …, n - 1` and then by left endpoint: in
`1`-indexed form `(1,2), (2,3), …, (n-1,n), (1,3), …, (n-2,n), …, (1,n)`.
