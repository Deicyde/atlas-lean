# The value $h_3(0) = 1$ of the Maximum Nim map

**The value $h_3(0) = 1$ of the Maximum Nim map.** For the map
$h_k(x) = x + \lfloor x/(k-1) \rfloor + 1$ on the natural numbers, we have $h_3(0) = 1$.
