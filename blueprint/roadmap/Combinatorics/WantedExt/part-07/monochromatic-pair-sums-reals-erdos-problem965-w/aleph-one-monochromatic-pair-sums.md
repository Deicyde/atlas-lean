# Aleph One Monochromatic Pair Sums

Erdős Problem 965: for every colouring of `ℝ` with two colours there is a set `A ⊆ ℝ` of
cardinality `ℵ₁` such that all sums `a + b` with `a ≠ b` in `A` have the same colour.
