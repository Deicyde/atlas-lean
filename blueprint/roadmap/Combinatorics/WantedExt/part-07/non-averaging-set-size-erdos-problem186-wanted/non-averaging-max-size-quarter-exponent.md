# Non Averaging Max Size Quarter Exponent

Erdős Problem 186: the largest non-averaging subset of `{1, …, N}` has size `N^{1/4 + o(1)}`:
for every `ε > 0` and all large `N` its size lies between `N^{1/4 - ε}` and `N^{1/4 + ε}`.
