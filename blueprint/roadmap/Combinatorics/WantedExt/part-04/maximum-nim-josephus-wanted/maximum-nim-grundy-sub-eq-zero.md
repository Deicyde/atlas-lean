# Maximum Nim Grundy sub eq zero

Lemma 3(iii): for `k ≥ 2` and each `j` from one through `k`, the position
`k-j` has Grundy number zero for rule `f(y)=⌊y/k⌋`. The bounded hypotheses encode
`j=1,...,k`; there is no deviation.
