# Zero-based integer interval

**Zero-based integer interval.** For a natural number $k$, the integer interval $[0, k-1]$ is
the set $\{0, 1, \dots, k-1\}$ of integers $i$ with $0 \le i < k$; it is empty when $k = 0$.
