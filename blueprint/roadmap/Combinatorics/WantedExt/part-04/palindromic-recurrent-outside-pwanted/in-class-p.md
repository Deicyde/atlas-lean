# Class P

**Class P.** A morphism $\varphi$ is in class P (Hof–Knill–Simon) when there is a palindrome $p$
such that for every letter $a$, $\varphi(a) = p q_a$ for some palindrome $q_a$. The palindromes
$p$ and $q_a$ may be empty.
