# Corollary 58

**Corollary 58.** For `k, m ≥ 1`, `l ≥ 0` and `w` the one-sided fixed point of `σ_{k,l,m}`,
`r(n) = ((m-1)/m) p_b(n) + ((k+l+1-m)/m) n + (m-l-1)/m` for `n ≥ 1`.
