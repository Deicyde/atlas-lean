# Lemma 13

**Lemma 13.** For `w ∈ a𝒲` and `k ≥ 1`: `b^k` is a subword of `w` iff
`sup Δp_a > k` iff `Δp_b` takes the value one at least `k - 1` times in a row; and `a^k` is a
subword iff `Δp_a` takes the value one at least `k - 1` times in a row.
