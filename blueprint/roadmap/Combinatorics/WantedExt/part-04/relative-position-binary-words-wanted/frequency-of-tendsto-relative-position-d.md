# Proposition 33

**Proposition 33.** For `w ∈ 𝒲` with `r(n)/n → L` in the extended reals, `Freq(b)` exists
and equals `0` if `L = ∞`, `1` if `L = -∞`, `1/2` if `L = 0`, and
`(2 + L - √(4 + L²)) / (2L)` otherwise.
