# Lemma 22

**Lemma 22.** For an equilibrious word `u` of length `2k` and `w ∈ 𝒲`,
`p_{a, uw}(n+k) = p_{a,w}(n) + 2k`, `p_{b, uw}(n+k) = p_{b,w}(n) + 2k`, hence
`r_{uw}(n+k) = r_w(n)`, for all `n ≥ 1`.
