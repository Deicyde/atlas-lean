# Theorem 70

**Theorem 70.** The Thue–Morse word `t` is the only word `w ∈ a𝒲` with `w = r(1) r(2) ⋯` on
the letters `a = 1`, `b = -1`, i.e. with `r(n) = 1` if `ℓ_{n-1} = a` and `r(n) = -1` otherwise.
