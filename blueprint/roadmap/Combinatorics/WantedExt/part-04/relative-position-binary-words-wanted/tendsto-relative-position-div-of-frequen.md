# Corollary 31

**Corollary 31.** If `Freq(b) = d ∈ (0, 1)` then `r(n)/n → 1/d - 1/(1-d)`. (Such a word has
both letters infinitely often, so no separate `w ∈ 𝒲` hypothesis is needed.)
