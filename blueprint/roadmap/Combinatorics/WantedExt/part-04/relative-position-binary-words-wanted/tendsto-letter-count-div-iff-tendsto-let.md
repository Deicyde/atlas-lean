# Lemma 28

**Lemma 28.** For `w ∈ 𝒲` and a letter `α`: (a) for `d ∈ (0, 1]`, `#_α(m)/m → d` iff
`p_α(n)/n → 1/d`; (b) `#_α(m)/m → 0` iff `p_α(n)/n → ∞`.
