# Lemma 66

**Lemma 66.** For `k ≥ 1`, `τ_k = (k + √(k² + 4))/2` and `M ∈ M₂(ℤ)`, `[τ_k 1]ᵀ` is a right
eigenvector of `M` iff `M = [[km + n, m], [m, n]]` for some integers `m, n`; then the eigenvalues
are `n + mτ_k` and `n + mτ_k'` with `τ_k' = (k - √(k² + 4))/2`.
