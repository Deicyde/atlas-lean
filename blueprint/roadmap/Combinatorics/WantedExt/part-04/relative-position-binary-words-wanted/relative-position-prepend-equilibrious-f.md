# Theorem 55

**Theorem 55.** For an equilibrious word `u` of length `2j` and `w_j = Pre_u(f)`,
`r_{w_j}(n) = n - j` for all `n > j`; if `u = (ab)^j`, then `r_{w_j}(1) = ⋯ = r_{w_j}(j) = 1`.
