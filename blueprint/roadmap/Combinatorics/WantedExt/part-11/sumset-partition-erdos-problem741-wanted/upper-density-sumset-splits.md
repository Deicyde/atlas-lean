# Upper Density Sumset Splits

Erdős Problem 741, first question (upper-density reading): if `A ⊆ ℕ` and `A + A` has positive
upper density, then `A = A₁ ⊔ A₂` with `A₁ + A₁` and `A₂ + A₂` both of positive upper density.
