# Three APFree Complement Contains Progression

Erdős Problem 199: if `A ⊆ ℝ` contains no three-term arithmetic progression, then `ℝ \ A`
contains an infinite arithmetic progression `a, a + d, a + 2d, …` with `d ≠ 0`.
