# Inversion set of a permutation

**Inversion set of a permutation.** For a permutation $\sigma$ of $\{0, \dots, n-1\}$, the
inversion set of $\sigma$ is the set of pairs of positions $(i, j)$ with $i < j$ and
$\sigma(j) < \sigma(i)$.
