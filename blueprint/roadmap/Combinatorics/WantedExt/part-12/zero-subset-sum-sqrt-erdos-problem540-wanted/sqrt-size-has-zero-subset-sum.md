# Sqrt Size Has Zero Subset Sum

Erdős Problem 540 (Erdős and Heilbronn): there is `C > 0` such that for every `N ≥ 1`, every
`A ⊆ ℤ / N ℤ` with `|A| ≥ C √N` has a nonempty subset with sum `0`.
