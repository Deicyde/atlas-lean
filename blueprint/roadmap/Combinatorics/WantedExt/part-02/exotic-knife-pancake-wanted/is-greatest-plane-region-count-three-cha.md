# Theorem 1

**Theorem 1** (3-chains). The maximum number of regions formed in the plane by `n` 3-chains
(a finite segment `[p, q]` with a ray attached at each end, arbitrary directions,
self-intersections allowed) is `(9n² - 5n + 2)/2`.
