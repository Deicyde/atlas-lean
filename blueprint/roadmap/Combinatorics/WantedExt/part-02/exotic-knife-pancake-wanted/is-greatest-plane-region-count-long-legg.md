# Theorem 1

**Theorem 1** (long-legged A's). The maximum number of regions formed in the plane by `n`
long-legged A's (a tip `c` with two rays `c + s u₁`, `c + s u₂` and a crossbar segment from
`c + a u₁` to `c + b u₂`, `a, b > 0`) is `(9n² - 5n + 2)/2`.
