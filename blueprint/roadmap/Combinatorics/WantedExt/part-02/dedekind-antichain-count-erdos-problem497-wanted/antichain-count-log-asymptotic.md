# Antichain Count Log Asymptotic

Erdős Problem 497, Kleitman's answer: the number of antichains of subsets of `[n]` is
`2 ^ ((1 + o(1)) C(n, ⌊n / 2⌋))`, i.e. `log₂ M(n) / C(n, ⌊n / 2⌋) → 1`.
