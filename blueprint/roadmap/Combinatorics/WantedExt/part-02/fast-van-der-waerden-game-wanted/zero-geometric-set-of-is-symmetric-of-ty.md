# Zero Geometric Set of is Symmetric Of Type

If `S` is symmetric of (one-based) type `(2, n)` (resp. `(1, n - 1)`), then
`S₂(n, k)` is a copy (resp. reflection) of `S` for some rational `k > 1`.
