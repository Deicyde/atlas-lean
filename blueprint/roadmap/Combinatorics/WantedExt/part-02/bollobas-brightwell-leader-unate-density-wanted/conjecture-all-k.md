# Conjecture All K

The Bollobás–Brightwell–Leader conjecture for every fixed `k`: `conjecture k` for all `k`,
i.e. for each `k ≥ 2` a `1 - o(1)` fraction of the `k`-SAT functions on `n` variables is unate
as `n → ∞`.
