# Is Periodic Continuous Tiling Set

We say that a (continuous) tiling set `Λ ⊆ ℝᵈ` is periodic if there exists a lattice `L`
of `ℝᵈ` such that `Λ` can be written as the union of finitely many cosets of `L`.
