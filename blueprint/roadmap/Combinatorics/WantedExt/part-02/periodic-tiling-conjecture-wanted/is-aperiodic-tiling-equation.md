# Is Aperiodic Tiling Equation

Given an abelian group `G`, and a set `F ⊆ G` we say that `F` forms an aperiodic tiling equation
if there exists `A ⊆ G` such that `F` tiles `G` with tiling set `A` but all such `A` are not
periodic.
