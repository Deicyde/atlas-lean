# Weights of the capacity-3 lower bound

**Weights of the capacity-3 lower bound.** The rational weights $y_i$ are
$y_1 = y_2 = y_3 = 0$, $y_4 = 2$, $y_5 = 4$, $y_6 = 5$, and $y_i = (4i - 8)/3$ for $i \ge 7$.
The value $y_0$ is unused and set to $0$.
