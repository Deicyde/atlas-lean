# Finite Sidon sets of natural numbers

**Finite Sidon sets of natural numbers.** A finite set $A$ of natural numbers is a Sidon set
when every equality $a + b = c + d$ with $a, b, c, d \in A$ is trivial, that is, $a = c$ and
$b = d$, or $a = d$ and $b = c$.
