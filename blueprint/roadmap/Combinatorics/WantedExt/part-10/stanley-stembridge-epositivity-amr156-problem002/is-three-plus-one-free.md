# $(3+1)$-free posets

**$(3+1)$-free posets.** A partially ordered set $P$ is $(3+1)$-free when there are no
elements $a, b, c, d \in P$ with $a < b < c$ such that $d$ is incomparable to each of $a$, $b$
and $c$ (neither $d \le x$ nor $x \le d$ for $x = a, b, c$).
