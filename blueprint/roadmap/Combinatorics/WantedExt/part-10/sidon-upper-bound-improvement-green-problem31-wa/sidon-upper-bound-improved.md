# Sidon Upper Bound Improved

Green's Problem 31, upper bound: Lindström's bound `F(N) ≤ N^{1/2} + N^{1/4} + O(1)` can be
improved, in the form `F(N) ≤ N^{1/2} + c N^{1/4}` for all large `N` with a constant `c < 1`.
