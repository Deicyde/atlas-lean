# Sidon Complement Contains Progression

Erdős Problem 198: the complement of every Sidon set `A ⊆ ℕ` (`Set.IsSidon`: `a + b = c + d`
with `a, b, c, d ∈ A` forces `{a, b} = {c, d}`) contains an infinite arithmetic progression
`a, a + d, a + 2d, …` with `d ≥ 1`.
