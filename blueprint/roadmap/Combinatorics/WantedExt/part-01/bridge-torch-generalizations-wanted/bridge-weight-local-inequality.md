# Bridge Weight local inequality

Local inequality: for every non-empty set `T` of positive integers with
`|T| ≤ 3`, `∑_{i ∈ T} yᵢ + (9/2)(|T| - 1) ≤ max T + ∑_{i ∈ T} i`.
