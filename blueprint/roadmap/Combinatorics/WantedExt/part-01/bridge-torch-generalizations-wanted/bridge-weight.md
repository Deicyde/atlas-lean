# Bridge Weight

The weights `yᵢ` of the capacity-3 lower bound: `y₁ = y₂ = y₃ = 0`,
`y₄ = 2`, `y₅ = 4`, `y₆ = 5`, and `yᵢ = (4i - 8)/3` for `i ≥ 7` (the value at
`i = 0` is unused and set to `0`).
