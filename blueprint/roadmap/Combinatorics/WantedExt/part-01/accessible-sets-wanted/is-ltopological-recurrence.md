# Is LTopological Recurrence

`D` is a set of `ℓ`-topological recurrence when every minimal compact
metric system and every nonempty open `U` admit `d ∈ D` for which the
intersection over `j = 0, …, ℓ` of `T⁻ʲᵈ U` is nonempty.
