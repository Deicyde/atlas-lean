# The Zeckendorf state of $4$

**The Zeckendorf state of $4$.** The Zeckendorf state of $4$ consists of one copy of $F_3$
and one copy of $F_1$, reflecting the Zeckendorf decomposition $4 = F_3 + F_1 = 3 + 1$.
