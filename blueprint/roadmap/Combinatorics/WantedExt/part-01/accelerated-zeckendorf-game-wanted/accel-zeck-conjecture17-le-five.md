# Accel Zeck conjecture17 le five

Conjecture 1.7 holds for `k ∈ {1, 2, 3, 4, 5}`: if the second player wins the game on `n`,
then for these `k` with `3k ≤ n` the state `(0, …, 0, k, 0, n - 3k)` is losing.
