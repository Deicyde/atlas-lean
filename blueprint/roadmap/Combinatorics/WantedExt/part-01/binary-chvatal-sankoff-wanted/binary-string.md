# Binary strings

**Binary strings.** For a natural number $n$, a binary string of length $n$ is a function
from $\{0, 1, \dots, n - 1\}$ to $\{\mathrm{false}, \mathrm{true}\}$, that is, a sequence of $n$
bits listed in order.
