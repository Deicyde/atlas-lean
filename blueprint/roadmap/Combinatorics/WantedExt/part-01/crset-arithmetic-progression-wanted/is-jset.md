# Is JSet

`A` is a `J`-set: for every finite family `F` of sequences `ℕ → S` there are
`a ∈ S` and a nonempty finite `H ⊆ ℕ` (a duplicate-free nonempty list) with
`a + ∑ n ∈ H, f n ∈ A` for every `f ∈ F`.
