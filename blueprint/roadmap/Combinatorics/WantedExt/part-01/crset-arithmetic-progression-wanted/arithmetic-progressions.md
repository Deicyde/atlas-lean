# Theorem 8

**Theorem 8** (main theorem). If `A` is a CR-set in a commutative semigroup `S`
and `l ∈ ℕ`, then the set of `(a, b)` with `a, a + b, a + 2b, …, a + l b ∈ A` is a
CR-set in `S × S`.

The paper takes `l ≥ 1`; `l = 0` is included.
