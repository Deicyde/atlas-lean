# Theorem 1

**Theorem 1** (Furstenberg–Glasner). If `S ⊆ ℤ` is piecewise syndetic, then for
every `k` the set of `(a, d) ∈ ℤ × ℤ` with `a, a + d, …, a + k d ∈ S` is piecewise
syndetic in `ℤ × ℤ`.

The paper takes `k ≥ 1`; `k = 0` is included.
