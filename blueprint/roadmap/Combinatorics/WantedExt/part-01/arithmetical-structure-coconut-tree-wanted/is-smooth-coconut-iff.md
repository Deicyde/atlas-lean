# Is Smooth Coconut iff

Lemma 2: an arithmetical structure on `CT(p, s)` (`p ≥ 1`) is smooth if
and only if `r_{ℓ_j} < r_p` for all `j` and `r_1 < r_2 < ⋯ < r_p`.
