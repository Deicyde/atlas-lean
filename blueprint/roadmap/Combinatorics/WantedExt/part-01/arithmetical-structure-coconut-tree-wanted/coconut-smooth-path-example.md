# Coconut Smooth Path example

Example 3.2: smoothing `d = (3, 1, 3, 2, 2 | 2, 2, 4)`,
`r = (1, 3, 2, 3, 4 | 2, 2, 1)` on `CT(5, 3)` at `v_2` gives `d' = (2, 2, 2, 2 | 2, 2, 4)`,
`r' = (1, 2, 3, 4 | 2, 2, 1)` on `CT(4, 3)`.
