# Is Smooth Coconut

A smooth arithmetical structure on `CT(p, s)`: an arithmetical structure
with `d_1, …, d_{p-1}, d_{ℓ_1}, …, d_{ℓ_s} ≥ 2` (no condition on `d_p`).
