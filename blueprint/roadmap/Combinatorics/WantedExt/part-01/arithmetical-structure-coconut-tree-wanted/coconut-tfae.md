# Coconut tfae

Lemma 1: for an arithmetical structure on `CT(p, s)` the following are
equivalent: (1) `d_i ≥ 2` for `1 ≤ i ≤ p - 1`; (2)
`0 < r_2 - r_1 ≤ r_3 - r_2 ≤ ⋯ ≤ r_p - r_{p-1}`; (3) `r_1 < r_2 < ⋯ < r_p`.
