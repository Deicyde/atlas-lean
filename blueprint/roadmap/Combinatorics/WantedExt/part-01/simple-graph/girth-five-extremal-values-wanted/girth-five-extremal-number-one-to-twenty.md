# Girth Five Extremal Number one to twenty

`ex(n; {C₃, C₄})` for `1 ≤ n ≤ 20`:
`0, 1, 2, 3, 5, 6, 8, 10, 12, 15, 16, 18, 21, 23, 26, 28, 31, 34, 38, 41`.
