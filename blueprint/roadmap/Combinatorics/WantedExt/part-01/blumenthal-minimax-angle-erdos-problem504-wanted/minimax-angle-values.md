# Minimax Angle Values

Erdős Problem 504 (Blumenthal), Sendov's answer: `α_3 = π/3`, `α_4 = π/2`, and for `n ≥ 2`,
`α_N = (1 - 2/(2n + 1)) π` for `2^n < N ≤ 2^n + 2^(n-2)` and `α_N = (1 - 1/(n + 1)) π` for
`2^n + 2^(n-2) < N ≤ 2^(n+1)`.
