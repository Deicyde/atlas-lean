# Volume staircase simplex ge

Lemma 4.8: for `c ≥ 0` and `n ≥ ct`, the set `X ⊆ ℝ^t` of `y` with `0 < y_{t-1}`,
`y_{i+1} + c < y_i` and `y_i < n - i c` (indices from `0`) has `μ_t(X) ≥ (n/t - c)^t`.
