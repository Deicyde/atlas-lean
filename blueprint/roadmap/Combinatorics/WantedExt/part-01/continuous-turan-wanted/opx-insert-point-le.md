# Opx insert point le

Corollary 2.10: if `P` has a rightmost column through `(x₀, y₀) ∈ P` and `P'` adds the point
`(x₀ + c, y₀)`, `c > 0`, then `opx(n, P') ≤ opx(n, P) + cn` (`n > 0`).
