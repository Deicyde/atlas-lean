# Opx union segment le

Lemma 2.9: if `P` has a rightmost column `x = x₀` through `(x₀, y₀) ∈ P`, and `P'` adds the
horizontal segment `[x₀, x₀ + c] × {y₀}`, `c ≥ 0`, then `opx(n, P') ≤ opx(n, P) + cn` (`n > 0`).
