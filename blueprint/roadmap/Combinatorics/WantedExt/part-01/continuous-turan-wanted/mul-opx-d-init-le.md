# Mul opx D init le

Lemma 5.5: for `P ⊆ ℝ^{d+1}` with projection `Pr(P) ⊆ ℝ^d` (drop the last coordinate),
`opx(n, P, d + 1) ≥ n · opx(n, Pr(P), d)`. Stated for all real `n`.
