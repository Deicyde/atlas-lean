# Pattern Ex D

`ex(n, M_P, d)`: the maximum number of cells of the grid `{0, …, n - 1}^d` forming a set that
does not contain `P` (`CellsContainPatternD`); for finite `P` this is the `d`-dimensional 0-1
matrix extremal function `ex(n, M_P, d)`.
