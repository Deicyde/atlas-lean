# The inverse Ackermann function at 8

**The inverse Ackermann function at 8.** The inverse Ackermann function $\alpha$ satisfies
$\alpha(8) = 3$, since $A(2, 2) = 7 < 8 \le 61 = A(3, 3)$, where $A$ is the two-argument
Ackermann function.
