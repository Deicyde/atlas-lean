# Wesley's constant $c_{n,0}$ for $n \equiv 0 \pmod 4$

**Wesley's constant $c_{n,0}$ for $n \equiv 0 \pmod 4$.** For every natural number $n$ with
$n \equiv 0 \pmod 4$, Wesley's constant satisfies $c_{n,0} = 2/5$.
