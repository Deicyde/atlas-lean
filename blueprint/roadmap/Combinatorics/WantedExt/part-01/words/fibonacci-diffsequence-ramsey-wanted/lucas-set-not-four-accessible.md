# Lucas Set not four accessible

`Δ(L, 3; 4) = ∞` for the Lucas numbers `L = {2, 1, 3, 4, 7, …}` (some `4`-coloring of `ℤ⁺`
has no monochromatic `3`-term `L`-diffsequence); in particular `L` is not
`r`-accessible for any `r ≥ 4`, i.e. `doa(L) ≤ 3`.
