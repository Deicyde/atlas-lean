# Half Even Fibonacci Set

The set `G = {1, 4, 17, 72, …} = {f / 2 : f ∈ F} ∩ ℤ` of halves of even Fibonacci numbers,
`g_n = f_{3n} / 2` for `n ≥ 1`.
