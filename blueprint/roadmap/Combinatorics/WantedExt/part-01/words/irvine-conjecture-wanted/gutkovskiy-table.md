# Gutkovskiy Table

The table `[g₀, …, gₙ]` of Gutkovskiy's sequence, built by course of values: entry `n + 1`
is `(n + 1) - g_{⌊gₙ/2⌋}`, read from the table so far (each step costs one lookup).
