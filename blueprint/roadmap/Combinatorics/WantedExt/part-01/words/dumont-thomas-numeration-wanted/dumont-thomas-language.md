# Dumont Thomas Language

The image language `⋃_{ℓ ∈ ℕ} ℒ_{ℓp+1}(𝒜_{η,s}) \ {0 W_min, 1 W_max} 𝒟*`: digit words
accepted by `𝒜_{η,s}` (`s = u₋₁|u₀`) whose length is `ℓp + 1`, which do not start with
`0 ⊙ 0^p` and do not start with `1 ⊙ W_max`.
