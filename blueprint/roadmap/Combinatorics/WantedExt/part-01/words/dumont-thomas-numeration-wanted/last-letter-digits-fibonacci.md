# Last Letter Digits fibonacci

For the Fibonacci substitution `a ↦ ab`, `b ↦ a` (`a = 0`, `b = 1`) and `p = 2`,
`W_max = tail_{φ,2,b}(|φ²(b)| - 1) = 01`, as computed in the paper.
