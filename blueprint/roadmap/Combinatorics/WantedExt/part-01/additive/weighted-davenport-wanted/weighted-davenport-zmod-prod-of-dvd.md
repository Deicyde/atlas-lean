# Weighted Davenport zmod prod of dvd

For `m, n ≥ 2` with `m ∣ n`, `α = ⌈n/(m-1)⌉ - 1` and `A ⊆ {1, …, α}` with `n/m ∈ A`:
if `α ∣ n`, then `D_A(Z_n ⊕ Z_{kn}) = m + ⌈kn/α⌉ - 1` for every `k ≥ 1`. The paper's
"non-empty" is implied by `n/m ∈ A` and is not repeated.
