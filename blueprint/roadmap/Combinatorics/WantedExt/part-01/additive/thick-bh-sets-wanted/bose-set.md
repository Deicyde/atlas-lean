# Bose Set

The generalized Bose set `Bose_h(q, b)`: for a finite field `F` with `q` elements, an
extension `K` of degree `h`, a generator `θ` of `K^×` and an exponent `b`, the residues
`a ∈ ℤ/(q^h - 1)ℤ` with `θ^a = θ^b + v` for some `v ∈ F`.
