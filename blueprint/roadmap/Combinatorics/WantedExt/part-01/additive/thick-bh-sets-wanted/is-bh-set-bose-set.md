# Theorem 3, Bose part

**Theorem 3, Bose part.** If `h ≥ 2`, `K` is a degree-`h` extension of the finite field
`F` with `q` elements, `θ` generates `K^×`, and `θ^b` has degree `h` over `F`, then
`Bose_h(q, b)` is a `B_h`-set in `ℤ/(q^h - 1)ℤ` with exactly `q` elements.
