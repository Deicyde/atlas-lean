# Singer Set

The generalized Singer set `Singer_h(q, b)`: for a finite field `F` with `q` elements,
an extension `K` of degree `h + 1`, a generator `θ` of `K^×` and an exponent `b`, the
residues `a ∈ ℤ/Mℤ`, `M = (q^(h+1) - 1)/(q - 1)`, with `θ^a = uθ^b + v` for some
`u, v ∈ F`.
