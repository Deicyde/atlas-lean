# Theorem 5(b)

**Theorem 5(b).** For `h ≥ 2`, if `n ≥ e^(e^34)` then `R_h(n) ≥ n^(1/h) - 7 n^(2/(3h))`,
and if `k ≥ e^(e^34)` then `R_h⁻¹(k) ≤ k^h + (3k)^(h - 1/3)`.
