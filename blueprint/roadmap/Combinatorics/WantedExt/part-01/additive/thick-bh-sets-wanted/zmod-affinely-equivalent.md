# ZMod Affinely Equivalent

Sets `A₁, A₂ ⊆ ℤ/Mℤ` are affinely equivalent, `A₁ ∼ A₂`, if `A₂ = {d a + s : a ∈ A₁}`
for some unit `d` and some `s`.
