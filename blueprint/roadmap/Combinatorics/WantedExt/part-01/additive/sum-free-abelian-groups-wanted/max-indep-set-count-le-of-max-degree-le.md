# Balogh–Liu–Sharifzadeh–Treglown bound

**Balogh–Liu–Sharifzadeh–Treglown bound.** If `k ≥ 1`, `Γ` has `n` vertices,
`Δ(Γ) ≤ k δ(Γ)` and `b = √δ(Γ)`, then
`mis(Γ) ≤ ∑_{0 ≤ i ≤ n/b} C(n, i) · 3^{(k/(k+1)) n/3 + 2n/(3b)}`.
