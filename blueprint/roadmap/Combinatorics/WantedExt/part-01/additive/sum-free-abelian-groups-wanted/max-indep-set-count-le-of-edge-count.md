# Liu–Sharifzadeh stability bound

**Liu–Sharifzadeh stability bound.** If `Γ` has `n` vertices, `n + k` edges (`k ∈ ℤ`) and
maximum degree `Δ ≥ 1`, then `mis(Γ) ≤ 3^{Δ/13} · 3^{n/3 - k/(13Δ)}`.
