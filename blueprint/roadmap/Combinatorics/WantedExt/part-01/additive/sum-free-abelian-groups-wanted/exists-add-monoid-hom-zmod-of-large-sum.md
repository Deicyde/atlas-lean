# Green–Ruzsa structure lemma

**Green–Ruzsa structure lemma.** If `G` is of type `I(p)`, `p = 3k + 2`, and `A ⊆ G` is
sum-free with `|A| > (1/3 + 1/(3(p+1)))|G|`, then some homomorphism `ψ : G → ℤ_p` maps `A`
into `{k + 1, …, 2k + 1}`.
