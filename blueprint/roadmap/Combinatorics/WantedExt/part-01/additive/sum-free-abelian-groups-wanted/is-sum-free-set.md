# Sum-free set

**Sum-free set.** Let $G$ be a set with an addition. A subset $S \subseteq G$ is sum-free if
$x + y \notin S$ for all $x, y \in S$, where $x = y$ is allowed; that is, $S$ contains no Schur
triple $x + y = z$ with $x, y, z \in S$.
