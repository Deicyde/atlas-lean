# Card bounded Subset Sums ge mixed Sign zero

For a set `A` of `p` positive integers, `n` negative integers and `0`, `1 ≤ n ≤ p`,
`k = n + p + 1`, `1 ≤ α` and `α + β ≤ k - 1`: `|Σ^β_α(A)| ≥ L₀(α, β, A)`, and the bound is
attained.
