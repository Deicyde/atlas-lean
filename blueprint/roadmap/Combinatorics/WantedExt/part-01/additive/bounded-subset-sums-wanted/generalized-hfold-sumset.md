# Generalized HFold Sumset

The generalized `h`-fold sumset `h^{(r̄)}A = {∑ sⱼ aⱼ : 0 ≤ sⱼ ≤ rⱼ, ∑ sⱼ = h}` of the
ordered set `A = {a₀, …, a_{k-1}}` (given as `a : Fin k → G`) with the tuple `r̄ = (r₀, …, r_{k-1})`.
