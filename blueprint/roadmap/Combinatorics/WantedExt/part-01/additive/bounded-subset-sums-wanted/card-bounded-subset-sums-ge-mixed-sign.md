# Card bounded Subset Sums ge mixed Sign

For a set `A` of `p` positive and `n` negative integers, `1 ≤ n ≤ p`, `k = n + p`, `1 ≤ α`
and `α + β ≤ k - 1`: `|Σ^β_α(A)| ≥ L(α, β, A)`, and the bound is attained.
