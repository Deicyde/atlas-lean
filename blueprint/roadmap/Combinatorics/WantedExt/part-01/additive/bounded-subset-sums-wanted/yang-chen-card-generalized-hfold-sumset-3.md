# Yang Chen card generalized HFold Sumset eq three

Yang–Chen inverse theorem for `k = 3`: if `2 ≤ h ≤ r₀ + r₁ + r₂ - 2`, then
`|h^{(r̄)}A| = L(r̄, h)` always when `r₁ = 1`, and if and only if `A` is a `3`-term arithmetic
progression when `r₁ ≥ 2`.
