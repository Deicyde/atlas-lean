# Bounded Subset Sums eq generalized HFold Sumset of zero mem

For `A = {0, a₁, …, a_{k-1}} ⊆ G` with `k` distinct elements, `1 ≤ α ≤ k`, `β ≤ k - 1` and
`α + β ≤ k`, `Σ^β_α(A) = (k - β)^{(r̄)}A` with `r̄ = (k - α - β + 1, 1, …, 1)`; here `k = m + 1`.
