# Bounded Subsequence Sums eq generalized HFold Sumset of zero not mem

For a sequence `𝒜 = (A, t̄)` with `A = {a₁, …, a_k}`, `0 ∉ A`, positive `t̄`,
`h = t₁ + ⋯ + t_k`, `1 ≤ α` and `α + β ≤ h - 1`,
`Σ^β_α(𝒜) = (h - β)^{(r̄)}A₀` with `A₀ = {0, a₁, …, a_k}` and `r̄ = (h - α - β, t₁, …, t_k)`.
