# Is MSTDSet int of card eq eight iff

Theorem 1 (quoting Hegarty), size 8: a set of eight integers is an MSTD set exactly when
it is an affine image `a S + b` (`a ≠ 0`) of `S = {0, 2, 3, 4, 7, 11, 12, 14}`.
