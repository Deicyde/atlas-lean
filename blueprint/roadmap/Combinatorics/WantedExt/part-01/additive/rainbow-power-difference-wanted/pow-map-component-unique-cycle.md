# Pow Map component unique cycle

Every component of the digraph `G^k_p` of `a ↦ a ^ k` on `ℤ/pℤ` contains exactly one
cycle: every vertex reaches a cycle vertex, and two cycle vertices in the same component lie
on one orbit.
