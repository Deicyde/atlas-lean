# Exists card color Class le div min Fac of rainbow Free pow Diff

For odd `n` with smallest prime factor `r₁`, an exact rainbow-free 3-coloring of `ℤ/nℤ`
for `x - y = z ^ k` has a color class of size at most `n / r₁`.
