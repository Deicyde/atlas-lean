# Lemma 15

**Lemma 15.** For integers `n ≥ 3`, `m ≥ 2`, `2 ≤ d ≤ n - 1` and `0 < x < n - 1` with `x`
irrational or `x = s + p/q` (`0 < p < q`, coprime, `q ≠ 2`), `I_n ∪ J(x, m, d)` is not an MSTD set.
