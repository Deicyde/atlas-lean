# Lemma 13

**Lemma 13.** For `n ≥ 3`, real `x ∉ ℕ` with `x > n - 1`, `d = s + p/q` with `0 < p < q` coprime
and `qd ≤ n - 1`, and `m ≥ q`, `I_n ∪ J(x, m, d)` is not an MSTD set.
