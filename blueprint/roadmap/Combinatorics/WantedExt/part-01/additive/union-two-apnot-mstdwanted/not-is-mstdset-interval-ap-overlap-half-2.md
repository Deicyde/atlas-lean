# Lemma 23

**Lemma 23.** For `n ≥ 3`, `m ≥ 2`, `x = s₁ + 1/2` with `x < n - 1`, `d > n - 1`, and `d = s₂ +
p₂/q₂` with `q₂` odd, `I_n ∪ J(x, m, d)` is not an MSTD set.
