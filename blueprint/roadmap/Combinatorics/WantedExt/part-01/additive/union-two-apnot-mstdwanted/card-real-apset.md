# Size of the progression $J(x, m, d)$

**Size of the progression $J(x, m, d)$.** For a real number $x$, a natural number $m$ and a
real number $d \ne 0$, the progression $J(x, m, d) = \{x + id : i = 0, 1, \dots, m\}$ has exactly
$m + 1$ elements.
