# Lemma 16

**Lemma 16.** For integers `n ≥ 3`, `m ≥ 2`, `2 ≤ d ≤ n - 1` and `x = s + 1/2` with `0 < x < n -
1`, `I_n ∪ J(x, m, d)` is not an MSTD set.
