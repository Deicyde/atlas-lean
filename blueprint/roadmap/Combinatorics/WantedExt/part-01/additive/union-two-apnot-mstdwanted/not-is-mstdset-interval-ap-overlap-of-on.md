# Lemma 21

**Lemma 21.** For `n ≥ 3`, `m ≥ 2`, `0 < x < n - 1`, `d > n - 1`, and reduced `x = s₁ + p₁/q₁`,
`d = s₂ + p₂/q₂` with `gcd(q₁, q₂) > 1`, `I_n ∪ J(x, m, d)` is not an MSTD set.
