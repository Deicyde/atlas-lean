# Exists is Sidon card gt cbrt mul log

Theorem 3, item 2 (Ajtai–Komlós–Szemerédi, as quoted): some Sidon set `A`
satisfies `|[1, n] ∩ A| > c (n log n)^{1/3}` for all `n ≥ 1`, for some `c > 0`.
