# Exists is Sidon card gt cbrt

Theorem 3, item 1 (Mian–Chowla, as quoted): some Sidon set `A` satisfies
`|[1, n] ∩ A| > c n^{1/3}` for all `n ≥ 1`, for some `c > 0`.
