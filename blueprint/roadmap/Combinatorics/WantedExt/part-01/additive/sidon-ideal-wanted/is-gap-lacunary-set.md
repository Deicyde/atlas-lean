# Is Gap Lacunary Set

An infinite set `A ⊆ ℕ` is *lacunary* if `A(n + 1) - A(n) → ∞` (gap lacunarity;
distinct from the multiplicative-growth `MetaMathlibExt.IsLacunarySet` of
`WantedExt.Combinatorics.AccessibleSetsWanted`).
