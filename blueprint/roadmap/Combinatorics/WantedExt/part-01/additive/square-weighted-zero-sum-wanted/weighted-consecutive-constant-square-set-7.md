# Weighted Consecutive Constant square Set odd Square large Prime

Corollary 35: if odd square `n ≥ 2` is divisible by `p⁴` for a prime
`p ≥ 7`, the consecutive defining set is nonempty and `C_{S(n)} = 5`.
