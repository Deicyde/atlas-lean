# Lunar Hoeffding Extremal Set ncard le

Lemma 24: for fixed `b ≥ 2` there is `C > 0` such that
`|ℋ_b^n(d)| ≤ C n² e^{-d²/(4(n+2))} bⁿ` for all `n ≥ 1` and `d > 0`.
