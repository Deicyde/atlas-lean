# Lunar Decomposable Set ncard le

Proposition 21: for fixed `b ≥ 2` there is `C > 0` such that for all `n ≥ 2` and
`d, v > 0`,
`|Σ_b^n| ≤ C b^{n+1} (n² e^{-d²/(4(n+2))} + n^{2d+4} 2^{d/2-(n+1)/3}
  + v n^{2d+2} 2^v b^{d/2-n/b} + n² 2^{-v})`.
