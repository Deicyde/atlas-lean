# Lunar Level Decomposable Set

`𝒟_b^n ⊆ Σ_b^n`: the `h` with a factorization `h = f ⊗ g` such that `f_a, g_a` are not
monomials, `a = ⌊b/2⌋`; then `ℐ_b^n = Σ_b^n \ 𝒟_b^n`.
