# Lunar Indecomposable Level diff ncard le

Lemma 28: for fixed `b ≥ 2` there is `C > 0` such that for all `n` and `d, v > 0`,
`|ℐ_b^n \ ℋ_b^n(d)| ≤ C (v n^{2d+2} 2^v b^{(b-1)n/b + d/2} + n² 2^{-v} b^{n+1})`, where
`ℐ_b^n = Σ_b^n \ 𝒟_b^n`.
