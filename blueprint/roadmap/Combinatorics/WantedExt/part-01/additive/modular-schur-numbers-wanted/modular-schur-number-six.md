# Modular Schur Number six

Values of `S_6(k, l)` for positive `k, l`: `0` if `l ≡ 1 (mod 6)`; otherwise
`1` if `k = 1, l ≠ 3` or `k ≥ 2, l ≡ 4`; `2` if `k = 1, l = 3` or `k ≥ 2, l ≡ 3, 5`;
`3` if `k = 2, l ≡ 0, 2, l ≥ 6`; `4` if `k = 2, l = 2`; `5` if `k ≥ 3, l ≡ 0, 2 (mod 6)`.
