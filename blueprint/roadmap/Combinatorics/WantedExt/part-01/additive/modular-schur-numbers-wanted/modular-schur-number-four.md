# Modular Schur Number four

Values of `S_4(k, l)` for positive `k, l`: `0` if `l ≡ 1 (mod 4)`; otherwise `1` if
`k = 1`, or `k ≥ 2` and `l ≡ 3 (mod 4)`; and `3` if `k ≥ 2` and `l ≡ 0, 2 (mod 4)`.
