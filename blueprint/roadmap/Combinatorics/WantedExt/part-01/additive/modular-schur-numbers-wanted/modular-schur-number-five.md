# Modular Schur Number five

Values of `S_5(k, l)` for positive `k, l`: `0` if `l ≡ 1 (mod 5)`; otherwise `1` if
`k = 1`; `k` if `k ∈ {2, 3}` and `l ≠ 2`; `4` if `k ∈ {2, 3}` and `l = 2`, or `k ≥ 4`.
