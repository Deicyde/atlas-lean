# Nathanson restricted Sumset inverse

Nathanson: if `A ⊆ ℤ`, `|A| = k ≥ 5`, `2 ≤ h ≤ k - 2` and `|h^A| = hk - h² + 1`, then `A` is
an arithmetic progression.
