# Vosper nsmul

Vosper's theorem for `h`-fold sumsets: if `A ⊆ ℤ_p`, `|A| = k ≥ 2`, `h ≥ 2` and
`|hA| = hk - h + 1 ≤ p - 2`, then `A` is an arithmetic progression.
