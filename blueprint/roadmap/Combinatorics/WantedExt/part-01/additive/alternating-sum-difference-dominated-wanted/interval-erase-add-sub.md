# Interval erase add sub

Lemma 1 (quoted from Nathanson): for `m ≥ 4` and `2 ≤ r ≤ m - 3`, the set
`B = [0, m - 1] ∖ {r}` has `B + B = [0, 2m - 2]` and `B - B = [-(m - 1), m - 1]`.
