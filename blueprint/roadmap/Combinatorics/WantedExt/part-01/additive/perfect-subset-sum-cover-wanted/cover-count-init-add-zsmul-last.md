# Cover Count init add zsmul last

In the setting of Lemma 8, if `S₁` covers `b` exactly `c` times, then for every integer
`t` it covers `b + 2t x_{k+1}` exactly `c` times and `b + (2t + 1) x_{k+1}` exactly
`2^j - c` times.
