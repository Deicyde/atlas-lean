# Zmod two pi good threshold is Big O

Zero sums with small cross number in `ℤ₂ᵈ`: with `n = 2^d`, every threshold function `t` for
the event that a uniformly random sequence in `ℤ₂ᵈ` is good satisfies, for every `ε > 0`,
`t ∈ O(n / (lg lg n)^{1-ε})`.
