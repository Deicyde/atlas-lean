# Affine Iterate Has Repetition

Erdős Problem 481: if `a, b : Fin r → ℕ` with every `a i ≥ 1` and `∑ 1 / a i > 1`, then
starting from `A₁ = (1)` some iterate `A_k = T^[k - 1] (1)` has a repeated entry.
