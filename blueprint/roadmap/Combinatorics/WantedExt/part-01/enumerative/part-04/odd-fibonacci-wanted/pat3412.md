# The permutation pattern $3412$

**The permutation pattern $3412$.** The pattern $3412$ with its values shifted down by
one: the map $\{0, 1, 2, 3\} \to \{0, 1, 2, 3\}$ sending $0, 1, 2, 3$ to $2, 3, 0, 1$
respectively.
