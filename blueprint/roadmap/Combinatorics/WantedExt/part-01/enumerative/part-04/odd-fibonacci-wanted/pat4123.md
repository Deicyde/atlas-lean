# The permutation pattern $4123$

**The permutation pattern $4123$.** The pattern $4123$ with its values shifted down by
one: the map $\{0, 1, 2, 3\} \to \{0, 1, 2, 3\}$ sending $0, 1, 2, 3$ to $3, 0, 1, 2$
respectively.
