# Sum pow mul choose mul second Order

For any real sequence `W` with `W_{n+2} = a W_{n+1} + b W_n`,
`∑_{k=0}^N k^r binom(N, k) a^k b^{N-k} W_k = ∑_{i=0}^r {r, i} (N)_i a^i W_{2N-i}`.
