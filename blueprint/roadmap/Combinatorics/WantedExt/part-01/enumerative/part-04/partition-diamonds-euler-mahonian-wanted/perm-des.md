# Number of descents

**Number of descents.** For a permutation $\tau$ of $\{0, 1, \dots, d - 1\}$, the number of
descents $\mathrm{des}(\tau) = |\mathrm{Des}(\tau)|$ is the number of elements of the descent
set $\mathrm{Des}(\tau)$.
