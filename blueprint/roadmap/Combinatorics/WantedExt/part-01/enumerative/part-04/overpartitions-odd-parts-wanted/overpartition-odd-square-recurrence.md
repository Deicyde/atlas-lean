# Overpartition Odd square recurrence

Square recurrence for overpartitions into odd parts: for `n ≥ 0`,
`po(n) + 2 ∑_{k ≥ 1} (-1)^k po(n - 2k²)` equals `2` if `n = m²` with `m ≥ 1`, `1` if
`n = 0`, and `0` otherwise.
