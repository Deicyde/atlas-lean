# Distincts pentagonal recurrence

Recurrence for partitions into distinct parts: for `n ≥ 0`,
`∑_{k ∈ ℤ} (-1)^k pd(n - k(3k+1))` equals `1` if `n = m(m+1)/2` for some `m ≥ 0` and `0`
otherwise.
