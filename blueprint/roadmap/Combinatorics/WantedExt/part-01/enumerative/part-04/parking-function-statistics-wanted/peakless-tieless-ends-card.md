# Peakless tieless ends card

With `G_m`, `E_m`, `L_m` the peakless-tieless parking functions of length `m` with
`a_1 > a_m`, `a_1 = a_m`, `a_1 < a_m` (so `G_1 = L_1 = ∅`, `E_1 = {(1)}`):
`|E_{n+1}| = |L_n|` for `n ≥ 1` and `|G_{n+1}| = |L_{n+1}|` for `n ≥ 0`.
