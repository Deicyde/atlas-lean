# Valleyless tieless prepend one bij On

The map `(a_1, …, a_n) ↦ (1, a_1 + 1, …, a_n + 1)` is a bijection from `VTPF_n` onto
the valleyless-tieless parking functions of length `n + 1` with `a_1 = 1` and
`a_{n+1} > 1`.
