# Parking Function descent Set card eq ascent Set reflect

`d(I;n) = a(J;n)` for `I ⊆ [n-1]` and `J = {n - i : i ∈ I}`, where `d` and `a` count
parking functions with descent set, respectively ascent set, exactly the given set.
