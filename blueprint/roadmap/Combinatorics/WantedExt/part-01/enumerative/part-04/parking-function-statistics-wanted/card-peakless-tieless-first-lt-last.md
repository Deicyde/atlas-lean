# Card peakless tieless first lt last

For `n ≥ 0`, the number of peakless-tieless parking functions of length `n + 1` with
`a_1 < a_{n+1}` is the Fine number `F_{n+1}` (OEIS A000957), `fineNumber (n + 1)`.
