# Restricted Combination Total Icc erase eq card compositions

Theorem 19: if `Q = {1, …, q} \ {p}` with `p < q < 2p`, then `S^Q_n` is the number of
compositions of `n + q` into parts `1` and `q + 1 + jp`, `j = 0, 1, 2, …`.
