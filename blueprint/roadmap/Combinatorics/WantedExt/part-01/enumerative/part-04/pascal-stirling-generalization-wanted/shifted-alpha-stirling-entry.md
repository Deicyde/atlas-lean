# Shifted Alpha Stirling Entry

Entries of the paper's shifted matrix `𝖲_α(n)` (0-based): first row and first column `α_1`,
and `𝖲_{i,j} = 𝖲_{i,j-1} + α_j 𝖲_{i-1,j}` for `i, j ≥ 2` (1-based).
