# Alpha Stirling Entry

Entries of the paper's matrix `S_α(n)` (0-based): first column `α_1`, rest of the first row
`0`, and `Ŝ_{i,j} = Ŝ_{i-1,j-1} + α_j Ŝ_{i-1,j}` for `i, j ≥ 2` (1-based).
