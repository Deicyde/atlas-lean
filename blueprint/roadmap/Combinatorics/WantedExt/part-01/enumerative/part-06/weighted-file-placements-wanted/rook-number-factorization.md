# Rook Number factorization

Goldman, Joichi and White: for a Ferrers board `B = (b_1, …, b_n)`,
`Σ_k r_k(B) x↓_{n-k} = ∏_i (x + b_i - (i - 1))`; here `r_k = r_{k,1}` and `x↓_k = x↓_{k,1}`, with
`0`-indexed columns.
