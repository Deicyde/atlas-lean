# Weighted File Number factorization

Barrese, Loehr, Remmel and Sagan: for any Ferrers board and `m ≥ 1`,
`Σ_k f_{k,m}(B) x↓_{n-k,m} = ∏_i (x + b_i - (i - 1)m)` (`0`-indexed columns).
