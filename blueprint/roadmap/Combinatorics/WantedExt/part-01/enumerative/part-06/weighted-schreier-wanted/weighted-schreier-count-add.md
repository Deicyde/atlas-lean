# Weighted Schreier Count add

Second case of Theorem 1.2: for `k ≥ 2` and `ℓ ≥ 0`,
`a_{k,k+ℓ} = 2 ∑_{i=0}^{k-2} C(ℓ,i) F_{k-i} + 2 C(ℓ,k-1) + ∑_{j=1}^{ℓ} C(j, ℓ-j+k)`.
