# Bool Fun Class Count var Perm unate le

Proposition 12: with `[·]` counting classes under permutation of
variables, `nd-[U]_n ≤ 2^n nd-[M]_n`, `nd-[BU]_n ≤ 2^n nd-[BM]_n`,
`[U]_n ≤ 2^n [M]_n` and `[BU]_n ≤ 2^n [BM]_n`.
