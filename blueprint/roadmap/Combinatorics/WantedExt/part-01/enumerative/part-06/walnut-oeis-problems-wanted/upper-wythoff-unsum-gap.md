# Upper Wythoff Unsum Gap

The `i`-th gap between consecutive unsums (counted from zero), `a(i + 2) - a(i + 1)` for the
unsums `a(1) < a(2) < ⋯` of OEIS A260317; this is OEIS A260311 shifted by one.
