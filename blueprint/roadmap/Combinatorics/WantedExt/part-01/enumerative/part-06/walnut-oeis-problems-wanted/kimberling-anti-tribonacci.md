# Kimberling anti Tribonacci

Kimberling's conjecture: for every `n ≥ 1`, `0 ≤ 10n - 6 - 3A_n ≤ 2`,
`0 ≤ 10n - 2 - 3B_n ≤ 3`, `0 ≤ 10n + 1 - 3C_n ≤ 3`, and `0 ≤ 10n - 3 - D_n ≤ 2`.
