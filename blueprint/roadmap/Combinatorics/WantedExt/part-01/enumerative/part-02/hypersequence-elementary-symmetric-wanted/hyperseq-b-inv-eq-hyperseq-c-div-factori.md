# Hyperseq B inv eq hyperseq C div factorial

Corollary 1: `B(n)⁻¹ = C(n) D⁻¹`, i.e. the lower triangular matrix with entries
`c_{ℓ,m}(n) / m!` is a two-sided inverse of `B(n)`.
