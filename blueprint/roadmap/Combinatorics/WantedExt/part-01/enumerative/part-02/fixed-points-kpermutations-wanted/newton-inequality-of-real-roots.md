# Newton inequality of real roots

Newton's inequalities (Theorem 1): if `p = ∑_{j=0}^{n} a_j x^j`, `n ≥ 2`, of degree `n` has
only real zeros, then `a_j² ≥ ((j + 1) / j) ((n - j + 1) / (n - j)) a_{j-1} a_{j+1}` for
`1 ≤ j ≤ n - 1`.
