# Sum k Perm Fixed Point Count

Proposition 3 (iv): `∑_{j=0}^{k} a(n, k, j) = c(n, k)`, the unsigned Stirling number of the
first kind.

The paper assumes `n ≥ k ≥ 1`; the identity is stated for all `n` and `k`.
