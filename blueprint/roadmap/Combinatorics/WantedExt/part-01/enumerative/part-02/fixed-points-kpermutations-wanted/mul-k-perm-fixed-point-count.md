# Mul k Perm Fixed Point Count

Proposition 3 (iii): `j a(n, k, j) = n a(n - 1, k - 1, j - 1)` for `1 ≤ j ≤ k`.

The paper assumes `n ≥ k ≥ 1`; the identity is stated for all `n`.
