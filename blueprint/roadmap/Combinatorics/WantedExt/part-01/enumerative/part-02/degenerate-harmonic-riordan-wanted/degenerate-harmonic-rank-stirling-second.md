# Degenerate Harmonic Rank stirling Second sum

Theorem 9: for `1 ≤ m ≤ n`,
`∑_{k=m}^n (-1)ᵏ S_{2,λ}(k, m) H_λ(n, k - 1, α) / k! = (-1)ᵐ / (m! αᵐ)`.
