# Degenerate Harmonic Rank shifted exp weighted sum

Theorem 5: for `n ≥ 0`,
`∑_{k=0}^n (-1)ᵏ (1)_{k+1,λ} / (k + 1)! · H_λ(n + 1, k, α) = 1 / α`.
