# Degenerate Daehee

Degenerate Daehee numbers `D_{n,λ} = n! binom(λ, n + 1) / λ`: by Equation (2),
`log_λ(1 + t) / t = ∑ binom(λ, n + 1) tⁿ / λ`, so this is the paper's definition (9) at `x = 0`.
