# Zurita MCoeff

The coefficients `m_k` of `M_{n-1}(x) = ∑_{k=0}^{n-1} m_k x^k`: `m_0 = 2/(2n - 1)` and
`m_k = 2(k - n)/(2k - 2n + 1) · m_{k-1}` for `1 ≤ k ≤ n - 1`.
