# First five generalized Motzkin numbers at $a = b = 1$

**First five generalized Motzkin numbers at $a = b = 1$.** The generalized Motzkin numbers
$M_n$ for $a = b = 1$, the constant terms of $(x^{-1} + 1 + x)^n (1 - x^2)$, are $1, 1, 2, 4, 9$
for $n = 0, 1, 2, 3, 4$.
