# Delannoy Array rows parity

In a Delannoy array `R` (`R(m+1, n+1) = R(m, n+1) + R(m+1, n) + R(m, n)`), rows `m` and `m + 1`
agree mod 2 everywhere if they agree at column `0`, and disagree everywhere otherwise.
