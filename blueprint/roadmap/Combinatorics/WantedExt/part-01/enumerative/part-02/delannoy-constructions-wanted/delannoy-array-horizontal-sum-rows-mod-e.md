# Delannoy Array horizontal Sum rows mod Eq

For a Delannoy array `R` and `i ≥ 1`, all rows of `R^i` (the `i`-fold horizontal sum
`S ↦ S(m, n) + S(m, n + 1)`) agree mod 2.
