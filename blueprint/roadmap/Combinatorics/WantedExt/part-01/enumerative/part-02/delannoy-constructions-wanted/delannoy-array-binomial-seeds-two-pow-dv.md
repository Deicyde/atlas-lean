# Delannoy Array binomial seeds two pow dvd

If a Delannoy array has horizontal seeds `R(0, n) = C(k + n, k)`, then for `i ≥ 1` every entry
of `R^(k+i)` is divisible by `2^i`, and some entry is not divisible by `2^(i+1)`.
