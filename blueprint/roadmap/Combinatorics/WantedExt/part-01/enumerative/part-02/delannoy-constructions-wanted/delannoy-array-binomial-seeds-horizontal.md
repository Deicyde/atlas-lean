# Delannoy Array binomial seeds horizontal Sum mod Eq

If a Delannoy array has horizontal seeds `R(0, n) = C(k + n, k)` with `k ≥ 1`, every row of
`R^1` is `C(k + n, k - 1)` mod 2.
