# Hyper Lucas recurrence

Theorem 6: `L^{(r)}_0 = 2`, `L^{(r)}_1 = 2r + 1`, and for `r ≥ 1`,
`L^{(r)}_{n+2} = L^{(r)}_{n+1} + L^{(r)}_n + (n + 2r)/(n + 2) · C(n + r, r - 1)` (written for
`r + 1`, in `ℚ`).
