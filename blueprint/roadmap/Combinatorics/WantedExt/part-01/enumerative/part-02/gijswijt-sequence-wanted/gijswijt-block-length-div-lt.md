# Gijswijt Block Length div lt

With `M_7 = 4` and `M_{k+1} = M_k (1 + 9 (k+1)^{1.59} / 2^k)` for `k ≥ 7`,
`β^{(m)}(u) / (m+1)^{u-1} < M_u` for all `m ≥ 1` and `u ≥ 7`.
