# Gijswijt Block Length estimates

For `m ≥ 1` and `u ≥ 2`,
`τ^{(m)}(m (m+1)^{u-2}) ≤ β^{(m+1)}(u) ≤ τ^{(m)}((m+1)^{u-1} + 1)`, and the second inequality
is strict when `u = m + 3`.
