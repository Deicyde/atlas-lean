# Curling Number block Word le

For `m ≥ 1`, `u ≥ 2`, and `a_1, …, a_{u-1} ∈ {0, …, m}` with `a_1 ≠ 0`, the prefix
`P = B_{u-1}^{a_{u-1}} ⋯ B_1^{a_1}` of `B_u^{(m+1)}` has `𝒞(P) ≤ m`.
