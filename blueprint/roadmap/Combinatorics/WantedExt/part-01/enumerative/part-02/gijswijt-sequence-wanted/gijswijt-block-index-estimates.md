# Gijswijt Block Index estimates

For `m ≥ 1` and `n ≥ m + 3`,
`m (m+1)^{t(m+1,n) - 2} ≤ t(m, n) ≤ (m+1)^{t(m+1,n) - 1} + 1`, and the second inequality is
strict when `n = m + 3`.
