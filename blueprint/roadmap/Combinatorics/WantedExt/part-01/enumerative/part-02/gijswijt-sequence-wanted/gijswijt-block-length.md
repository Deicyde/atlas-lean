# Gijswijt Block Length

The block lengths `β^{(m)}(t)`: `β(1) = 1`, and `β(t+1)` is the least `k > (m+1) β(t)` with
`A^{(m)}(k+1) = m`, so that `B_{t+1} = (B_t)^{m+1} S_t` with `S_t` the run before the next `m`.
