# Card trace Zero conj Classes

Corollary 31: the number of conjugacy classes (Galois orbits) of elements of `K` with
trace `0` equals the number `|F^n_0 / C_n|` of zero-sum `n`-necklaces over `F`,
`n = [K : F]`.
