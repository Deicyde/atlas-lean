# Sum div mul eq sum totient mul

Lemma 9: if `g(k) = ∑_{d ∣ k} f(d)` for all `k ≥ 1`, then
`∑_{d ∣ k} (k/d) f(d) = ∑_{d ∣ k} φ(k/d) g(d)` for all `k ≥ 1`.
