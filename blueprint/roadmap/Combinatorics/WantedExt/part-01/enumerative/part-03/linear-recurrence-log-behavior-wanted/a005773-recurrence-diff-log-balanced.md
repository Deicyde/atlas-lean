# A005773 Recurrence diff log Balanced

The sequences `(ΔA n)_{n ≥ 3}` and `(Δ²A n)_{n ≥ 3}` are log-balanced: for every `n ≥ 4`,
both satisfy `z n ^ 2 ≤ z (n - 1) z (n + 1)` and
`(z (n - 1) / (n - 1)!) (z (n + 1) / (n + 1)!) ≤ (z n / n!) ^ 2`.
