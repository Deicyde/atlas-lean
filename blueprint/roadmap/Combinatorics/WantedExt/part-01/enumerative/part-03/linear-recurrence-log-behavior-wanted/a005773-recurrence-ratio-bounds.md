# A005773 Recurrence ratio bounds

With `x n = A (n + 1) / A n` and `φ n = 3 (2n + 1) / (2 (n + 1))`, for every `n ≥ 0`:
`x n ≤ φ n` (2) and `x (n + 1) / x n ≥ 2 (3n² + 6n + 2) / ((n + 2)(2n + 1) φ n)` (3).
