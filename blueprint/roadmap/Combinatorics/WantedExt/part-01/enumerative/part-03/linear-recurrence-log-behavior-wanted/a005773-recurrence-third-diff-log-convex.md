# A005773 Recurrence third Diff log Convex log Balanced

`(Δ³A n)_{n ≥ 2}` is log-convex (`z n ^ 2 ≤ z (n - 1) z (n + 1)` for `n ≥ 3`) and
`(Δ³A n)_{n ≥ 3}` is log-balanced (additionally
`(z (n - 1) / (n - 1)!) (z (n + 1) / (n + 1)!) ≤ (z n / n!) ^ 2` for `n ≥ 4`).
