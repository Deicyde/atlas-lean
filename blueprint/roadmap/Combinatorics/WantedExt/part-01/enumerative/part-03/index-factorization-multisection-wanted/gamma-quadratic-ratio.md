# Gamma Quadratic Ratio

The function `g(a, b, z) = b/(b - z) · Γ(a - √(a² - b)) Γ(a + √(a² - b)) /
(Γ(a - √(a² - b + z)) Γ(a + √(a² - b + z)))`, with the principal complex square root (the value
does not depend on the choice of root).
