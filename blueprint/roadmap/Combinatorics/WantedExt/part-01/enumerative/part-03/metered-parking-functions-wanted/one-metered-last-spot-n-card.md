# One metered last spot n card

For `1 ≤ m ≤ n`, `mpf_{m-1,n}(1)` counts the `1`-metered `(m, n)`-parking functions whose last
car parks in spot `n` (zero-based `n - 1`). The source leaves `1 ≤ m` implicit (a last car).
