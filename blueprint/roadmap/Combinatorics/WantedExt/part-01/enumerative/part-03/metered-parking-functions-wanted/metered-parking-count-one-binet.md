# Metered Parking Count one binet

For `m ≤ n + 1` and `n > 2`, the Binet form
`mpf_{m,n}(1) = (n(n+√(n²-4)) - 2)/(n(n+√(n²-4)) - 4) · ((n+√(n²-4))/2)^m
  + (n(n-√(n²-4)) - 2)/(n(n-√(n²-4)) - 4) · ((n-√(n²-4))/2)^m`.
