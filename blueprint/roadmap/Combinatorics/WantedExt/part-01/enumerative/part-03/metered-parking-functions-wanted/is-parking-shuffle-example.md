# Is Parking Shuffle example

Characteristic example: `(3, 7, 2, 1, 7, 2)` (one-based) is a `(7, 8)`-parking function shuffle
with `k = 6`, a shuffle of `(3, 2, 1, 2) ∈ PF_{4,5}` and `(7, 7) = (1, 1) + (6, 6)`.
