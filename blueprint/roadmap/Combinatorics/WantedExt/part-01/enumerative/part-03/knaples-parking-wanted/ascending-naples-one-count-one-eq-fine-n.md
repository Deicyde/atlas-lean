# Ascending Naples One Count one eq fine Number

Theorem 4: `U_{n,1} = F_{n+1}`, the `(n + 1)`-th Fine number (OEIS A000957, with
`F_0 = 1`, `F_1 = 0`; `fineNumber` uses this indexing).
