# Naples Park Int example three

Characteristic example (Remark 2): under the `3`-Naples rule on `ℤ` the cars of
`(1, 2, 2, 5, 7, 7, 7, 3)` park in spots `1, 2, 0, 5, 7, 6, 4, 3`.
