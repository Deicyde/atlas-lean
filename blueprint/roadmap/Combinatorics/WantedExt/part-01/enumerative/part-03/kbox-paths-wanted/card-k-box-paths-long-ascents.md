# Card k Box Paths long Ascents

The number of `k`-box paths of size `n` with exactly `j ≥ 1` long ascents is
`1/j · binom((k+1)n-2, j-1) · binom(n-1, j-1)`; denominator cleared. (For
`j > n` both sides vanish.)
