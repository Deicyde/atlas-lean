# K Box Paths

`B_n^{(k)}`: the `k`-box paths of size `n`, i.e. skew Dyck paths of semilength
`(k+2)n - 1` with exactly `n` factors `U D^k L`. (For `n = 0` the truncated
semilength is `0` and the set is `{ε}`; the statements below take `n ≥ 1`.)
