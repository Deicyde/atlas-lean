# K Box Paths returns mean variance

Among `k`-box paths of size `n`, the mean number of returns is
`(k+2)((k+2)n-1) / ((k+1)((k+1)n+1))` and the variance is
`(k+2)((k+2)n-1)((2k+1)(k+1)n-2)(n-1) / ((k+1)²((k+1)n+1)²((k+1)n+2))`.
