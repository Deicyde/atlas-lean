# Mean bubble size

Mean bubble size over all bubbles on linear chord diagrams with `2n` vertices: for `n ≥ 2`,
`(∑_p p B_{n,p}) / (∑_p B_{n,p}) = 2(2n-1)(n-1) / (4n-5)`.
The hypothesis `n ≥ 2` is added: for `n = 1` there are no bubbles.
