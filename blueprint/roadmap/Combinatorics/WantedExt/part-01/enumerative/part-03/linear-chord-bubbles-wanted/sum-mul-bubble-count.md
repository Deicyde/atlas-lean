# Sum mul bubble Count

Un-normalized first moment of bubble size: for `n ≥ 2`,
`∑_{p=1}^{2n} p B_{n,p} = (2n-1)! / (2^{n-2} (n-2)!)`.
The hypothesis `n ≥ 2` is added (the right side involves `(n-2)!`).
