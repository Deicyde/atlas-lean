# Tribonacci numbers with initial values $1, 0, 1$

**Tribonacci numbers with initial values $1, 0, 1$.** The sequence
$t : \mathbb{N} \to \mathbb{Z}$ with $t(0) = 1$, $t(1) = 0$, $t(2) = 1$ and
$t(n) = t(n-1) + t(n-2) + t(n-3)$ for $n \ge 3$.
