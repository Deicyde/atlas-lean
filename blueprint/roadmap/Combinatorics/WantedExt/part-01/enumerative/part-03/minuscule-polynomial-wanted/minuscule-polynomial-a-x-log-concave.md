# Minuscule Polynomial A x log Concave

`x`-log-concavity: every coefficient of `N_n(x)^2 - N_{n+1}(x) N_{n-1}(x)` is
non-negative. Stated for every `n : ℕ`; for `n ≤ 1` the polynomial is `0` since
`N_0 = N_1 = 0`.
