# Minuscule Polynomial A

The type-A minuscule polynomial
`N_n(x) = (1 / (4n + 2)) ∑_{k=1}^{n-1} k (n - k) binom(2n + 2, 2k + 1) x^k`.
For `n = 0` the sum is empty, so `N_0 = 0`.
