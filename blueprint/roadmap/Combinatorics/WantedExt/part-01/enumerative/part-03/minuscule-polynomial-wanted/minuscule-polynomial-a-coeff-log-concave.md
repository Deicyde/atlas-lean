# Minuscule Polynomial A coeff log Concave

The coefficients of `N_n(x)` are log-concave: `N_{n,k-1} N_{n,k+1} ≤ N_{n,k}^2`. Stated for
all `n, k : ℕ`; the cases outside `n ≥ 1`, `1 ≤ k ≤ n - 1` hold because the extra coefficients
vanish.
