# Fib add sq eq

Corollary 3.12: for `n ≥ 2` and `m ≥ 1`,
`F²_{m+n} = F²_{m+1} F²_n + F²_m F²_{n-1} + 2 ∑_{i=1}^{m} F²_i ∑_{j=1}^{n-1} F²_j`.
