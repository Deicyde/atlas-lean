# R Minus Associated Perm EGF q eq pow

Corollary 16: for `r ≥ 2`, `A^{r-}(q,x,u) = (A^{r-}(x,u))^q`, with the power read
as `exp(q ln A^{r-}(x,u))`: for every `L` with `L(0) = 0` and `exp L = A^{r-}(x,u)`,
`A^{r-}(q,x,u) = exp(q L)`.
