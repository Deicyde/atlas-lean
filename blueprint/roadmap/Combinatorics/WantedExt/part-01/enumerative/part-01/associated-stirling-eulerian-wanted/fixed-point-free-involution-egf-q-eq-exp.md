# Fixed Point Free Involution EGF q eq exp

Corollary 41: over fixed-point-free involutions (all cycle lengths equal to `2`),
the `q`-analogue excedance generating function is `A^{(2)}(q,x,u) = exp(q x u^2/2)`.
