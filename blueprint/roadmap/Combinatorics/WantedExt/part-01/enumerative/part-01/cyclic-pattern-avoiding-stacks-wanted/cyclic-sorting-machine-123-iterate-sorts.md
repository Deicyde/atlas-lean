# Cyclic Sorting Machine 123 iterate sorts

For every permutation `π` of `[n]`, `n ≥ 3`, `SC_[123]^{n-2}(π) = id_n`, and the bound is
tight: `SC_[123]^{n-3}(ξ_n) ≠ id_n`.
