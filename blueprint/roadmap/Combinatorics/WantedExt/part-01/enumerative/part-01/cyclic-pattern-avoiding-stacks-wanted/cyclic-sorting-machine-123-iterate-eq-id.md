# Cyclic Sorting Machine 123 iterate eq id iff reduction Seq

For every permutation `π` of `[n]` and every `k`, `SC_[123]^k(π) = id_n` if and only if
`SC_[123]^k(red(π)) = id_{|red(π)|}`.
