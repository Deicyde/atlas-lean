# Cyclic Sorting Machine 321 superimpose

For `n ≥ 4` and `1 ≤ m < ⌈(2n-1)/3⌉ = (2n+1)/3`,
`SC_[321](si((1,…,m), (m+1,…,n))) = si((1,…,m+1), (m+2,…,n))`.
