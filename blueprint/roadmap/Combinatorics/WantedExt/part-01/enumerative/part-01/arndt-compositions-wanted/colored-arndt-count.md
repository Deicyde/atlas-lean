# Colored Arndt Count

The number `c(n, k)` of colored (`n`-color) Arndt compositions of `n` with `k` parts: Arndt
compositions of `n` with `k` parts in which a part of size `m` takes one of `m` colors, so each
Arndt composition `c` contributes `∏ c i`.
