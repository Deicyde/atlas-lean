# Colored Arndt GF mul

`C(x, y) = (1 - x)²(1 + x)³(1 + x² + x(y - 2)) /
(1 - x - 3x² - x³(2y² - 3) - x⁴(y² - 3) - x⁵(3 + y²) - x⁶ + x⁷)`, stated multiplicatively.
