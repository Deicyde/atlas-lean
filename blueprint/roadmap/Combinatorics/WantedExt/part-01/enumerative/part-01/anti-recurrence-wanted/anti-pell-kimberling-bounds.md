# Theorem 1

**Theorem 1.** The anti-Pell numbers (`a = (1, 2)`) satisfy Kimberling's bounds (1): for
`n ≥ 1`, `0 ≤ A_n - 7n + 3 ≤ 2`, `0 ≤ 3B¹_n - 7n + 6 ≤ 3` and `0 ≤ 3B²_n - 7n + 2 ≤ 3`.
