# Choose mul colored Dyck Path Count eq

Dyck paths and polygon partitions:
`binom(n+k, k) d_{n,k}(γ) = binom(n+1, k) p_{n,k}(γ)` for `1 ≤ k ≤ n` and every
coloring sequence.
