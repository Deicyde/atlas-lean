# Is Carlitz Type With

`(T_n(x))_n` is a Carlitz-type `q`-polynomial sequence with associated real sequence `(a_k)`:
`T_n(x) = (q - 1)^{-n} ∑_{k=0}^{n} (-1)^{n-k} C(n,k) a_k q^{kx}` for all `n` and real `x`.
