# Phi Five Core Analog congruences

Corollary 3: `ā_5(20n+6) ≡ ā_5(20n+14) ≡ 0 (mod 10)` and, for `k ≥ 2`,
`4 ā_5(5^k n) ≡ 5 ā_5(n) - ā_5(5n) (mod 5^k)`.
