# Generalized Cubic Partition Count prime three seven mod eight

For a prime `p ≥ 7` with `p ≡ 3, 7 (mod 8)`,
`a_{p-6}(pn + 13(p² - 1)/24) ≡ 0 (mod p)` for all `n ≥ 0` (`24 ∣ p² - 1`, so the shift is
an exact natural-number quotient).
