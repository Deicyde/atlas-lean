# Overcubic Triple Count congruences eight mod sixteen args

For all `n, α ≥ 0`: `bt(64n+40) ≡ 0 (mod 8)`, `bt(576n+264) ≡ bt(576n+456) ≡ 0 (mod 8)`,
and `bt(64·9^{α+2} n + 264·9^{α+1}) ≡ 0 (mod 8)`.
