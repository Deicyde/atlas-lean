# Psi Five Core Analog congruences

Corollary 8: for `k ≥ 2`, `4 b̄_5(5^k(n+3) - 3) ≡ 5 b̄_5(n) - b̄_5(5n+12) (mod 5^k)`,
and `b̄_5(5^k(20n+18) - 3) ≡ b̄_5(5^k(20n+22) - 3) ≡ 0 (mod (5^k - 1)/4)`.
