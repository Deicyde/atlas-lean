# Card diagonal Class eq prod choose

Theorem 1 (main theorem): with `q`, `L`, `b_i` as in Proposition 8, the number of partitions
with diagonal sequence `d = δ(α)` is `|[d]| = ∏_{i=q}^{L-1} C(b_i + b_{i+1} + 1, b_i + 1)`.
