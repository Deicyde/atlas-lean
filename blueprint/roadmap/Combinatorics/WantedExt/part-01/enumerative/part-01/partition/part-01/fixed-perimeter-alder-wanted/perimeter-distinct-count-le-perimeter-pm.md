# Perimeter Distinct Count le perimeter PMResidue Count

Theorem 1.5 (reverse Alder-type inequality): for positive `d, n, a` with `a < (d + 3)/2`,
`h_d^(a)(n) ≤ ℓ_d^(a)(n)`.
