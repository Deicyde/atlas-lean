# Max Rook Partition Count three formula

Exact formula for `R_3(n)`, `n = 3m + a > 9`, `0 ≤ a ≤ 2`:
`6m² - 15m + 7`, `6m² - 11m + 2`, `6m² - 7m - 1` for `a = 0, 1, 2`.
