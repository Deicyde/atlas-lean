# Psi Five Core Analog five pow mul

Theorem 4, second identity: for `k ≥ 2`,
`b̄_5(5^k(n+3) - 3) = ((5^k - 1)/4) b̄_5(5n+12) - ((5^k - 5)/4) b̄_5(n)` (exact divisions).
