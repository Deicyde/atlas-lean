# Regular Cubic Overlined Count three mod eighteen twelve

For all `n ≥ 0`: `a_3(8n + 5) ≡ 0 (mod 18)`, `a_3(16n + 11) ≡ 0 (mod 12)` and
`a_3(16n + 15) ≡ 0 (mod 12)`.
