# Amdeberhan–Sellers–Singh congruences

**Amdeberhan–Sellers–Singh congruences**: for all `n ≥ 0`,
`a_3(7n + 4) ≡ 0 (mod 7)` and `a_5(11n + 10) ≡ 0 (mod 11)`.
