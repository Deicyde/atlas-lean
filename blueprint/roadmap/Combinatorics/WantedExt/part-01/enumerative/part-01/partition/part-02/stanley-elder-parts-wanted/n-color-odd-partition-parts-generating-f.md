# N Color odd Partition Parts generating Function

Theorem 9: with `Q(O, m)` the total number of parts over the `n`-color partitions of `m` into
odd parts,
`∑_{m ≥ 1} (2m-1) q^{2m-1} / (1 - q^{2m-1}) = ∏_{m ≥ 1} (1 - q^{2m-1})^{2m-1} ∑_{m ≥ 1} Q(O, m) q^m`.
