# Card diagonal Class Of min two

Corollary 6, part 5: replacing every `s_i` by `σ_i = min {s_i, 2}` does not change the
class size: `|[d]| = |[d']|` for `d = (1, …, q, q^{(s_q)}, …, 1^{(s_1)})` and
`d' = (1, …, q, q^{(σ_q)}, …, 1^{(σ_1)})`, `q ≥ 1`.
