# Overcubic Triple Count congruences sixteen mul args

For all `n, α ≥ 0`: `bt(64n+48) ≡ 0`, `bt(128n+80) ≡ 0`, `bt(128n+96) ≡ 0`,
`bt(256n+160) ≡ 0`, `bt(256n+32) ≡ bt(128n+16)`, and `bt(256·2^α n + 192) ≡ 0`, all modulo `4`.
