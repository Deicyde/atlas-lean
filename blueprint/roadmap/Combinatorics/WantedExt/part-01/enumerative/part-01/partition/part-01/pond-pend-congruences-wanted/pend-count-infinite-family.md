# Pend Count infinite family

For all `α ≥ 1` and `n ≥ 0`, `pend(3^{2α+1} n + (17 · 3^{2α} - 1) / 8) ≡ 0 (mod 3)`;
the division is exact since `3^{2α} ≡ 1 (mod 8)`.
