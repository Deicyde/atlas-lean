# Overcubic Triple Count congruences four mul args

For all `n, α ≥ 0`: `bt(32n+28) ≡ bt(32n+20) ≡ 0 (mod 16)`, `bt(64n+56) ≡ 0 (mod 8)`,
`bt(576n+408) ≡ 0 (mod 8)`, `bt(5184n+216) ≡ bt(5184n+3672) ≡ 0 (mod 8)`, and
`bt(64·81^{α+2} n + 216·81^{α+1}) ≡ 0 (mod 8)`.
