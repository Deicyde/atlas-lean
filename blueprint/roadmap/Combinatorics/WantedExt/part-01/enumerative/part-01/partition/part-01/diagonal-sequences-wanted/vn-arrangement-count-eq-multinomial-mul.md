# Vn Arrangement Count eq multinomial mul prod

Proposition 7: for `0 ≤ k ≤ t` the multiset `M = {0^{(b_0)}, …, t^{(b_t)}}` has
`multinomial(b_0, …, b_k) · ∏_{i=1}^{t-k} C(b_i + ⋯ + b_{i+k}, b_{i+k})` k-vn-arrangements.
