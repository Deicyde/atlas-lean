# Regular Cubic Overlined Count five mod sixteen eight

For all `n ≥ 0`: `a_5(8n + 7) ≡ 0 (mod 16)` and `a_5(20n + 2j + 1) ≡ 0 (mod 8)` for
`j = 1, …, 9`.
