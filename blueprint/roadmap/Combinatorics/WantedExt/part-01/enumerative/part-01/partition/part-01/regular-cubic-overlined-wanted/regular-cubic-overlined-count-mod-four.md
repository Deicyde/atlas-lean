# Regular Cubic Overlined Count mod four

For all `k, n ≥ 0`: (i) `a_{2k}(4n + 3) ≡ 0 (mod 4)` for `k > 1`;
(ii) `a_{2k+1}(4n + 2) ≡ 0 (mod 4)` for `k ≥ 1`; (iii) `a_{4k}(4n + 2) ≡ 0 (mod 4)` for
`k > 0`; (iv) `a_{4k+1}(4n + 3) ≡ 0 (mod 4)` for `k > 0`.
