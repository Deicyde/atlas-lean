# N Color odd Parts generating Function

Theorem 5: with `A_o(m)` the total number of odd parts over the `n`-color partitions of `m`,
`∑_{m ≥ 1} (2m-1) q^{2m-1} / (1 - q^{2m-1}) = ∏_{m ≥ 1} (1 - q^m)^m ∑_{m ≥ 1} A_o(m) q^m`.
