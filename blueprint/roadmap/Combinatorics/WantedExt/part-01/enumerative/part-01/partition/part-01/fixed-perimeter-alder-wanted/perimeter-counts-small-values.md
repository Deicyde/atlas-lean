# Perimeter Counts small values

Small values at `d = a = 1`, perimeter `3`: `h = f = ℓ = 2`; `h_1^(1)(2, 2) = 1`
(`2 + 1`), `f_1^(1)(3, 1) = 1` (`3`), `ℓ_1^(1)(1, 3) = 1` (`1 + 1 + 1`).
