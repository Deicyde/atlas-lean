# Frobenius Partition Rep Count four ten mul add one mod five

`φ₄(10n + 1) ≡ k + 1 (mod 5)` if `n = k(3k + 1)` for an integer `k`, and
`φ₄(10n + 1) ≡ 0 (mod 5)` otherwise.
