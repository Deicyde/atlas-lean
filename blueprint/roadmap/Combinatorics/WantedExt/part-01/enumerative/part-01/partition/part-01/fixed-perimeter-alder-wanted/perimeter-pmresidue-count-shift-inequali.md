# Perimeter PMResidue Count shift inequalities

Proposition 1.6, `ℓ` part: for positive `d, n, a` with `a < (d + 3)/2`,
`ℓ_d^(a)(n) ≤ ℓ_d^(a)(n + 1)` and `ℓ_{d+1}^(a)(n) ≤ ℓ_d^(a)(n)`.
