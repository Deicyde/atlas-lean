# Frobenius Partition Rep Count four four mul add one mod two

`φ₄(4n + 1)` is odd exactly when `n = 5k(3k ± 1)/2` for some integer `k`; the two signs
are covered by `2n = 5k(3k + 1)` with `k ∈ ℤ` (replace `k` by `-k`).
