# Max Rook Partition Count three gen Fun

Generating function of `R_3(n)`, denominator cleared:
`(1-q)³(1+q+q²) ∑ R_3(n) qⁿ = q⁶(1+2q+q²+2q³-q⁴-q⁶-q⁷+q⁸)`.
