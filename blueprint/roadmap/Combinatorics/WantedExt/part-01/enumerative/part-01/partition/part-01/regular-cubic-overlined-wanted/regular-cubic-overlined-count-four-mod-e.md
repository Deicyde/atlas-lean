# Regular Cubic Overlined Count four mod eight fifty Six twenty Four

For all `n ≥ 0`: `a_4(4n + 3) ≡ 0 (mod 8)`, `a_4(28n + 4j + 3) ≡ 0 (mod 56)` for
`j = 1, …, 6`, and `a_4(36n + 19) ≡ 0 (mod 24)`.
