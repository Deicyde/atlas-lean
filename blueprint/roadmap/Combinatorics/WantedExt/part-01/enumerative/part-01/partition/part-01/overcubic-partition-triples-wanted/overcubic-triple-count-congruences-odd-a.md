# Overcubic Triple Count congruences odd args

For all `n, α ≥ 0`: `bt(8n+7) ≡ 0 (mod 32)`, `bt(8n+5) ≡ 0 (mod 8)`,
`bt(72n+33) ≡ 0 (mod 8)`, `bt(72n+57) ≡ 0 (mod 8)`, and
`bt(8·9^{α+2} n + 33·9^{α+1}) ≡ 0 (mod 8)`.
