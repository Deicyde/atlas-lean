# Overcubic Triple Count twenty Four mul add one

For all `n ≥ 0`, `bt(24n+1) ≡ 2 [q^n] f_1 (mod 4)`, i.e.
`∑ bt(24n+1) q^n ≡ 2 f_1 (mod 4)`. This is the `α = 0` case of the paper's statement.
