# K Arndt Composition total gf neg

For `k < 0`, written `k = -k'` with `k' ≥ 1`, the number `a_k(n)` of `k`-Arndt compositions
has generating function `A_k(x) = (1 - x²)/(1 - x - 2x² + x^{2-k})`.
