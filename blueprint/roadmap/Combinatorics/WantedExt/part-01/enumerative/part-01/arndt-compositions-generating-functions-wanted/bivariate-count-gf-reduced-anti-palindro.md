# Bivariate Count GF reduced Anti Palindromic

The generating function of reduced anti-palindromic compositions by weight and number of
parts is `Bp(x, y) = (1 - x - x² + x³ + xy - x³y)/(1 - x - x² + x³ - x³y²)`.
