# Arndt Composition Count holonomic recurrence

Holonomic recurrence: for all `n, m ≥ 0`,
`(m - n - 2 + ⌊m/2⌋) a(n+2, m) + (m - ⌊m/2⌋) a(n+1, m) + n a(n, m) = 0`.
