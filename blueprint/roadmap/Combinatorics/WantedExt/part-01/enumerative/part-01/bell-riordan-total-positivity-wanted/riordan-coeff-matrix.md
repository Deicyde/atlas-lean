# Riordan Coeff Matrix

The coefficient matrix `J(Z(x), A(x))` of a Riordan array: column `0` is `z_0, z_1, …`, and
the remaining columns form the lower Toeplitz matrix of `a`, so row `n` reads
`z_n, a_n, a_{n-1}, …, a_0, 0, …`.
