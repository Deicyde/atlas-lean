# Two Pattern Avoider Count

`A_n(τ, ρ)`: the number of permutations of length `n` avoiding both classical
patterns `τ` and `ρ` (containment is
`MathlibExt.Combinatorics.Enumerative.OddFibonacciWanted.HasPattern`).
