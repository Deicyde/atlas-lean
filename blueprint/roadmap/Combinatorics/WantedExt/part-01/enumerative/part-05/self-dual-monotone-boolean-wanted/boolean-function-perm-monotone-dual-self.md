# Lemma 5

**Lemma 5.** For every `f : Bⁿ → B` and permutation `π`: `f ∘ π` is monotone if `f` is;
if `f ∈ D_n` then `f* ∘ π = (f ∘ π)*`; if `f ∈ Λ_n` then every `g ∈ [f]` is in `Λ_n`.
