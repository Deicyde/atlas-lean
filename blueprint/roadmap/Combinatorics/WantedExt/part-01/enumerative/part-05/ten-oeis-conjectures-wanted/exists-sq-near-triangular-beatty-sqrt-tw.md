# Exists sq near triangular beatty sqrt two

With `a_n = ⌊n√2⌋` (A001951) and `T_a = a(a+1)/2`, some square `k^2`, `k ∈ ℤ`, satisfies
`|T_{a_n} - k^2| ≤ ⌊a_n / 2⌋`; that is, `min_{k ∈ ℤ} |T_{a_n} - k^2| ≤ ⌊a_n / 2⌋`.
