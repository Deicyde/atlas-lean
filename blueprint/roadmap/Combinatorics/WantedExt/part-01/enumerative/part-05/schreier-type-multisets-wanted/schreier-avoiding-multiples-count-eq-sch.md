# Schreier Avoiding Multiples Count eq schreier Parent D

Proposition 3: for `u ≥ 2`, `(|D_{u,n}|)` is a periodic subsequence of `(d_{u,n})`:
`|D_{u,n}| = d_{u,un-(u-1)}` for all `n ≥ 1`.
