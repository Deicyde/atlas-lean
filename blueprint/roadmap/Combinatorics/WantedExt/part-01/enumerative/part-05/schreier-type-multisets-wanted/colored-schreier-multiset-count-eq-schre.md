# Colored Schreier Multiset Count eq schreier Parent B

Lemma 1: `(|B^{(s)}_{p,n}|)` is a periodic subsequence of `(b^{(s)}_{p,n})`:
`|B^{(s)}_{p,n}| = b^{(s)}_{p,ns-s+1}` for positive `s, p, n`.
