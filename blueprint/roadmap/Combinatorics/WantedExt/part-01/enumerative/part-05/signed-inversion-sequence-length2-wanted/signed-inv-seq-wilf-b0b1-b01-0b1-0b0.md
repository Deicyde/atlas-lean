# Theorem 3, class C21

**Theorem 3, class C21.** `{0̄1̄, 0̄1, 01̄, 00̄}` ∼ `{0̄0̄, 0̄1, 01̄, 00̄}`. The printed
generating function `1/(1 - x)² + ∑_{j ≥ 0} j! xʲ` is false (its constant term is `2`, while
`|Ī_0(B)| = 1`) and is omitted.
