# Theorem 3, class C2

**Theorem 3, class C2.** `{0̄0̄, 0̄0, 0̄1, 01}` ∼ `{0̄0̄, 0̄1, 00̄, 01}`, and `F(x) = 1 + 2 ∑_{k
≥ 1} xᵏ / ∏_{i=1}^{k} (1 - ix)`; each coefficient `[xⁿ]` is compared with the partial sum
through index `n`, which carries all of `[xⁿ]`.
