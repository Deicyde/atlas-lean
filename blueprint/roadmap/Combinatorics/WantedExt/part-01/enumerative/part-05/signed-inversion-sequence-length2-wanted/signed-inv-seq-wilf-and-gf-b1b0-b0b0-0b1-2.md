# Theorem 3, class C41

**Theorem 3, class C41.** `{1̄0̄, 0̄0̄, 01̄, 00}` ∼ `{1̄0, 0̄0̄, 0̄0, 01}`, and `F(x) = 1/(1 -
x) + 1/(1 - x) ∑_{j ≥ 1} xʲ / (1 - (j + 1)x)`; each coefficient `[xⁿ]` is compared with the
partial sum through index `n`, which carries all of `[xⁿ]`.
