# Smallest cycle moment asymp

Theorem 1, second part: for integers `ℓ ≥ 2` there is `ε > 0` with
`E(X_n^ℓ) = ℓ n^{ℓ-1} (∫_1^∞ ω(x) / x^ℓ dx) (1 + O(n^{-ε}))`.
