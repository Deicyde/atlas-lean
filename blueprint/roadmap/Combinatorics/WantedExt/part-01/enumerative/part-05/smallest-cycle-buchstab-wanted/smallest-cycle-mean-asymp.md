# Smallest cycle mean asymp

Theorem 1, first part: `E(X_n) = e^{-γ} log n (1 + O(h(n)/log n))` for some
`h(n) = o(log n)`, stated in the equivalent form `E(X_n) / (e^{-γ} log n) → 1`.
