# Fine Number eq half neg one pow add sum

Corollary 3: for `n ≥ 2`,
`f_n = (1/2)(-1)^n + (1/2) ∑_{k=0}^{n} (-1)^{n-k} (1 - n/(k+1)) C(n+k, k)`.
