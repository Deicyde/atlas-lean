# Harmonic eq sum inv choose add sum sabar Number

Theorem 2: for `n ≥ 2`,
`H_n = C_n + ∑_{i=0}^{n-2} (-1)^{n-i} s(n-1, i) / (n - i)`, where
`C_n = (1/n) ∑_{i=0}^{n-1} C(n-1, i)⁻¹`.
