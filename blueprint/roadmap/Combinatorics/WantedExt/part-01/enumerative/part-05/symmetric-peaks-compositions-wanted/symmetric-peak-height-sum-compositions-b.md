# Symmetric Peak Height Sum compositions bivariate gen Fun

Bivariate generating function of `hsp(n, k)` (`k` = number of parts):
`∑ hsp(n, k) xⁿ yᵏ = y³ x⁴ / ((1 - x³)(1 - x - yx)²)`, stated in `ℤ[y]⟦x⟧` after
clearing denominators.
