# Symmetric Peak Height Sum compositions closed form

Closed form of `hsp(n)`, with `ω± = 1 ± i√3`:
`hsp(n) = 2^{n-1} (7n - 24) / 49 + (-33 - 15i√3)(-2)ⁿ / (441 ω₊^{n+1})
+ (-33 + 15i√3)(-2)ⁿ / (441 ω₋^{n+1}) + 1/3` for all `n ≥ 0` (`2^{n-1}` written `2ⁿ / 2`).
