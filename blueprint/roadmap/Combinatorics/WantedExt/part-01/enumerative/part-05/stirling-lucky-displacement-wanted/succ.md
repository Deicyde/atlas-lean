# Succ

If `S` is `n`-admissible (`n ≥ 1`), then `S` and `S ∪ {2n + 1}` are both
`(n + 1)`-admissible. (`n ≥ 1` is added: the empty set is `0`-admissible but not
`1`-admissible.)
