# The Vandermonde matrix $V(n)$

**The Vandermonde matrix $V(n)$.** For $n \in \mathbb{N}$, $V(n)$ is the $n \times n$ rational
matrix whose entry in row $i$ and column $j$ ($1 \le i, j \le n$) is $V_{i,j} = j^{i-1}$.
