# Stirling Second succ sub eq sum

Corollary 4: for `i, j ≥ 1`,
`S(i + 1, j) - S(i, j) = ∑_{k=1}^{j-1} (-1)^{j-k+1} (k + 1)^{i-1} / ((k - 1)! (j - k - 1)!)`.
