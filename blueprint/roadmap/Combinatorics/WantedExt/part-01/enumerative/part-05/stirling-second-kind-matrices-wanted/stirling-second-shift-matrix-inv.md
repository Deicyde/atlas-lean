# Stirling Second Shift Matrix inv

Theorem 3: `S^[m](n)⁻¹ = Ṽ(n)^m s(n)`. The paper takes `m ≥ 1`; the case
`m = 0` (`S(n)⁻¹ = s(n)`) also holds and is included.
