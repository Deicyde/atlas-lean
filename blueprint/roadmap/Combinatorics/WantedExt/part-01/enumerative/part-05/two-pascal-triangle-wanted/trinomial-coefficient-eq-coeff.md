# Theorem 3

**Theorem 3.** `binom(n, k)_2 = [t^{2n}] (1 - t + t^2)^n (1 - t)⁻¹ (t / (1 - t))^k`,
for `k ∈ ℕ` (the record allows `k ∈ ℤ`; negative `k` is omitted).
