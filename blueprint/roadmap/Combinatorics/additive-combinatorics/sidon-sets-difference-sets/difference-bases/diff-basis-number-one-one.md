# The value $\eta_1(1) = 2$

**The value $\eta_1(1) = 2$.** Let $\eta_1(1)$ be the least size of a finite set
$A \subseteq \mathbb{Z}$ containing elements $a, a'$ with $a - a' = 1$. Then $\eta_1(1) = 2$: such a
set needs two elements, and $\{0, 1\}$ is one.
