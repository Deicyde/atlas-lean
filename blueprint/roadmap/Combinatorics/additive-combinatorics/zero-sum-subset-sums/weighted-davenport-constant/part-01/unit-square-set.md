# Squares of units modulo n

**Squares of units modulo n.** For a natural number $n$, $U(n)^2$ is the set of elements of
$\mathbb{Z}/n\mathbb{Z}$ of the form $u^2$ with $u$ a unit of $\mathbb{Z}/n\mathbb{Z}$.
