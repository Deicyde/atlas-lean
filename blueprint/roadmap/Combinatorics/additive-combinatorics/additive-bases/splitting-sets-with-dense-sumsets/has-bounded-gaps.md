# Sets with bounded gaps

**Sets with bounded gaps.** A set $S \subseteq \mathbb{N}$ has bounded gaps (is syndetic) if
there is a natural number $g$ such that for every natural number $n$ some $s \in S$ satisfies
$n \le s < n + g$.
