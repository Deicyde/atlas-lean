# Bollobás's set-pairs inequality

Bollobás's set-pairs inequality (1965) bounds a family of pairs of finite sets $(A_i, B_i)$ with $A_i \cap B_i = \emptyset$ and $A_i \cap B_j \neq \emptyset$ for $i \neq j$: $\sum_i \binom{|A_i| + |B_i|}{|A_i|}^{-1} \le 1$.
