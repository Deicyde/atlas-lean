# Odd cycle lengths

**Odd cycle lengths.** For a simple graph $G$, the set of odd cycle lengths of $G$ is the set
of those cycle lengths of $G$ that are odd, that is, the odd natural numbers $m$ such that $G$
contains a cycle of length $m$.
