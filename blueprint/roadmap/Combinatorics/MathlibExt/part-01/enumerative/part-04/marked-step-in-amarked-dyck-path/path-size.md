# Size of a marked Dyck path

**Size of a marked Dyck path.** The size of a marked Dyck path $P$ is $N^*(P) + E(P)$,
where $N^*(P)$ is the number of marked vertical steps of $P$ and $E(P)$ the number of its
horizontal steps.
