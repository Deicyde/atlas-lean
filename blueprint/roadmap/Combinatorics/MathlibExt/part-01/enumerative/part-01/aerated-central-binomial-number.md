# Aerated central binomial numbers

**Aerated central binomial numbers.** For a natural number $n$, the $n$-th aerated central
binomial number is $\binom{n}{n/2}$ if $n$ is even and $0$ if $n$ is odd. The sequence begins
$1, 0, 2, 0, 6, 0, 20, \dots$.
