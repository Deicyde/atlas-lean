# Index-weighted partial sum

**Index-weighted partial sum.** For $n \in \mathbb{N}$ and a function
$f \colon \mathbb{N} \to \mathbb{N}$, this is the sum $\sum_{i=0}^{n-1} (i + 1)\,f(i)$.
