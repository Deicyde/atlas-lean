# Sum of the first n values of a sequence

**Sum of the first n values of a sequence.** For a natural number $n$ and a sequence
$f \colon \mathbb{N} \to \mathbb{N}$, this is the natural number $\sum_{i=0}^{n-1} f(i)$.
