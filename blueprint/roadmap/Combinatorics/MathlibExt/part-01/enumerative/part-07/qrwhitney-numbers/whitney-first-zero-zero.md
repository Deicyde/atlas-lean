# Initial value of the first-kind (q, r)-Whitney numbers

**Initial value of the first-kind (q, r)-Whitney numbers.** For all complex numbers
$m, r, q$ with $q \ne 0$, the (q, r)-Whitney number of the first kind satisfies
$w_{m,r,q}(0, 0) = 1$.
