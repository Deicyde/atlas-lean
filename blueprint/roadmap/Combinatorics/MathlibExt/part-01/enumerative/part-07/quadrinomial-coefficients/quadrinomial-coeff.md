# Quadrinomial sequence A005725

**Quadrinomial sequence A005725.** For a natural number $n$, the quadrinomial number is
$Q(n) = \sum_{k=0}^{n} \binom{n}{k} \binom{n}{2k}$. This is OEIS sequence A005725.
