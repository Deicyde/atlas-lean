# Set partition

**Set partition.** A set partition of $\{0, \dots, n-1\}$ is a finite collection of nonempty,
pairwise disjoint subsets of $\{0, \dots, n-1\}$, called blocks, whose union is
$\{0, \dots, n-1\}$.
