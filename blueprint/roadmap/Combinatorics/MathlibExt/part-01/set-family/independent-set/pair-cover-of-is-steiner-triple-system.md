# Pairs in a Steiner triple system

**Pairs in a Steiner triple system.** If $H$ is a Steiner triple system on a vertex type
$V$, then for all vertices $u \ne v$ of $V$ there is exactly one edge $e$ of $H$ with
$u \in e$ and $v \in e$.
