# Nonintersecting Path Weight Sum

For k∈ℤ_{≥ 0} write [k]={1,…,k}, so that [0]=∅. Let n∈ℤ_{≥ 0}. If n≥ 1, let p=[p₁,…,pₙ] and
q=[q₁,…,qₙ] be tuples of points of ℤ_{≥ 0}². If n=0, each is the empty tuple.
