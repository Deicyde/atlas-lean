# Cycle codes

**Cycle codes.** For natural numbers $q$ and $n$, a cycle code of length $n$ modulo $q$ is a
finite set of words of length $n$ over $\mathbb{Z}/q\mathbb{Z}$ that is an independent code for
the $q$-cycle.
