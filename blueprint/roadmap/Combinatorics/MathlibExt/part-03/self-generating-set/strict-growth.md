# Strict growth of a set of generators

**Strict growth of a set of generators.** A finite set $F$ of functions
$\mathbb{N} \to \mathbb{N}$ has strict growth when $x < f(x)$ for every $f \in F$ and every
$x \in \mathbb{N}$.
