# The pair partition of a matching

For a [noncrossing perfect matching](is-ncmatching.md) $f$ of $\{0, \dots, n-1\}$, the partition of
`Fin n` whose blocks are the arcs $\{i, f(i)\}$. It is built as the partition into classes of the
equivalence relation "$y = x$ or $y = f(x)$", which is an equivalence relation because $f$ is an
involution. It is a noncrossing pair partition.
