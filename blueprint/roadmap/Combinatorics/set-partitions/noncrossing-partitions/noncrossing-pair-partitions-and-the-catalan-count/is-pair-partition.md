# Pair partition

A set partition $P$ of $\{0, \dots, n-1\}$ (a `Finpartition` of `Fin n`) is a *pair partition* if
every block of $P$ has exactly two elements. A pair partition exists only when $n$ is even, and
for $n = 2k$ the pair partitions are the perfect matchings of $2k$ points; the noncrossing ones are
counted by the Catalan number $C_k$.

## Sources

- G. W. Anderson, A. Guionnet and O. Zeitouni, *An Introduction to Random Matrices*, Cambridge
  University Press, 2010, §2.1.3, the definition before Proposition 2.1.11 ("a pair partition of
  $K_k$ [is] a partition all of whose parts are two-element sets").
