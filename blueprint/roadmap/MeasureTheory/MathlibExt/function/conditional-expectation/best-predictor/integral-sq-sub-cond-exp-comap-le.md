# The regression function is the Bayes-optimal regressor

**The regression function is the Bayes-optimal regressor**: for features `X` and a
square-integrable response `Y`, the conditional mean `E[Y | X]` (conditional expectation given
the σ-algebra generated by `X`) has expected squared error at most that of every
square-integrable prediction `h ∘ X`.
