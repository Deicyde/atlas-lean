# Bounded convergence theorem

**Bounded convergence theorem.** If `F n` is uniformly bounded
(`‖F n a‖ ≤ C` almost everywhere) on a finite measure space and `F n → f` in
measure (i.e. in probability), then `∫ F n dμ → ∫ f dμ`.
