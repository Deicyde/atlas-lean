# Bounded convergence theorem, `L¹` form

**Bounded convergence theorem, `L¹` form.** If `F n` is uniformly bounded
(`‖F n a‖ ≤ C` almost everywhere) on a finite measure space and `F n → f` in
measure, then `∫ ‖F n - f‖ → 0`.
