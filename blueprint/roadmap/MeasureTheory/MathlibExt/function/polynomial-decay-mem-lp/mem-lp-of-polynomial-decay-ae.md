# Polynomial decay implies `L^p` membership

**Polynomial decay implies `L^p` membership.** If `f : ℝ → E` is a.e. strongly
measurable and `‖f x‖ ≤ C * (1 + |x|) ^ (-q)` almost everywhere, where
`C ≥ 0` and `q > 1`, then `f ∈ L^p (ℝ)` for every `1 ≤ p ≤ ∞`.
