# Scheffé's lemma

**Scheffé's lemma.** If `f n → g` almost everywhere and
`‖f n‖₁ → ‖g‖₁`, then `f n → g` in `L¹`, i.e.
`eLpNorm (f n - g) 1 μ → 0`.
