# Exists measure extension

Existence part of the Carathéodory extension theorem: any `σ`-subadditive
`AddContent` `μ₀` on a set algebra `𝒜` extends to a measure on the generated
`σ`-algebra `σ(𝒜)`, agreeing with `μ₀` on `𝒜`.
