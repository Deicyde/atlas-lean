# Atomless measure

**Atomless measure.** A measure $\mu$ on a measurable space is atomless when every
measurable set $s$ with $\mu(s) > 0$ contains a measurable subset $t \subseteq s$ with
$0 < \mu(t) < \mu(s)$.
