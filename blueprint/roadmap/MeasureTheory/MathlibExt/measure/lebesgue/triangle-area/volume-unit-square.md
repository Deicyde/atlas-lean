# Area of the unit square

**Area of the unit square.** The closed unit square
$\{x \in \mathbb{R}^2 : 0 \le x_1 \le 1 \text{ and } 0 \le x_2 \le 1\}$ in the Euclidean plane has
Lebesgue measure (area) $1$.
