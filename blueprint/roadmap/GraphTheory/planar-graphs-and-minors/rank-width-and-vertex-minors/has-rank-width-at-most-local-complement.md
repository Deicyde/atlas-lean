# Local complementation preserves rank-width

For every finite graph $G$, vertex $v$ and natural number $k$, the graph $G * v$ has rank-width at most
$k$ if and only if $G$ does. Indeed every rank-decomposition has the same width for both graphs,
since their cut-rank functions agree.
