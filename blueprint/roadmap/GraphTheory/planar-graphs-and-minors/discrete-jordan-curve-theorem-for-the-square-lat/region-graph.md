# Rotated region graph of a lattice subgraph

The square lattice with the edge `{ρa, ρb}` removed for every edge `{a, b}` of `G`, where
`ρ(x, y) = (-y, x)` is the quarter-turn rotation of `ℤ²` (see
[Quarter-turn rotation of unordered site pairs](../self-duality-of-the-square-lattice/cross-edge.md)).
Since this rotation is global, the result is not the faithful dual complement; see
[Face-region graph of a square-lattice subgraph](../whitney-s-cut-cycle-duality-on-the-square-lattic/whb-face-region.md)
for the version built from the
[Primal edge shared by adjacent faces](shared-primal-edge.md).
