# Bramble

A bramble in a graph $G$ is a set $\mathcal{B}$ of vertex sets of $G$ such that each member induces
a connected subgraph (in particular it is nonempty) and any two members touch.

A typical example is the set of $k^2$ crosses (unions of a row and a column) of the $k \times k$
grid, a bramble of order $k$.
