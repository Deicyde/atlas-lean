# Erdős–Stone theorem

The Erdős–Stone theorem: $\varepsilon n^2$ edges above the Turán number force a complete $(r+1)$-partite graph with parts of any fixed size, and its corollary $\pi(H) = 1 - 1/(\chi(H) - 1)$ for the Turán density.
