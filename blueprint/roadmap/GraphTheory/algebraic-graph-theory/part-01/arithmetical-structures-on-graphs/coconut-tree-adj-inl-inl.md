# Adjacent path vertices of a coconut tree

**Adjacent path vertices of a coconut tree.** Let the coconut tree $CT(p, s)$ have path
vertices $v_1, \dots, v_p$. Two path vertices $v_a$ and $v_b$ are adjacent if and only if
$|a - b| = 1$.
