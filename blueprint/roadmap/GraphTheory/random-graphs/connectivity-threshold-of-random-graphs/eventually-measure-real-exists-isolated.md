# Isolated vertices are rare beyond `e^{-c}`

If `pₙ = (log n + c)/n` for all large `n`, then
for every `δ > 0`, eventually `P(G(n, pₙ) has an isolated vertex) ≤ e^{-c} + δ` (first moment
method; Frieze and Karoński, *Introduction to Random Graphs*, 2016, proof of Theorem 4.1). The
exact limit `1 - e^{-e^{-c}}` is the Poisson statement
`WantedExt.Combinatorics.SimpleGraph.RandomGraphConnectivityWanted`.
